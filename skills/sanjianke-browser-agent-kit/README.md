# 三剪客 · 浏览器自动化 Skill

让 AI Agent 真正操作浏览器：打开页面、点按、填表、翻页、抓取、截图、下载，并保持稳定可控

---

## 前置条件

- Node.js 18+ 或 Python 3.9+（取决于你走哪条路线）
- 至少安装一个浏览器内核（推荐 Chromium；首次安装需下载上百 MB）
- 能访问目标站点；内网站点需保证运行环境可达
- 涉及登录的任务：账号来源（环境变量 / 密钥管理）+ 一个可写的登录态存档目录
- 目标站点已获授权，且你的操作符合站点条款与当地法规

---

## 使用

1. 先读 `SKILL.md` 的「快速开始」，用路径一（最小闭环）把链路验通：退出码 0、截图非空白、取到真实标题。
2. 照路径二把定位写成「候选档位 + 降级链」骨架，每档校验唯一命中，等待用语义信号而不是硬睡。
3. 需要模型自己看页面决策时走路径三：先把页面压成语义快照（元素编号 + 角色 + 名称 + 可用态），模型只回编号，编号每轮重算。
4. 涉及登录、截图、下载的流程按路径四处理：登录态存档并复用、先挂下载监听再触发、`saveAs` 及时落盘。
5. 遇到页面改版、元素找不到、点击无效，按 `references/locator-and-wait.md` 重写定位，按 `references/safety-and-troubleshooting.md` 逐条排查。
6. 上线前过一遍 `SKILL.md` 的自检清单，尤其是授权、凭证、并发与失败上报四项。

## 安全

- 不内嵌任何密钥、Token、Cookie；账号密码一律走环境变量或密钥管理。
- 登录态存档（`storageState` / 用户数据目录）按凭证对待：加入忽略规则、最小文件权限、到期即删。
- **不提供任何验证码识别或绕过手段**（图形码、滑块、点选、短信验证码一律不做）。
- **不做反检测对抗**：不涉及指纹伪装、特征篡改、代理池轮换规避风控。
- **不做限流规避**：不通过切换 IP / 账号 / UA 绕开站点频控；触发限流就退避、降速、缩量。
- 只操作已获授权的站点；抓取内容涉及个人信息与敏感字段时按最小必要原则采集并脱敏。
- 脚本遇到登录墙、验证码、频控、403 时应**停止并上报**，而不是加大重试力度。
