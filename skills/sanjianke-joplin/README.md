# 三剪客 · 开源笔记与知识同步 Skill

把笔记以本地 Markdown 形式掌握在自己手里，并在多设备之间同步的落地指引。

---

## 前置条件

- 桌面端 / 移动端：从上游发布页取对应平台的安装包即可，不需要额外运行时。
- 终端版（本 Skill 主要覆盖的部分）：需要 Node 运行环境与 npm，上游文档给出的 Node 下限是 12+。
- 同步功能需要一个可用的存储位置，二选一：
  - 本地或网络文件目录；
  - 一个 WebDAV / Nextcloud 地址，或 S3 兼容对象存储，或相应网盘的账号。
- 需要能在应用里写入配置（同步目标与凭证都写在配置项里）。

---

## 使用

先判断用户要的是哪一种形态，再给命令——三端命令不通用。

1. **要「笔记留在自己机器上」**：桌面端 / 移动端安装 + 配同步目标。核心动作是设置 `sync.target`，再补齐该目标需要的 `sync.N.*` 参数，最后同步一次验证。
2. **要「命令行批量处理」**：走终端版。先用 `joplin help all` 拿到当前版本的真实命令清单，再按下面的顺序做事：
   ```bash
   joplin mkbook "项目资料"
   joplin use "项目资料"
   joplin mknote "会议纪要 0312"
   joplin ls -l
   ```
3. **要「搬家」**：从源工具导出成 `.enex`，然后 `joplin import <path> --format enex`，一个文件一个笔记本。
4. **要「归档或喂给别的工具」**：`joplin export <path> --format md`，也可以只导某个笔记本。
5. **要「无人值守同步」**：把 `joplin sync` 丢进 crontab。

细节命令、参数含义与踩坑应对写在 `SKILL.md` 的「常用操作」与「常见坑」两节。

## 依赖

- 终端版：Node + npm；安装后二进制默认在 `~/.joplin-bin`。
- 桌面端 / 移动端：平台原生安装包，无 Node 依赖。
- 同步：一个存储位置（本地目录 / WebDAV / Nextcloud / S3 / 网盘账号）。
- 端到端加密为可选能力，启用后主密码由使用者自己保管。
- 外部编辑器集成（`config editor`）需要本机已安装对应编辑器。

---

## 安全

- 不内嵌任何密钥。
- 同步凭证由使用者在自己的应用配置里填写，本包不收集、不转发。
- 终端版的 `config --export` 会把包含敏感项在内的配置以 JSON 输出，涉及凭证时不要贴到公开渠道或日志里。
- 启用端到端加密后，主密码丢失即无法恢复内容，需要使用者自行做好备份与保管。
- 终端版附带的本地 API 服务属于实验性能力，对外暴露前请自行评估风险，并为其单独使用一个 profile。
- 同步目标路径不要随意改动；上游明确提示过改动位置前必须先完整复制已有内容，否则同步可能把本地数据当作待清理项处理。
