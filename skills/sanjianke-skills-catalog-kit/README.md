# 三剪客 · 技能生态实战 Skill

在公开技能目录里读懂、挑对、装稳、自己写出能被触发的技能

---

## 前置条件

- **一个能加载技能目录的 Agent 客户端。** 没有它这套方法论仍然可以读，但触发相关的部分验证不了。
- **能读写 Markdown 文件。** 纯文本即可，不需要工具链。
- **（推荐）本地已下载的技能目录副本。** 审查一项就得能看见 `SKILL.md` 和 `scripts/` 的真实内容，只看网页上的介绍等于没审。
- **（推荐）一个干净的一次性环境。** 要试未筛选层的技能时，别在主力账号下试。

不需要网络、API Key、数据库、Docker 或任何付费服务——本 Skill 自身全程离线。

---

## 使用

本 Skill 处理四件事，按你当前卡在哪一步选入口：

| 你要做的 | 从哪开始 |
|---|---|
| 打开一个陌生技能目录，不知道从哪看起 | `references/reading-a-catalog.md`（分层读法 + 包内文件约定） |
| 手上有个候选技能，判断值不值得装 | `references/choosing-skills.md`（六维打分卡，低于 70 分不装） |
| 想自己写一个技能 | `references/writing-a-triggerable-skill.md`（六步流程 + description 写法） |
| 技能不触发 / 乱触发 / 两个抢触发 | `references/trigger-troubleshooting.md`（三步定位法 + 失灵速查表） |
| 装别人的技能，装前要审 | `references/security-review.md`（五面清单 + 10 条红线） |

**建议路径**：先花 3 分钟认分层，再用打分卡筛掉大部分候选，**一次只装一个**并验证触发；自己写技能时，动笔前先写下三句你真实会说的话。

主体流程、权限说明与自检清单一律在 `SKILL.md`。

## 依赖

**本 Skill 自身零依赖**：全部是 Markdown，不含脚本、不含可执行文件。

它**讨论**到的外部对象（客户端技能目录、校验命令、版本控制）都是你本地按需使用的工具，本 Skill 不安装、不调用、不绑定任何一项。

---

## 安全

- 不内嵌任何密钥、Token、Cookie 或账号密码
- 不发起任何网络请求；要读远程仓库时由你或主 Agent 自行取回
- 不执行第三方技能里的脚本——安全审查是**静态阅读**，不运行、不回连
- 不读取工作区之外的文件；审查时只读你已下载的技能目录
- 生成文件时不覆盖已有文件，目标存在时先停下给你看差异
- 示例一律使用占位符：正文与参考文件中不含真实密钥、内网地址、客户名

**能力边界**：本 Skill 提供的是**人工审读清单**，不是沙箱、不是静态扫描器、不是运行时拦截。它能帮你发现明显越界，发现不了刻意混淆的恶意代码。真正的隔离靠你的沙箱与权限配置。
