# 应用矩阵与选型

api.a7w.cn 在架 **21 个生成应用**。本文按「传什么进 → 拿什么出」组织，
帮你在一分钟内决定该调哪个。接口参数用 `python3 scripts/a7w.py schema <应用代号>` 现查。

---

## 一、按输入形态选（最快的判断方式）

**先说清你手上有什么，再选应用。** 名字像不代表输入一样。

| 你手上是 | 用哪个 | 接口 |
|---|---|---|
| 一句画面描述 | `nano_banana`（要图）、`full_video` / `happy_horse` / `wan`（要视频） | `/submit`、`/create` |
| 一张图 + 音频 | `image_human`（全驱动，头部表情身体一起动） | `/submit` |
| 一张图 + 文案 | `pic_lipsync`（只要嘴动） | `/submit` |
| 一段视频 + 音频 | `lipsync`（换口型对齐新音轨） | `/submit` |
| 一段视频 + 一段音频（改音色） | `seedsvc` | `/submit` |
| 一张参考图 + 一段动作视频 | `action_transfer`（把 A 的动作搬到 B 身上） | `/submit` |
| 一段视频 + 目标形象 | `person_replacement`（换人） | `/submit` |
| 模特图 + 服装图 | `dressing_diffusion`（换装） | `/submit` |
| 文本 | `voice_tts/tts`（短）、`tts_async`（长）、`music_generation/create`（歌） | 见接口表 |
| 关键词 | `music_search/search`（找现成曲子） | `/search` |
| 一段视频（要补音效） | `mmaudio` | `/submit` |
| 一段糊视频 | `flashvsr`（超分） | `/submit` |
| 一堆素材 + 模板 | `smart_clip`（5 个接口，含模板列表与混剪） | 见接口表 |
| 公网文档 | `file_qa`（问答 / 解析） | `/chat`、`/parse` |

> **口诀：能直接「看」的走视觉模型，需要先「解析」的走文档接口；
> 有真人连续动作才用视频生成，静态对话用「图 + 口型」。**

## 二、五个视频应用打分表

| 你的约束 | 选它 | 输入形态 | 说明 |
|---|---|---|---|
| 不知道选谁 | `full_video` | 文 / 首尾帧 / 多模态参考 | **通用首选**；`duration` 只吃 4～15 秒整数 |
| 要声画一起出 | `happy_horse` | 文 / 1～9 张图 | 统一多模态建模，对白与画面一阶段出 |
| 要分辨率分档 + 素材管理 | `seedance` | 文 + 图 + 视频 + 音频任意组合 | 480p / 720p / 1080p；另带 5 个素材管理接口 |
| 要多参考混着用 | `wan` | 文 / 角色参考 / 视频编辑 | 版本通过 `model` 参数切换 |
| 只要快 | `grok_video` | 文 | 有快速与标准两档 |

### 决策树

```
要声音画面一起出            → happy_horse
要多种参考素材（图/音/视频）混用 → wan
要按分辨率分档、要管理素材   → seedance
只要快                      → grok_video
静态对话戏，不需要运镜       → image_human / lipsync（别用视频生成）
都不确定                    → full_video
```

## 三、数字人三个应用的差别（最容易选错）

| 应用 | 输入 | 输出 | 什么时候用 |
|---|---|---|---|
| `pic_lipsync` | 一张人物图 + 音频或文案 | 口播视频 | 只要**嘴动**即可 |
| `image_human` | 图片 + 参考音频 | 全驱动数字人视频 | 要**头、表情、身体一起动** |
| `lipsync` | 视频 + 音频 | 对口型后的视频 | 已有真人视频，**换口型**对齐新音轨 |

```
手上是照片  → pic_lipsync（只要嘴动）或 image_human（要自然全身动）
手上是视频  → lipsync（换口型）
```

`image_human` 四档价差很大：`fast` 1.5 点/秒、`standard` 2、`2k` 4、`4k` 8。
**先算钱再选档** —— `fast` 到 `4k` 单价差 5.3 倍。

## 四、语音与音乐怎么分

### `voice_tts` 内部

```
文本 ≤ 500 字            → tts（同步，直接返回音频 URL）
文本很长（≤ 10000 字）    → tts_async（异步，回调或轮询）
要边说边出（流式）        → tts_live
要自己的声音             → 先 clone_voice，拿返回的音色 ID 去合成
不知道有哪些音色          → list_voices（免费）
要转写已有音频            → stt
```

### `music_generation` / `music_search` / `mmaudio` / `seedsvc`

| 需求 | 用哪个 |
|---|---|
| 生成原创配乐（纯伴奏） | `music_generation/create`，`instrumental: true` |
| 还没词 | `music_generation/lyrics` |
| 想让某个声音风格唱 | `music_generation/persona` |
| 歌词卡点字幕 | `music_generation/timing`（免费） |
| 导出交付 | `music_generation/midi` / `wav` / `mp4` |
| 找现成曲子 | `music_search/search` |
| 给视频配环境音 / 音效 | `mmaudio/submit` |
| 改音色 / AI 翻唱 | `seedsvc/submit` |

## 五、剪辑与特效

| 需求 | 应用 | 关键点 |
|---|---|---|
| 模板化混剪 | `smart_clip` | 顺序：先 `template` 拿模板 ID → `template_detail` 看要传什么 → 再调对应混剪接口 |
| 真人口播混剪 | `smart_clip/realman_broadcast` | 720p 0.2 点/秒、1080p 0.3 点/秒 |
| 素材混剪 | `smart_clip/broadcast_mixcut` | 同上 |
| 新闻体视频 | `smart_clip/news_mixcut` | 同上 |
| 动作迁移 | `action_transfer` | 分 fast / standard / max 三档（1 / 2 / 3 点每秒） |
| 人物替换 | `person_replacement` | 同动作迁移分档 |
| 换装 | `dressing_diffusion` | 支持上衣 / 下装 / 全身 |
| 糊视频救成高清 | `flashvsr` | 只吃公网 URL |

## 六、工作台的「核心六件套」

真正每天在用的就这六个，先把它们的参数背熟，其余按需插拔：

| 应用 | 干什么 | 最常用的参数 |
|---|---|---|
| `nano_banana` | 出图、锁角色长相 | `action=edit` + `image_urls` |
| `full_video` | 出片 | `content` + `duration`（4～15）+ `ratio` |
| `voice_tts` | 音色克隆 + 台词合成 | `reference_id` + `text` |
| `lipsync` | 换口型 | `video_url` + `audio_url` |
| `music_generation` | 配乐 | `instrumental: true` + `prompt` |
| `flashvsr` | 成片超分 | `input_url` |

## 七、现查最新情况

```bash
python3 scripts/a7w.py apps                  # 列全部应用（含接口数）
python3 scripts/a7w.py schema nano_banana    # 看某应用的接口与参数
python3 scripts/a7w.py schema voice_tts
python3 scripts/a7w.py points                # 看最近的用量
```

> 应用与接口会变。**动手前先跑一遍 `schema`，以实际返回为准**，
> 不要照抄任何文档（包括本文）里的参数名。
