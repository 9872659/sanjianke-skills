# 三剪客 · A股行情与财务数据接口 Skill

把「A股/期货/基金/宏观数据从哪来」这件事收敛成一个 token 加一次接口调用：安装、鉴权、日线与财务数据取法、积分与频次约束、字段格式坑

---

## 前置条件

- **Python 3 环境**。需要一个可用的 Python 3 解释器，并建议使用独立虚拟环境（`venv` 或 `conda`）。
- **平台账号与 token**。数据来自 tushare 平台，需要先注册账号，再到个人中心「账号与TOKEN」复制 token；token 是调取数据的唯一凭证。
- **积分够用**。平台接口按积分分级授权，并在频次与单次返回行数上分档；调用前先确认目标接口在当前积分档位下可用。
- **pandas**。安装 tushare 时会一并装好，若要手工管理依赖请自行确认版本兼容。
- **网络出口**。运行环境需要能访问数据平台；公司内网或代理环境请先确认放行。

---

## 使用

本 Skill 面向「拿到数据并落盘」这一类任务，典型用法：

1. 读 `SKILL.md` 的「什么时候用 / 不用」，先判断该不该调这个工具——尤其是有实时推送、逐笔成交、交易下单需求时，不要用它。
2. 按「安装」一节把包装进独立环境，并用 `python -c "import tushare as ts; print(ts.__version__)"` 确认可导入。
3. 按「常用操作」里的顺序走：先初始化 `pro_api`，再取股票列表与交易日历做底表，最后按交易日或按代码取行情与财务数据。
4. 大批量历史数据务必分段拉取（按交易日循环优于按代码循环），并在每段之后落盘。
5. 遇到报错先查「常见坑」表：token、积分、日期格式、代码后缀、复权口径是最常见的五类原因。

接口名、参数与返回字段请以平台站点的数据接口文档为准；仓库 README 中记录的是旧版接口，与本平台的接口并不通用。

## 安全

- 不内嵌任何密钥：本 Skill 正文不含 token，也不含任何可直接使用的凭证。
- token 只从环境变量或本机配置读取，不要硬编码进脚本，更不要提交进版本库。
- token 是调取数据的唯一凭证，一旦泄露应立刻在平台个人中心刷新，使旧 token 失效。
- 拉取的数据可能包含未公开或需要授权的信息，落盘与再分发前先确认合规要求。
- 本 Skill 不提供投资建议；数据本身的准确性、时效性与适用性由使用者自行核验。
