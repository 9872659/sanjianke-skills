## 前置条件

- **Node.js 与包管理器**：需要 Node.js 和 npm（或 Yarn / pnpm）。具体版本要求以项目 `package.json` 的 `engines` 字段和仓库说明为准，不要拿最新版硬套。
- **一个可用的商城后端**：这套前端不含任何商品与订单数据，必须有后端提供商品、购物车、订单等接口才能跑出真实页面。
- **接口地址**：项目通过环境变量文件（形如 `.env` / `.env.development` / `.env.production`）与请求封装配置后端地址。变量名以仓库里的环境变量文件为准，先确认再修改。
- **端口**：本地开发服务会占用一个端口，以终端实际输出为准；冲突时先释放端口。
- **上线托管**：需要一个静态站点服务器（如 Nginx）托管构建产物，并配置子路由回退到 `index.html`。
- **可选**：微信内使用时，需要公众号 / 开放平台配置与后端签名支持。

## 使用

最短跑通路径：

```bash
# 1. 取源码
git clone https://github.com/newbee-ltd/newbee-mall-vue3-app.git
cd newbee-mall-vue3-app

# 2. 装依赖
npm install

# 3. 起开发服务（端口看终端输出）
npm run serve
```

打开终端给出的地址，确认首页能加载出商品列表。

打包上线：

```bash
npm run build
```

构建产物一般在 `dist/`，本地先预览一次再上传：

```bash
npx serve -s dist
```

如果 `npm run serve` 报「脚本不存在」，说明项目实际脚本名与预期不同，先看真实脚本：

```bash
npm run
```

**关键一步是接口地址**：把环境变量文件里的后端地址改成你自己的服务地址，并确认后端在跑、路由前缀对得上，否则页面能开也是一片空白。若脚本名、变量名或目录结构与你看到的不一致，以仓库里的 `package.json` 与实际配置文件为准。

更多操作、联调与避坑要点见 `SKILL.md`。

## 依赖

- Node.js 与 npm（或 Yarn / pnpm），版本要求见项目 `package.json`。
- 一个可访问的商城后端服务（提供商品、购物车、订单等接口）。
- 静态站点服务器（如 Nginx）用于托管构建产物。
- 可选：微信相关配置（要在微信内置浏览器里跑通支付时）。
- 无任何模型服务依赖，也不需要 API Key。

## 安全

- 不内嵌任何密钥；本包只包含说明文字，不含上游项目源码。
- 前端代码里不要写后端密钥、数据库口令或第三方支付私钥；这些一律留在后端。
- 用户登录态与 token 只保存必要项，并处理过期与登出清理。
- 环境变量文件里若含敏感值，加入 `.gitignore`，不要提交进版本控制。
- 生产环境用 HTTPS 访问，接口域名与静态资源域名保持一致或正确配置跨域策略。
- 上线前检查构建产物中是否残留调试开关、测试接口地址与内网地址。
- 第三方依赖要定期更新并对安全告警做处理，避免把已知漏洞带到线上。
