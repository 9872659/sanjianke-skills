# 三剪客 · 文章结构设计 Skill

动笔前先把论点、章节和顺序定下来，别写到一半才发现结构不对

---

## 前置条件

- 一个**真实的写作任务**：你手上有一批素材，要写一篇非虚构的东西（说明文、提案、复盘、科普、公众号文都可以）。
- 素材已经落到纸上。存在脑子里没法盘点。
- 不需要任何工具链。纸笔、记事本、任何编辑器都可以；本 Skill 不调用 API、不需要密钥。

**不适用**：小说、剧本、诗歌、实验性写作——这类文体的结构本身就是表达内容，套骨架会毁掉它。

---

## 使用

把整个包放进 Agent 的 skills 目录，或直接把 `SKILL.md` 的内容贴给 Agent。然后按你的处境选入口：

| 你的处境 | 入口 |
|---|---|
| 什么都还没写，只有一堆素材 | 走 `SKILL.md` 的「快速开始」四步，产出骨架纸（模板 C） |
| 已经有骨架，想验一下立不立得住 | 直接过 `SKILL.md` 的十二问自检清单 |
| 想知道有哪些结构可选、各自适合什么 | `references/structure-patterns.md` 的选用矩阵 |
| 想看一个真实的前后对照 | `references/self-check-and-rewrite.md` 第二部分 |
| 写到一半发现结构不对了 | `references/build-process.md` 末尾的「诊断表」 |

完整流程 20~40 分钟，产出是一张骨架纸，不是一篇文章。**先出骨架，再出句子**——这是这套方法唯一的前提。

---

## 依赖

- **运行时**：无。纯 Markdown 方法论，任何能读文本的 Agent 都能用。
- **外部服务**：无。不抓网页、不调接口、不查资料。
- **第三方库**：无。
- **可选**：一个可写文件的位置，用来存骨架纸。

---

## 安全

- 不内嵌任何密钥，不需要你提供任何凭证。
- 不联网，不上传任何内容。
- 写入文件前会先给你看差异，**不覆盖已有文件**。
- 结构诊断经常需要你贴未完成的草稿。如果草稿含客户名、未公开数据或内部信息，**先脱敏再贴**。骨架纸如果落盘，注意存放位置。
