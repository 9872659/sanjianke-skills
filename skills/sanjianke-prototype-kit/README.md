# 三剪客 · 想法快速原型 Skill

把一个还模糊的想法快速做成能看、能点、能反馈的原型，先验证方向再决定是否投入

---

## 前置条件

- Agent 需要能读到你提供的材料（想法描述、会议记录、历史反馈），并能写出 markdown 文档
- 需要有一个能被一句话说清的对象：给谁、解决什么问题
- 需要至少能接触到 5 个可做反馈的人（找不到时先解决「找谁看」，再谈原型）
- 不需要安装任何工具，也不需要联网

---

## 使用

1. 先过门槛：用 `references/01-原型精度分级与选型.md` 的「该不该做原型」四问筛一遍，答不上两条以上就不要动手
2. 定档位与路径：同一份资料里有四档精度对照表（L0 纸面草图 / L1 低保真可点 / L2 中保真交互 / L3 高保真半可用），按观众与风险选一档
3. 填模板：抄 `references/02-制作流程与模板.md` 的原型目标卡与关键路径表，把「本轮不做什么」写满
4. 做最小可验证版本：时间固定、范围浮动，先砍精致度，再砍分支，最后砍步数
5. 收反馈：按 `references/03-反馈收集与决策.md` 找 5 人各做一场 30 分钟，问过去不问未来
6. 出结论：套决策矩阵，落到加码 / 改方向 / 止损三选一，并写下「这一轮没有证明什么」
