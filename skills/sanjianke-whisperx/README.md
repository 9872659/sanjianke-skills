# 三剪客 · 音视频转写与逐词对轴 Skill

WhisperX：把音视频转成带逐词时间戳的字幕，并区分说话人。含安装、常用命令、显存与对轴避坑要点。

---

## 前置条件

- 一台能跑 Python 的机器；GPU 路线需要支持 CUDA 的显卡与匹配驱动，CPU 路线也能跑但慢。
- 系统里要有可用的 `ffmpeg` 可执行文件。
- 首次运行需要联网下载模型（识别模型、音素对齐模型、分离模型）。
- 要用说话人分离，需准备 Hugging Face 访问令牌，并在分离模型页面接受用户协议。
- 需要腾出足够的磁盘空间放模型缓存与输出文件。

---

## 使用

1. 装好工具，并确认 `whisperx --version` 能正常输出。
2. 先用一次最小命令跑通：`whisperx path/to/audio.wav`，确认能出字幕。
3. 按需要逐步加参数：要词级精度就确认对齐在跑，要多角色就加分离与人数范围。
4. 显存不够时按「先降 batch、再换小模型、最后换 int8」的顺序调。
5. 出结果后抽查对齐质量，再把它接进剪辑或字幕流程。

完整参数清单以仓库 README 与 `whisperx --help` 为准；本包只写了经过确认的常用项。

---

## 依赖

- Python 运行环境
- `ffmpeg`
- GPU 路线依赖 CUDA 工具链（官方 README 点名 CUDA 12.8）与显卡驱动
- 工具自身依赖的推理与对齐组件在安装时一并拉取，建议使用干净的虚拟环境或 conda 环境
- 说话人分离额外依赖 Hugging Face 账号与访问令牌

---

## 安全

- 不内嵌任何密钥；令牌请通过 `--hf_token` 或环境变量在运行时传入，不要写死在脚本里。
- 不要把令牌、模型缓存的私有路径、隐私音频随包提交或分享。
- 处理他人音频前请确认已获得合法授权，转写文本同样属于敏感数据。
- 默认不上传音频；只有下载模型的出站请求，如企业环境有限制请提前放行模型域名。
- 分离模型属于受限许可模型，使用前请阅读其许可条款。
