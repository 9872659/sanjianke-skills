# 广告投放素材 · 一个卖点 15 条矩阵

> **先申请你自己的 API Key。** 本包不内嵌任何 Key，用的是你在 [api.a7w.cn](https://api.a7w.cn/) 注册的 Key，扣的是你自己账户的余额。填 Key：`python3 scripts/a7w.py login --key sk-你的key`。

## 一句话

**一个卖点 15 条素材，90 点 = 0.90 元。** 5 个平台尺寸乘 3 个钩子，一次排成矩阵：价格钩报到手价，痛点钩报场景，效果钩报可验证的结果。两个卖点正好一批 30 条，180 点 = 1.80 元。

## 15 条矩阵怎么排（1 卖点 x 5 尺寸 x 3 钩子）

| 钩子 | 前 3 秒说什么 | 主标 | 适合的版位 |
|---|---|---|---|
| `H1` 价格钩 | 到手价与原价摆在一起 | 券后 79 元 | 千川信息流、朋友圈、开屏 |

## 三条干货（别人不写进文档的）

**一、轮询一次就是一次的钱。** 应用层 `/query` 每查一次按该应用单价结算，`nano_banana/query` 实测 72 点/次。本包 `status` 只打 `GET /api/v1/tasks/<id>`，价目表里这条是 cost:0，等十分钟也是 0 点。

**二、`GET /api/v1/apps/<app>` 是收费的。** 它命中 `/apps/<app>/*` 的通配计价，按该应用 flat 单价即时扣费、不退（实测 dressing_diffusion 200 点、nano_banana 72 点各一笔）。要目录只看 `/api/v1/apps` 列表和 `/api/v1/pricing`，两条都是 cost:0。

**三、首帧图有域名白名单。** 外站地址一律 400 `url_not_allowed`，只认 vr.a7w.cn、cdn2.jiujiushuyuan.cn/vr/、oss.gpu.likeadmin.cn/openapi/。`film --image 本地图.png` 与 `img --ref 实拍.jpg` 会先 `POST /api/v1/upload`（免费）换地址。

## A/B 测试与素材衰减节奏

| 时间 | 动作 | 判据 |
|---|---|---|
| D0 | 三个钩子各分 1/3 预算，等比跑量 | 每个钩子至少 3,000 次展示再判断 |
| D3 | 留 CTR 前两名，预算集中 | 低于平均点击率 60% 的钩子先停 |
| D7 | 衰减判定 | CTR 比首日掉 30%，或 CPM 涨 50%，进淘汰位 |
| D14 | 出 v2，只换钩子，尺寸与卖点不动 | 一次只改一个变量，A/B 才归因 |
| 每两周 | 新一批 30 条 | 老素材留 2 条跑量，其余换新 |

## 合规检查（`qc` 已经做成默认动作）

- **用语用可验证描述**：「洗 30 次仍凉感」比「全网最凉」更稳，也更有画面。
- **价格三处对齐**：口播数字、主标券后价、落地页到手价保持一致。
- **钩子三套说法**：三条素材的前 3 秒台词各不相同，A/B 才测得出差异。
- **行动号召一句**：领券 / 点击 / 下单 / 立即，至少一个，落在安全区内。
- **素材来源**：实拍图自有优先，参考图只借构图，人物与 logo 自己出。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--sell` | 必填（`plan`） | 卖点，可重复给多个 |
| `--price` / `--list` | 79 / 129 | 到手价 / 原价（元），差价自动算进话术 |
| `--pain` / `--proof` | 闷热贴背 / 洗 30 次仍凉感 | 痛点与效果证据，进 H2 / H3 |
| `--size` | 9x16 | 9x16 / 1x1 / 16x9 / 3x4 / 4x5 |
| `--hook` | H1 | H1 价格 / H2 痛点 / H3 效果 |
| `--n` | 1 | 出图张数 1~4（一次多图，按张计费） |
| `--budget` | 3000 | 点数上限（**单位：点**，1 元 = 100 点） |
| `--yes` / `--dry-run` | — | 确认真实扣费 / 只打印请求 |

退出码：`0` 成功 / `2` 用法错 / `3` 检查没过 / `4` 需 `--yes` / `5` 预算不足 / `6` 调用失败 / `1` 内部错 / `130` 中断。`--json` 成功是 `{"ok": true, ...}`，失败是 `{"ok": false, "exit": 5, "error": {"kind": "budget", "message": "…"}}`。
