# 广告投放素材 一个卖点 15 条矩阵

**一个卖点 15 条素材，90 点 = 0.90 元。** 5 个平台尺寸乘 3 个钩子，一次排成矩阵；两个卖点正好一批 30 条，180 点 = 1.80 元。

投手一天真正要交的不是「一张图」，是「一个卖点的一组素材」：千川要 9:16 和 1:1，腾讯要 16:9，小红书要 3:4，朋友圈要 4:5；同一个卖点还要有价格钩、痛点钩、效果钩三套说法，才能在 A/B 里测出到底是哪一句在起作用。

## 投放平台尺寸表

| `--size` | 比例 | 请求尺寸 | 上架尺寸 | 平台 | 安全区 |
|---|---|---|---|---|---|
| `9x16` | 9:16 | 720x1280 | 1080x1920 | 巨量千川 / 抖音 / 视频号 | 顶部 12% 角标，底部 18% 行动号召 |
| `1x1` | 1:1 | 1024x1024 | 1080x1080 | 千川信息流 / 朋友圈 / 小红书 | 主体居中偏上，四角留白 |
| `16x9` | 16:9 | 1280x720 | 1920x1080 | 腾讯广告 / 激励视频 / 开屏 | 主体居中，左侧 1/4 给标题 |
| `3x4` | 3:4 | 1152x1536 | 1242x1660 | 小红书笔记 / 蒲公英 | 上 1/3 主标，底部 15% 留白 |
| `4x5` | 4:5 | 1024x1280 | 1080x1350 | 朋友圈广告 / Instagram | 中心构图，上下各留 10% |

五个请求尺寸都在 gpt-image 的合法区间里：16 的倍数、长短边 3:1 内、单边 3840 内、总像素 655,360~8,294,400。`qc` 按这四条再验一遍，省得跑完 15 张才发现尺寸不合法。

## 15 条矩阵怎么排

**卖点 x 尺寸 x 钩子。** 一个卖点 5 个尺寸 x 3 个钩子 = 15 条；两个卖点 = 30 条，正好一批。

| 钩子 | 前 3 秒说什么 | 主标 | 副标 | 适合的版位 |
|---|---|---|---|---|
| `H1` 价格钩 | 到手价与原价摆在一起 | 券后 79 元 | 原价 129 · 第二件半价 | 千川信息流、朋友圈、开屏 |
| `H2` 痛点钩 | 场景里的具体难受 | 别再闷热贴背 | 通勤上班族的冰丝凉感 | 抖音、小红书、视频号 |
| `H3` 效果钩 | 可复现的使用结果 | 洗 30 次仍凉感 | 实拍记录 | 小红书笔记、详情页联动 |

**命名 `卖点码-钩子_尺寸_v版本`**：

```
SP01-H1_9x16_v1.png    卖点 01 / 价格钩 / 竖版 / 第 1 版
SP01-H2_3x4_v2.png     卖点 01 / 痛点钩 / 小红书 3:4 / 第 2 版
SP02-H3_1x1_v1.png     卖点 02 / 效果钩 / 方版 / 第 1 版
```

文件名就是 A/B 表的主键：一眼看出这一轮改的是钩子、尺寸还是版本。`qc` 会按这条正则逐个验。

## 退出码

| 码 | 含义 |
|---|---|
| `0` | 成功 |
| `2` | 用法错（缺 `--sell`、秒数越界、选项缩写） |
| `3` | `qc` 检查没过 |
| `4` | 需要确认 —— 没给 `--yes` |
| `5` | 预算不足 —— **一个请求都不发** |
| `6` | 调用失败 |
| `1` | 内部错误 |
| `130` | 被 Ctrl-C 中断 |

`--json` 成功是 `{"ok": true, ...}`，失败是 `{"ok": false, "exit": 5, "error": {"kind": "budget", "message": "…"}}`，stdout 只有一个 JSON 文档；`--json` 写在子命令前后都可以。

## 三条用钱换来的规矩

**一、轮询一次就是一次的钱。** 应用层的 `/query` 每查一次按该应用单价结算，`nano_banana/query` 实测 72 点/次，一天轮询 30 次就是 2,160 点。本包 `status` 只打 `GET /api/v1/tasks/<id>`，价目表里这条是 cost:0，等十分钟也是 0 点。

**二、`GET /api/v1/apps/<app>` 是收费的。** 它命中 `/apps/<app>/*` 的通配计价，按该应用 flat 单价即时扣费、不退（实测 dressing_diffusion 200 点、nano_banana 72 点各一笔）。要目录只看 `/api/v1/apps` 列表和 `/api/v1/pricing`，两条都是 cost:0。

**三、首帧图有域名白名单。** 外站地址一律 400 `url_not_allowed`，只认 vr.a7w.cn、cdn2.jiujiushuyuan.cn/vr/、oss.gpu.likeadmin.cn/openapi/。`film --image 本地图.png` 与 `img --ref 实拍.jpg` 会先 `POST /api/v1/upload`（免费）换地址。

## 合规检查（`qc` 已经做成默认动作）

- **用语用可验证描述**：「洗 30 次仍凉感」比「全网最凉」更稳，也更有画面。
- **价格三处对齐**：口播数字、主标券后价、落地页到手价保持一致。
- **钩子三套说法**：三条素材的前 3 秒台词各不相同，A/B 才测得出差异。
- **行动号召一句**：领券 / 点击 / 下单 / 立即，至少一个，落在安全区内。
- **素材来源**：实拍图自有优先，参考图只借构图，人物与 logo 自己出。
- **生成标识**：平台要求 AIGC 标识时，`film` 的 `aigc_watermark` 改成 true 重跑。
