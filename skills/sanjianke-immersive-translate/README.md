# 三剪客 · 沉浸式双语网页翻译扩展 Skill

immersive-translate：沉浸式双语网页翻译扩展 的安装、常用命令与避坑要点

---

## 前置条件

- **一个允许安装扩展的浏览器**。Chromium 系需要满足新版扩展规范的最低版本要求（版本过低会被官方降级到较早的扩展版本）；Firefox、Safari 走各自的安装渠道。
- **网络可达所选翻译服务**。扩展本身不做翻译，它把文本发给第三方翻译服务或大模型；默认通路要能连上对应服务商的接口，用境外服务时取决于你的网络环境。
- **判断需求落在哪一档**：网页翻译、输入框、悬停、字幕、字幕文件、标准（非扫描）PDF 属于免费档能力；漫画翻译、服务端图片翻译、复杂与扫描版 PDF 属付费档。免费档的图片翻译只在 Chrome/Edge 且只识别英语与部分拉丁语系。
- **如果要接自己的模型或接口**：准备好 OpenAI **兼容**的接口地址（形如 `/v1/chat/completions`）与 Key；本机跑推理服务时（例如 Ollama）要先放开跨域。
- **改高级配置前先备份**：开发者页里的「完整用户配置」与「用户规则」是 JSON，改坏会让扩展行为异常，官方文档也建议改前备份。

## 使用

最短上手路径如下，完整内容见 `SKILL.md`。

**1）装**：优先从浏览器商店安装（自动更新）。商店不可用时，按官方安装文档的步骤手动加载压缩包：解压后在浏览器地址栏进扩展管理页，打开开发者模式，选择「加载已解压的扩展程序」并指向解压出来的文件夹。

**2）翻当前页**：默认快捷键 `Alt+A` 翻译 / 再按回到原文；`Alt+W` 翻整页（默认只翻网页主体内容区）；`Alt+I` 翻输入框；`Alt+S` 开侧边栏。键位可在设置里改。

**3）换服务**：在扩展面板里切换翻译服务与目标语言（桌面悬停悬浮球、移动端长按悬浮球）。配置 JSON 里 `translationService` 支持的取值枚举为：

```text
bing | transmart | google | deepl | openai | gemini | baidu | volc | youdao | caiyun | tencent | openl
```

**4）接自己的 OpenAI 兼容接口**：选 `openAI` 服务，填 `api_key`、`Custom model`、`Custom URL` 三项，URL 形如：

```text
http://localhost:11434/v1/chat/completions
```

**5）按站点写翻译规则**：在开发者页的「用户规则」里写数组，用 `matches` 命中站点、`selectors.add` / `selectors.remove` 做增量范围调整。注意 `*.example.com` 只匹配子域名，不含根域名。

**6）PDF / EPUB / 字幕**：在线 PDF 点图标选翻译文件；本地 PDF 要**右键点扩展图标**；EPUB 走 PDF/ePub 入口；字幕文件在 More 里。

## 依赖

- **必需**：受支持的浏览器（Chromium 系 / Firefox / Safari）；可访问所选翻译服务的网络
- **可选**：自备的 OpenAI 兼容接口或按官方契约实现的翻译接口及其 Key；Tampermonkey 等脚本管理器（用用户脚本形态时）
- **移动端**（可选）：官方 APK 或 Android 浏览器、iOS Safari
- **不需要**：源码、构建工具链或 Node.js —— 上游仓库只发布编译好的安装包，**没有 `package.json`、没有构建脚本、没有 `src/` 目录**，不存在"从源码构建"的步骤

## 安全

- 不内嵌任何密钥；本 Skill 正文中不含任何凭证
- 待翻译的文本会被发送给**你所选择的第三方翻译服务或你自配的接口**，请按内容的敏感程度选择服务，不要把不该外发的内容交给外部接口
- 该扩展申请的作用范围是全部网址（含本地文件协议），这是它能在任意网页上工作的前提；安装前请确认这与你的使用环境与合规要求相符
- 若填写自备的 API Key，凭证保存在本机浏览器配置里；不要在共享电脑上留存生产环境的 Key
- 用户脚本形态下，自定义接口需要在脚本头部用 `@connect` 声明目标域名才能请求
- 上游仓库**不含源代码**，安装包来自官方分发渠道；不要从第三方站点下载改包
- 本 Skill 不提供该产品的技术支持，产品问题走官方反馈渠道
