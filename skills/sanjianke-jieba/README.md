# 三剪客 · 中文分词与关键词抽取 Skill

给中文文本切词、加自定义词典、抽关键词、标词性、拿词语在原文里的起止位置，纯 Python、无模型、装上就能跑

---

## 前置条件

- **Python 2 或 3**：官方说明代码对两者都兼容，`import jieba` 即可用
- **不需要深度学习框架**：做分词、关键词抽取、词性标注零第三方依赖
- **不需要显卡、不需要联网**：词典随包分发，全程离线
- **自定义词典文件必须是 UTF-8**：格式为「词语 词频 词性」，后两段可省略、顺序不可颠倒
- **用 paddle 模式才需要额外依赖**：`paddlepaddle-tiny==1.6.1`，且 jieba 需 v0.40 以上、代码里先调 `jieba.enable_paddle()`
- **并行分词只在 Linux 可用**：基于 multiprocessing，官方明确说暂不支持 Windows
- **不需要账号或 API Key**

---

## 使用

加载这个 Skill 之后，Agent 会按 `SKILL.md` 里的六个板块来干活：判断该不该用、怎么装、常用操作怎么跑、有哪些坑、权限边界在哪、能覆盖到什么程度。

典型用法：

1. **选模式**——「统计词频」和「建搜索索引」用的模式不一样：前者精确模式，后者搜索引擎模式。选错了结果就废了。
2. **加词典**——行业术语被切碎时，按「词语 词频 词性」写一份 UTF-8 词典，用 `load_userdict` 挂上；临时调整用 `suggest_freq` 或 `add_word`。
3. **抽关键词**——TF-IDF 与 TextRank 两套接口，注意两者 `allowPOS` 的默认值不一样。
4. **拿位置**——`jieba.tokenize` 返回 `(词, 起始下标, 结束下标)`，做高亮、对齐、标注直接用。
5. **命令行批处理**——`python -m jieba` 支持 `-p` 词性、`-d` 分隔符、`-D`/`-u` 词典、`-a` 全模式、`-n` 关 HMM、`-q` 静默。
6. **排障**——「打印出来是 generator」「第一次调用卡两三秒」「Windows 并行报错」这类现象，对照「常见坑」表逐条排查。

## 安全

- 不内嵌任何密钥：本 Skill 正文里没有任何 token、口令或私有地址
- **全程离线**：分词、关键词抽取、词性标注不发起任何外部请求，处理敏感文本时没有外传风险
- **不要直接把 bytes 丢进去**：官方提示输入 GBK 编码字符串可能被无法预料地错误解码成 UTF-8；统一先解码成 unicode 再传，避免内容错乱
- **自定义词典与语料是数据文件**：从外部拿到的词典/停用词表建议先看一眼内容，别盲目挂载
- **并行分词会起子进程**：`enable_parallel` 基于 multiprocessing，在受限容器里可能被禁止；非 Linux 平台不支持
- **缓存文件会落盘**：默认在 `tmp_dir` 下写缓存，受限文件系统上要显式改路径，否则启动即失败
