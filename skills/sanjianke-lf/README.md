# 三剪客 · 终端文件管理器 Skill

lf：终端文件管理器 的安装、常用命令与避坑要点

---

## 前置条件

- 需要一个真实的交互式终端（Linux、macOS、BSDs、Windows 均可）；没有 TTY 的环境里没有意义。
- 从源码构建需要 Go 工具链；直接用发行版包或预编译二进制则不需要编译环境。
- 建议准备一个终端字体（要显示图标时）和一个终端复用器（`lf` 不做标签页与多窗口）。
- 建议设置 `$EDITOR`、`$PAGER`、`$OPENER`，否则打开与预览动作会没有目标程序。
- 不需要网络、账号或 Key。

---

## 使用

最短跑通路径：

```bash
lf                            # 从当前目录开始浏览
lf ~/projects                 # 指定起始目录
lf ~/projects/README.md       # 指定文件：进入它的父目录并选中它
lf -print-selection           # 选好后按 l 确认，退出时打印选中路径
cd "$(lf -print-last-dir)"    # 让 shell 跟随 lf 的退出目录
lf -doc                       # 离线查看完整文档
```

配置文件位置：Unix 是 `~/.config/lf/lfrc`，Windows 是 `%APPDATA%\lf\lfrc`。什么时候该用、什么时候不该用、常见坑与能力边界，见同目录的 `SKILL.md`。

## 依赖

- 运行期：单个静态二进制，无外部运行时依赖。
- 构建期：Go 工具链（`go install` 方式）。
- 自定义能力依赖本机工具：shell、`file`、编辑器、pager，以及你自己写的预览或打开脚本。
- 可选：终端复用器（多窗口）、终端字体与 color/icon 配置（图标与配色）。
- 不需要网络、账号或 Key。

---

## 安全

- 不内嵌任何密钥。
- 默认不绑定删除键，这是刻意的保护；请自己定义删除命令，并优先考虑先移入回收站再清理。
- 内置复制移动不覆盖同名文件，会在目标处生成带编号的新名字；自定义 `paste` 若换成 `cp`、`mv`，请自行决定覆盖策略。
- shell 命令模板会执行你配置的任意命令，等于把 shell 权限交给配置文件；只使用可信来源的配置片段。
- 服务端进程可能常驻：`lf -server` 会监听本机连接供 `-remote` 使用，任务结束可用 `lf -remote 'quit!'` 收掉。
- 状态文件（选择、书签、标签、历史）会记录你浏览过的路径，共享机器上注意隐私。
