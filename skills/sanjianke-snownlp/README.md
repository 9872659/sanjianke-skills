# 三剪客 · 中文文本处理与情感分析 Skill

snownlp：中文文本处理与情感分析 的安装、常用命令与避坑要点

---

## 前置条件

- 一个可用的 Python 3 解释器；该包年代较早，建议先用目标解释器做一次最小自检
- 建议放在虚拟环境里，避免与其他分词库、NLP 库的依赖互相干扰
- 能访问 PyPI（仅安装阶段需要联网，运行阶段完全离线）
- 若要做情感判定：准备好一批自己领域的样本，用于确认阈值
- 若要用自备语料重训：准备符合训练要求的语料文件，并留出一个可写目录放 `.marshal`

---

## 使用

本篇是操作整理，把「装、跑、避坑」按顺序讲清楚，代码与接口名均来自上游仓库自己的示例。

常用入口速查：

- 构建对象：`SnowNLP(text)`
- 分词 / 词性 / 情感 / 拼音：`s.words`、`s.tags`、`s.sentiments`、`s.pinyin`
- 繁体转简体：`s.han`
- 关键词 / 摘要 / 分句：`s.keywords(n)`、`s.summary(n)`、`s.sentences`
- TF-IDF 与相似度：`s.tf`、`s.idf`、`s.sim([分词后的词])`
- 重训入口：`snownlp.seg`、`snownlp.tag`、`snownlp.sentiment` 三个模块的 `train` / `save`

完整的六块内容（用与不用、安装、常用操作、常见坑、权限与用途、能力边界）见 `SKILL.md`。

## 依赖

- Python 3 运行时（不含第三方依赖；PyPI 元数据未声明 `requires_dist`）
- 不需要 NLTK，不需要下载外部模型，不需要编译工具链
- 不需要显卡、不需要数据库、不需要任何服务端组件
- 无网络、账号、API Key 要求
- 安装包体积偏大，因为训练好的字典随包分发，装之前留意磁盘与镜像体积

---

## 安全

- 不内嵌任何密钥
- 全程本地推理，输入文本不会离开本机，也没有遥测上报
- 只处理你自己有权处理的文本；把抓取到的第三方内容入库或对外发布前，自行确认授权与合规
- 情感分析是统计模型输出，只能当参考信号，不要用它单独做审核、判罚或风控决策
- 重训会把语料写入本地产物文件，注意不要把这些文件误提交到公开仓库
