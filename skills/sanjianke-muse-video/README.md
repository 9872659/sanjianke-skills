# muse video单条支持3分钟视频 0.11元一秒
**720P、带声音、4–180 秒，11 点一秒（¥0.11/秒）。**

走 [api.a7w.cn](https://api.a7w.cn/) 的 `muse-video`（Meta Muse 视频模型），
接口与 OpenAI 视频接口一致，**异步三步**：提交 → 查询 → 下载。

## 这个包替你处理的四件事

### 一、按请求秒数计费，不是糊涂账

| 秒数 | 价格 | 秒数 | 价格 |
|---|---|---|---|
| 4 秒 | 44 点（¥0.44） | 10 秒 | 110 点（¥1.10） |
| 5 秒 | **55 点（¥0.55）** | 15 秒 | 165 点（¥1.65） |
| 6 秒 | 66 点（¥0.66） | 30 秒 | 330 点（¥3.30） |
| 8 秒 | 88 点（¥0.88） | 60 秒 | 660 点（¥6.60） |

`cost --seconds 30` 先报 330 点，`--budget` 是第一道闸门（超了**一个请求都不发**）。

### 二、凑档不加钱

出片时长会**凑到档位**（填 7 秒出 8 秒、填 17 秒出 20 秒），但**只按你填的秒数收钱**。

所以 `cost --seconds 17` 会同时告诉你：

```
时长：17 秒 × 11 点 = 187 点 = ¥1.87
出片：约 20 秒（凑档不加钱，仍只收 17 秒）
```

**这是白拿的 3 秒。**

### 三、等待可能很久 —— 所以默认不等

| 请求秒数 | 一般耗时 |
|---|---|
| 4–10 秒 | 1.5–2.5 分钟，慢的 4 分钟 |
| 11–30 秒 | 3–5.5 分钟，慢的 7 分钟 |
| 31–60 秒 | 5–13 分钟 |
| 61–180 秒 | 8–15 分钟 |

高峰排队更久。

**`gen` 默认提交完就返回 task id**，把等待交给你决定；要一次跑完就加 `--wait`。

**⚠️ 超时不会自动重提：**

```
失败：等待超时（60 分钟）—— 任务可能仍在生成。
  不要重新提交（重提会再扣一次钱）。稍后用：
    python3 scripts/run.py wait task_xxxx --outdir .
```

### 四、成品只保留 24 小时

`--wait` 成功就**立刻下载**，并打印过期时间。

## 快速开始

```bash
# 1) 填 Key
export A7W_API_KEY=sk-你的key
# 或者：python3 scripts/a7w.py login --key sk-你的key

# 2) 免费自检
python3 scripts/run.py doctor

# 3) 先算钱
python3 scripts/run.py cost --seconds 10

# 4) 出片（提交完就返回 task id）
python3 scripts/run.py gen --prompt "金色的枫叶在微风中飘落，阳光穿过树梢，电影感" \
    --seconds 5 --yes

# 5) 等它完成并下载
python3 scripts/run.py wait task_xxxx --outdir .
```

想一次跑完：

```bash
python3 scripts/run.py gen --prompt "..." --seconds 5 --yes --wait --outdir .
```

## 用法示例

```bash
# 竖屏 8 秒，用本地图当首帧
python3 scripts/run.py gen --prompt "女孩在海边转身走向镜头，海风吹起头发" \
    --seconds 8 --size 720x1280 --first-frame girl.jpg --yes --wait

# 多图参考（第 1 张开头，其余当人物/场景/画风参考）
python3 scripts/run.py gen --prompt "镜头跟着人物走进森林小屋，人物照第二张图" \
    --seconds 10 --ref first-frame.jpg --ref character.jpg --ref palette.jpg --yes

# 30 秒长片
python3 scripts/run.py gen --prompt "..." --seconds 30 --budget 400 --yes --wait

# 只看请求，不花钱
python3 scripts/run.py gen --prompt "..." --seconds 5 --dry-run
```

## 时长怎么选

| 档位 | 出片 | 说明 |
|---|---|---|
| 4 / 5 | 5 秒 | |
| 6 | 6 秒 | |
| 7 / 8 | 8 秒 | 填 7 出 8，只收 7 |
| 9 / 10 | 10 秒 | 填 9 出 10，只收 9 |
| 11 以上 | 凑到 5 的倍数 | 11–15→15、16–20→20 …… 176–180→180 |

**<4、>180、带小数 → 400，不扣费。**

## 镜头结构

- **10 秒以内**：一个连续镜头
- **11–60 秒**：分段生成，后一段从前一段最后一帧接着拍，**接缝处画面连续**
- **61–180 秒**：分成 2–3 部分**同时生成**再拼接；**部分之间会换镜头**，人物可能变化 → 要一致就传参考图

## 退出码

| 码 | 含义 |
|---|---|
| `0` | 成功 |
| `2` | 用法错 |
| `4` | 需要确认 —— 没给 `--yes` |
| `5` | 预算不足 —— **一个请求都不发** |
| `6` | 提交/查询失败，或任务 `failed` |
| `7` | **等待超时** —— 用 `wait <id>` 继续，**别重提** |
| `1` | 内部错误 |
| `130` | 被中断（任务仍在跑，用 `status <id>` 查） |

## 任务状态

| `status` | 含义 | 该做什么 |
|---|---|---|
| `queued` | 排队中 | 继续查 |
| `in_progress` | 生成中 | 继续查 |
| `completed` | 完成 | 下载 |
| `failed` | 失败，**预扣全额退回** | 看 `error.message` 改一下再提交 |
| `unknown` | 平台在确认状态 | 继续查（不重复扣费） |

> `progress` 到 99 时平台在核对成片，可能多持续几分钟。**判断完成看 `status`，不看 `progress`。**
