## 6 项必标 + AI 素材三条规矩

1. **医疗机构执业许可证登记号**：PDY… 与执业许可证逐字一致。
2. **医疗广告审查证明文号**：`（京）医广【2026】第 03-15-0123 号`，范围要覆盖片里的项目。
3. **广告标识**：标题或首帧标「广告」，正文首行再标一次。
4. **风险提示**：效果因人而异，具体方案需面诊评估；列该项目常见风险。
5. **机构全称与项目**：全称照写，项目用注册名。
6. **项目与价格**：项目名 + 计价单位 + 价格区间，加项单列。

AI 素材三条：① 只做环境 / 器械 / 空间示意，不当疗效示意；② 角标「AI 生成 · 场景示意，非真人案例」，`video` 默认开 `aigc_watermark`；③ 数字人扮「医生」要标合成，真人医生要能对上执业证书。

## 三条干货（别人不写进文档的）

1. **`GET /api/v1/apps/<app>` 是收费的。** 它命中 `/apps/<app>/*` 通配计价，按该应用单价即时扣费、不退（实测 dressing_diffusion 200 点、nano_banana 72 点）。看 schema 用 `GET /api/v1/apps` 列表 + `GET /api/v1/pricing`，两条都 cost:0。
2. **`/submit` 缺参数不是免费探针。** pic_lipsync、full_video 走 reserve_sync：先冻结点数、再校验、再全额退，净额 0 但钱包被短暂动过。本包 `doctor` 一条应用层 submit 都不发，改用空 body 的 `/video/viapi/enhance` 停在 400 empty_url。
3. **AI 图的「示意图」三个字救不了你。** 执法口径看的是「有没有把 AI 画面当疗效展示」，所以角标写「场景示意」之外，画面本身就得是环境、器械、空间 —— 本包示例 prompt 一律避开人脸与皮肤特写。

## 参数与退出码

| 参数 | 默认 | 说明 |
|---|---|---|
| `--asset` | copy | copy / image / video / voice；image 与 video 加查 AI 标识 |
| `--avatar-seconds` / `--broll-seconds` | 20 / 10 | `cost` 用；口播段与空镜段秒数 |
| `--images` / `--tts-chars` | 4 / 60 | `cost` 用；图张数与旁白字数 |
| `--resolution` / `--seconds` | 1080P / 20、10 | 五档分辨率；成片单段 4~15 秒 |
| `--budget` | 5000 | 点数上限（**单位：点**，1 元 = 100 点） |
| `--strict` `--review` `--yes` `--dry-run` | — | 严格拦截 / 人工复核 8 条 / 确认真实扣费 / 只打印请求 |

退出码：`0` 成功 / `2` 用法错或合规未过（一个请求都不发）/ `3` 自检未过 / `4` 缺 `--yes` / `5` 超预算且一个请求都没发 / `6` 调用失败 / `1` 内部错 / `130` 中断。`--json` 成功是 `{"ok": true, ...}`，失败是 `{"ok": false, "exit": 5, "error": {"kind": "budget", "message": "…"}}`，stdout 只有一个 JSON 文档；`--json` 写在子命令前后都可以。
