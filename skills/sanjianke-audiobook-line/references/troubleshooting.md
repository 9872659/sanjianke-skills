# 排错：按报错找原因

> 先看这一行：`python3 scripts/run.py doctor` —— 6 项全 √ 就说明 Key、接口、价目、查询、音色库都通，
> 问题在参数或素材。任何一项 × 就先解决那一项再往下走。

---

## 一、命令层报错（本包自己抛的）

| 退出码 | 屏幕上看到 | 原因 | 怎么办 |
|---|---|---|---|
| `2` | `失败：必须给 --book（书稿路径…）` | `split` 少参数 | 加 `--book 书稿.md` |
| `2` | `失败：书稿不存在：…` | 路径写错 | 用绝对路径，或先 `cd` 到书稿所在目录 |
| `2` | `失败：书稿是空的：…` | 文件 0 字节，或编码读不出来 | 本包按 utf-8-sig → utf-8 → gb18030 依次试；都不是就用编辑器另存为 UTF-8 |
| `2` | `失败：… 里没有 chapters.json，先跑 split …` | `--book-dir` 指错目录 | 指到 `split --out` 那个目录 |
| `2` | `失败：给 --chapter ch01（可重复）或 --all。现有章：ch01、ch02 …` | 没选章 | 按提示里的 id 给 `--chapter`，或 `--all` |
| `2` | `失败：没有旁白音色。跑一次 cast --voice-default …` | `cast.json` 里旁白是空的 | `cast --book-dir … --voice-default <音色ID>`，或这次给 `--voice` |
| `2` | `失败：角色「某某」还没配音色…` | 那个角色没分配音色 | `cast --assign 某某=<音色ID>`，或 `--voice` 统一顶上去 |
| `2` | `失败：--assign 要写成 名字=音色ID` | 格式不对 | `--assign 林昭=99489fa…` |
| `2` | `失败：这些音色 ID 不在你的音色库里：…`（`--live`） | ID 抄错或不是自己的音色 | `voices` 重新抄一遍 |
| `2` | `失败：给 --audio-url（公网音频地址）或 --file（本地 mp3/wav）` | `align` 少参数 | 二选一 |
| `2` | `失败：必须给 --title（音色名字）` | `clone` 少参数 | 加 `--title` |
| `2` | `失败：这条要 --task-id 和 --audio-id 两个参数` | `timeline` 少参数 | 两个都从异步任务返回里拿 |
| `2` | `失败：没有 API Key。三选一：…` | 没配 Key | `a7w.py login --key sk-…`，或设 `A7W_API_KEY` |
| `4` | `失败：这会真实提交 …，预计 23 点（0.23 元…）。确认请加 --yes。` | 缺 `--yes` | 看清点数后加 `--yes` |
| `5` | `失败：预计 23 点…超过 --budget 5 点。一个请求都没发。` | 超预算 | 调大 `--budget`（单位：点）或先跑一章 |
| `6` | `失败：第 ch03#2 段任务失败（failed）：…` | 上游合成失败 | 失败任务全额退回，按原参数重跑那一段 |
| `6` | `失败：等了 900 秒还没完成。任务没丢…` | 轮询超时 | `status --task-id …` 接着查，或 `--wait` 调大 |
| `3` | `doctor` 有 × 项 | 见第二节 | 按那一项处理 |
| `130` | `已中断。` | Ctrl-C | 加 `--resume` 续跑，已完成的段不重复扣 |

## 二、`doctor` 六项检查对应的排错

| 检查项 | × 时的典型原因 | 怎么办 |
|---|---|---|
| Key 有效 + 余额接口可达 | Key 错、过期、被停用 | `a7w.py whoami` 再验一次；`--key` 显式给一把 |
| `voice_tts` 六个接口齐全 | 应用下架或改代号 | 打 `GET /api/v1/apps` 看目录里还有几条 |
| `media_services_33` 两条配音接口在架 | 同上 | 同上 |
| 价目表：voice_tts ×3 + 通配保底 50 | 平台调价，`markupPercent` 变了 | 重跑 `catalog` 看价目口径，`cost` 的报价按新比例手动核 |
| 任务查询 `GET /tasks/{id}` 可达 | 网关限流或 `task_id` 撞上真实任务 | 重试；返回里出现真实任务说明那个 id 恰好存在 |
| 音色库 `list_voices` 可达 | 音色服务异常 | `--no-voices` 先跳过这一项，其它项照常验 |

## 三、上游返回的报错（原文 → 原因）

| 返回原文 | 含义 | 处理 |
|---|---|---|
| `{"code":0,"msg":"任务处理失败，请稍后重试"}` | 上游合成/克隆/转写失败，话术统一 | 失败任务全额退；换音色或缩短单条再试 |
| `{"code":0,"msg":"任务不存在","data":null}` | `task_id` 不存在或已过期 | 用 `log` 里的 id；任务详情保留时间有限 |
| `{"code":0,"msg":"input.task_id: 缺少必填参数；input.audio_id: 缺少必填参数"}` | `timeline` 缺参 | `--task-id` + `--audio-id` 都给 |
| `{"code":0,"msg":"应用或 API 不可用或未配置价格"}` | 应用层兜底话术，**任何** app/接口组合都可能返回同一句 | 别当判据；用 `GET /api/v1/apps` 目录核接口是否在架 |
| `HTTP 401` | 鉴权失败 | Key 无效或已过期 |
| `HTTP 402` | 点数不足 | 充值后重试（`/user/balance` 看余额） |
| `HTTP 404` + HTML | 端点没注册，命中了 SPA 兜底 | 检查路径前缀是不是 `/api/v1/apps/<app>/<code>` |
| `HTTP 502` + `InvalidMpsUser` | 路由在、上游凭据坏了 | 换接口或等平台修 |
| `网络抖动（WinError 10054）` | 网关重置了空闲连接 | 本包已内置 3 次退避重试；长轮询仍断时把 `--wait` 缩短、分次查 |

## 四、钱包相关的现象

| 现象 | 解释 | 依据 |
|---|---|---|
| 跑完 `doctor` 看到 `冻结 150 点` 一闪而过 | `list_voices` 是路径级预扣，随请求同步退回 | 流水里 `reserve_sync -150` + `refund +150` |
| 一章跑完，`available_points` 少的不止「字数 × 0.18」 | 预扣 150 点先扣、完成按真实点数结算 | 差额自动退回；`status` 里看 `usage.points_cost` |
| `balanceMoving` 没变但流水多了几条 | 预扣（`reserve`/`reserve_sync`）不计入 `balanceMoving`，退款也不计 | 只有 `charge` / `refund` 才动 `balanceMoving` |
| 任务 `failed` 但钱少了 | 结算延迟，退款晚几秒 | 几十秒后再看 `/user/balance` |
| 同一段重复提交，扣了两次 | 没有 `--resume`，或 `state.json` 被删 | 加 `--resume`；`state.json` 别手动删 |

## 五、分章与分角色的常见偏

| 现象 | 原因 | 怎么改 |
|---|---|---|
| 只有 1 章 | 书稿没有「第 N 章」这类标题行 | `--target-chars 3000` 按字数切；或在书稿里补 `## 第 N 章` |
| 章切得太碎 | 标题行太密（每段都有 `#`） | 抬高 `--max-chars`，或把正文里的小标题改成普通行 |
| 一个角色都没抽到 | 台词写成 `"……"某某说`（名字在行尾） | 改成行首 `某某：台词`；这和上游 schema 无关，纯本地规则 |
| 角色抽到了但漏字 | 名字超过 6 个字被当成普通行 | 缩短角色名，或先手动改书稿 |
| `--assign` 的名字被忽略 | 这个名字在书稿行首没出现过 | `cast --min-lines 1` 再抽一次；输出里会提示「已忽略」 |
| 整章被切成 4 段 | 单章超过 10000 字上限 | 正常行为：每段一条请求，总字数不变、点数不变 |

## 六、Windows 控制台

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 输出里出现 `?` | 控制台编码不是 UTF-8 | 本包已按 `errors='replace'` 兜底，对勾只用 √ ×；`chcp 65001` 可整屏转 UTF-8 |
| `UnicodeEncodeError` | 老环境把 `PYTHONIOENCODING` 设成了别的编码 | 本包不会因这个崩（`reconfigure(errors='replace')`），仍建议 `set PYTHONIOENCODING=utf-8` |
| 跑一次多出 `__pycache__` | 没关字节码缓存 | 命令前加 `set PYTHONDONTWRITEBYTECODE=1`；`run.py` 自己也会关 |
| 路径里有中文/空格 | 命令行解析 | 路径加引号：`--book "D:\我的书稿\第一章.md"` |
