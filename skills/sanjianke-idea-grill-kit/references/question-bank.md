# 问题库

按层分类的问句，**可以直接照着念**。每条都标了适用条件；强问句（高质疑密度）附了配套承接句——单独使用会伤关系，一起用才安全。

## 怎么用

1. **按层取用，不跳层。** 层的顺序见 `grill-framework.md`。目标层没对齐就不要从假设层抽。
2. **每层抽 3~5 条，不要全问。** 一份想法问 20 条就已经是深度追问了。全问一遍会得到一次审讯。
3. **跟着回答走。** 问题库是**备用弹药**，不是问卷。对方答得含糊的地方，当场回抽一条追问句式。
4. **强问句留到第 2 轮以后。** 开场就问「如果三年后失败，最可能的原因是什么」，大概率得到一个敷衍的答案加一段沉默。
5. **带编号引用。** 复盘时说「1-7 那条假设你没答」，比「我们上次说过的问题」清楚得多。

## 快速定位表

| 你感觉哪里不对劲 | 大概率缺哪层 | 先问这几条 |
|---|---|---|
| 说了很久不知道要什么 | 目标层 | 1-1、1-4、1-5 |
| 数字很多但都说不清出处 | 事实层 | 2-1、2-2、2-10 |
| 一切听起来都顺 | 假设层 | 3-1、3-3、3-4 |
| 越听越像个赌注 | 反例层 | 4-2、4-6、4-9 |
| 越听越贵 | 代价层 | 5-1、5-6、5-9 |
| 越听越像只有这一条路 | 替代层 | 6-1、6-11、6-12 |
| 全程没有异议也没有兴奋 | 没给真问题 | 通用组 A 全部 |

## 一 · 目标层（1-1 ~ 1-11）

| 编号 | 问句 | 想拿到什么 |
|---|---|---|
| 1-1 | 这件事做成之后，**哪个数字会变**？现在是多少，你希望变成多少？ | 可检验的成功标准 |
| 1-2 | 这个数为什么是它？换成另一个数会发生什么？ | 目标值背后有没有依据 |
| 1-3 | 如果做成了，**谁会第一个说「成了」**？他会看什么？ | 把目标落到具体观察者 |
| 1-4 | 什么样的结果，在你眼里算**失败**？ | 失败判定 |
| 1-5 | 如果只能保一个指标，保哪个？妥协哪个？ | 优先级 |
| 1-6 | 这个标准是你定的还是别人给你定的？ | 目标归属 |
| 1-7 | 三年后回头看，做成什么样你会说「值了」？ | 长期锚点 |
| 1-8 | 为了这件事，什么可以牺牲，什么绝对不能碰？ | 底线清单 |
| 1-9 | 你说的「好」，具体是哪三件事同时发生？ | 拆解形容词 |
| 1-10 | 这个目标现在达成多少了？还差多少？ | 基期 |
| 1-11 · **强** | 你是不是其实在追一个**说不出口的目标**？比如证明点什么。 | 真实动机 |

**1-11 承接句**（说完这句再往下走）：

> 「我问这个不是要拆你，是因为目标一旦不真实，后面每一层都会算错。如果里面有这个成分，说出来反而好办——我们可以把两个目标分开算。」

## 二 · 事实层（2-1 ~ 2-16）

| 编号 | 问句 | 想拿到什么 |
|---|---|---|

| 2-2 | 什么时候的事？ | 时效 |
| 2-3 | 你从这个样本量里数出来的，还是估的？ | 分母 |
| 2-4 | 有没有一个**反过来的例子**你见过？ | 反证据 |
| 2-5 | 这个数据是你自己跑的，还是别人给你的？ | 来源链 |
| 2-6 | 如果这个数错了三倍，你的结论还成立吗？ | 敏感度 |
| 2-7 | 除了你，还有谁知道这件事？ | 交叉验证的可能 |
| 2-8 | 你上一次**直接观察**这件事是什么时候？ | 亲历事实 |
| 2-9 | 这条是行业常识，还是这个行业特有的？ | 真假常识 |
| 2-10 · **强** | 这些证据里，**有多少是你为了支持这个结论才去找的**？ | 确认偏误 |
| 2-11 | 如果让你现在推翻这个判断，你需要看到什么？ | 可证伪性 |
| 2-12 | 这个坑，是你踩过还是听说的？ | 经验来源 |
| 2-13 | 有没有一种解释，既能解释你看到的现象，又不需要你这个方案？ | 替代解释 |
| 2-14 | 你现在最不确定的一条事实是哪个？ | 行动项 |
| 2-15 | 验证这几条，**最便宜的那个方式**是什么？ | 尽快动手的路径 |
| 2-16 | 如果我明天只给你一天，你会去核哪一条？ | 优先级 |

**2-10 承接句**：

> 「这不是说你在作弊。人一旦有了结论，找证据的手就会自动往一边偏——这是本能，不是道德问题。我只是想看看有没有反向的证据被漏掉了。」

## 三 · 假设层（3-1 ~ 3-18）

| 编号 | 问句 | 想拿到什么 |
|---|---|---|
| 3-1 | 这个方案要成立，**必须为真的三件事**是什么？ | 假设清单 |
| 3-2 | 这三件事里，哪一件你**最没把握**？ | 排序 |
| 3-3 | 如果只留一条假设，赌哪条？ | 真正的核心 |
| 3-4 | 有没有什么是你**默认成立但从来没说出口**的？ | 隐形假设 |
| 3-5 | 「只要做出来，用户就会用」——这句话里有多少是假设？ | 拆穿默认 |
| 3-6 | 客户愿意为这个付钱，这件事你**亲眼验证过吗**？ | 付费假设 |
| 3-7 | 这里面，有多少是「行业一直这么做」，而不是「必须这么做」？ | 习惯假设 |
| 3-8 | 你上一次做类似的事，实际用了预期时间的几倍？ | 规划谬误 |
| 3-9 | 如果关键的那个人不在，这个方案还成立吗？ | 关键人假设 |
| 3-10 | 这条假设，你打算**多久内、用什么方式**验证掉？ | 行动项 |
| 3-11 | 这条假设，你是懒得查所以默认，还是查过了？ | 懒惰假设 |
| 3-12 | 这条假设不成立的话，方案是「作废」还是「变麻烦」？ | 致命度分级 |
| 3-13 | 有没有哪条假设，你其实是**希望**它成立的？ | 动机污染 |
| 3-14 | 这个前提是你控制的，还是别人控制的？ | 控制力 |
| 3-15 | 同样的事别人做过并失败了吗？他们死在哪一步？ | 前车之鉴 |
| 3-16 | 你说「应该没问题」的时候，心里有几成把握？ | 不确定度 |
| 3-17 | 如果有个完全不懂行的人来看，他会第一个问什么？ | 外部视角 |
| 3-18 · **强** | 你**希望**这个假设不成立吗？如果它不成立，是不是就不用干了？ | 隐藏的退缩 |

**3-18 承接句**：

> 「这个问题有点冒犯，我先说为什么问：人有时候会用一个『一定做不成的前提』来保护自己——这样就不必面对『万一我做不成』。如果有这种情况，挑出来反而轻松。」

## 通用追问句式（贯穿六层）

对方给出含糊答案时，从这十句里挑一句。**前六句温和，后四句加压**——后四句建议在第 2 轮之后使用。

| # | 句式 | 用途 |
|---|---|---|
| A1 | 「你说的『不错』，具体是哪三件事？」 | 把形容词拆开 |
| A2 | 「能不能给我一个具体的例子？」 | 从抽象拉到具体 |
| A3 | 「这句话里有几个词我想确认一下，你说的 X 是指什么？」 | 对齐术语 |
| A4 | 「如果我说错了你纠正我——你的意思是 ……？」 | 复述式追问 |
| A5 | 「这是一个事实，还是一个判断？」 | 分档 |
| A6 | 「再往前一步，如果这件事真的发生了，接下来会怎样？」 | 推演后果 |
| A7 | 「这个数如果错一半，你的结论还成立吗？」 | 敏感度测试 |
| A8 | 「你是在说服我，还是在想清楚？」 | 指出对话性质变了 |
| A9 | 「你刚才说的和五分钟前那句，好像是两件事。」 | 指认内在矛盾 |
| A10 | 「你不想回答哪一条？那条通常就是关键。」 | 识别回避 |

**关于 A8、A9、A10 的纪律**：这三句会明显改变现场温度。用之前先确认两件事——对方是否已经充分表达过、关系是否经得起。用完必须给一个台阶：**「我问得有点直接，你先不用答，回去想想也行。」**

## 强问句汇总（复盘用）

高质疑密度，**不要开场用，不要连用**。

| 层 | 问句 | 用在第几轮最合适 |
|---|---|---|
| 1-11 | 你是不是其实在追一个说不出口的目标？ | 第 2 轮 |
| 2-10 | 这些证据里，有多少是你为了支持这个结论才去找的？ | 第 2 轮 |
| 3-18 | 你希望这个假设不成立吗？如果它不成立，是不是就不用干了？ | 第 3 轮 |
| 4-14 | 如果三年后这件事失败了，最可能的原因是什么？ | 第 2 轮 |
| 5-18 | 一年后回头看，最可能让你后悔的是哪一笔支出？ | 第 3 轮 |

**使用节奏**：一场 90 分钟的追问，强问句不超过 2 条，两条之间至少隔 20 分钟。说出口之前先给对方一句授权：**「这个问题有点直接，你可以不答，但我还是想问。」**

## 不该问的问题

下面这些句式看起来像在追问，实际是在关闭对话。列出来是为了让追问者能自我识别。

| 句式 | 为什么有害 | 换成什么 |
|---|---|---|
| 「你有没有想过……？」 | 暗示对方没想到，触发防御 | 「我们来看一下这一点：……」 |
| 「这不就是……吗？」 | 把对方的想法降级成已知套路 | 「换个说法的话，它和……的区别在哪？」 |
| 「万一……怎么办？」（只有半句） | 没有具体场景的反例，等于制造焦虑 | 「具体哪个月、谁会先出问题？」 |
| 「你凭什么觉得……？」 | 质疑动机，不是质疑逻辑 | 「这个判断来自哪一次观察？」 |
| 「那照这么说，是不是也可以……」 | 滑坡，看起来是逻辑其实是威胁 | 「有没有一个更小的版本能达到同样目的？」 |
| 「我早就说过……」 | 记账，不是追问 | 不换，删掉 |
| 「理论上讲……」 | 用抽象压具体 | 「现实里最近一次发生是什么时候？」 |
| 「你先别急。」 | 否定了对方的情绪，通常会让对方更急 | 「慢慢说，我记着。」 |

**一条判据**：如果你问完之后，对方的第一反应是**解释自己**而不是**思考问题**，那么这句话属于上表。停下来，换一句。

## 自问版：把问句改成第一人称

一个人用这套方法时，问句要换说法，否则会自己绕过自己。改写规则三条：

1. **「你」改「我」**：1-1「这件事做成之后，哪个数字会变？」→「做成了，哪个数字会变？」
2. **加一句「写下答案」**：只在脑子里回答的问题，会自动答成最舒服的版本。**写下来的必须是一句完整的话，不是几个词。**
3. **答不上来就留一个空**：不许用「大概」「差不多」填空。留空是有效产出。

### 单人速问卡（照这个顺序念）

```text
【目标】做成是什么样？哪个数从几变到几？什么时候看？什么样算失败？
【事实】我知道的里面，哪些是我亲眼见的？哪些是听来的？
【假设】要成立，必须先成立的三件事是什么？哪件最没把握？
【反例】哪个月、谁、发生什么，会让它崩？我怎么发现？
【代价】最坏赔多少？因为做这个我放弃了什么？
【替代】预算砍到 1/5 先做哪件？如果不做会怎样？
【收口】哪一条最致命？我下一步去验证哪一条？什么时候？
```

全程 15~20 分钟。**结论必须写下来**，否则第二天会恢复成原来的想法。
