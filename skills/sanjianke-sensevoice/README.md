# 三剪客 · 多语言语音理解（识别 / 语种 / 情感 / 事件） Skill

把一段音频交给它，除了文字，还能拿到语言、情绪和笑声掌声这类事件标签：安装、推理参数、长音频与说话人日志组合、服务化部署和常见坑。

---

## 前置条件

- 一个可用的 Python 环境；仓库依赖通过 `requirements.txt` 安装。
- 首次运行需要访问模型托管站下载权重（默认按名称 `iic/SenseVoiceSmall` 拉取），请预留磁盘与网络时间。
- 想要 GPU 推理，需要可用的 CUDA 环境；没有 GPU 就退到 CPU，速度明显更慢。
- 走 Docker 路线需要本机 Docker；GPU 容器需要容器运行时支持 GPU 透传。
- 走 llama.cpp / GGUF 单文件二进制路线不依赖 Python，但需要预编译二进制或自行编译。
- 免 VAD 的长音频参考脚本依赖 ffmpeg 做音频解码。
- 要微调的话，额外需要训练框架源码、按约定整理的数据清单，以及足够的显存。

---

## 使用

1. 按 `SKILL.md` 的「安装」一节装依赖并准备好模型。
2. 按场景挑推理路径：长音频走 VAD 分段；全是 30 秒内短音频就去掉 VAD 改为定长组批；不接受 VAD 就用定窗重叠脚本；要按角色分段就组合说话人模型。
3. 转写结果统一过后处理函数清洗特殊标记，再按需打开标点与逆文本归一化。
4. 需要给别的程序调用时，起 FastAPI 服务或 Docker 容器；需要图形界面就起网页界面。
5. 详细参数、可复制示例与排错对照，见 `SKILL.md`。

## 安全

- 不内嵌任何密钥；本 Skill 不要求账号或 API Key。
- 模型代码可以按 URL 远程加载，这条路径等于执行远端代码，只对可信来源启用，并优先固定到具体版本而不是跟随主干。
- 音频内容可能涉及他人隐私与肖像/声音权益，转写与情感分析结果请只在获得授权的范围内使用。
- 服务化部署会常驻监听端口，默认监听地址建议限制在内网，不要直接暴露到公网。
- 情感与事件标签是模型推断结果，不能当作事实结论用于对个人的评价或决策。
