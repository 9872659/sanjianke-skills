## 人话入口

| 参数 | 对应什么 |
|---|---|
| `--image 图.png` | 自动匹配第一个必填的图片参数（本地文件会自动上传换 `asset://`）|
| `--video 视频.mp4` | 视频参数 |
| `--audio 音频.mp3` | 音频参数 |
| `--text "…"` | 文本 / 提示词 |
| `--set 名=值` | 兜底，任意参数（可重复）|

## 子命令

| 子命令 | 扣费吗 | 干什么 |
|---|---|---|
| `info` | 免费 | 应用信息 + 自检 |
| `params` | 免费 | 参数表（label 对照）|

## 退出码

`0` 成功 · `2` 用法错 · `4` 需 `--yes` · `5` 预算不足（**不发请求**）· `6` 调用失败 ·
`7` 轮询超时（用 run_order_id 再查，**别重提**）· `1` 内部错 · `130` 中断
