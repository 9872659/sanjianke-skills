# 通用说明

本文件是跨包通用的部分：权限与用途、异步任务机制、计费口径、错误码、能力边界。

---

## 一、权限与用途说明

| 项目 | 内容 |
|---|---|
| **读什么** | 用户显式传入的图片/音频/视频 URL；`--key` 或环境变量里的 API Key；`~/.a7w/config.json`（仅取 `key` 字段）；本地待上传文件（`upload` 子命令）；可选调用 `ffprobe` 探测本地媒体 |
| **写什么** | 只在标准输出/标准错误打印结果与进度。**不写任何文件、不改任何配置**（`--json` 也是打到 stdout）。上传的文件由上游平台暂存 |
| **连哪里** | 只连 `--base` 指定的一个地址，默认 `https://api.a7w.cn/api/v1`。不连任何第三方埋点、不回报任何遥测 |
| **凭据** | **包内零凭据**。Key 只从命令行/环境变量/本机配置文件读，不写入任何文件、不进日志、不进错误信息 |
| **网络副作用** | 会向平台提交**计费任务**并消耗点数（见第三节）。`--dry-run` 下不发任何写请求 |

**最低权限**：只需要一把普通 API Key。不需要管理员权限、不需要读写他人数据。
Key 的 `permissions` 需要允许 `app` 类型（本包全走应用 API）。

## 二、异步任务机制

`pic_lipsync/submit` 与 `smart_clip` 的三个提交接口都是**异步**的：

```
提交 → 立刻返回 task_id（此时点数被冻结）
  ↓
轮询 GET /api/v1/tasks/{task_id}   或   POST /api/v1/apps/<app>/query
  ↓
status: pending → processing → completed / failed / cancelled
  ↓
completed 时拿到视频地址
```

**查任务的三条注意：**

1. 任务**只能由创建它的 Key 所属租户和用户**查询。换 Key 查不到。
2. 轮询间隔建议 10~30 秒并逐步退避。数字人实测 4.9 秒的音频约 **36 秒**出片；
   剪辑更长。本包默认起始 10 秒、每次 ×1.3、封顶 30 秒。
3. **提交成功 ≠ 出片成功**。必须等 `completed` 才算成。超时不代表失败 ——
   任务可能还在跑，用 `task <task_id>` 继续查。

也可以用 `callbackUrl` 让平台在终态时回调，省掉轮询。**注意字段是驼峰 `callbackUrl`**。

## 三、计费口径

| 接口 | 计费方式 |
|---|---|
| `pic_lipsync/submit` | **按输入音频实际时长**结算 |
| `smart_clip/realman_broadcast` | **按输入媒体时长**（探 `videoUrl`，探不到素材） |
| `smart_clip/broadcast_mixcut` | 按输入媒体时长（探 `audioUrl`，无音频则探素材） |
| `smart_clip/news_mixcut` | 按输入媒体时长（探素材；传了 `videoDuration` 则跟随） |
| `smart_clip/template`、`template_detail` | **免费**（同步查询） |
| `voice_tts/list_voices` | **免费** |

**三条硬规则：**

1. **唯一可信的数只有响应里的 `usage.points_cost`**。平台页面上、`pricing` 接口里
   的字段价与实际结算价**经常不一致**，别拿字段价当预算依据。
2. **探不到媒体时长会直接拒绝创建任务**，不会用默认时长兜底。这是平台刻意的设计
   （避免不明确扣费）。所以素材/音频 URL 必须公网可达且能被探测。
3. **预算要留 10% 余量** —— 平台侧探测到的时长**可能比本地实测高约 10%**
   （实测 14.16 s vs 12.75 s）。

提交时响应里的 `frozen_points` 是冻结的点数，完成后按实际结算。
本包的 `--budget` 单位是**点**，超了立刻中止并返回退出码 5。

## 四、错误码

| HTTP | code | 含义 | 怎么办 |
|---|---|---|---|
| 400 | `invalid_request` | 参数缺失或格式错 | 看 `msg`；本包大部分这类问题在本地就拦下了（退出码 4） |
| 401 | `auth_failed` | Key 缺失或无效 | 换 Key |
| 402 | `insufficient_points` | 点数不足 | 充值 |
| 402 | `key_quota_exceeded` | 该 Key 额度用完 | 换 Key 或提额 |
| 403 | `permission_denied` | 无权调用该应用 | 给 Key 开 `app` 权限 |
| 404 | `not_found` | 应用/任务不存在 | 检查应用代号与 task_id |
| 429 | `queue_limit_exceeded` | 排队任务达上限 | 等前面跑完 |
| 5xx | `server_error` | 服务异常 | 重试 |

**额外实测到的两类：**

- **网关 502**（nginx 返回 HTML）：中转层偶发，**不是业务错误**，隔几秒重试即可。
  本包对 502/503/504 与连接错误自动重试（GET 3 次、POST 2 次）。
- **`{"code":0,"msg":"任务处理失败，请稍后重试"}`**：**上游服务侧**失败，
  参数通常没问题。换时间重试，或改用该能力的另一个分支（如 TTS 的异步版）。

## 五、能力边界

**能做：**

- 一张人物图片 + 音频 → 口播视频（`pic_lipsync`）
- 口播视频 / 音频 / 标题 + 素材 → 套模板成片（`smart_clip`）
- 文案 → 音频（`voice_tts`，作为数字人的前置）
- 模板列表与结构详情查询、任务轮询、余额与价格查询、临时文件上传
- 本地预检（素材格式/时长/分辨率/地址重名/字幕边界/元水印），**不花点数就发现问题**

**不做：**

- **不做形象库**：`pic_lipsync` 只吃 `image_url`，没有"注册一次反复用"的 avatar_id。
  想复用就把图片放在自己的图床/CDN 上，每次传 URL。
- **不做声音克隆**：本包不包含 `voice_tts/clone_voice`；音色只能用平台已有的。
- **不做文案驱动 + 混剪**：`broadcast_mixcut` 当前不支持 `content + speakerId`。
  要文案驱动只能走 `pic_lipsync` 的 text 模式（且仍需参考音色音频）。
- **不给 `news_mixcut` 配旁白**：该接口不吃 `audioUrl`。
- **不做本地剪辑**：本包**零 ffmpeg 硬依赖**，只做接口编排与预检。
  要本地转码/烧字幕/加 BGM，用别的工具。
- **不保证成片质量**：模板决定版式，素材决定观感，这些是模板与素材的事，不是本包能调的。
- **不代管版权与授权**：见下。

## 六、合规：人格权不是版权

⚠️ **数字人涉及的是人格权（肖像权、声音权），不是版权。人格权不可转让，只能取得本人授权。**

本包在接口层做了硬门禁：

- `lipsync` 与 `make` 两个子命令，**必须显式传 `--authorized`**，
  否则直接拒绝并以**退出码 7** 结束，一个请求都不发。
- 也可以用 `AVATAR_AUTOCLIP_AUTHORIZED=1` 常驻声明（适合你自己就是权利人的批处理场景）。
- 剪辑类命令默认**开启 AI 生成标识**（`watermarkShow` + AIGC 元水印），
  可用 `--no-ai-label` 关掉 —— **关之前先确认你所在地区的标识要求**。

**明确不要做的事：**

- 不要用明星、公众人物、来源不明的网络图片
- 不要用未获授权的他人声音做参考音色
- 不要把生成结果用于冒充真人、伪造证言、虚假宣传

中国的 AIGC 标识要求（`Label` / `ContentProducer` / `ProduceID`）由
`processRules.metadata.AIGC` 承载。本包 `build_ai_label_metadata()` 生成的格式是：

```json
{"AIGC":"{\"Label\":\"1\",\"ContentProducer\":\"…\",\"ProduceID\":\"AC-…\"}"}
```

注意 `metadata` 的 **value 必须是字符串**（上游硬性要求），所以里面那层要再 `json.dumps` 一次。
只支持**一组**数据。

## 七、这个包不内嵌任何密钥

Key 的解析顺序：

1. `--key`
2. 环境变量 `AVATAR_AUTOCLIP_KEY` → `A7W_API_KEY` → `A7W_KEY` → `LIKEADMIN_API_KEY`
3. `~/.a7w/config.json` 或 `~/.likeadmin/config.json` 的 `key` / `api_key` / `apiKey` / `token`

都没找到就报用法错误（退出码 2），并提示去 https://api.a7w.cn/ 注册领取。
