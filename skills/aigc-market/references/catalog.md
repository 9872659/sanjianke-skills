### `happy_horse` · Happy Horse

Happy Horse（HappyHorse-1.1 系列）面向文生/图生高质量短视频，采用统一多模态建模，可一阶段生成声画、支持多语言对白与多镜头场景衔接。计费按目标分辨率与生成秒数对应的参数档位计点。本能力为内测邀请制，正式调用前需完成内测申请。

| 接口 | 名称 | 模式 | 计费 |
|---|---|---|---|
| `submit` | 提交任务 | 异步 | 免费 |
| `create` | 创建任务 | 异步 | 免费 |
| `query` | 查询任务 | 同步 | 免费 |

`submit` 的**必填参数**：

| 参数 | 类型 | 说明 |
|---|---|---|
| `model` | string | 生成能力代号，决定 media 的使用规则 |
| `prompt` | string | 画面、镜头、风格与对白等描述；最多 2500 字，不能为空 |
| `duration` | number | 目标视频时长(秒)，整数；文生、图生、多参考支持 3～15 秒。本平台按该值计费 |
| `resolution` | string | 目标分辨率；支持 720P、1080P（也接受小写，平台会归一） |

`create` 的**必填参数**：

| 参数 | 类型 | 说明 |
|---|---|---|
| `model` | string | 生成能力代号；create 接口不支持 video-edit |
| `prompt` | string | 画面、镜头、风格与对白等描述；最多 2500 字，不能为空 |
| `duration` | number | 目标视频时长(秒)，整数；文生 / 图生 / 多参考支持 3～15 秒。本平台按该值计费 |
| `resolution` | string | 目标分辨率；支持 720P、1080P（也接受小写，平台会归一） |

`query` 的**必填参数**：

| 参数 | 类型 | 说明 |
|---|---|---|
| `task_id` | string | submit 返回的平台任务 id |
