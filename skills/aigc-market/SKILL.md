# AI 插件市场 · 全能创作

**aigc.a7w.cn** 是三剪客的 AI 插件市场：把散在各家的图片、视频、音频、数字人能力收进一个入口，**一个 Key 全部调用**。

不用同时开五六个账号、管五六份账单和配额。想换模型换插件，改一个 app 代号就行。

## 市场里有什么

**21 个插件 / 71 个接口**，按能力分成六类：

| 分类 | 插件 | 能做什么 |
|---|---|---|
| **图片** | `nano_banana` | 文生图、图生图、图片编辑，多规格模型可选 |
| **视频生成** | `full_video` `happy_horse` `grok_video` `wan` `seedance` | 文生视频、图生视频、视频编辑；`wan` 支持 9 图 / 5 音 / 5 视频混合参考 |
| **数字人 / 口播** | `image_human` `pic_lipsync` `lipsync` | 全驱动数字人、图片数字人、数字人对口型 |
| **视频剪辑 / 特效** | `action_transfer` `person_replacement` `dressing_diffusion` `smart_clip` `flashvsr` | 动作迁移、人物替换、AI 换装、智能混剪、视频超分 |
| **音频 / 音乐** | `voice_tts` `music_generation` `music_search` `mmaudio` `seedsvc` | 语音合成与识别、音色克隆、音乐生成、音效生成、视频配音、AI 翻唱 |
| **文档 / 检索** | `file_qa` | 文档问答与解析 |

完整接口清单与参数表见 [`references/catalog.md`](references/catalog.md)。

## ⚠️ 用之前：先拿一个 Key，否则跑不起来

**本 Skill 不内嵌任何密钥，也不代付费用。** 必须有一个 `api.a7w.cn` 的 API Key。

### 第一步：注册并创建 Key

1. 打开 **[算力集市 api.a7w.cn](https://api.a7w.cn/)** 注册（新用户有赠送点数，可以先白跑几条试试）
2. 在控制台创建一个 API Key，形如 `sk-xxxxxxxx...`
3. **完整复制保存** —— 多数平台只在创建时显示一次

### 第二步：把 Key 填进你正在用的地方

| 你在哪用 | 怎么填 |
|---|---|
| **AI 工具 / Agent 平台**（Kimi、扣子、SkillHub 客户端等） | 平台的**环境变量 / 凭证管理 / 插件配置**里加：`A7W_API_KEY` = `sk-你的key` |
| **本机命令行** | `export A7W_API_KEY=sk-你的key`（Windows 用 `$env:A7W_API_KEY="..."`） |
| **只想跑一次** | 命令里直接带 `--key sk-你的key` |
| **长期本机使用** | `python3 scripts/a7w.py login --key sk-你的key` |

**读取顺序**：`--key` 参数 → 环境变量 `A7W_API_KEY` → `~/.a7w/config.json`

## 怎么调用

### 零安装用法（推荐先看这个）

本 Skill 自带一个只用 Python 标准库的客户端，**不需要装任何第三方包**：

```bash
# 1. 配置你自己的 API Key（只需一次）
export A7W_API_KEY=sk-你的key

# 2. 看市场里有哪些插件
python3 scripts/market.py list

# 3. 看某个插件的接口与参数
python3 scripts/market.py schema nano_banana

# 4. 调用（异步任务自动轮询到结束）
python3 scripts/a7w.py call nano_banana create --json '{"prompt":"一只戴墨镜的柴犬"}'
```

### 直接 curl

```bash
curl -sS -X POST "https://api.a7w.cn/api/v1/apps/nano_banana/create" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"一只戴墨镜的柴犬"}'
```

### 同步 vs 异步

| 模式 | 表现 | 怎么处理 |
|---|---|---|
| **同步**（`call_type=1`） | 直接返回结果 | 一次请求搞定 |
| **异步**（`call_type=2`） | 返回 `task_id` | 轮询 `GET /api/v1/tasks/{task_id}` 到 `status=completed` |

`a7w.py call` **默认自动轮询到结束**；加 `--no-wait` 只提交不等。

## 计费与限制

- **按点数计费**，各插件、各接口单价不同，部分接口按次固定价、部分按视频秒数或 token 量
- 异步任务**提交时预冻结点数**，完成后按实际用量结算
- **不要重复提交同一个任务** —— 每次提交都可能产生费用
- 平台同时给出**标准价**和**租户实际结算价**，两者可能差很大，**以实际扣费为准**
- 查询类接口（`query` / `list_*` / `template`）通常免费

各插件的具体单价见 [`references/catalog.md`](references/catalog.md)。

## 常见坑

| 坑 | 表现 | 怎么避 |
|---|---|---|
| **拿本地路径当输入** | 报参数错误 | 图片/视频/音频入参都是**公网可访问的 URL**，不支持本地路径，也不支持 Base64（`file_qa`、`voice_tts` 的 `stt` 等少数接口支持文件上传，见各自文档） |
| **重复提交异步任务** | 扣两次钱 | 提交后先记下 `task_id`，用查询接口确认状态 |
| **轮询被网关重置连接** | `WinError 10054` | 本 Skill 的客户端内置重试（网络/5xx 才重试），自己写脚本要加 |
| **以为单价是统一的** | 预算算不准 | 每个 app、每个接口单价都不一样，还有租户价与标准价的差别 |
| **语言/地区参数没传** | 结果语言不对 | 涉及语音的插件多数有 `language` / `lang` 参数 |
| **长任务超时** | 客户端先超时，服务端其实已完成 | 视频类任务常见，适当放大超时或改用 `--no-wait` + 手动查 |

## 权限与用途说明

| 能力 | 是否申请 | 用途 |
|---|---|---|
| 网络访问 | **申请** | 调用 `api.a7w.cn` 的插件接口（本 Skill 唯一的联网行为） |
| 读取文件 | 仅读取用户指定的输入文件 | 少数支持上传的接口用作入参 |
| 写入文件 | 仅在传入 `--out` 时 | 保存接口返回的 JSON 或下载成片 |
| 子进程 / 后台常驻 | 不申请 | 脚本执行完即退出 |
| 凭证 | 读取**使用者自己**提供的 API Key | 从 `~/.a7w/config.json` 或环境变量读取 |

**不内嵌任何密钥。** 脚本只把 Key 发往 `api.a7w.cn`，不发送到其他任何地址。

## 能力边界

- **不提供 API Key**：Key 必须由使用者自己获取
- **不代付费用**：调用消耗的是使用者自己账号的点数
- **不保证可用性**：接口由各上游模型服务提供，可用性、限流与计费以站内为准
- **不替代内容合规审查**：生成内容的合规责任由使用者承担
- **不含平台数据抓取类接口**：本 Skill 只覆盖创作类能力
