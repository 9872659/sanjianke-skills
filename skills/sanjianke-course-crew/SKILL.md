# 三剪客 · 课程教研组

## 这是产品线 L3：多智能体协作型

| 层 | 形态 | 同族已有的包 |
|---|---|---|
| **L1 单点生成型** | 一个输入 → 一个产出，开箱即用 | 爆款标题工坊、一稿多平台改写 |
| **L2 智能体型** | **单循环**：抽档 → 写 → 自检 → 迭代（**一个声音在自我迭代**） | 课程生产线、课件配图与排版、内容质量闭环 |
| **L3 多智能体协作型** | **多角色分工互审**，一条命令出成品 | 内容团队、评审委员会、短剧剧组、**← 本包** |

### 与 L2 的分界（拿 `课程生产线` 与 `课件配图与排版` 对照）

| 维度 | L2 · 课程生产线 | L2 · 课件配图与排版 | **L3 · 课程教研组（本包）** |
|---|---|---|---|
| 起点 | 一个主题 | 一份讲义 | 一个主题（**从课程设计开始**） |
| 角色数 | 1 | 1 | **4**（教研 / 讲师 / 课件 / 质检） |
| 目标函数 | 一条流水线：出大纲 → 写讲义 → 出习题 | 一条链路：分页 → 写页 → 配图 → 排版 | 四个**互不相同甚至冲突**的目标 |
| 最小单位 | **节** | **页** | **整门课**（节 + 页 + 裁决一起交付） |
| 产出物 | 大纲 / 讲义 / 习题（**纯文本三件套**） | 逐页 PNG + 备注 + `deck.html`（**排版产物**） | 设计卡 + 讲义 + 课件方案 + 质检记录 + 裁决（**纯文本**） |
| 谁能否谁 | 没有人能否任何人 | 没有人能否任何人 | 教研**能否掉设计**、课件**能说「这页放不下」**、质检**能否决** |
| 上下文 | 单条链共享 | 单条链共享 | **信息不对称**：讲师自评不进课件/质检，课件意见不进质检 |
| 课程特有的闸门 | 大纲结构校验 | 文字溢出（像素级） | **目标可考核性 / 知识点依赖 / 术语一致性** |
| 失败时 | 报"结构不合格" | 报"这页放不下（实际像素 vs 可用像素）" | 报"是谁在第几轮否掉了什么、引用哪句讲义原话" |

**一句话**：L2 问的是"这份讲义还能不能更好、这页放不放得下"；
L3 问的是"这门课该不该这么设计、**谁说了算**"。

> **⚠️ 三条产出侧的边界，先看清楚再选包**（本包只做第三条）：
>
> - 要**大纲 / 讲义 / 习题的纯文本三件套** → 用 `sanjianke-course-outline`（L2）；
> - 要**逐页 PNG / 排版 / 配图** → 用 `sanjianke-slide-kit`（L2，需要 pillow 与中文字体）；
> - 要**四个立场从课程设计开始协作、课件能说放不下、质检能否决、并且留下裁决记录** →
>   用本包。
>
> 本包**不出图、不出 PPTX**（`python-pptx` 不是标准库、本包不依赖它），
> 课件方案只出**文本**（页型 / 标题 / 要点 / 备注）。要成片课件，
> 把本包的 `deck.json` 交给既有的课件排版包做渲染。

## 四个角色与职权

| 角色 | 目标函数 | 产出物 | 否决权 |
|---|---|---|---|
| **教研** | 这门课值不值得学、给谁学、学完能做到什么、拿什么考核 | 课程设计卡（课程目标 / 受众 / 前置知识 / 逐单元目标 / 考核标准） | **能否掉自己的设计并重开**（`--design-retries`） |
| **讲师** | 每一节都要讲透 | 逐节讲义 + 自评（`self_check`，**课件与质检都看不到**） | 无 |
| **课件** | 每一页放不放得下、版式能不能看 | 逐页课件方案（页型 / 标题 / 要点 / 备注）+ **放不下清单** | **能说「这页放不下」**并要求讲师拆（`--slide-rework`） |
| **质检** | 前后一致 + 事实与合规 | **问题清单（每条必须引用讲义原句）** + 风险裁决 | **能否决**（`--inspect-rework`） |

零成本看这张表：

```bash
python3 scripts/run.py roles
```

### 一次协作的走向

```
教研 design ──▶ 讲师 lecture ──▶ 课件 slides ──┬─ fits ──────▶ 质检 inspect ──┬─ pass/fix ─▶ 交付
   ▲                     ▲                    │                          ├─ send_back ─┐
   │                     └── 放不下清单（引讲义原句）┘ cannot_fit               └─ veto ──────┼─▶ 带未决项产出
   └── 设计卡不达标 / 重开（上限 --design-retries）      └──── 讲师按反馈改写（上限给定）──┘
```

**三个否决是串行关系，不是投票**：设计卡不达标就轮不到讲师；课件说放不下就先改讲义；
质检在两者之后仍可**独立**否决 —— 它看不到课件的结论。

## 怎么用（命令行）

### 第 0 步：获取 API Key

到 **[api.a7w.cn](https://api.a7w.cn/)** 注册，创建一个 API Key（形如 `sk-...`）。

### 第 1 步：装依赖

**零依赖。** 只要机器上有 Python 3.7+：

```bash
python3 --version
```

`scripts/run.py` 是全部实现，`scripts/a7w.py` 是零依赖 API 客户端
（只用 `urllib` / `json` / `mimetypes`）。**没有任何 `pip install`。**

### 第 2 步：填 Key

```bash
# Linux / macOS
export A7W_API_KEY=sk-你的key

# Windows PowerShell
$env:A7W_API_KEY="sk-你的key"
```

也可以存进配置文件反复用（推荐）：

```bash
python3 scripts/a7w.py login --key sk-你的key
```

### 第 3 步：先做零成本自检（不联网、不花点数）

```bash
# 看四个角色的职权与信息不对称设计
python3 scripts/run.py roles

# 报价：这次协作大概花多少 token（金额要你自己填单价）
python3 scripts/run.py cost --file 材料.md --chapters 3 --sections-per-chapter 1

# 只看将要发出去的提示词，不调模型不花钱
python3 scripts/run.py run --brief 材料.md --dry-run
```

### 第 4 步：跑第一个例子

```bash
# 一条命令出整门课：教研 → 讲师 → 课件 → 质检（带裁决、轮次上限与明确出口）
python3 scripts/run.py run --brief 材料.md --chapters 3 --sections-per-chapter 1 \
    --target-chars 800 --max-pages 8 --outdir /tmp/cc

# 读回全过程记录：谁在第几轮否掉了什么、引用哪句原话
python3 scripts/run.py log --outdir /tmp/cc
```

`--outdir` 里会落这些文件：

| 文件 | 内容 |
|---|---|
| `final.md` / `final.json` | 定稿：讲义全文 + 设计卡 + 课件方案 + 质检裁决 + 收敛判定 |
| `REPORT.md` / `log.json` | **全过程记录**：职权表、裁决记录、动作流水、信息不对称实检、终止判定、成本 |
| `design.json` / `design.md` | 教研交的课程设计卡 |
| `lectures.json` + `lectures/*.md` | 逐节讲义（另存人读版，含**不进下游**的自评栏） |
| `deck.json` + `slides/deck-r*.md` | 逐页课件方案（含放不下清单） |
| `inspect/inspection-r*.{md,json}` | 每轮质检：问题清单 + 锚定判据 + 本地兜底说明 |
| `state.json` | 断点。**同一个 `--outdir` 重跑只会打印"已在断点里，跳过"** |

### 也可以一个角色一个角色地跑

```bash
# 教研出设计卡（不达标会自动重开）
```

## 信息不对称：本包凭什么不是"一个模型演四个角色"

**四个角色共享同一份上下文**是假协作的根源：课件永远看得到一个它不该看到的
「讲师自评」，质检永远顺着课件的结论走 —— 产出里的"独立判断"其实是同一个声音的
自言自语，而报告里写着一堆"多方确认"。

本包用**两层机制**把这件事做成结构性的：

1. **字段白名单** —— `ROLES[*]["inputs"]` / `["forbidden"]` 是提示词模板真实读的数据，
   被排除的字段在物理上没有进入 prompt 的路径。给课件的设计卡只是一份**窄字典**
   （课程名 + 逐单元标题），讲师拿得到学习目标但**拿不到考核标准**。
2. **调用前实检**（`assert_isolation()`）—— 拿被禁字段的标记词对**真实提示词文本**
   扫一遍，泄漏就抛 `IsolationBreach`、**中止这次调用**（一个字都不发出去）。
   每次调用的判定逐条写进产物与 `REPORT.md`，外部可复核。

三条最关键的排除：

| 角色 | 看不到什么 | 为什么 |
|---|---|---|
| **课件** | 讲师的 `self_check`（自评） | 作者说"我觉得这段讲得清楚"会污染版式与容量判断 |
| **质检** | 讲师的 `self_check` **与**课件的 `slide_issues` | 质检若知道课件已经逐页验过，就会顺着放行。它的提示词里明写「**本团队内部没有向你提供任何风险结论**」 |
| **讲师** | 单元的 `assessment`（考核标准） | 讲师一旦看到考核标准，就会把讲义写成对着考点划重点的形态 —— 那是备考资料，不是课 |

**真机实测**（1 单元 1 节，5 次调用）：`slides` 检查 6 个标记词（排除
`self_check` / `instructor_self_check`）、`inspector` 检查 13 个标记词（排除
`self_check` / `slide_issues` / `slides_verdict`），**全部通过、零泄漏**，
产出里 `information_asymmetry.all_ok = true`。

**反向验证**（零成本）：往课件的提示词里注入「顺带附上：讲师自评如下」→ 当场拦下；
往质检的提示词里注入「课件结论：放不下清单已处理」→ 三个标记词同时命中。

## 裁决与终止条件（谈不拢有明确出口）

| 否决方 | 条件 | 后果 | 上限参数 |
|---|---|---|---|
| 教研 | 设计卡不达标（目标不可考核、缺考核标准、前置知识为空、目标太泛） | 重开 | `--design-retries` |
| 课件 | 逐页规格放不下（要点超 6 条 / 单条超 40 字 / 标题超 30 字 / 备注越界 / 超页数） | 打回讲师按清单改写 | `--slide-rework` |
| 质检 | 有任何一条 **高** 严重度问题，或本地闸门命中 | 打回，附必须修清单 | `--inspect-rework` / `--rounds` |
| 质检 | 判 `veto` | **直接终止**，产出带未决项 | 无（否决权） |

### 六种显式出口（**不许假装谈拢**）

| 出口 | 什么时候走 | 怎么处理 |
|---|---|---|
| `design_retries_exhausted` | 设计卡重开上限用尽仍不达标 | **升级给人看**（真机第一次跑就是走这个出口） |
| `slide_rework_exhausted` | 课件说放不下，重做上限用尽 | 带未决项产出 |
| `inspect_send_back_exhausted` | 质检打回次数用尽仍不放行 | 带未决项产出 |
| `rounds_exhausted` | 总轮次用尽 | 升级给人看，附全部未决项 |
| `no_effective_change` | 连续两轮修订"没有实质改动"（正文相似度 ≥ 0.86） | 升级给人看 —— 继续跑只是烧钱 |
| `stalled_same_quote` | 质检连续两轮指向**同一段文字**仍被拒 | 升级给人看 —— 讲师改不动它 |

走任何一种出口，退出码都是 **3**，`escalation.unresolved` 里逐条写明未决项，
stderr 打印标红汇总。**跑不通就说跑不通。**

### 本地兜底：模型说了不算的五件事

1. 有 **高** 严重度问题却判 `pass` → 强制改判 `send_back`
2. 本地**违禁词**扫描命中（且词都在安全替代表里）而质检判 `pass` → 降级为 `fix`，
   由**本地**替换，不再花一次调用重写整节讲义；不在表里的 → `send_back`
3. 本地**占位符** / **照抄示例**扫描命中而质检判 `pass` → `send_back`
4. 本地**课程闸门**（目标可考核性 / 知识点依赖 / 术语一致性）命中而质检判 `pass`
   → `send_back`
5. 本地按逐页规格复核发现放不下而课件判 `fits` → 强制改判 `cannot_fit`；
   反过来，课件说 `cannot_fit` 却**引不出讲义原句** → 诉求不算数、降级为 `fits`

每一次改判都**单独入账**（`log.rulings` 里多一条「质检（本地兜底）→ 改判为 …」），
理由写进 `forced_by_local`。**读报告的人要能看出是谁改的判。**

### 驳回也必须留理由

`check_ruling_completeness()` 在收口时核一遍：凡是
`send_back` / `veto` / `cannot_fit` / `rejected` / `ineffective` 这类否决性裁决，
理由少于 8 个字就判「无理由裁决」→ 整次运行退出码 3 并逐条指出是哪一条。

## 八道本地硬闸门（确定性，跑两次结果一样，可直接进 CI）

命中一律：**压分 + 标红 + stderr 汇总 + 退出码非 0**。

| # | 闸门 | 拦什么 | 判据 |
|---|---|---|---|
| 1 | **合规** | 广告法违禁词 + **教育类特有**（保过 / 包过 / 包学会 / 保证提分 / 保就业 / 包分配） | 本地正则表；「最X」可枚举上下文豁免（**句首不豁免**）+「第一」序数/枚举豁免 + **警告语境豁免** |
| 2 | **占位符残留** | `{}` / `[待填]` / `XXX` / `（此处省略）` / `TODO` / `待补充` | 六条正则，括号那条只认枚举词 |
| 3 | **照抄提示词示例** | 把提示词里的示例原句写进课程产出 | 去标点相等 / 二元组 Jaccard ≥ 0.75 / **覆盖度 ≥ 0.60**；长度守卫是**相对阈值** `max(6, len(示例)//2)`；覆盖度判据外加**适用窗口**（片段 ≥ 24 字才启用） |
| 4 | **学习目标可考核性**（本包特有） | 「了解 / 熟悉 / 掌握 XX」这类**无法考核**的目标 | 不可考核动词一票否决 + 必须有可观察行为或可测标准；逐条判、逐条列出 |
| 5 | **知识点依赖**（本包特有） | 讲义里用到但**前面从没讲过**的术语 | 术语候选按五类来源抽取 + 出现次数 ≥ 2 + 通用词停用；「出现过」不算「讲过」 |
| 6 | **术语一致性** | 同一节里同一概念的两种叫法 | 同长度 + 只差一个字（`完播率` / `完看率`） |
| 7 | **质检锚点** | 编造引文 | 每条问题必须引用讲义真实存在的句子（`exact` / `substring` / `fuzzy`）；未锚定率 > 40% 判「定位失败」，编造的引文**不进讲师的修订输入** |
| 8 | **成本上限 + 产出不许进包** | 超 `--budget`；`--outdir` 在包内 | 预算核验**提到每个会花钱子命令的第一步**，超了就地停、一次调用都不发；`--outdir` 在包内 → 退出码 2 |

### 闸门一的两条实测修正（都是真机跑出来的）

**① 教育类效果承诺单列一档高风险、无豁免。** 广告法明确禁止教育、培训广告对通过
考试、获得学位学历或合格证书作保证性承诺，所以 `保过 / 包过 / 包学会 / 保证提分 /
保就业 / 包分配 / 一次通过` 全部高风险拦截。

**② 产出侧与材料侧口径分开。** 同族的评审委员会踩过：评审自己写
「本文已删除保证提分的表述」这类**提到式**表述，被自己的闸门拦下。本包是课程教研
场景，这个形态更常见 —— 质检结论里必然要写「不得出现保过这类承诺」。所以：

- **产出侧**（讲稿 / 课件方案 / 质检结论）：前后 24 字内有
  `禁止 / 不得 / 不许 / 违规 / 删除 / 避免 / 杜绝 / 风险 / 反面 / 错误示范` 等标记词
  → 判为"在**提到**禁令而不是在承诺"，放行，但**每一处都留原因**（`exempted` 列表）；
- **材料侧**（用户给的 `--brief`）：**照拦不误，不走这个豁免** ——
  用户材料里写了就是写了。

**两条真机误伤也已修正**：讲义里分条列举常见错误几乎必然写「**第一**，边看边剪。
第二，只记内容。」—— 这是**枚举标记**，与「销量第一」无关，现在只在**句首 + 紧跟
顿号/逗号**时豁免（「他是第一名」照拦）；
「组名是你排序、复查的**唯一**线索」是日常中文，现在只拦
`唯一(选择|指定|授权|官方|认证|品牌|推荐|渠道|合作|代理)` 这类排他性搭配。

### 闸门三为什么是三条路径而不是两条

**教训来自同族的实测事故**：提示词里写过的示例，哪怕明确标着"这是错的写法"，
模型照样照抄 —— 那一批**最高分**的产出一字不差就是提示词里的示例。

而 Jaccard 在两个长度差几十倍的对象之间会被**稀释**：把一条 40 字的示例原样
塞进一份 2400 字的产出，Jaccard 只有 **0.171**（旧判据放行 ❌），
而覆盖度是 **1.000**（新判据拦下 ✓）。所以加了第三条路径：
**示例二元组的覆盖度 ≥ 0.60** —— 覆盖度只看"示例被抄了多少"，不看产出有多长。

**治本的一面在提示词侧**：提示词里**不许出现任何一份可直接复制的完整产出**，
举例统一用**跨主题**示例（社区团购选品 / 机械制图停机点 / 架子鼓坐姿，
与课程主题明显不搭），登记在 `PROMPT_SAMPLES` 常量里。

### 学习目标可考核性：标定过程（一次真机误伤）

第一版要求「有行为**且**有刻度」，真机第一次跑就把**两份合格的目标**判成不可考核
（行为已经可观察，只是没写刻度），两张设计卡连续被否，整次运行停在
`design_retries_exhausted`、一个讲义都没写。

误伤的代价很实在：**一个天天误报的闸门会被用户关掉**，而闸门关掉之后真正该拦的
（「了解 XX」这一类）也一起不拦了。所以现在：动词一票否决 + 必须落到行为或刻度上，
**刻度不再单独构成失败**。

### 闸门五：「出现过」不等于「讲过」

早先的版本把**每一节出现过的术语**都记进"已讲过"，于是这个闸门**永远不可能触发**。
现在只有**引入过**的术语才进入已知集合：讲师自报的 `terms_introduced` 里有它，
或正文里用定义句式当场解释掉了（`X，指的是…`）。

术语抽取也收了三轮（真机台账 17 条 → 6 条 → 3 条）：要求候选**前面是边界**、
**引号里的例证只出现一次就丢掉**、**本节出现 ≥ 2 次才算术语**。
第 3 版的判据来自一个观察：真正的知识点在一节里会被反复使用
（`拉片` / `时间码` / `分镜清单`），而「老板讲用料」这种**引用一次的例子**只出现一次。
**一个打不响的闸门等于没有闸门；一个天天误报的闸门会被关掉。**

## 退出码（可直接用于 CI）

| 码 | 含义 |
|---|---|
| 0 | 收敛：课件逐页放得下 + 质检放行 + 硬闸门全过 |
| 2 | 用法 / 配置错（文件不存在、`--outdir` 在包内、`--budget` 没配单价、参数超区间、长选项缩写） |
| 3 | **硬闸门命中**，或**未收敛**（含质检否决） |
| 4 | 调用失败（网络 / 鉴权 401 / 点数 402 / 模型名 404） |
| 5 | 预算超限，**已就地中止，未发起任何调用** |
| 130 | 用户中断（Ctrl+C） |
| 1 | **没预料到的异常**（代码 bug）：`--json` 下给 `internal` 信封 + **完整 traceback 到 stderr** |

`--json` 的失败信封：`{"ok": false, "exit": <码>, "error": {"kind": …, "message": …}}`，
`kind` 取 `usage` / `gate` / `call` / `budget` / `interrupt` / **`internal`**。

> ⚠️ **Windows PowerShell 5.1 的 `>` 重定向会写成 UTF-16LE**。
> 存 `--json` 结果请用 `| Out-File -Encoding utf8 <文件>` 或脚本的 `--out`。

## 排错

| 现象 | 处置 |
|---|---|
| `没有找到 API Key` | `--key` / `A7W_API_KEY` / `a7w.py login` 三选一 |
| `鉴权失败（401）` / `点数不足（402）` | 到 https://api.a7w.cn/ 重新创建 Key 或充值 |
| `模型不存在（404）` | `run.py models` 现查在架名，别写死 |
| 上游 502/503/504、`网络抖动（WinError 10054）` | 脚本自动退避重试 4 次；真机上重试一次就成功过 |
| `预估成本已超预算，未发起这次调用`（退出码 5） | 提高 `--budget`、减少节数/篇幅，或先 `cost` 试算 |
| `用了 --budget 就必须给 --price-in / --price-out`（退出码 2） | 补上单价 —— 不给单价时 `--budget` 是个**假保险丝** |
| `出口 = design_retries_exhausted` | **这是真实结论，不是 bug**。看 `unresolved` 里逐条原因（通常是目标不可考核），加 `--design-retries` 或人工改设计卡 |
| `出口 = slide_rework_exhausted` | 看放不下清单要拆哪几页；压低该页的内容量，或提高 `--max-pages` |
| `出口 = inspect_send_back_exhausted` | 看 `reason` 与必须修清单；提高 `--inspect-rework` 或人工定口径 |
| `出口 = no_effective_change` | 讲师在原地打转。**继续加轮次只会烧钱**，看必须修清单是不是写得太抽象 |
| `出口 = stalled_same_quote` | 质检两次指向同一段文字。通常是那两个要求互相冲突，需要人来定口径 |
| 质检裁决 `send_back` 但 `issues` 是空的 | 本地兜底改判：看「质检（本地兜底）」那条裁决的 `forced_by_local`，里面写清了是**哪条**本地闸门 |
| `[前置缺失]` 里出现明显不是术语的词 | 术语抽取的已知误报面（见 `references/课程设计与考核.md`）；把该短语写进设计卡的 `prerequisites` 也能放行 |
| 断言「课件说放不下，但定位不到具体的节」 | 已实现「节 id → 页 id → 引文唯一锚点」三级回退；三级都失败才会报这个 |
| `--outdir` 在包内退出码 2 | 产出**必须落包外**：包里只应该有待发布的白名单文件（`.md .py .txt .json .sh .js .yaml .yml .csv`） |
| 断点续跑没生效 | key 含材料/设计卡/产物摘要、节 id、篇幅、规模、页数上限、各角色提示词版本、裁决口径版本；任一变化都会重跑（故意的）。要强跑用 `--force` |
| `unrecognized arguments: --out` | 本包**不允许长选项前缀缩写**（故意的）。请写全 |

更多排错见 `references/成本与排错.md`。

## 零成本自检（复核本包的说法）

```bash
# 1) 四个角色与信息不对称设计，不花钱
python3 scripts/run.py roles

# 2) 报价，不花钱
python3 scripts/run.py cost --file 材料.md --chapters 3 --sections-per-chapter 1

# 3) 只看提示词，不调模型
python3 scripts/run.py run --brief 材料.md --dry-run

# 4) 跑完之后：包里不该出现任何 .pyc
python3 -c "import pathlib,sys; p=[x for x in pathlib.Path('.').rglob('*.pyc')]; \
print('.pyc 数量:', len(p)); sys.exit(1 if p else 0)"

# 5) 跑完之后：全过程记录 —— 如果"否决 / 打回"是 0，说明互审没有真的发生
python3 scripts/run.py log --outdir /tmp/cc
```
