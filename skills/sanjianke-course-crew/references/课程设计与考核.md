# 课程设计与考核

> 这份资料讲三件事：**教研怎么出一张能用的设计卡**、**三道课程特有的闸门到底怎么判**、
> **判错了怎么办**。三道闸门是本包区别于「一篇文章 + 一个排版包」的地方。

## 一、设计卡里必须有的六样东西

| 字段 | 要求 | 为什么 |
|---|---|---|
| `title` | 课程名，≥ 4 字 | 太短看不出这门课讲什么 |
| `audience` | 具体到一类人与使用场景，≥ 4 字 | 「所有人」不是一个受众 |
| `objectives` | 整门课的课程目标，2~4 条，**每条都能考核** | 见第二节 |
| `prerequisites` | 学员进课前就该会的东西，**至少 1 条** | 空的前置表会让下游每个术语都被判「前置缺失」 |
| `units[].objectives` | 每个单元 2~3 条学习目标，可考核 | 讲师照它写讲义 |
| `units[].assessment` | 每个单元**拿什么考核**（产出物 / 动作 / 合格线），≥ 4 字 | 目标与考核必须对得上 |
| `assessment_criteria` | 整门课的合格标准，可测 | 没有合格标准的课没有终点线 |

`prerequisites` 这一栏**宁可多写**：它同时是下游「前置缺失」判定的白名单 ——
没写进去的术语，只要不是更早的节里讲过的，都会被列成缺失。

## 二、学习目标的三种写法（两种不合格）

「了解 / 熟悉 / 掌握 XX」是课程开发里最常见的偷懒方式，因为它**无法考核**：
学员学完说"我了解了"，你也无法说他没了解。可考核的目标必须落到
**可观察的行为**或**可测的标准**上。

| 写法 | 判定 | 原因 |
|---|---|---|
| 「了解内容运营的整体思路」 | ❌ 不可考核 | 「了解」一票否决 |
| 「熟悉常见剪辑工具」 | ❌ 不可考核 | 「熟悉」一票否决 |
| 「掌握并能写出三段脚本」 | ❌ 不可考核 | **两头都占照样拦** —— 前半截就不可考 |
| 「能」 | ❌ 不可考核 | 只有「能」这种泛泛表述，没落到对象或刻度上 |
| 「把长视频拆成 6 条短视频」 | ❌ 不可考核 | 找不到可观察的**行为动词**（这是任务描述，不是学习目标） |
| 「能写出 3 个候选开场钩子并挑出 1 个」 | ✅ | 行为动词 + 具体对象 |
| 「在 5 分钟内列出 6 条素材筛选清单」 | ✅ | 行为动词 + 可测刻度 |
| 「能独立剪出一条 30 秒成片」 | ✅ | 行为动词 + 具体对象 |

### 判定口径（`objective_assessable()`）

1. **不可考核动词一票否决**：`了解 / 熟悉 / 认识 / 理解 / 体会 / 感悟 / 感知 / 领略 /
   知晓 / 知道 / 掌握 / 懂得 / 明晰 / 明白 / 感受 / 领会 / 领悟 / 意识到 / 关注`。
2. **必须有可观察的行为**：`写出 / 画出 / 算出 / 列出 / 说出 / 讲出 / 复述 / 演示 /
   做出 / 完成 / 对照 / 核对 / 检查 / 判断 / 区分 / 选出 / 排序 / 拆解 / 拆分 / 重构 /
   修改 / 改写 / 搭建 / 配置 / 执行 / 提交`，或「能 / 会」+ 具体对象。
3. **刻度是加分项，不是硬要求**：`5 分钟` / `6 条` / `三段` / `不少于 8 个` / `合格线` /
   `模板`。

### 标定过程（一次真机误伤）

这条闸门的第一版要求「有行为**且**有刻度」，真机第一次跑就把**两份合格的目标**
判成了不可考核（它们的行为已经可观察，只是没写刻度），两张设计卡连续被否，
整次运行停在 `design_retries_exhausted`，一个讲义都没写。

误伤的代价很实在：**一个天天误报的闸门会被用户关掉**，而闸门关掉之后真正该拦的
（「了解 XX」这一类）也一起不拦了。所以标定成现在这样：动词一票否决 +
必须落到行为或刻度上，**刻度不再单独构成失败**。

## 三、闸门二：知识点依赖（前置缺失）

**这是课程独有的失败形态** —— 单篇文章没有"前面"，一门课有。

判定是**确定性**的。对每一节的术语候选做两件事：

1. 在**本节之前**的所有讲义 + 设计卡的 `prerequisites` 里找过没有；
2. 没找到 → 记一条「前置缺失」（术语 + 出现在哪一句）。

### 「出现过」不等于「讲过」——一个打不响的闸门

早先的版本把**每一节出现过的术语**都直接记进"已讲过"。结果是这个闸门
**永远不可能触发**：第 2 节用到的新术语，在第 1 节只是被**提到**过一次
（不是被**讲过**），也会被算作"前面讲过了"。

现在只有**引入过**的术语才进入已知集合，引入的定义有两条：

- 讲师自报的 `terms_introduced` 里有它；
- 正文里用定义句式当场解释掉了（`X，指的是…` / `X 是指…` / `叫做 X` / `所谓 X`）。

### 术语候选怎么抽（真机三轮收紧）

中文没有词边界，从连续文本里抽"术语"必然会抽到噪声。真机台账里的三轮收紧：

| 轮次 | 台账条数 | 噪声样例 | 处理 |
|---|---|---|---|
| 第 1 版 | 17 条 | `老板讲用料`、`后厨流程`、`完整记完清单`、`时间点 + 一句话内容点` | 后缀模式从任意位置切段 |
| 第 2 版 | 6 条 | `老板讲用料`、`后厨流程` | 要求候选**前面是边界**（句首 / 标点 / 空白 / 数字） |
| 第 3 版 | 3 条 | —— | 再加两道：**引号里的例证**只出现一次就丢掉；候选必须在本节出现 **≥ 2 次** |

第 3 版的判据来自一个观察：**真正的知识点在一节里会被反复使用**
（`拉片`、`时间码`、`分镜清单` 各出现多次），而「老板讲用料」这种
**引用一次的例子**只出现一次。

抽到的候选分五类来源，各带自己的严格档位：

| 来源 | 例子 | 档位 |
|---|---|---|
| 定义句式 | 「完播率，指的是…」 | 严格 |
| 中文引号 / 书名号 | 「分镜清单」 | 严格 |
| **领域术语表** | 完播率 / 时间轴 / 分镜表 / 黄金三秒 / 素材库… | **宽松**（高置信，不要求前面是边界） |
| 后缀模式（2~4 字 + 率/度/模型/漏斗/清单/口径…） | 漏斗指标 / 验收标准 | 严格 |
| 拉丁缩写 | ROI / CTR | 宽松 |

另外还有一张**通用词停用表**（内容 / 方法 / 结果 / 目标 / 标准 / 流程 / 数据 /
用户 / 团队 / 课程 / 练习 / 步骤 / 重点…）。不做停用会让台账被日常中文淹没，
而台账一多报，人就不看台账了 —— 那等于没有这个闸门。

### 真机实测

| | 修复前 | 修复后（对同一份真机讲义重跑） |
|---|---|---|
| 抽到的术语 | 9 条（含 6 条噪声） | `分镜清单`、`拉片`、`时间码` |
| 前置缺失 | **6 条**（全为误报） | **0 条** |

## 四、闸门三：术语一致性

「完播率」和「完看率」是不是同一个概念，本质是**语义判断**，本地判不了。
所以这条闸门只做两件确定性的事：

1. **逐字比对**，抓「同长度、只差一个字」的两种叫法（`完播率` / `完看率`、
   `时间码` / `时间轴`）—— 差一个字是中文术语改名最典型的形态；
2. 把各节引入的术语并排列出来，让人一眼看到"同一门课里出现了两种叫法"。

### 为什么不用相似度阈值

试过 Jaccard：`完播率` 与 `完看率` 的字符二元组是 `{完播, 播率}` 与 `{完看, 看率}`，
**交集为空**，纯二元组相似度 **0.0**；即使把单字并进特征集合，也只有 **0.25**。
靠相似度阈值判这一条会**永远不触发** —— 又一个"打不响的闸门"。
所以改成逐字比对：同长度、`diff == 1` 即命中，判据确定性、可解释。

**语义层面的不一致仍然要靠质检角色。** 质检的提示词里明确要求逐条过
「术语一致性：同一个概念在整门课里有没有两种叫法；术语表与讲义实际用词对不对得上」。

## 五、判错了怎么办

三道闸门的误报面是已知的，处理口径**统一是加豁免、不是关闸门**：

| 闸门 | 已知误报 | 处置 |
|---|---|---|
| 目标可考核性 | 行为已可观察、只是没写刻度 | 刻度降级为加分项（已修） |
| 知识点依赖 | 引用一次的例证被当成术语（`老板讲用料`） | 出现次数 ≥ 2 才收；引号例证只出现一次直接丢（已修） |
| 术语一致性 | 正常的两条不同术语被逐字比对误伤 | 只认「同长度 + 只差一个字」（已修） |

**加豁免时必须留原因。** 被豁免的每一处都进 `exempted` 列表，带
`word` / `level` / `reason` / `context` 四个字段，stderr 里逐条打出来：

```
提示：产出侧放过 1 处疑似违禁词（每一处都留了原因），请人工确认：
      · 「第一」—— 枚举标记（句首「第一，…第二，…」）　上下文：…
```

## 六、讲师拿不到什么（课程设计相关）

讲师**看得到**学习目标（他必须照着写），**看不到**考核标准 `assessment`。

理由是：讲师一旦看到"考核标准"，就会把讲义写成对着考点划重点的形态 ——
那是备考资料，不是课。考核标准只给质检，它用这一栏检查"目标与考核对不对得上"。

## 七、篇幅口径

单节讲义的目标篇幅由 `--target-chars` 定（默认 800，可用区间 400~3000）。
可接受区间是**名义 ±15%，再叠一个绝对容差** `max(20, 目标 × 2%)`：

| 目标 | 纯 ±15% | 加绝对容差后 |
|---|---|---|
| 400 | 340~460 | 320~480（上下各放宽 20） |
| 700 | 595~805 | 575~825 |
| 800 | 680~920 | 660~940 |

**为什么要加绝对容差**：同族真机实测过目标 600 字写 693 字（超 3 个字、0.5%）
被判硬闸门命中的事 —— 那种噪声会让人把闸门关掉，而闸门一关，真正该拦的
（违禁词、丢内容）也一起失效了。
