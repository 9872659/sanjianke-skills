# 质量自检口径：五道闸门怎么判、怎么复现

这份文档说明 `scripts/run.py` 里五道硬闸门的**确切判据**，以及每一条为什么这么定。
所有判定都是**本地确定性判定**——模型自评（"我已经检查过合规"）不参与，也不算数。

判据全部落在代码里的常量上，改这里就要改代码，改了代码要回归本文档里的标定数据。

---

## 总原则：为什么闸门是"拦截"而不是"警告"

课程是**要交付出去的成品**：讲义会被印出来、录出来发给学员，习题会被学员照着做。
缺陷一旦出了这道门，代价是学员的时间与你的口碑——比"重新跑一次模型"贵得多。

所以每道闸门命中的动作是固定的四件：

1. 产出照常输出（不藏，你要看得见问题）
2. 命中项**标红**（终端支持 ANSI 时用红色，否则用 `✗` 前缀；`NO_COLOR=1` 可关掉颜色）
3. 命中明细**汇总到 stderr**（便于 CI 抓取）
4. 退出码变 **3**

`all` 模式下还会把命中写进 `AUDIT.md` / `audit.json`，方便交给别人复核。

---

## 退出码

| 退出码 | 含义 |
|---|---|
| `0` | 全部干净，闸门全绿 |
| `3` | **被闸门拦下**（违禁词 / 占位符 / 照抄示例 / 结构不合格 / 超预算） |
| `4` | 调用失败（网络 / 鉴权 / 点数 / 模型名） |
| `130` | 用户中断（Ctrl+C） |

`3` 与 `4` 分开是有意的：`3` 意味着"上游没问题，是被本地规则拦了"，
`4` 意味着"上游/网络有问题"。CI 里这两种要采取完全不同的动作。

## 闸门一：合规（广告法违禁词 + 教育类效果承诺）

### 教育类为什么单列一档

知识付费与企业内训最常见的违规不是"最"字，而是**效果承诺**。广告法第二十四条
本来就禁止教育、培训广告对升学、通过考试、获得学位学历或者合格证书作保证性承诺，
所以下面这些按**高风险**处理：

| 命中词 | 说明 |
|---|---|
| 保过 / 包过 / 保过关 / 包拿证 / 不过退款 / 考不过退 | 考试通过率承诺 |
| 包学会 / 保证学会 / 学不会退 / 包教包会 / 学会为止 / 一定学会 | 学习效果承诺 |
| 提分保证 / 保证提分 / 必提分 / 分数保证 / 稳提 N 分 / 保底 N 分 | 提分承诺 |
| 保就业 / 包 offer / 包分配 / 推荐就业保证 | 就业承诺 |
| 零基础也能月入 / 学完就能年薪 | 收益承诺与培训效果绑定 |

### 绝对化用语

`最好 / 最佳 / 最优 / 最便宜 / 最快 / 最强 / 最大 / 最高 / 最先进 / 最流行`、
`全网最低 / 史上最低 / 全国第一 / 排名第一 / TOP1`、`国家级 / 世界级`、
`100% / 百分之百`、`绝对有效 / 保证成功 / 无效退款`、`独家 / 首创 / 唯一选择`、
`央视推荐 / 国家认证 / 官方推荐`、`零风险 / 稳赚 / 躺赚`、`根治 / 治愈 / 疗效`、
`纯天然 / 无添加`、`点击链接 / 加微信 / 扫码加` 等。

完整正则表见 `scripts/run.py` 的 `BANNED_PATTERNS`。

### ⚠️ 已知的一段误伤：普通中文里的「最」

**实测抓到的原例**（真机跑讲义，4 次里有 1 次被这条拦下）：

> 做菜和剪辑**最大**的共同点是：先做减法，再做加法。

这里的"最大"是在讲一件常识，不是给商品贴最高级标签。学员花钱买的课程内容被这条规则
拦下，比漏报更糟。所以加了一层**可枚举、可复核**的上下文豁免
（`SUPERLATIVE_OK_AFTER` + `SUPERLATIVE_OK_RE`）：

- 命中"最 X"之后紧跟（允许夹一个「的」）：不同 / 区别 / 差异 / 共同 / 相同 / 相似 /
  常见 / 容易 / 重要 / 关键 / 主要 / 先 / 后 / 基本 / 简单 / 难 / 麻烦 / 省事 /
  常用 / 合适 / 适合 / 保险 / 稳妥
- 命中即判为普通用法，放行

仍然照拦的：`最好的课程`、`最强`、`最高级`、`最大优惠`（后文不在豁免表里）。

**这条豁免只对以「最」开头的命中生效**，教育类效果承诺（保过 / 包学会 / 提分保证）
**没有任何豁免**，一律拦。

### 另一段已修正的误伤：「唯一」

真机跑习题时，模型在题干里写了：

> 判断一段画面是不是废片，**唯一标准**是画面够不够清晰稳定。（答案：错）

"唯一标准"是把"唯一"当普通词用。原来那条规则写成裸的 `唯一`，属于必然误伤，
已收紧为 `唯一(选择|指定|授权|官方|认证|品牌|推荐|渠道|合作)`。

### 这张表是粗筛，不是法律意见

表来自公开经验整理，**宁可多报也不漏报**，不等于任何平台的官方审核标准，
也不构成法律意见。医疗、保健食品、金融、投资、母婴、特殊化妆品等高风险类目必须人工复核。

## 闸门二：占位符残留

| 判据 | 正则 | 说明 |
|---|---|---|
| 模板占位符 | `\{\{?\s*[\u4e00-\u9fffA-Za-z0-9_]*\s*\}?\}` | `{}` / `{{标题}}`——JSON 骨架被当正文写进去了 |
| 括号空档 | `[\[【](填空\|待补充\|待填\|待定\|待完善\|略\|此处省略\|XXX\|xx\|XX)[\]】]` | `[填空]` / `【待补充】` |
| 裸占位词 | `(?<![A-Za-z0-9])X{3,}(?![A-Za-z0-9])` | `XXX`（只认大写三个以上，小写 `xx` 在中文里常是变量名，不拦） |
| 未完成标记 | `待补充\|待完善\|后续补充\|此处略\|TODO\|TBD` | 模型给自己留的活 |

### 为什么括号那一条要做**白名单**而不是一刀切

讲义里出现 `[1]`（引用序号）、`[图 2]`（配图位）、`[待定]` 之外的大量方括号内容
是完全正常的写法。一刀切"括号里有字就拦"会把好讲义全拦下。

所以只认**枚举出来的占位词**，并且**不做长度通配**。代价是模型自创一个没登记的空档词
（比如 `[此处需补充案例]`）会漏过——这个代价是刻意接受的，因为它的误伤面太大。
如果实际使用中反复遇到某个新形态，把它加进正则表，不要放开成通配。

## 闸门三：`prompt_echo`（照抄提示词示例）

### 事故复盘（这条闸门不是假想出来的）

来自爆款标题工坊的两次实测：

1. 提示词里写过正例 `结论先说：便携榨汁杯不适合三类人` → 模型直接产出近似句
2. 提示词里留过 `便携榨汁杯不适合这三类人，理由有三个` → 公众号那一轮
   **最高分 89.0 的标题一字不差就是它**

第 2 例性质更重：最高分那条是"抄了标准答案"，不是"真的最好"，而排序是那个包的核心产出。

**教训是：模型会照抄提示词里的示例，哪怕示例明确标着"这是错的写法"。**
在本包里形态不同但同样致命：大纲的示例章节名如果被照抄，整份大纲会变成
"把示例换个主题词"——章节顺序、学习目标的写法全部雷同，看起来完全正常，
直到你发现它是模板填空题。

### 判定三条路径

| 路径 | 条件 | 抓什么 |
|---|---|---|
| `exact` | 与示例去标点后**完全相同** | 最直接的照抄 |
| `jaccard` | 字符二元组 **Jaccard ≥ 0.75** | 长度相当的同构改写 |
| `contain` | 示例的二元组**覆盖度 ≥ 0.60** | 长文里夹带示例 |

归一化：只留中文、字母、数字，丢掉所有标点与空白（抄示例常只改标点）。

### 标定数据（都是实测）

`jaccard` 阈值 0.75 的依据：

| 输入 | Jaccard | 结果 |
|---|---|---|
| 逐字照抄示例 | 1.000 | 拦 |
| 只改标点 | 1.000 | 拦 |
| 少两个字 | 0.786 | 拦 |
| **真实业务大纲章节名** | **0.077** | 放行 |
| **真实讲义正文 vs 示例** | **0.000** | 放行 |

正常产出与示例之间有 10 倍以上的安全距离。

**为什么必须再加覆盖度（这条是本次真机实测抓出来的设计缺陷）**：Jaccard 在两个长度差
几十倍的对象之间会被**稀释**。实测把一条 40 字的示例原样塞进一份 2400 字的讲义：

| 输入 | Jaccard | 覆盖度 | 结果 |
|---|---|---|---|
| 2400 字讲义里夹带 40 字示例 | **0.171**（低于 0.75，会侥幸放行） | **1.000** | 覆盖度拦下 |
| 真实讲义（`co-all` 产出，2483 / 2226 字） | 0.000 | ≤ 0.05 | 放行 |

覆盖度只看"示例被抄了多少"，不看产出有多长，所以长文夹带照抄躲不过去。

### 提示词侧的纪律（治本）

判定是兜底，治本是**提示词里不许出现任何一份可直接复制的完整产出**：

- 举例一律用**跨主题**示例，登记在 `PROMPT_SAMPLES`
  （本包用的是社区团购选品 / 机械制图停机点 / 架子鼓坐姿，与短视频剪辑明显不搭）
- 讲形态只用描述性语言，不给可复制的正例

### 已知边界（刻意保留）

- 归一化后短于 12 个字符的串不比 Jaccard / 覆盖度：短串二元组集合太小，指标会虚高
- 换掉两个词后 Jaccard 掉到 0.60 以下、覆盖度也掉下去时不拦。要拦住它得把阈值压到
  0.6，余量从 10 倍缩到 4 倍，误伤风险不值

## 闸门四：结构校验

`plan` 产出后、`lesson` / `quiz` **载入大纲时**（再校验一遍）都会跑。

| 检查项 | 判据 | 不合格的后果 |
|---|---|---|
| 章节数 | ≥ 1；给了 `--chapters` 则要求完全相等 | 空大纲 |
| 每章都有小节 | 每章 `sections` 非空 | 有章无节，讲义没法写 |
| 每节都有学习目标 | 每节 `objectives` 非空 | 讲义没有覆盖目标 |
| 学习目标不是空话 | 不匹配"了解/熟悉/掌握…"套话，且长度 ≥ 6 | 目标无法出题检验 |
| 小节都有标题 | 标题非空 | 产出文件名与目录都是空的 |
| 每节都有正数时长 | `minutes > 0` | 总时长算不出来 |

**为什么 `lesson` / `quiz` 要再校验一遍**：大纲文件是 JSON，手工改坏它是最容易被忽略的
失败入口；拿一份结构残缺的大纲去写讲义，等于把错误放大到几十节。

## 闸门五：成本上限

### 怎么算

网关不公布逐模型的逐 token 单价，所以我们**不编单价**：

- 默认口径 `YUAN_PER_KTOK_DEFAULT = 0.02 元 / 千 token`，**这是估算口径，不是账单**
- 可用 `--yuan-per-ktok` 覆盖成你自己的口径
- 1 元 = 100 点（`POINTS_PER_YUAN`）

### 什么时候拦

| 时机 | 动作 |
|---|---|
| 发起调用**之前** | 按预估 token 算总价，超 `--budget` 直接停，一次调用都不发，退出码 3 |
| 每一节**提交之前** | 再核一次真实累计用量，超了就就地停，已完成的留在断点里 |

`cost` 子命令是这条路线的离线版本：不出网、不花钱，只打印预估与预算结论。
**估不出价也算"闸门不放行"**——拿不到可信口径就放行，等于没有成本前置。

### 真实用量从哪来

每次调用返回的 `usage`（`prompt_tokens` / `completion_tokens` / `total_tokens`）。
`all` 跑完会打印累计真实 token 与估算金额，方便你拿 token 数去控制台核对。
脚本在 `usage` 缺失时会按估值记账并**明确标出"含 N 次估值非真实 usage"**，不假装是实测。

**账单以 api.a7w.cn 控制台为准。** 本包没有用真金白银跑出逐模型单价，
所以文档里不写死任何一个模型的价。
