# 合规红线：课程与教辅内容的宣发口径

这份文档面向**把课程卖出去**的那一步（详情页、招生海报、直播话术、社群文案），
以及**课程内容本身**的口径。课程生产线产出的讲义与习题会被直接引用到这些物料里，
所以两边用的是同一张违禁词表。

> ⚠️ 本文与脚本内置的词表是**启发式自检工具**，来自公开经验整理，
> **不构成法律意见**，也不代表任何平台的官方审核标准。
> 内容与宣发的合规责任由使用者承担；高风险类目必须人工复核。

---

## 一、教育 / 培训类专有的四条高压线

广告法对教育、培训广告有专门限制：**不得对升学、通过考试、获得学位学历或者
合格证书作出保证性承诺**。落到文案上就是下面四类话一个字都不能写：

### 1. 考试通过类

| 不许写 | 为什么 |
|---|---|
| 保过 / 包过 / 保过关 / 包过关 / 保拿证 / 包拿证 | 通过率承诺，无法举证 |
| 不过退款 / 考不过退 | 用退款承诺替通过率背书，同样是把结果写死 |

**可以怎么写**：写你提供什么，不写你会得到什么证书结果。
"含 12 套模拟卷 + 逐题解析" ✅　"保过" ❌

### 2. 学习效果类

| 不许写 | 为什么 |
|---|---|
| 包学会 / 保证学会 / 学不会退 / 包教包会 / 学会为止 / 一定学会 | "学会"没有可检验的定义，无法举证 |

**可以怎么写**：把效果拆成可检验的动作。
"学完能独立完成一次 30 秒成片" ✅（这是可检验的目标，不是效果承诺）
"包学会" ❌

### 3. 提分类

| 不许写 | 为什么 |
|---|---|
| 提分保证 / 保证提分 / 必提分 / 分数保证 | 分数结果承诺 |
| 稳提 N 分 / 保底 N 分 | 量化承诺，更危险——数字成了合同条款 |

**可以怎么写**：写方法与覆盖范围。"覆盖高考函数全部 9 类题型" ✅

### 4. 就业 / 收益类

| 不许写 | 为什么 |
|---|---|
| 保就业 / 包 offer / 包分配 / 推荐就业保证 | 就业结果承诺 |
| 零基础也能月入 N / 学完就能年薪 N | 收益承诺，且与培训效果绑定 |

## 二、绝对化用语（跨类目通用）

广告法第九条禁止使用"国家级""最高级""最佳"等用语。落到自检表里：

| 类别 | 典型词 |
|---|---|
| 最高级 | 最好 / 最佳 / 最优 / 最便宜 / 最快 / 最强 / 最大 / 最高 / 最先进 / 最流行 / 最受欢迎 |
| 排他性位置 | 全网最低 / 史上最低 / 全国第一 / 排名第一 / 销量第一 / TOP1 / No.1 |
| 权威性词汇 | 国家级 / 世界级 / 全球级 / 国际级 |
| 绝对化程度 | 100% / 百分之百 / 绝对有效 / 保证成功 / 无效退款 |
| 排他性表述 | 独家 / 首创 / 填补空白 / 唯一选择 / 唯一指定 / 行业领先 |
| 虚构背书 | 央视推荐 / 国家认证 / 官方推荐 / 教育部指定 / 权威认证 |

### ⚠️ 一段必须知道的误伤

**普通中文里的「最大」「最常见」「最重要的」不是广告语。** 真机实测抓到过这一例：

> 做菜和剪辑**最大**的共同点是：先做减法，再做加法。

脚本对此做了可枚举的上下文豁免（详见 `quality-gates.md` 的闸门一节）：
"最 X"后面紧跟「不同 / 区别 / 共同 / 常见 / 重要 / 关键 / 简单 / 难 / 省事…」时放行。
**但这条豁免只对以「最」开头的命中生效**，教育类效果承诺没有任何豁免。

## 三、其他类目（课程常会顺带提到的）

| 类目 | 不许写 | 备注 |
|---|---|---|
| 医疗健康 | 治愈 / 根治 / 痊愈 / 疗效 / 无副作用 / 药到病除 | 非药品、非医疗器械不得宣称功效。健身、养生、心理类课程高发 |
| 投资金融 | 零风险 / 稳赚 / 躺赚 / 包赚 / 高回报 / 内部渠道 | 荐股、理财课高发。"跟着买就赚"直接违法 |
| 食品 | 纯天然 / 无添加 / 零添加 / 无毒无害 | 成分宣称需与检测报告一致 |
| 特殊品类 | 催情 / 壮阳 / 丰胸 / 减肥药 / 美白针 / 生发神器 | 特殊功效与特殊品类敏感词 |
| 促销时限 | 秒杀 / 抢购 / 限时抢 / 最后一天 / 仅限今天 / 名额有限先到先得 | 必须与实际活动一致，否则构成虚假宣传 |
| 免费类 | 免费领 / 免费送 / 0 元购 / 白送 | 可能构成虚假优惠或诱导分享 |
| 站外导流 | 点击链接 / 加微信 / 私信我 / 扫码加 + 微信号 | 平台普遍限制，课程详情页尤其严 |

## 四、内容本身的合规（不只是宣发）

课程讲义与习题会被印出来、录出来、发给学员。除了上面这些词，讲义还要注意：

1. **不编数据**：没有依据就写定性描述。销量、检测结论、专家背书、机构名称
   都要有出处，模型最喜欢凭空补一个漂亮的数字——脚本在提示词里写死了这条约束，
   但**只有你能最终确认它有没有编**。
2. **不点名同行**：讲"某某平台的算法"要中性表述，不要指认具体公司做了错事。
3. **不承诺结果**：讲义正文里也不要写"照这个方法做你就能…"。
4. **案例分析用虚构人物**：不要用真实姓名、真实公司名做负面案例。
5. **引用他人内容要标出处**：教程类内容搬运他人教程的段落属于侵权高发区。

## 五、自检与复核流程

```bash
# 1) 生成时自动跑：命中即标红 + stderr 汇总 + 退出码 3
python3 scripts/run.py all --topic "零基础短视频剪辑" --outdir ./course-out

# 2) 看汇总报告
cat ./course-out/AUDIT.md

# 3) 把已有内容单独过一遍闸门（不调模型，不花钱）
python3 scripts/run.py lesson --plan ./course-out/outline.json --count 1 \
    --from-file ./待检查的讲义返回.json
```

退出码 `3` 表示被本地规则拦下，**必须人工复核后才能发布/录课**；
复核结论是"误伤"时，改内容重跑，不要去改脚本里的词表来绕过它
（真要改，改完必须回归 `quality-gates.md` 里的标定数据）。

**收集排错信息时请附上**：完整命令、`--dry-run` 输出、`AUDIT.md` 内容、原始报错文本。
**不要在报错信息或截图里带上你的 API Key。**
