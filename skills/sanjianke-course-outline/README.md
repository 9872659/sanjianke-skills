# 三剪客 · 课程生产线

给一个主题和受众水平，**一条流水线跑完课程三件套**：大纲 → 逐节讲义 → 习题与解析。
面向知识付费、企业内训与录课老师。纯大模型产出，零第三方依赖。

## 它解决什么问题

备课卡住的从来不是"写不出来"，而是**先想清楚讲什么**：章节怎么排、每节学员学完要做到什么、
讲多长、拿什么检验。这三件事想清楚了，写只是时间问题；想不清楚，写出来的讲义
就是一堆正确但没用的废话。

这个包把这条链路拆成四步，**每一步的产出都能单独拿去用**：

| 子命令 | 干什么 | 产出 |
|---|---|---|
| `plan` | 出课程大纲 | 章节 / 小节 / 每节学习目标 / 每节时长 |
| `lesson` | 按大纲逐节写讲义 | 每节 1500~3000 字，四段结构 |
| `quiz` | 按大纲逐节出习题 | 基础 / 应用 / 进阶三档，每题带答案与解析 |
| `all` | 串起来跑完整套 | 大纲 + 讲义 + 习题 + 合并讲稿 + 质检报告，**断点续跑** |
| `cost` | 只算钱 | 预估 token 与金额，一次调用都不发 |
| `models` | 现查在架模型 | 模型清单（免费） |

## 三分钟上手

```bash
# 1) 到 https://api.a7w.cn/ 注册领 Key，然后填进环境变量
export A7W_API_KEY=sk-你的key          # Windows PowerShell: $env:A7W_API_KEY="sk-你的key"

# 2) 零依赖，不需要 pip install 任何东西，只要 Python 3.7+
cd sanjianke-course-outline

# 3) 确认网关通（免费）
python3 scripts/run.py models --type text

# 4) 先算钱（不出网）
python3 scripts/run.py cost --chapters 4 --sections-per-chapter 2

# 5) 跑第一个例子
python3 scripts/run.py plan --topic "零基础短视频剪辑" --level zero \
    --chapters 4 --sections-per-chapter 2 --json --out outline.json
```

跑完整套（推荐用法）：

```bash
python3 scripts/run.py all --topic "零基础短视频剪辑" --level zero \
    --chapters 4 --sections-per-chapter 2 --per-tier 2 \
    --budget 5 --outdir ./course-out
```

产出目录：

```
course-out/
├── outline.md / outline.json      大纲
├── lessons/1-1.md ...             每节讲义正文
├── quiz/1-1.json ...              每节习题（含答案与解析）
├── course.md                      合并讲稿（大纲 + 讲义 + 习题）
├── AUDIT.md / audit.json          质量与合规自检报告
└── course-outline-state.json      断点文件
```

中断了就**原样重跑**，已完成的节会跳过，不会重复扣费。

**输出目录请指到包外**（`./course-out`、`%TEMP%\...`）。Skill 包的上传白名单只收
`.md .py .txt .json .sh .js .yaml .yml .csv`，包内塞图片会让上传 400。

## 讲义长什么样

每节讲义固定四段：

1. **本节要解决的问题** —— 为什么学它，不学会在哪里卡住
2. **核心内容** —— 概念 + 步骤 + 至少一个能跟着做的具体例子
3. **常见错误** —— 至少 2 条，每条写清"错在哪、为什么错、怎么改"
4. **小结与承接** —— 3~5 条要点 + 一句引出下一节的话

第 3 块是"能用的课"与"搬运教程"的分水岭。没有常见错误的讲义，学员做错时还是不知道错在哪。

字数按去 Markdown 符号后的中文字符数算，区间 **1500~3000 字**：少于 1500 讲不透，
多于 3000 单节听不完（该拆成两节）。越界会标红，脚本**不替你截断**——删哪句是内容判断。

## 习题怎么分层

| 档位 | 能力指向 | 题型 |
|---|---|---|
| 基础 | 能复述、能识别、能照着做 | 单选、判断 |
| 应用 | 能在新场景里用出来、能改参数 | 情境单选、简答 |
| 进阶 | 能判断取舍、能排错、能迁移到没讲过的情形 | 案例分析、纠错型判断 |

每档题数由 `--per-tier` 决定（默认 2，即每节 6 道），脚本会**逐档核对数量**，
某档对不上就标红。每道题的解析必须说清**为什么对、别的为什么错、考的是哪个知识点**，
空解析直接被拦。

## 五道硬闸门

闸门是**拦截**不是警告：标红 + stderr 汇总 + 退出码非 0。

| # | 闸门 | 拦什么 |
|---|---|---|
| 1 | 合规 | 广告法违禁词；教育类专有一档：保过 / 包学会 / 提分保证 / 保就业 |
| 2 | 占位符残留 | `{}` / `[填空]` / `XXX` / `待补充` |
| 3 | `prompt_echo` | 照抄提示词示例（模型会抄，哪怕标着"这是错的"） |
| 4 | 结构校验 | 大纲缺章节 / 缺小节 / 缺学习目标 / 目标是"了解 XX"这种套话 |
| 5 | 成本上限 | 超 `--budget`：发起调用前核一次，每节提交前再核一次 |

判据与标定数据见 [`references/quality-gates.md`](references/quality-gates.md)，
合规红线见 [`references/compliance.md`](references/compliance.md)，
课程设计口径见 [`references/course-design-method.md`](references/course-design-method.md)。

### 两条来自真实跑测的修正

真机连跑 4 次讲义，1 次被闸门拦下，拦的是这句：

> 做菜和剪辑**最大**的共同点是：先做减法，再做加法。

这是普通中文用法，不是最高级广告语。所以"最 X"后面紧跟
`不同 / 区别 / 共同 / 常见 / 重要 / 关键…` 时放行（豁免表可枚举、可复核）。
`最好的课程` / `最强` / `最高级` 照拦。

同类修正：原来那条排他性规则写成裸的 `唯一`，而模型在习题题干里写了
「判断是不是废片，**唯一标准**是画面够不够清晰稳定（答案：错）」——
已收紧为只拦 `唯一选择 / 唯一指定 / 唯一授权` 这类。

## 算力接入

只用大模型，端点（域名来自算力集市 api.a7w.cn）：

```
POST https://api.a7w.cn/api/v1/chat/completions     大纲 / 讲义 / 习题
GET  https://api.a7w.cn/api/v1/models               在架模型清单
```

- **不留任何密钥在代码或文档里**，Key 从环境变量 `A7W_API_KEY` 读
- **模型名会变，用 `models` 子命令现查，别写死**
- `deepseek-chat` 这个别名**实测可用**（路由到 `deepseek-flash`），
  但它**不在** `/api/v1/models` 的返回列表里——"列表里没有"不等于"不能用"
- 大模型调用带**退避重试**（网关 `upstream timeout` / HTTP 502 实测很常见）
- JSON 解析用 `json.JSONDecoder().raw_decode()` 扫描第一个完整对象，
  模型在合法 JSON 后多吐字符也不会炸
- **走 `/chat/completions` 的成功响应不带 `code` 字段**；
  带 `code == 1` 的那层信封（`{"code":1,"data":{...}}`）是给生成应用的

## 成本

网关不公布逐模型的逐 token 单价，所以本包**不编单价**：默认按 **0.02 元/千 token** 估算
（`--yuan-per-ktok` 可覆盖），文档与输出里都标成"估算"。真实用量来自每次调用返回的
`usage`，`all` 跑完会打印累计真实 token 供你核对；**账单以 api.a7w.cn 控制台为准。**

实测参考（模型 `deepseek-chat`，主题"零基础短视频剪辑"）：

| 动作 | token | 耗时 |
|---|---|---|
| 4 章 8 节大纲 | 1952 | 7.1s |
| 1 节讲义 | 2480 | 10.3s |
| 1 节 6 道分层习题 | 2280 | 9.2s |
| `all` 1 章 2 节（5 次调用） | 12095 | 34.1s |
| `all` 原样重跑 | 0 | 0.1s（全部跳过） |

## 退出码

| 退出码 | 含义 |
|---|---|
| `0` | 全部干净，闸门全绿 |
| `3` | 被闸门拦下（违禁词 / 占位符 / 照抄示例 / 结构不合格 / 超预算） |
| `4` | 调用失败（网络 / 鉴权 / 点数 / 模型名） |
| `130` | 用户中断 |
