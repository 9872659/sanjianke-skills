# 三剪客 · 视频超分与补帧 Skill

video2x：把低清视频用机器学习模型放大到高清，或用补帧把帧率提上去，支持 Anime4K、Real-ESRGAN、Real-CUGAN、RIFE。含命令行用法、硬件门槛与容器部署避坑要点。

---

## 前置条件

- CPU 需支持 AVX2（预编译包的最低要求），GPU 需支持 Vulkan；不满足要自行从源码构建或换机器。
- 一张可用的显卡与配套驱动；容器路线还需要 Docker 或 Podman 以及 GPU 运行时。
- 6.x 版本处理时帧全程在内存中流转，不需要为中间帧预留大块磁盘，但成品体积要留足。
- 想用自定义着色器，需要准备 MPV 兼容的 GLSL 文件。
- 建议先拿一小段素材试跑，确认参数与耗时再放量处理整片。

---

## 使用

1. 按平台装好程序：Windows 用官方预编译包或带界面的安装包，Linux 用发行版包或 AppImage，也可以直接用容器镜像。
2. 用 `video2x --help` 确认本机版本的实际参数名，用 `video2x --list-devices` 看可用设备索引。
3. 选处理器：动画向线条优先考虑 libplacebo + Anime4K 着色器；实拍素材可用 Real-ESRGAN 或 Real-CUGAN；要抬帧率用 RIFE。
4. 明确输出目标：按分辨率就传宽高，按倍数就传缩放倍数；两类模型对倍数与宽高的要求不同。
5. 需要控制体积就显式给出编码器与编码参数，`-e` 可重复传编码器专属的 key=value。
6. 正式处理前用基准模式或小样估时间，处理完抽帧对比画质。

参数以本机 `video2x --help` 与官方文档站为准；本包写入的是经过核对的命令形态。

---

## 依赖

- 预编译版本：支持 AVX2 的 CPU、支持 Vulkan 的 GPU 与驱动
- Linux 发行版包 / AppImage；Windows 预编译包或安装包
- 容器路线：Docker 或 Podman，加 GPU 运行时
- 源码构建：CMake、C++ 编译器、Vulkan SDK、FFmpeg、ncnn 等（以官方各平台构建说明为准）
- 内部通过 FFmpeg 的库完成解码与编码，并内置所需模型资源

---

## 安全

- 不内嵌任何密钥；命令行使用不需要账号或 Key。
- 从非官方镜像拉取容器或二进制包存在被篡改的风险，请只使用官方发布渠道并校验来源。
- 容器里为拿到 GPU 而使用 `--privileged` 会显著放大权限，仅在确认环境可信时临时使用。
- 处理版权素材前请确认授权；超分不改变素材的版权归属。
- 处理过程会重编码视频，请保留原始素材，不要在原始文件上原地覆盖。
