# 三剪客 · 执行计划拆解 Skill

把复杂目标拆成有顺序、有检查点、每步都能独立验证的执行计划

---

## 前置条件

- 能说清最终想让什么发生变化（一句话即可，不必精确）
- 知道基本约束：时间上有无死线、资源上有无硬边界、有无不能碰的东西
- 无软件依赖，不需要安装任何工具

---

## 使用

直接描述目标即可，例如：

> 帮我把「内容后台支持 Excel 批量导入」这件事拆成执行计划

Skill 会按五步输出：

1. **钉目标**——把模糊说法改写成可判真假的目标 + 3~5 条成功判据
2. **先切层再切步**——2~4 个里程碑，每个里程碑下 3~8 步
3. **补验证**——每步写"产出物 + 验证动作 + 通过标准"三件套
4. **排依赖**——标前置与被依赖，分出并行批次，找出关键路径
5. **埋风险**——关键路径每步写失败方式、最早发现点、回退点、延期对策

分三种情况取资料：

| 情况 | 看哪份 |
|---|---|
| 从零开始拆 | `references/decomposition-method.md` |
| 要模板或看填好的示例 | `references/template-and-example.md` |
| 计划已写完，要挑毛病 | `references/self-check-and-pitfalls.md` |

**核心区别**：待办清单写"做什么"，本 Skill 写"**怎样才算做完**"。
每步必须留下可指认的产出物，且有一个"通过 / 不通过"不需要再讨论的验证动作。
