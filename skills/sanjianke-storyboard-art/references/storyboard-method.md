# 分镜方法：从剧本到「一格一格能画的东西」

这份文档解决的是**切分与取景**：一段剧本怎么切成格，每格用什么景别与机位，
格怎么排成页，比例用多少。

---

## 一、剧本 → 分镜，切的是什么

一段剧本里有三种东西，分镜要区别对待：

| 剧本里的东西 | 分镜怎么处理 |
|---|---|
| **动作**（谁做了什么） | 一定要有格。一个连贯动作可以拆成「起手 / 发力 / 结果」三格 |
| **台词**（说了什么） | 不必然占一格。台词可以压在同一格的对白区，靠**说话人的反应格**承接情绪 |
| **情绪转折**（态度变了） | 值得单独给一格，而且通常该给**近景或特写**——距离就是强调 |
| **环境交代**（在哪） | 只在开场或转场给，用**远景/全景**；不要每格都交代环境 |

`shots` 子命令的提示词就是按这个口径写的：每格必须齐
`shot_size / camera / emotion / characters / visual / dialogue / prompt`。
少了 `visual` 或 `shot_size` 会被闸门标红——因为那两样是分镜的骨架。

**切分粒度**：一格大约对应读者"看一眼"的时间。条漫一格一屏、页漫一页 4~6 格是常见区间。
`--count` 给上限，`--per-page` 决定 `page` / `panel` 字段怎么编号。

## 二、景别（读者离人物多远）

八档枚举，本包的闸门只认这八个（常见口语写法有别名兜底，见下表）：

| 景别 | 画面里有什么 | 什么时候用 |
|---|---|---|
| **大远景** | 人在环境里只是个小点 | 开场定场、交代规模、时间流逝 |
| **远景** | 全身 + 大片环境 | 交代地点、人群、空间关系 |
| **全景** | 全身，环境占一半 | 动作戏的起手、人物进场 |
| **中景** | 膝盖/腰以上 | **对白戏的主力景别**，兼顾表情与手势 |
| **中近景** | 胸以上 | 对话中的情绪递进、双人过肩 |
| **近景** | 肩以上 | 情绪明确、台词有分量 |
| **特写** | 脸 / 手 / 关键物 | 情绪爆发、伏笔道具 |
| **大特写** | 眼睛 / 一个细节 | 冲击点；连用会麻木，一话用 1~2 次 |

别名兜底：`半身 → 中近景`、`全身 → 全景`、`大全 → 远景`、`局部 → 特写`、
`中近 → 中近景`、`大特 → 大特写`；`close-up` / `medium` / `full` 也认。
**认不出来的写法会被拦**，例如"看得见人""常规镜头"——那不是景别。

**景别的节奏**：同一种景别连着用三格以上，读者会失去距离感。
常规做法是「远 → 中 → 近」逐步推，或在情绪点突然切一格特写（落差就是强调）。

## 三、机位（读者站在哪）

机位不改内容，改的是**观众与角色的关系**：

| 机位 | 心理效果 |
|---|---|
| **平视** | 中性、客观。对白戏默认 |
| **微俯 / 俯视** | 角色处于弱势、被观察、被压 |
| **仰视** | 角色有压迫感、权威感 |
| **过肩 / 越肩** | 让读者"站在某人身后"，双人对话首选 |
| **主观视角** | 读者即角色，代入最强；信息受限，别用来交代全局 |
| **斜侧** | 打破平视的呆板，适合静态场面 |
| **背身** | 隐藏表情、制造距离；常用于离别与沉默 |
| **正面** | 直视读者，强调、宣告 |

**同一场戏里机位不要乱跳**：一组对话戏保持平视 + 过肩，观众才不会迷路。
要跳就跳到明确的目的上（例如从平视切仰视表达反派登场）。

## 四、格怎么排成页

`sheet` 支持两种布局，对应两种载体：

### 条漫（`--layout strip`）

- **单列竖排**，从上往下读，没有跨页概念
- 一格一屏宽度固定（`--panel-w`，实测常用 620~1080），高度按每格自己的比例算
- `--rows` 是**一页装几格**（导出成多张图时用；条漫也可以 `--rows 0` 全部拼一张长图）
- 上下留白要比页漫大一点：手指划屏会盖住边缘

### 页漫（`--layout grid`）

- `--cols` × `--rows` 网格，一页一页出图
- 单格尺寸由 `--panel-w` / `--panel-h` 决定，页尺寸 = 边距 + 格 + 格间距
- `--fit contain`（默认）：**整格画进格子，不裁画**——做分镜稿时不要裁掉画师的构图
- `--fit cover`：填满格子并居中裁画——排版已定死格子比例时用
- 阅读顺序默认**右→左、上→下**（日式）；要左→右就自己按顺序排 `panels`

**装订留白**：`--margin` 默认 24 像素。要打印或装订，
内侧（订口）建议留到 3~5mm 以上，别把内容顶到边。

**页与格的比例关系**：`--panel-w/--panel-h` 只决定格子，不决定画。
每格图的真实比例由 `images` 的 `--aspect-ratio`（或分镜表里的 `aspect_ratio`）决定，
拼页时按 `--fit` 缩放——所以**先定格子的比例，再去出图**，不要反过来。

## 五、比例：请求什么、拿到什么

上游（`nano_banana`）的 `aspect_ratio` 可选值：
`auto / 1:1 / 16:9 / 9:16 / 4:3 / 3:4 / 3:2 / 2:3 / 5:4 / 4:5 / 21:9`。

**实测的关键事实：上游不是按比例给像素，而是先定总像素、再把每边向下对齐到 32 的倍数。**
所以 10 种比例里有 5 种拿不到像素级精确比例：

| 请求 | 实测像素（1K） | 实际比例 | 偏差 |
|---|---|---|---|
| 3:4 | 864x1184 | 0.7297 | **2.70%** |
| 4:5 | 896x1152 | 0.7778 | 2.78% |
| 5:4 | 1152x896 | 1.2857 | 2.86% |
| 16:9 | 1344x768 | 1.7500 | 1.56% |
| 9:16 | 768x1344 | 0.5714 | 1.56% |
| 1:1 | 1024x1024 | 1.0000 | 0% |
| 4:3 | 1184x864 | 1.3333 | 0% |
| 3:2 | 1248x832 | 1.5000 | 0% |
| 2:3 | 832x1248 | 0.6667 | 0% |
| 21:9 | 1536x672 | 2.2857 | 0% |

**容差 3%** 就是为这个特性定的：容差内不算"假"，但真实像素与偏差照样打印出来。

**拼页时建议加 `--snap-exact`**：容差内不代表比例齐。3:4 出 864x1184，
`--snap-exact` 裁到 **864x1152（偏差 0.0000%）**，裁完再读文件头复核。
差 2.7% 在一格里不明显，一页四格错开就很明显（横向留白一格宽一格窄）。

### 各载体常用比例

| 载体 | 比例 | 备注 |
|---|---|---|
| 条漫（竖屏） | `9:16` 或 `3:4` | 单格一屏 |
| 页漫内页 | `3:4` / `2:3` | 与单行本开本接近 |
| 横版分镜稿 | `16:9` | 投屏/审片用 |
| 社交方图 | `1:1` | 宣发物料 |
| 宽幅跨页 | `21:9` | 大场面跨页；上游能给精确比例 |

## 六、分镜表的字段（`shots.json` 的结构）

```json
{
  "script_title": "…",
  "style_bible": "一句话交代全篇画风（画种 + 线条 + 明暗 + 色彩倾向）",
  "characters": ["chen", "woman"],
  "charset_version": "设定卡摘要，进断点 key",
  "panels": [
    {
      "id": 1, "page": 1, "panel": 1,
      "shot_size": "中景", "shot_size_norm": "中景",
      "camera": "平视", "emotion": "压抑",
      "characters": ["chen"],
      "visual": "画面描述（30~80 字，写清谁在哪、在做什么、环境与光线）",
      "dialogue": "这一格的对白（不写进出图提示词）",
      "narration": "旁白",
      "aspect_ratio": "3:4",
      "prompt": "直接发给文生图模型的出图提示词",
      "leaks": []
    }
  ]
}
```

- `visual` 与 `prompt` **不是一回事**：`visual` 是给人和排版看的画面描述，
  `prompt` 是给模型的、必须包含出场角色的**全部特征词**
- `dialogue` 是**给人加字用的**，本包不会把它画进图里（见下）
- `leaks` 是本地闸门的命中记录，空数组表示这一格结构合格

**手工改分镜表是允许的**（这是最实用的工作流）：改完直接跑 `consistency` 复核，
再跑 `images`——提示词改了 key 就变，只有改动的那一格会重出。

## 七、常见毛病清单

| 毛病 | 表现 | 怎么改 |
|---|---|---|
| **景别单调** | 连续 5 格"中景" | 按远→中→近推，或在情绪点插一格特写 |
| **机位乱跳** | 平视、俯视、仰视来回切 | 一场戏锁定一组机位，只在明确目的处跳 |
| **每格都交代环境** | 每格都是全景 | 只有开场/转场才需要定场 |
| **台词即格** | 说一句给一格，画面没变化 | 合并台词，把格让给**反应**与**动作结果** |
| **空有情绪无画面** | `visual` 写"气氛压抑" | 写看得见的东西：光线、雨、低头的动作、被压住的影子 |
| **特征词不进提示词** | 一致性闸门报漏词 | 把设定卡的 `features` 逐字贴进该格 `prompt` |
| **要求画文字** | 图上出现歪掉的招牌字 | 出图不承担加字；对白走 `dialogue.md` |
| **比例没对齐** | 拼页留白一格宽一格窄 | `images --snap-exact` |
| **格数太少** | 3 格讲完一场戏，读起来像大纲 | 一格 = 读者看一眼的时间，拆到 6~12 格再收 |
