# 开始使用：注册、充值、配置 Key

本 Skill 的所有能力都通过 **a7w 插件市场**（`https://api.a7w.cn`）调用。
你需要一个 a7w 账号和一把 API Key，**Skill 本身不提供、也不内嵌任何 Key**。

---

## 一、注册账号

1. 打开 **https://aigc.a7w.cn**
2. 点右上角「**登录 / 注册**」
3. 用**手机号 + 短信验证码**完成注册（首次登录即自动注册）
4. 登录后右上角会显示你的账号

> 如果提示「该功能需要更多算力」或「配额不足」，说明账号已注册但还没充值，看第二节。

---

## 二、充值 / 兑换算力

平台的计费单位是**点数（算力）**，按调用量扣。

1. 进入「**算力中心**」（路径 `/compute-mall`）
2. 两种方式获取点数：
   - **在线充值**：选择套餐直接支付
   - **激活码兑换**：有激活码的话在算力中心兑换

> 未充值的账号调用会返回 `402`，错误信息里会写明**本次需要多少点、当前有多少点**，
> 可以据此判断要充多少。

---

## 三、获取 API Key

1. 在「**算力中心**」里找到 **API Key** 管理入口
   （对应站内接口 `/compute-mall/user-key`，也可以直接问站内客服具体位置）
2. **创建一个 Key**，形如 `sk-xxxxxxxx...`
3. **完整复制保存** —— 多数平台只在创建时显示一次完整 Key
4. 部分模型/插件是**邀请制或需单独申请**（例如 `happy_horse` 内测邀请制），
   按站内提示提交申请后再调用

---

## 四、把 Key 配置到客户端

本 Skill 自带一个零依赖的命令行客户端 `scripts/a7w.py`。

### 方式一：登录保存（推荐）

```bash
python3 scripts/a7w.py login --key sk-你的key
```

验证通过后会写入 `~/.a7w/config.json`（权限 600），之后所有命令都不再需要带 Key。

### 方式二：环境变量

```bash
export A7W_API_KEY=sk-你的key
```

> 优先级：`--key` 参数 > 环境变量 > 本机配置文件。

### 验证是否配好

```bash
python3 scripts/a7w.py whoami     # 应返回 ok: true 与可用插件数量
python3 scripts/a7w.py apps       # 列出你这个 Key 能用的所有插件
```

---

## 五、常见错误对照

| 现象 | 原因 | 处理 |
|---|---|---|
| `401` / 鉴权失败 | Key 无效或已过期 | 重新创建 Key 并 `login` |
| `402` / 点数不足 | 账号余额不够本次调用 | 去算力中心充值；错误信息里有本次所需点数 |
| `403` / 无权限 | Key 所属账号没有该插件权限 | 确认插件是否需单独申请 |
| `请先配置API Key` | 客户端没读到 Key | 执行 `login` 或设置 `A7W_API_KEY` |
| 「License 已过期，请激活」 | 账号授权到期 | 算力中心重新激活 |

---

## 六、安全提示

- **不要把 Key 写进代码或提交到仓库**；用 `login` 存本机或环境变量
- Key 泄露等于余额泄露，发现异常立即在算力中心**吊销重建**
- 本 Skill 的脚本**不会**把 Key 发送到 a7w 以外的任何地址
