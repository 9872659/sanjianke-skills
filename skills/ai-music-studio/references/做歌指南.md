# 做歌指南 · 从一句话到一首成品

这份指南解决一件事：**怎么把"我想要一首歌"变成实际能跑的命令，并且第一次就出得能听。**

---

## 一、先想清楚：你要哪一种

| 你的状态 | 走哪条路 | 花多少 |
|---|---|---|
| "我也不知道要什么，先听听" | **灵感模式**：一句 `prompt` 直接 `create` | 0.65 元 |
| "我有明确主题，想让 AI 写词" | `lyrics` 写词 → `create`（`custom:true` + `lyric_prompt`） | 0.77 元 |
| "歌词我自己写好了" | `style` 优化风格 → `create`（`custom:true` + `lyric`） | 0.79 元 |
| "要正式交付，得有无损" | 上面任一条 + `wav` 导出 | +0.14 元 |
| "要用我的声音唱" | 额外做一次 `voice_clone`（可复用） | +0.20 元 |

> **不确定的时候先走灵感模式。** 0.65 元听一版，方向对了再用自定义模式精修，
> 比一上来就纠结歌词省事得多。

---

## 二、灵感模式：一句 prompt 出歌

关键就一句：**把"风格 + 情绪 + 乐器 + 人声"四件事写清楚。**

```bash
curl -sS -X POST "https://api.a7w.cn/api/v1/apps/music_generation/create" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type":"generate","custom":false,"prompt":"一首轻快的城市清晨民谣，木吉他扫弦，温暖男声，中速","instrumental":false}'
```

**prompt 四要素：**

| 要素 | 例子 |
|---|---|
| 风格 / 曲风 | 城市民谣、lofi、City Pop、国风、交响、电子舞曲、爵士 |
| 情绪 | 温暖、治愈、燃、孤独、复古、紧张 |
| 乐器 / 编制 | 木吉他扫弦、钢琴、弦乐铺底、808 鼓组、无人声 |
| 人声 | 温暖男声 / 清亮女声 / 合唱 / **纯伴奏（`instrumental: true`）** |

**常用 prompt 模板：**

```
[情绪] 的 [曲风]，[乐器]，[人声]，[速度]
```

| 场景 | 可直接用 |
|---|---|
| 短视频口播背景 | `轻松愉快的 lofi 背景音乐，钢琴与轻鼓点，无人声，循环感，中速` |
| 短剧高燃片头 | `紧张感强的电子配乐，重低音鼓组，弦乐渐强，无人声，快速` |
| 电商带货 BGM | `明亮活泼的流行电子，合成器，节奏轻快，无人声，中速` |
| 播客片头 | `简洁现代的爵士钢琴小品，低音贝斯，无人声，慢速` |
| 情感向文案 | `略带忧伤的钢琴独奏，弦乐铺底，无人声，慢速` |

> 想要**纯音乐**就一定要带 `instrumental: true` —— 否则即使 prompt 写了"无人声"
> 也可能给你一版带唱的。

## 三、自定义模式：自己掌控词和风格

### 3.1 让 AI 写词

```bash
curl -sS -X POST "https://api.a7w.cn/api/v1/apps/music_generation/lyrics" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"写一首关于凌晨加班后骑车回家的城市民谣，主歌写疲惫，副歌写希望"}'
```

**`lyrics` 的 prompt 也要给结构**，不要只给主题：

| 给什么 | 效果 |
|---|---|
| ❌ `写一首关于青春的歌` | 泛泛，结构可能不完整 |
| ✅ `写一首关于毕业那天最后一次走出校门的歌，主歌写具体场景（教室/操场/自行车棚），副歌要明亮有希望，两段主歌一段副歌` | 结构清晰，可直接用 |

**★ 实测发现：`lyrics` 顺手把 `style` 也给你了。**

返回的 `data.result.data.tags[0]` 是一段**专业英文编曲描述**，直接可以当 `style` 用：

```json
{
  "title": "夜归单车",
  "text": "[Verse 1]\n楼下的风有点冷\n... (完整 Verse/Pre-Chorus/Chorus/Bridge)",
  "tags": ["City folk with gentle fingerpicked acoustic guitar, brushed percussion,
            and a steady walking bass; verse feels weary and close-mic ..."]
}
```

> 实测：输入 `写一首关于凌晨加班后骑车回家的城市民谣，主歌写疲惫，副歌写希望`，
> **8.5 秒**返回，`title` = 「夜归单车」，扣 **12 点**。
>
> **结论：走 `lyrics` 就不用再单独调 `style`，省 0.14 元。**

### 3.2 把风格描述优化得更专业（可选）

**如果你已经走 3.1 拿到了 `tags`，这一步可以跳过。**
只有在「**词是自己写的**」或「**想在现有风格上再精修一版**」时才需要：

```bash
curl -sS -X POST "https://api.a7w.cn/api/v1/apps/music_generation/style" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"城市民谣，木吉他，温暖男声，慢速"}'
```

你写一句大白话，它给你一段更完整的**专业风格描述** —— 把这段填回 `create` 的 `style`，
效果通常比自己写的好。**这 0.14 元很值。**

### 3.3 生成

```bash
curl -sS -X POST "https://api.a7w.cn/api/v1/apps/music_generation/create" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type":"generate",
    "custom":true,
    "title":"凌晨两点的环路",
    "lyric":"<3.1 拿到的歌词>",
    "style":"<3.2 优化后的风格>",
    "vocal_gender":"m",
    "weirdness":0.3,
    "style_influence":0.7,
    "style_negative":"电子, 说唱, 高亢"
  }'
```

**三个"控制旋钮"怎么调：**

| 参数 | 调低（0.2 左右） | 调高（0.8 左右） |
|---|---|---|
| `weirdness` | 稳、规整、像标准流行歌 | 敢玩、结构意外、可能出惊喜也可能翻车 |
| `style_influence` | 风格描述只是参考，AI 自由发挥 | 紧贴你写的风格，偏离小 |
| `audio_weight` | 少依赖参考音频 | 更像参考音频（翻唱场景用） |

**建议起点**：`weirdness: 0.3` + `style_influence: 0.7` —— 既有个人风格又不失控。

`style_negative` 是最容易被忽略但很有用的一项。比如要民谣就写
`"电子, 说唱, 重金属"`，能明显减少跑偏。

## 四、用你自己的声音唱

分两步：**先克隆音色（做一次），再在生成时带上它。**

```bash
# ① 克隆（0.20 元，只需一次）
curl -sS -X POST "https://api.a7w.cn/api/v1/apps/music_generation/voice_clone" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"audio_url":"https://你的存储/我的清唱.mp3","name":"我的声音","description":"清亮男声"}'
```

**参考音频的要求（达不到效果会很差）：**

| 要求 | 说明 |
|---|---|
| 格式 | MP3 或 WAV |
| 时长 | **至少 10 秒**（建议 30 秒以上） |
| 内容 | **单人清晰人声** |
| 环境 | **尽量避免背景噪音和背景音乐** |
| 访问 | 必须是**公网可访问的 URL**，不支持本地路径 |

```bash
# ② 用克隆出来的音色生成
curl -sS -X POST "https://api.a7w.cn/api/v1/apps/music_generation/create" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type":"generate","custom":true,"lyric":"...","style":"...","persona_id":"<克隆返回的 ID>"}'
```

**另一种玩法：`persona`** —— 先把一首**已经生成的歌**变成可复用的"歌手风格"，
之后所有歌都保持这个人设。适合要做**系列内容 / 矩阵号**的场景：

```bash
curl -sS -X POST "https://api.a7w.cn/api/v1/apps/music_generation/persona" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"audio_id":"<已生成歌曲的 audio_id>","name":"城市夜行者","vocal_start":30,"vocal_end":60}'
```

## 五、导出与交付

| 你要什么 | 用哪个接口 | 费用 |
|---|---|---|
| 无损音频 | `wav` | 0.14 元 |
| 带画面的视频 | `mp4` | 0.20 元 |
| 想再编曲 | `midi` | 0.14 元 |
| 做字幕 / 卡点 | `timing`（歌词时间轴） | **免费** |
| 只要伴奏 / 只要人声 | `vox` 或 `create` 的 `stems` | 0.14 / 0.65 元 |

```bash
# 导出无损 WAV
curl -sS -X POST "https://api.a7w.cn/api/v1/apps/music_generation/wav" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" -d '{"audio_id":"<audio_id>"}'

# 歌词时间轴（免费，做字幕用）
curl -sS -X POST "https://api.a7w.cn/api/v1/apps/music_generation/timing" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" -d '{"audio_id":"<audio_id>"}'
```

## 六、几个省钱的实战技巧

1. **`query` 和 `timing` 免费** —— 轮询状态、拿时间轴都不花钱，放心用
2. **先用灵感模式探方向**（0.65 元），方向对了再走自定义模式精修
3. **克隆音色只花一次钱** —— 同一音色后面所有歌都能复用，做矩阵号特别划算
4. **`lyrics` 一趟拿两样** —— 歌词 + `tags` 里的专业风格描述，省掉单独的 `style` 调用
5. **`instrumental: true` 出纯伴奏**，比生成带唱版再分离人声便宜得多
6. **别重复提交** —— 每次 `create` 都扣 65 点，提交后先记 `task_id` 再查状态
7. **用 `usage` 对账** —— 每次返回里 `data.usage.points_cost` 是真实扣费，可以核对
