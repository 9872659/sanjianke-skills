# 房产汽车 一单一套房源片 28 元

**一单房源片 28 元，一天 10 单 279 元。** 小区大门 3 秒说清位置，楼栋交代楼位与朝向，户型图讲动静分区，采光当面给，配套报地铁与学校，价格摆总价与单价，最后一句落到核验码与看房。

车源是同一套打法，换 `--vertical car`：绕车一圈、坐进内饰、报参数、试一段、算落地价。

## 房源 30 秒的七段结构

| 时间 | 段落 | 画面 | 口播干什么 |
|---|---|---|---|
| 0-2.4 秒 | 小区大门 | 街边推到大门，门禁、招牌、绿化 | 报楼盘名 + 城市区域 + 户型 + 总价 |
| 2.4-5.9 秒 | 楼栋与楼位 | 外立面、单元门、楼层指示 | 报楼层、朝向、楼位 |
| 5.9-11.2 秒 | 户型图 | 户型图动画，手指走动线 | 报面积，讲动静分区 |
| 11.2-16.5 秒 | 采光 | 客厅窗户推到阳台，自然光实拍 | 报朝向与采光 |
| 16.5-21.2 秒 | 配套 | 小区内景、门口地铁口与学校 | 报交通、学校、生活配套 |
| 21.2-26.5 秒 | 价格 | 挂牌页、单价对比、在挂套数 | 报总价与单价 |
| 26.5-30 秒 | 联系方式 | 封面定格、二维码、私信入口 | 报核验码与看房方式 |

秒数按权重分配（8 / 12 / 18 / 18 / 16 / 18 / 12），`--seconds 45` 时七段等比缩放，脚本不用手改。

## 车源 30 秒的五段结构

| 时间 | 段落 | 画面 | 口播干什么 |
|---|---|---|---|
| 0-7.2 秒 | 外观环绕 | 绕车 45 度，大灯、轮毂、腰线 | 报车型、车款、车价、里程、一手车 |
| 7.2-13.2 秒 | 内饰 | 车门拉开，中控、座椅、方向盘 | 报内饰与成色 |
| 13.2-19.2 秒 | 参数 | 仪表、参数牌 | 报上牌年份、排量、变速箱、过户次数 |
| 19.2-25.2 秒 | 试驾 | 起步、掉头、倒车影像 | 讲底盘、转向、刹车的主观感受 |
| 25.2-30 秒 | 落地价 | 报价单、落地明细 | 报车价、过户费、保险、落地价 |

快切版只留最能转化的几段：房源是小区大门 → 户型图 → 价格 → 联系方式；车源是外观 → 内饰 → 落地价。

## 三条用钱换来的规矩

**一、读比写贵。** 应用层 `/query` 每查一次都按该应用单价结算，`nano_banana/query` 实测 72 点/次；`GET /api/v1/apps/<app>` 更狠，命中 `/apps/<app>/*` 通配计价、即时扣费不退（实测 dressing_diffusion 200 点、nano_banana 72 点各一笔）。本包所有查询走 `GET /api/v1/tasks/<id>`，要目录只看 `/api/v1/apps` 与 `/api/v1/pricing`，三条都是 cost:0。

**二、先用 480P 把结构跑通。** 一单 45 秒 480P 只要 761 点，1080P 是 2,831 点。结构没定稿前用 480P 试片，定稿那一条再上 1080P，一单差 21 块。

**三、首帧图有域名白名单。** 外站地址一律 400 `url_not_allowed`，只认 vr.a7w.cn、cdn2.jiujiushuyuan.cn/vr/、oss.gpu.likeadmin.cn/openapi/。`film --image 本地图.png` 会自动先 `POST /api/v1/upload`（免费）换地址。

## 合规检查（`qc` 已经做成默认动作）

- **房源核验码写在文案里**：核验码与挂牌页一致，口播念一遍、描述写一遍，客户搜得到。
- **价格表述三处对齐**：总价 + 单价 + 平台挂牌价，用「挂牌价」「参考价」，一处一个数字。
- **面积与里程口径统一**：房源写「建筑面积 89 平」与产证一致；车源写「2021 年上牌，表显 3.6 万公里」，报告编号与检测单对齐。
- **车况如实描述用正向说法**：「一手车」「原厂漆面」「保养记录齐全」「4S 店全程保养」，事实用正向句子讲。
- **学区信息给口径**：学校名照写，附一句「划片以当年公示为准」，不替教育部门下结论。
- **宣传语可核对**：「地铁 3 号线 200 米」「同小区在挂 12 套」比形容词更有说服力。
- **素材来源**：房源与车源自拍优先；同行爆款只借结构，画面自己拍。

## 退出码

| 码 | 含义 |
|---|---|
| `0` | 成功 |
| `2` | 用法错（缺 `--name` / `--text` / `--file`、秒数越界、选项缩写） |
| `3` | 自检或合规检查没过 |
| `4` | 需要确认 —— 没给 `--yes` |
| `5` | 预算不足 —— **一个请求都不发** |
| `6` | 调用失败 |
| `1` | 内部错误 |
| `130` | 被 Ctrl-C 中断 |

`--json` 成功是 `{"ok": true, ...}`，失败是 `{"ok": false, "exit": 5, "error": {"kind": "budget", "message": "…"}}`，stdout 只有一个 JSON 文档；`--json` 写在子命令前后都可以。
