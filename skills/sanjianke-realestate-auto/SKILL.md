# 房产汽车 一单一套房源片 28 元

> **先申请你自己的 API Key。** 本包不内嵌任何 Key，用的是你在 [api.a7w.cn](https://api.a7w.cn/) 注册的 Key，扣的是你自己账户的余额。填 Key：`python3 scripts/a7w.py login --key sk-你的key`。

**一单 28.31 元，把一套房源讲完。** 小区大门 3 秒说清位置，楼栋交代楼位与朝向，户型图讲动静分区，采光当面给，配套报地铁与学校，价格摆总价与单价，最后一句落到核验码与看房。车源是同一套打法：绕车一圈、坐进内饰、报参数、试一段、算落地价。

## 三条干货（别人不写进文档的）

1. **读比写贵，轮询只走通用查询。** 应用层 `/query` 每查一次按该应用单价结算，`nano_banana/query` 实测 72 点/次；本包只打 `GET /api/v1/tasks/<id>`，价目表里这条是 cost:0，等十分钟也是 0 点。同一个道理，`GET /api/v1/apps/<app>` 会命中 `/apps/<app>/*` 的通配计价、即时扣费不退（实测 dressing_diffusion 200 点、nano_banana 72 点各一笔），要目录只看 `/api/v1/apps` 与 `/api/v1/pricing`。
2. **先按 480P 把结构跑通。** 一单 45 秒 480P 只要 761 点（7.61 元），1080P 是 2,831 点；结构没定稿前用 480P 试片，定稿那一条再上 1080P，差 21 块。
3. **首帧图有域名白名单。** 外站地址一律 400 `url_not_allowed`，只认 vr.a7w.cn、cdn2.jiujiushuyuan.cn/vr/、oss.gpu.likeadmin.cn/openapi/。`film --image 本地图.png` 会先 `POST /api/v1/upload`（免费）换地址，`cover` 出的图正好落在白名单里。

## 合规检查（`qc` 已经做成默认动作）

- **房源核验码写在文案里**：核验码与挂牌页一致，口播念一遍、描述写一遍，客户搜得到。
- **价格表述三处对齐**：总价 + 单价 + 平台挂牌价，用「挂牌价」「参考价」，一处一个数字。
- **面积与里程口径统一**：房源写「建筑面积 89 平」与产证一致；车源写「2021 年上牌，表显 3.6 万公里」，报告编号与检测单对齐。
- **车况如实描述用正向说法**：「一手车」「原厂漆面」「保养记录齐全」「4S 店全程保养」，事实用正向句子讲。
- **学区信息给口径**：学校名照写，附一句「划片以当年公示为准」，不替教育部门下结论。
- **宣传语可核对**：「地铁 3 号线 200 米」「同小区在挂 12 套」比形容词更有说服力。
- **素材来源**：房源与车源自拍优先；同行爆款只借结构，画面自己拍。

## 参数与退出码

| 参数 | 默认 | 说明 |
|---|---|---|
| `--vertical` / `--name` | house / 必填（`plan`、`cover`） | house 房源 / car 车源；楼盘名或车型 |
| `--price` / `--verify` | 268 / 空 | 总价或车价（万）；房源核验码 / 车源检测报告编号 |
| `--platform` | beike | beike / anjuke / dcd / autohome |
| `--seconds` / `--short-seconds` | 30 / 15 | 主片与快切版秒数；`film` 单段 4~15 |
| `--resolution` | 1080P | 480P / 768P / 1080P / 2K / 4K |
| `--budget` | 6000 | 点数上限（**单位：点**，1 元 = 100 点） |
| `--yes` / `--dry-run` | — | 确认真实扣费 / 只打印请求 |

退出码：`0` 成功 / `2` 用法错 / `3` 自检或合规没过 / `4` 缺 `--yes` / `5` 超预算且一个请求都没发 / `6` 调用失败 / `1` 内部错 / `130` 中断。`--json` 成功是 `{"ok": true, ...}`，失败是 `{"ok": false, "exit": 5, "error": {"kind": "budget", "message": "…"}}`，stdout 只有一个 JSON 文档；`--json` 写在子命令前后都可以。
