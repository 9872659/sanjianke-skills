# 三剪客 · 本地出图工作台 Skill

在自己机器上跑扩散模型出图的操作指引：装好浏览器界面、放好模型权重、按显存调启动开关、用 HTTP 接口批量出图。

---

## 前置条件

- 一台有独立显卡的机器（NVIDIA 最省事，AMD / Apple Silicon / Intel 官方也有各自路径），显存越大越从容。
- Python 与 Git。官方对 Windows 明确要求 Python 3.10.6：更新的 Python 版本与 torch 兼容性不佳。
- 与本机显卡匹配的 PyTorch 构建（CUDA / ROCm 等），由启动脚本自动准备，不要手动全局装。
- 足够的磁盘空间放权重：单个检查点通常数 GB，再加 VAE、LoRA、放大模型。
- 首次启动需要联网下载依赖；想避免「自动下模型」这一步，就先自己把权重放进模型目录。

---

## 使用

1. 按平台走安装：Windows 可以下载 Release 里的 `sd.webui.zip`，依次运行 `update.bat` 与 `run.bat`；也可以克隆仓库后以普通用户身份运行 `webui-user.bat`。Linux 装好系统依赖后运行 `webui.sh`。
2. 把启动开关写进启动脚本的 `COMMANDLINE_ARGS` 变量，例如 `--medvram --xformers`、`--port 7861`、`--ckpt-dir /data/models/stable-diffusion`。
3. 启动后在浏览器里打开本地页面（默认 `7860`），先确认界面能加载出模型，再开始调参。
4. 要让别的程序调用：加 `--api`；不需要网页界面时再加 `--nowebui`，然后用 HTTP 调出图接口。
5. 出图卡住或爆显存时，回头调显存档位与分辨率，而不是先怀疑模型。

具体的开关清单、接口调用示例与避坑条目见 `SKILL.md`；开关的真实含义以当前版本 `--help` 输出和仓库 wiki 为准。

## 依赖

- Stable Diffusion WebUI 本体（克隆仓库运行，或用官方 Release 的 Windows 便携包）。
- Python 与 Git；Linux 侧还需要若干系统库（图形与内存分配相关，各发行版包名不同）。
- 与本机显卡匹配的 PyTorch / xformers 等推理依赖，由启动脚本装入项目自带的虚拟环境。
- 模型权重：检查点、VAE、嵌入、LoRA、放大器，按需自备；它们不随项目分发。
- 可选：社区扩展（例如控制网、图片浏览一类），装进扩展目录后启动时加载。

---

## 安全

- 不内嵌任何密钥；本地出图本身不需要任何 Key，只有接入外部算力服务时才需要。
- 默认只监听本机。加 `--listen` 等于把服务暴露给同网段，而它默认没有访问控制——只在可信网络里这么做，并用防火墙限制来源。
- 允许在界面里执行代码的开关是真正的高危项：开启后服务端可以跑任意代码，不要对不信任的人开放。
- 生成参数默认写进 PNG 元数据。把图发出去，等于把提示词、种子、模型名一起发出去；对外发布前先关掉或清理。
- 权重、扩展、样式文件都来自第三方来源。装之前确认来源可信，扩展会以你的权限运行在服务进程里。
- 出图结果是否可用于商业用途取决于模型授权，与这个界面无关，自己确认清楚再用。
