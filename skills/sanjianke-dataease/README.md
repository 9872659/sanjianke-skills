# 三剪客 · 开源 BI 数据可视化平台 Skill

DataEase 是自建的开源数据可视化分析平台：接上数据库或 Excel，用鼠标拖出图表、仪表板与数据大屏。本 Skill 讲清怎么装、怎么用 `dectl` 运维、常见故障怎么排。

---

## 前置条件

- 一台 64 位 Linux 服务器（官方文档口径为 Ubuntu 22.04 / CentOS 7.6）
- 4 核 8G 内存、200G 磁盘起；默认安装目录 `/opt/dataease2.0`
- 具备 root 或 sudo 权限，能执行安装脚本、操作 Docker
- 在线安装需要服务器可访问互联网；离线安装需要先自行取得官方安装包并放到 `/tmp`
- Docker 满足要求：优先用安装包内自带的，否则 v23.0.5 及以上
- 放通 22（SSH 运维）与 8100（Web 服务）端口，云主机需同时检查安全组
- 若复用已有数据库，需满足 MySQL 8.0.16 以上及官方给定的 `[mysqld]` 参数

---

## 使用

1. **部署**：走官方在线一键脚本，或用离线安装包解压后改 `install.conf` 再执行 `install.sh`。两者都在 `SKILL.md` 的「安装」一节。
2. **登录**：浏览器访问 `http://<服务器IP>:8100`，初始账号 `admin` / `DataEase@123456`，**首次登录立即改密**。
3. **接入数据**：在工作台建数据源（关系库、OLAP、Excel/CSV、API 等），在数据源之上建数据集。
4. **出图**：基于数据集拖拽生成图表，组合成仪表板；投屏场景另建数据大屏。
5. **日常运维**：`dectl status` 看状态，`start` / `stop` / `restart` / `reload` 做控制，`version` 查版本，`upgrade` 在线升级。
6. **升级前必做**：`dectl backup`（需要 v2.4 及以上）。升完用 `dectl clear-images` 清旧镜像，`dectl clear-logs` 清日志。
7. **忘记 admin 密码**：从 `/opt/dataease2.0/conf/mysql.env` 取库密码，改 `per_user` 表 `pwd` 字段的 md5 值。
8. **排障起点**：页面打不开先 `dectl status`；图表白屏/报错看「常见坑」一节对应的行。

## 依赖

- DataEase 本体（Docker 编排部署，包含应用、MySQL、APISIX 等容器）
- Docker 与 Docker Compose，版本满足官方要求
- 一个可选的外部 MySQL 8.0.16+ 实例（不使用内置库时）
- 各数据源的网络可达性与连接账号
- 出外网能力：用于在线安装，以及流向地图 / 符号地图这类依赖在线地图服务的组件

---

## 安全

- 不内嵌任何密钥
- 初始密码 `DataEase@123456` 是公开值，部署后**必须立即修改**；不要把 8100 端口直接暴露到公网
- 数据源连接串与数据库密码写入配置文件后会落在磁盘上，注意 `/opt/dataease2.0` 的目录权限与备份产物保管
- 重置密码用的 md5 哈希是弱校验手段，仅用于忘记密码时恢复访问，不能当作密码存储方案
- 平台会持有你接入的全部数据源凭证，接入前先确认这些数据源的授权范围
- 生产环境升级前先 `dectl backup`，并确认备份产物已复制到另一台机器
