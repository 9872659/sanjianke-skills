# 编剧阶段：事件图谱 → 故事骨架 → 剧本

这一步的产出直接决定片子能不能卖。Toonflow 的 ScriptAgent 三层里，
**骨架搭建**是含金量最高的一环——上游在这一份提示词里塞进了整套短剧方法论。

> 下面的规范是从 Toonflow 内置的 `script_execution_skeleton.md` 等技能文件里
> 提炼的执行口径。它们已经写进提示词，你不用手写，但**必须懂**——因为你要
> 审它的产出，不懂就挑不出问题。

---

## 一、章节事件提取（第 3 步，最容易被糊弄）

每个事件要落成结构化记录：

| 字段 | 说明 |
|---|---|
| 章节号 | **必须与原著严格一致**，后面所有环节都靠它对齐 |
| 人物 | 谁参与了 |
| 地点 | 在哪 |
| 事件 | 发生了什么 |
| 结果 | 造成什么改变 |
| 牵扯 | 埋了哪条线、牵扯到谁 |

**自检三条**：

1. 随便抽一章，事件表能不能还原出这一章的剧情？还原不出就是粒度太粗。
2. 事件里的章节号，有没有原著里不存在的？有就是模型编造的，必须清掉。
3. 副线和伏笔有没有被记成孤立事件？漏了后面埋伏笔会断。

---

## 二、故事骨架的八个组成部分

ScriptAgent 输出的骨架固定包含这些块（包在 `<storySkeleton>` 标签里，一次性完整输出）：

| 块 | 内容 |
|---|---|
| **故事核** | 一句话核心吸引力 + 核心心理级爽点 + 金手指及其约束 |
| **隐线** | 主角的内在成长轨迹（人物弧） |
| **人物小传** | 大三角核心角色，**全剧 ≤4 人** |
| **三幕结构** | 每幕的功能、核心问题、覆盖章节、对应集数、幕末转折 |
| **分集决策** | 逐集或总览展开 |
| **全局删减决策表** | 删了哪些章节、为什么 |
| **付费卡点设计** | 按总集数比例定位 |
| **股价级反转登记表** | 全剧约 3 个 |

**硬约束**：

- 总时长 = 集数 × 单集时长，从【项目配置】读取，**禁止硬编码**
- **压缩比 ≤ 40%**
- 每集必须有集末钩子
- 章节必须与事件表一致，不允许出现不存在的章节
- 每集须满足**黄金单集公式**：情节承接 + 冲突升级 + 价值币环 + 下集勾连

## 三、三条底层原则（统领所有招式）

1. **短剧是投放变现的即时情绪产品，情绪先行**
   长剧剧情先行，短剧情绪先行。平台算法只认单集停留率 / 完播率 / 互动率 → 当日 ROI。
   每个结构选择最终都回到一句话：这能不能让观众停留、追下去、点开下一集、愿意付费。

2. **三大密度是骨架级总标尺**

   | 密度 | 作用 |
   |---|---|
   | **情绪密度** | 让观众**愿意看**——单位时长内可共情情绪波动的频次与强度 |
   | **信息密度** | 让观众**看得懂、不敢划走**——有效信息量 |
   | **情节密度** | 让观众**追下去**——每个事件都服务主线、有因果、有冲突升级、有不可逆的价值转变 |

   注意最后一句：**情节 ≠ 事件**。流水账不算情节。

3. **预期管理是留人核心机制**
   建立预期 → 打破预期 → 埋下新预期。钩子、悬念、反转、卡点、节奏都是它在不同时间
   尺度上的应用。设计任何结构点前先问：现在观众处于哪一步？

## 四、大三角与矛盾设计

**大三角嵌套小三角**：

- **大三角**：3 个核心角色/势力构成全剧主要矛盾，贯穿始终，不可轻易改动
- **小三角**：围绕主角的次要矛盾，解决一个再进入下一个，避免多线并行
- 主流是**单线型**——短剧面向下沉市场，多线并行容易退稿

**矛盾 ≠ 冲突**（这条最容易被忽略）：

- 矛盾 = 内在、静态的「想要但得不到」（强欲望 vs 强阻碍）
- 冲突 = 外在、动态的「为解决矛盾与对手对抗的行为」
- 只堆冲突（吵架打斗）不强化矛盾，戏是空的

**矛盾四级阶梯**，爆款骨架须达 3~4 级：

| 级 | 特征 |
|---|---|
| 1 基本 | 欲望 vs 阻碍成立但太弱——平淡 |
| 2 强化 | 强欲望 + 强阻碍 + 不可调和 + 二选一困境 |
| 3 高级 | **两个好人因不同选择走向不同命运**（没有绝对好坏） |
| 4 升级 | 主角解决初始矛盾的行动招致更严重、不可回头的后果 |

> 金句：最好的矛盾不是好人打坏人，而是两个好人因不同选择走向不同命运。

## 五、爽点与金手指

**心理级爽点三类**，骨架须锁定核心 1 种：

| 类型 | 说明 | 典型赛道 |
|---|---|---|
| **优势/金手指** | 主角独有能力 | 系统、异能 |
| **归属** | 团结合作 / 共同目标 / 家国情怀 | 帮派、修仙、大女主、女战神 |
| **秩序** | 用逻辑推进还原真相 | 复仇、宫斗、悬疑、重生、寻亲、无限流、穿越 |

生理级爽点（性 / 暴力）易踩审核红线，归擦边剧，**慎用**。

**金手指原创性 = 能否售出的关键**：

- 必须新颖独一无二。同质化金手指 = 同质化剧本 = 卖不出去
- 桥段/反转若市面已出现 **>10 次**就别用
- 可以借结构骨架（先模仿再创新），但**设定必须升级**
- 金手指**必须有约束**（如有限次数的预知），避免无敌外挂

## 六、人物小传（≤4 人）

只为**大三角核心角色**立传：主角 + 反一号 + 1~2 关键配角，**总数 ≤4 人**。
短剧是单线型，人多则散。

每个角色**五要素**：

| 要素 | 内容 |
|---|---|
| 身份 | 姓名、外貌、职业、与主角关系、正/反面、作用 |
| 特征 | 性格、能力、行为习惯、家庭背景、标志动作或物件（记忆点） |
| 境遇 | 开场处境、目标、动机 |
| 行动 | 动机驱动的核心行动（一句话） |
| 结局 | 因行动达成的终点方向（不剧透细节） |

主角**额外四项**：

- **代入感五要素**：贴近普通人 / 无责受难（困境外部强加，主角责任≈0）/ 穷而不脏 /
  共情保护（开场就让观众想护他）/ 反差感
  > 注意「无责受难」的量级：多 1% 责任，少约 10% 共情。
- **反差两面**：表面 vs 内里 + 轮流出现的触发条件
- **金手指规则与边界**：能做什么 / **绝对不能做什么** / 释放代价
  > 边界最关键，无边界即贬值。
- **形态法则**（按赛道选一）：男频「隐刚义柔」，女频「敢爱敢狠」；
  女频核心爽点须**女主独立兑现**

再加两项防漂移：

- **说话风格**：句式偏好 + 2~3 个全剧复用口头禅 + 反差状态下的口吻变化
- **出场设计**：套「出场七技」至少一种（局部特写 / 动作登场 / 配角衬托 / 声音登场 /
  场景反差 / 道具登场 / 氛围铺垫）

**铁规矩**：反派必须有合理动机。「纯嫉妒所以害人」是低级写法，不是工具人。

## 七、前 10 集黄金结构

> 「前 10 集」指全剧开篇约 **前 10%~15%**，总集数短时按比例压缩
> （如 N=20 对应前 2~3 集）。付费点位置以比例公式为准，不是死记集数。

| 集数 | 核心任务 |
|---|---|
| 第 1-2 集 | 快速引入主角，**直接抛出强烈冲突**，实现「一秒入坑」 |
| 第 3-4 集 | 明确主角核心行动目标，埋后续伏笔 |
| 第 5-8 集 | 引入多方配角，多角度施压，强化矛盾 |
| 开篇段末 | 设「假付费点」（目标近在咫尺却落空）+ 首个正式卡点 |

**一卡三招**（前 10 集决定剧本生死，缺一就被毙）：

1. **三集定生死**：第 1 集写清主角的**性格 / 困境 / 目标 / 动机**四要素，
   敲定类型，男女主与反一号尽量都登场；2-3 集让主角立刻解决一个与反派相关的重大危机
2. **十集定全篇**：一卡是全剧定调（虐/爽/燃），前 10 集每集都体现类型元素
3. **卡点要卡住**：第 10 集结尾一个强钩子，且**卡在主线上**

**开篇即绝境、即高潮**（2 秒防划走、5 秒勾住）：

- 用三样东西直击人心：**极端困境 / 身份反差 / 情感暴击**，不交代前因后果
- **三天坑必避**：① 上来介绍人物、铺背景、讲世界观 ② 一群人开会、角色乱冒
  ③ 慢悠悠写景、扯前情
- 正反例：废稿（真千金回豪门，紧张自卑打量别墅）vs 报款（甩假千金一耳光、
  砸行李箱「这家有它没我」）

**投放视角**：前 10 集就是投放素材库——需凑出约 **10 个可剪成 30 秒投流素材的爆点**，
平均每集至少 1 个。付费冲动**前置到前 3 集**。

## 八、付费卡点

### 位置按比例算（N = 总集数，四舍五入）

| 位置 | 比例 | 设计要求 |
|---|---|---|
| 首次卡点 | ≈⌈N×0.10⌉ 集 | 核心矛盾升级（秘密将曝光、关系将破裂） |
| 二次卡点 | ≈⌈N×0.30⌉ 集 | 生死危机、秘密将揭露或遭反派陷害 |
| 中期卡点 | ≈⌈N×0.50⌉ 集 | 阶段性目标达成时迎来重大反转 |
| 后期卡点 | ≈⌈N×0.70⌉ 集 | 前期悬念与伏笔逐渐展开，引入重大翻转 |
| 收尾卡点 | ≈⌈N×0.90⌉ 集 | 克服困难、揭露阴谋、圆满收尾（短剧必保爽剧收尾） |

示例：20 集 → 约第 2/6/10/14/18 集；100 集 → 约第 10/30/50/70/90 集。

### 卡点设计三步（决定留存率）

1. **先把观众爽透**——把前几集憋的情绪一次性彻底释放，实实在在喂到嘴里
2. **顺主线拉高预期**——明确告诉观众「刚才只是开胃菜」，扣死主线
3. **卡准核心钩子**——结尾钩子必须绑定核心主线，不看下集不知如何发展

> **铁律**：卡点必须卡在主线上。脱离主线，再炸也没用。
>
> **错误写法**：结尾把高潮戛然而止吊胃口。观众没吃到甜头，凭什么留。

### 4 类核心付费点

| 类型 | 适用 | 写法 |
|---|---|---|
| 身份差 | 通用 | 隐藏身份暴露 / 身份错认澄清 / 身份升级展现 |
| 感情错位 | 女频 | 认错信物、认错人、欺骗蒙蔽解开 |
| 人物命运巨变 | 通用 | 被打压欺辱 → 机缘改变命运 → 强势反击 |
| 环境剧变 | 末世类 | 世界突发灾难，只有主角能掌控局面 |

付费点核心特征：**场面宏大、事态紧急、围观群众多**（大型宴会、认亲仪式、
新闻发布会、婚礼现场）。

## 十、审骨架时的检查清单

交给 ScriptAgent 出骨架后，拿这张表逐条对：

- [ ] 压缩比是否 ≤40%？超了说明该删的没删
- [ ] 每集结尾有没有钩子？随便抽 3 集看
- [ ] 章节号是否都能在事件表里找到？有对不上的就是编造
- [ ] 大三角是否贯穿始终？中途换主要矛盾会崩
- [ ] 核心矛盾在第几级？低于 3 级基本是平淡剧
- [ ] 金手指有没有约束？没有边界就是无敌外挂
- [ ] 人物小传是否 ≤4 人？超了就是铺群像，短剧会散
- [ ] 反派动机是否合理？「纯嫉妒」要打回
- [ ] 五个卡点位置是否按比例落位？
- [ ] 卡点是否卡在主线上？
- [ ] 前 10 集能否剪出约 10 个 30 秒爆点？
- [ ] 全剧是否有约 3 个股价级反转？
- [ ] 结局是不是爽剧收尾？

任一条不过，**让监督层打回重做，别带着问题往下走**。骨架阶段改一句话，
到分镜阶段可能要重出十几张图，到出片阶段就是几百块的视频生成费。
