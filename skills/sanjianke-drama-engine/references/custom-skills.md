# 自定义画风 / 题材技能包

内置的 11 个画风 + 12 个题材覆盖不了所有需求。比如你要做水墨风、要做港片复古、
要做某个特定 IP 的视觉，就得自己加一个。

---

## 一、先决定加哪一种

| 你的需求 | 加什么 |
|---|---|
| 画面不好看 / 风格不对味 / 色彩乱 | **画风包** `art_skills/` |
| 节奏不对 / 情绪不到位 / 镜头平淡 | **题材包** `story_skills/` |
| 两个都要改 | 两个都加，然后组合使用 |

判断方法：**看问题出在「画面」还是「讲故事」**。

- 角色长相、服装、场景、色彩、光影、质感 → 画风
- 燃点节奏、情绪设计、景别选择、运镜节奏、转场 → 题材

---

## 二、用脚手架生成

手建很容易漏文件或拼错目录名。用自带脚本：

```bash
# 画风包
python3 scripts/new_toonflow_skill.py --kind art --name 2D_ink_wash --out ./my-skills

# 题材包
python3 scripts/new_toonflow_skill.py --kind story --name Time_travel --out ./my-skills
```

生成的是**带 TODO 的空模板**，章节结构与上游一致，不含任何现成风格的内容。

### 命名规范

| 规则 | 原因 |
|---|---|
| 只用英文、数字、下划线 | 中文名在部分系统上会导致路径读取异常 |
| 画风包建议 `维度_风格` 前缀 | 如 `2D_`、`3D_`、`realpeople_`，与内置包排列一致 |
| 题材包用 `大驼峰_小写` | 如 `Hot_blooded_action`，与内置包一致 |
| 不要双下划线、不要前导下划线 | 避免与系统保留名冲突 |

脚本会自动拒绝不合规的名字。

## 三、每个文件写什么

### 画风包

优先级从高到低：

#### 1. `prefix.md` —— 最重要

这是**全局美学基础**，其他文件都从它派生。必须写清楚：

- **风格基因**：一级风格 / 二级风格 / 情感基调 / 质感锚词（4~6 个）
- **全局色彩盘**：核心色盘要带**具体色值**（如朱红 `#C93752`），并说明每个色的用途
- **色彩使用层级**：哪些是 L1 硬约束、哪些 L2 可微调、哪些 L3 可突破

> 色彩盘不带色值等于没写。模型对「中国红」的理解每次都不一样，
> 写 `#C93752` 才能稳定。

开头要保留这句强约束（上游的做法）：

```
必须严格、完整遵循下方全部风格约束与全局规则，并严格按提示词模板格式生成提示词；
仅输出提示词正文，不得附加任何解释、说明、注释、标题或其他额外文本。
```

没有这句，模型会在提示词里加解释文字，污染下游的生图输入。

#### 2. `art_prompt/art_character.md` 和 `art_character_derivative.md`

前者定**基础形象**（面容、肤感、体型、发型、基础服装、四视图规范），
后者定**衍生**（妆容、发型造型、服饰、配饰）。

这两份决定「角色长得稳不稳」。**四视图设定图规范**尤其关键——它保证
同一个角色在正面/侧面/背面/特写里是同一个人。

每份末尾都要有：

- **提示词模板**：可直接套用的模板
- **约束规则**：分「必守」和「严禁」两栏

「严禁」栏要写明**本风格不允许出现什么**。比如国风包严禁「完全写实摄影/3D 写实渲染」
「西方奇幻/哥特/维多利亚风格」「赛博朋克/科幻/过度现代元素」。不写严禁项，
模型会在某些场景偷偷漂移。

#### 3. `art_prompt/art_scene.md` 和 `art_scene_derivative.md`

场景基础和衍生（景别、时段、天候、角度变体）。

`art_scene.md` 里的**季节色调映射**值得认真写——同一场景春夏秋冬的色调基调不同，
不写清楚同一地点跨季会像换了个地方。

#### 4. `driector_skills/director_storyboard.md`

分镜提示词的**风格专属技法**。这份直接决定出图质量，重点写：

- **情绪 → 面容/眼神词映射表**（让情绪可执行）
- **光影氛围词库**：分时间段光线、情绪光影
- **固定风格锚定词**：所有输出必须包含的那几个词
- **美学禁止项**
- **完整生成示例**：给一组「输入 → 输出」，模型照着学最快

#### 5. `art_storyboard_video.md`

图生视频环节的风格约束。内容可以很短，但别留空——不写的话视频阶段会丢掉风格。

#### 6. `README.md`

给**人**看的：风格定位、适用范围、严禁内容、风格体验。不参与生成，但团队协作时有用。

### 题材包

只有两份，但都是精华：

#### `director_planning_narrative.md`

六节叙事要点：

| 节 | 写什么 |
|---|---|
| 主题立意与内核 | 这类故事的核心魅力是什么 |
| 叙事结构与节奏 | 情绪曲线怎么走 |
| 分场景情绪设计 | 典型段落怎么设计情绪 |
| 声音与音乐方向 | 什么时候用声音推情绪 |
| 构图与景别叙事 | 用什么景别表达什么 |
| 镜头运动与节奏 | 运镜怎么服务情绪 |

#### `director_storyboard_table_narrative.md`

分镜表阶段的叙事技法：景别选择、运镜节奏、时长把控、关键镜头设计、台词处理、转场设计。

> **写法建议**：先写「核心理念」3~4 条（一句话能记住的），再把它们展开成具体技法。
> 光有技法没有理念，模型抓不住重点；光有理念没有技法，模型不知道怎么落地。

## 四、校验

生成或写完后跑一次结构校验：

```bash
python3 scripts/check_toonflow_skill.py ./my-skills/2D_ink_wash
```

它会检查：

- 文件是否齐全（画风 12 个 / 题材 3 个）
- 有没有空文件
- **导演目录名是否误写成 `director_skills`**（写成这样会静默不生效）
- 哪些文件还是 TODO

加 `--json` 可以拿到结构化结果。

---

## 五、安装

把整个包目录复制到 Toonflow 的对应位置：

| 包类型 | 目标路径 |
|---|---|
| 画风包 | `data/skills/art_skills/<你的包名>/` |
| 题材包 | `data/skills/story_skills/<你的包名>/` |

然后刷新页面（或重启服务）让技能列表重新加载。

**目录名就是技能 ID**，改名等于换一个技能。

## 六、自检清单

写完别急着跑全剧，先做这几件事：

- [ ] `check_toonflow_skill.py` 通过
- [ ] `prefix.md` 的色彩盘带具体色值
- [ ] `prefix.md` 开头有「仅输出提示词正文」的强约束
- [ ] 每个 art_prompt 文件末尾都有「必守 / 严禁」
- [ ] 「严禁」栏写了本风格**不允许**出现的画风漂移方向
- [ ] `director_storyboard.md` 有情绪→画面词的映射表
- [ ] 有完整生成示例（输入 → 输出）
- [ ] 导演目录名是 `driector_skills`

然后：

- [ ] 拿**同一段原著**用新包跑一遍，和内置包对比
- [ ] 出 5~10 张同一角色的不同角度图，看是不是同一个人
- [ ] 出一个跨昼夜/跨季节的场景，看色调是否统一
- [ ] 跑一段含长台词的戏，看分镜拆得对不对

整个过程用 `scripts/cost_estimate.py` 先算一下预算，图片环节很便宜，
可以多试几轮；视频环节贵，定稿前别批量生成。

## 七、常见错误

| 现象 | 原因 |
|---|---|
| 风格完全没生效 | 目录名写成了 `director_skills`，或包没放在 `data/skills/art_skills/` 下 |
| 提示词里混进解释文字 | `prefix.md` 开头缺「仅输出提示词正文」的强约束 |
| 同一角色不同镜头长得不一样 | `art_character.md` 的四视图规范没写清楚 |
| 同一场景跨季像换了地方 | `art_scene.md` 缺季节色调映射 |
| 色彩每次都不同 | 色彩盘只写了色名没写色值 |
| 某些场景突然变成别的画风 | 「严禁」栏没列全漂移方向 |
| 画面好看但节奏平 | 缺题材包，或题材包只写了技法没写理念 |
