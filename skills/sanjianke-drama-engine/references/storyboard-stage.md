# 制片阶段：分镜表 → 分镜图 → 视频

制片阶段由 ProductionAgent 负责。它的「分镜表」环节是整条流水线里**规则最硬**的一环
——上游把一位「从业 50 年的导演」的经验写成了 13 条铁律 + 9 条红线，写死在提示词里。

> 下面是从 Toonflow 内置的 `production_execution_storyboard_table.md` 等技能文件
> 提炼的执行口径。你要审它的产出，就得按同一套标准看。

---

## 一、分镜表的输出格式

整张分镜表包在 `<storyboardTable>` 标签里，**一次性完整输出**，内部按场次组织。

**场头**：

```
## 场N：场景名 ｜ 参演角色：角色A、角色B、…
```

- N 从 1 起，与剧本 / 分场汇总表的场次顺序和场景名一致
- 参演角色 = 该场全部出场角色（**含仅局部 / 背影 / 虚焦可见者**），按出场顺序列
- 纯空镜场写「参演角色：无」

**片段**：

```
### 片段一（约10s）
**引用资产名称**：[苏晚卿, 凌玄, 青云令, 大殿]
**引用资产ID**：[101, 100, 202, 300]

| 序号 | 画面描述 | 时长 | 景别 | 运镜 | 台词 | 音效 |
|------|------|------|------|------|------|------|
| 1 | … | 5 | 近景 | 缓推 |  | 音效：… |
```

注意这几列的分工：

| 列 | 只能写什么 |
|---|---|
| 画面描述 | 谁做了什么动作、姿态、表情、**当下正在发生的状态变化**（汗湿、泪痕、衣衫凌乱、青筋暴起） |
| 台词 | 剧本原文**逐字搬运**，标明来源人 |
| 音效 | 只写**环境音 + 音效** |

## 二、13 条铁律

**冲突时的优先级**：
`台词零删改` > `出场人物完整` > `只描述动作状态` > `长台词/长 VO 拆镜规则`

| # | 铁律 |
|---|---|
| 1 | 分镜做到优秀即可，**不追求唯一解**；镜头间景别视角注意错开 |
| 2 | **每个片段 ≤15 秒**，台词超载就拆片段 |
| 3 | **长台词 / 长 VO 强制拆镜**：同一片段内台词或 VO 超 **20 字**必须拆多个连续镜头，每镜换视角/景别，**按语义停顿点切，不平均切分**。跨镜可切到他人反应镜（画面是听者，声音继续是说话人）。语义不可切时必须单镜呈现的，用表情微妙变化 / 肢体持续演进 / 运镜缓慢推动填满时间，**禁止单镜固定** |
| 4 | **台词零删改**：引号内台词、VO、系统播报、面板文字 **100% 逐字搬运**。禁合并、禁精简、禁省略修饰词。分镜师只设计画面，**不做台词二次创作** |
| 5 | **台词时间按 4 字/秒**计算，按情绪语气分配，不平均切 |
| 6 | **在场人物不能消失**：先看清 `$ 出场人物` 列表，剧本没写「XX 离开」就还在场，必须有视觉痕迹（背景、局部、反应镜、纵深虚焦剪影、前景遮挡、环境音留痕均可）。出场人物都要用对应**资产名称**代替 |
| 7 | **群演只做微动作**（遮、瞥、垂、攥），服务当前戏核情绪；**禁止抢主角戏，禁止给群演单独配台词**；焦点锁前排，后方逐渐失焦 |
| 8 | **人物外观交给图片资产**：服装、发型、长相**不进分镜提示词** |
| 9 | 画面描述只写动作、姿态、表情、正在发生的状态变化 |
| 10 | **声音只写环境音 + 音效**；**禁止写 BGM / 配乐 / 音乐**。剧本里的【BGM】只读不抄 |
| 11 | **VO 音画同步**：旁白 / 内心独白 / 系统播报 / 面板文字 / 短信 / 弹幕 / 标语等一切文字信息，一律按普通台词处理，画面照常描写，文字 100% 原样写在分镜末尾的 VO 里。面板 / 屏幕 / 短信呈现时**逐行点亮 + 滴答音效**，关键数值（等级、数量、时间）单独**高亮放大一拍**，禁止整块静态显示 |
| 12 | 同场内要考虑切镜的连贯性和流畅性 |
| 13 | （专项）片段间过渡见下节 |

## 三、片段间过渡（消灭「跳跃感」）

这是分镜质量的分水岭。四类桥梁：

### 1. 动作的桥梁

相邻片段是同一组人物的连续动作时，**禁止让动作在片段边界「冻结」然后「跳转」**。
前一片段结尾必须是动作的**起始态**，后一片段首镜必须是该动作的**进行时或完成时**。

> ❌ A 结尾「他握紧剑柄。」→ B 开头「他拔剑冲上前。」
> ✅ A 结尾「他的手猛地握住剑柄，指节泛白。」→ B 开头「利剑『锵』一声出鞘，剑身映出他因怒火而扭曲的脸。」

### 2. 情绪的接力

前一片段结尾用**反应镜、眼神、微表情或肢体细节**为后一片段的情绪爆发做铺垫。

> ❌ A 结尾「她说：『你走吧。』」→ B 开头「他转身离开。」
> ✅ A 结尾「特写她说完后紧抿的嘴角和瞬间泛红的眼眶。」→ B 开头「他看着她强忍泪水的脸，喉结滚动，最终挫败地垂下眼，转身。」

### 3. 空间与视线的链接

用**空镜、视线引导、声音元素**建立空间联系。

> ❌ 室内激烈争吵结束 → 直接切到第二天喧闹的街市
> ✅ 争吵结束，人物愤怒看向窗外 → 接窗外暴雨敲打玻璃的空镜（雨声延续 0.5 秒）→ 叠化至次日街市大全景

### 4. 台词与动作的黏合

前一片段末尾的声音可以延续到后一片段首镜，由下一个画面承接。

> ✅ A 结尾「话音落下，『咚』的一声沉闷撞击。」→ B 开头「特写地上一只青花瓷碗，还在微微打转。」

## 四、执行流程（严格线性六步，不可回退）

| 步 | 做什么 |
|---|---|
| **1** | **一次性读取数据**：同轮调用 `get_flowData("script")`、`get_flowData("assets")`、`get_flowData("scriptPlan")`。**此后严禁再读**——冒出「再确认一下」的念头就是错误信号 |
| **2** | **对齐导演规划**：逐场取场景名 / 情绪浓度 / 情绪基调作为情绪依据；把「逐场注意事项」里的情感砸点、一致性锚点、空间距离、易错提示落实到具体镜头 |
| **3** | **生成结构化草案**：估时长（4 字/秒）→ 切 ≤15 秒片段 → **明确写出片段间的桥梁元素** → 片段内切镜 → 全员在场校验 |
| **4** | **输出分镜表**：一次性写入 `<storyboardTable>`，此时不再调用任何工具 |
| **5** | **自检**：对照下方红线逐项检查，**不得为此重新读数据** |
| **6** | 结束，回一句简短确认，不复述内容 |

第 2 步有个关键点：**导演规划只给情绪与注意事项，不提供镜头**。景别、镜头运动、
画面内容、镜头数量与拆分，全部由分镜表阶段自行设计。把这两者搞混会写出空洞的分镜。

## 五、9 条红线（写完必检）

- [ ] **不加载技法/skill**：第 1 步只读数据，全部规则以提示词为准
- [ ] **依据剧本、顺序一致**：按叙事顺序拆分，不遗漏、不新增情节
- [ ] **台词照搬**：所有台词（含 OS / VO）一字不改、标明来源人。**漏台词视为严重错误**
- [ ] **不可拍摄内容已处理**：心理 / 旁白 / 抽象交代已转译为可见物象或 OS/VO
- [ ] **连贯优先**：相邻剧情已合并为连贯镜头、未切无谓碎镜；长台词已按语义停顿拆镜；**已逐片段检查过渡规则**
- [ ] **资产真实**：只引用 `assets` 已有资产的真实名称，**缺失资产不编造名称、不编造 ID**
- [ ] **禁光影色调 / 禁配乐**：任何字段不出现光 / 影 / 色温 / 明暗 / 色调 / 暖色 / 冷色 / 逆光等词（特殊光照走场景衍生）；不写音乐 / 配乐 / 乐器烘托
- [ ] **只读引用资产**：严禁创建 / 修改 / 删除 / 生成任何资产
- [ ] **XML 一次性完整**：标签及全部内容一次性输出，禁止拆成多次

> 第 7 条最容易违反。模型很爱写「暖黄色夕阳逆光」，但这属于**风格层**的职责，
> 应该由画风技能包统一管，写进分镜表会导致全剧光影不一致。

## 六、从分镜表到出片

```
分镜表（本文件）
   ↓ 逐条出图
分镜图  ← 按画风包的 art_prompt / director_storyboard 规范
   ↓ 图生视频
视频节点  ← 回流无限画布
   ↓ 精调 + 拼接
成片
```

**分镜图阶段**：人物外观、服装、发型全部由**图片资产**决定（铁律 8），
所以出图前先把角色 / 场景 / 道具资产做齐。资产没做齐就出分镜图，
模型会自己编外观，出到第 10 张就跟第 1 张不是一个人了。

**视频阶段**：成本大头在这里（占九成以上）。先按分镜表出低规格试节奏，
分镜定稿后再批量吃高规格。别用「多生成几条挑一条」代替分镜设计——
那是把分镜师该干的活交给了视频模型，成本翻几倍。

## 七、出片质检

| 检查项 | 怎么看 |
|---|---|
| 台词是否漏 | 拿剧本逐场对，漏一句就是严重错误 |
| 人物是否消失 | 对照每场参演角色列表，逐片段数人 |
| 片段过渡是否跳跃 | 重点看片段边界，动作有没有「冻结后跳转」 |
| 光影是否统一 | 全剧抽 10 个镜头比对色温 |
| 角色形象是否漂移 | 同一角色在不同集里抽帧比对 |
| 废片率 | 剪掉的素材占比。官方 Demo 约 1/3，明显偏高说明分镜设计有问题 |
