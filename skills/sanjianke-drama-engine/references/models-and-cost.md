# 模型配置与成本

Toonflow 本身不带模型，它是个壳——**你不接模型，它什么都做不了**。
这也是新人最常卡住的地方：「装好了，进去是空的」。

---

## 一、三类模型，各干各的

| 类型 | 干什么 | 什么时候用 | 上游 Demo 用的 |
|---|---|---|---|
| **文本模型** | 拆章节事件、写故事骨架、定改编策略、写剧本、生成提示词 | 全流程 | Claude Opus 4.6 |
| **图像模型** | 角色 / 场景 / 道具 / 分镜图 | 制片阶段 | GPT Image 2 |
| **视频模型** | 图生视频 | 出片阶段 | Seedance 2.0 |

三类都要配，缺一类流程就在对应环节断掉。

**文本模型是主脑**。它不只写剧本，还要驱动三层 Agent 的调度、审核、打回。
所以文本模型的能力直接决定成片质量——这里省钱是最不划算的。

---

## 二、怎么配

在界面的**模型服务**里，按 **OpenAI 标准接口**填两样：

1. **API 密钥**
2. **请求地址**（Base URL）

因为走 OpenAI 兼容协议，所以任何兼容的网关都能接。

上游内置的厂商预设覆盖：

OpenAI · Anthropic · Google · DeepSeek · 智谱 · MiniMax · 通义千问 · xAI

填完点空白处，提示「供应商配置已更新」即生效。模型名如果不在预设里，
用**手动添加**把完整模型名粘进去。

### 可编程供应商

供应商层支持**直接在设置中心写 TypeScript 逻辑并即时生效**——不用改源码、不用重启。

用途：

- 接自建网关或私有化部署
- 做请求改写（换字段名、加 header、做重试策略）
- 多 Key 轮询 / 按模型路由

这是 Toonflow 比较少见的能力，私有化场景下很省事。

---

## 三、配完必查两处

漏一处就会出现「明明配了但不生效」：

- [ ] **模型服务**里的三个调用开关是否都已开启
- [ ] **Agent 配置**里各 Agent 引用的模型，是否与你刚配的一致

第二处最容易漏。你新配了模型，但 Agent 还指向旧的或空的，跑起来就报错或没反应。
不一致时点开改成你配的那个即可。

## 四、官方 Demo 的成本账单

上游给了一份很实在的参考：

| 项目 | 费用 | 占比 |
|---|---|---|
| 视频模型（全量生成） | 约 ¥120 | **92%** |
| 语言模型 | 约 ¥10 | 8% |
| 图片模型 | 不足 ¥1 | <1% |
| **合计** | **约 ¥130** | |

制作条件：约 2 小时完成，成片约 2 分钟（原始素材 3 分钟，剪除废片约 1 分钟）。

**结论非常清楚：视频生成占了九成以上成本。**

## 五、省钱只有一条路

减少**要生成的视频秒数**。具体做法：

| 做法 | 效果 |
|---|---|
| 剧本阶段就删掉不拍的场次 | 省的是最贵的那部分 |
| 分镜表先审到位 | 别用「多生成几条挑一条」代替分镜设计 |
| 先出低分辨率试节奏，定稿后再吃高分辨率 | 同一段重做三次的成本 ≈ 一次高规格 |
| 压缩废片率 | 官方 Demo 废片率约 1/3；明显更高说明分镜有问题 |
| 先跑通 1 集再全剧铺开 | 把试错成本压在第 1 集 |

**不要省的地方**：分镜图。图片成本不足总额的 1%，
多出几张挑一挑远比省图片钱划算。

## 六、先算一笔

用自带的估算脚本，按你的规模和单价算：

```bash
# 默认参数（约 2 分钟成片，复现官方 Demo 量级）
python3 scripts/cost_estimate.py --minutes 2

# 30 集 × 2 分钟，并看单集成本
python3 scripts/cost_estimate.py --episodes 30 --minutes 2

# 换一个更贵的视频模型
python3 scripts/cost_estimate.py --minutes 2 --video-price 1.2

# 分镜粗、废片多
python3 scripts/cost_estimate.py --minutes 2 --waste 0.5

# 拿 JSON 自己接后续处理
python3 scripts/cost_estimate.py --minutes 2 --json
```

关键参数：

| 参数 | 含义 | 默认 |
|---|---|---|
| `--minutes` | 成片总时长（分钟） | 2 |
| `--episodes` | 集数，用于另算单集成本 | 0（不算） |
| `--waste` | 废片率 | 0.34（对齐 Demo 的 3 分钟剪成 2 分钟） |
| `--video-price` | 视频生成 元/秒 | 0.67 |
| `--shot-seconds` | 平均每镜时长 | 3 |
| `--image-price` | 单张出图 元 | 0.02 |
| `--words` | 原著字数 | 150000 |
| `--llm-per-1k` | 语言模型 元/千字 | 0.067 |

> 默认单价是按官方 Demo 反推的**校准值**，不是报价。实际以你所用模型的实时价格为准，
> 把真实单价通过参数传进去才准。

## 七、想省事：官方算力镜像

如果不想自己配模型环境（尤其是想跑本地图片/视频模型），
镜像，开箱即用，预装了 Toonflow 和 ComfyUI。

**适合**：要跑本地模型、不想配环境。
**不适合**：只用 API 模型——那本机装客户端就够了，不必租 GPU。

一个 Key 可以调它平台上的所有模型。
