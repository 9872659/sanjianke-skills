# 三剪客 · 直给结论输出规范 Skill

让 AI 把结论放第一行、步骤编号、不写废话，输出一眼能用的极简结果

---

## 前置条件

- 一个支持自定义提示词或技能目录的 AI 客户端（多数对话客户端、AI 编程助手都支持）。
- 无需安装脚本、无需 API Key、无需联网。
- 建议先约定一个关闭口令（例如「恢复正常模式」），用于创作类与需要完整性的任务。

---

## 使用

三步生效：

1. 把 `SKILL.md` 与 `references/` 整个目录放进技能目录（SkillHub 安装会自动完成）。
2. 在会话里声明启用，例如「按直给结论规范回复」。
3. 需要退出时说「恢复正常模式」。

只想临时用一次，不必安装，直接把这段贴进对话：

```text
从现在起按以下形状回复，本轮有效：
1. 第一行就是结论或可直接执行的动作
2. 多步任务写成编号列表，每步一个动作
3. 结尾只给一个下一步动作
4. 不写开场白、不写复述、不写「还需要什么随时说」
```

想看得更深，按需读 `references/`：

| 文件 | 内容 |
|---|---|
| `references/attention-friendly-principles.md` | 五条认知约束、十条规则、六类破例场景 |
| `references/templates-and-examples.md` | 七类场景骨架、正反例、改写对照、句式替换表 |
| `references/adoption-and-pitfalls.md` | 团队落地、人工评分维度、十二种误用与修法 |

## 依赖

- **模型能力**：需要模型能稳定遵循格式指令；弱模型可能只执行「短」，不执行「先给动作」。
- **会话上下文**：规则要出现在系统提示或首轮消息里才可靠，只在某一轮说一次会被稀释。
- **宿主外壳**：宿主系统提示优先级高于本规范，冲突时以宿主为准。
- **无第三方依赖**：不调用任何接口，不引入任何包。

---

## 安全

- 不内嵌任何密钥、Token 或凭证。
- 零权限：不联网、不读写文件、不启动子进程。
- 不降低安全性：破坏性操作确认、风险提示、正确性优先于简洁，这三条不受本规范约束。
- 保留真实不确定性：只删不承载信息的模糊词，承载不确定性的措辞必须保留。
