# 三剪客 · 开源项目管理 Skill

Plane：开源项目管理 的安装、常用命令与避坑要点

---

## 前置条件

- **用托管云**：注册账号即可，不需要自备基础设施。
- **要自托管**：硬件按官方下限准备 2 核 CPU、4 GB 内存（生产建议 8 GB）；系统为 Ubuntu、Debian、CentOS、Amazon Linux 2/2023、macOS，或 WSL2 下的 Windows。
- 装好 Docker 与最新版 Docker Compose；社区版脚本需要 bash 环境（Windows 用 gitbash），执行用户要有 Docker 权限。
- 准备好域名与 TLS 证书（对外提供服务时），并确认所选监听端口在宿主上没有被占用。
- 生产环境按官方建议准备外部数据库与对象存储，而不是只用随部署拉起的本机容器。

---

## 使用

1. 先确定发行版与安装方式：官方主推的是商业版自托管安装器；社区版走发行版携带的脚本。
2. 社区版流程：建部署目录 → 下载 `setup.sh` → 赋可执行权限 → 运行并按菜单选安装。
3. 安装完先编辑生成的 `plane.env`：确认监听端口空闲，把 `WEB_URL` 与 `CORS_ALLOWED_ORIGINS` 改成实际访问地址（含端口），并替换默认口令。
4. 回脚本菜单选启动，确认一次性迁移任务成功退出、其余服务在跑，再访问配置的地址。
5. 日常运维（启停、重启、升级、查日志、备份）都从同一个脚本菜单进入。
6. 需要程序化访问时，用工作区维度接口与接口密钥；注意默认的调用频率限制。

部署变量含义、接口说明与排错清单见 `SKILL.md`。

## 依赖

- Docker 与 Docker Compose（官方要求最新版）。
- 组件：PostgreSQL、Redis、消息队列、S3 兼容对象存储；生产环境建议外接数据库与存储。
- 对外服务需要域名、TLS 证书与反向代理，以及防火墙侧放行所选端口。
- 本地开发另有从源码构建各子服务的工具链，与生产部署路径无关。
- 可选：代码托管 / 告警 / 检索等服务凭据（启用集成时）；商业档位可能另有授权密钥。

---

## 安全

- 不内嵌任何密钥
- 数据库、缓存、消息队列与对象存储的默认口令是公开的模板值，部署后必须全部替换。
- `plane.env` 含全部组件凭据，不要提交进版本库，也不要放在能被公网访问的位置。
- 默认监听 `80` / `443`，对外暴露前确认反向代理、证书与管理后台访问范围都已收敛。
- 生产环境把数据放在本机容器里意味着机器故障即数据丢失；至少要做到备份可恢复，并优先改用外部数据库与存储。
- 接口密钥有速率限制，且权限等同于其所属账号；按集成分别发放，避免共用一把。
- 升级前先备份，跨大版本按官方迁移文档执行，不要跳版本直接升级。
