# 把 a7w 接进框架 · 不同语言的写法

原则只有一条：**把模型提供方的 `base_url` 换成 `https://api.a7w.cn/api/v1`，
Key 换成你自己的 Key，`model` 换成模型清单里的名字。** 其余代码不动。

## 鉴权与端点

```
Base URL: https://api.a7w.cn/api/v1
Authorization: Bearer <你的 API Key>
```

| 用途 | 方法 | 路径 |
|---|---|---|
| 对话补全 | POST | `/api/v1/chat/completions` |
| 模型清单 | GET | `/api/v1/models` |
| 应用任务 | POST | `/api/v1/apps/{app}/{api}` |
| 任务查询 | GET | `/api/v1/tasks/{task_id}` |
| 计费规则 | GET | `/api/v1/pricing` |
| 账户点数 | GET | `/api/v1/user/balance` |

## Python

```python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://api.a7w.cn/api/v1",
    api_key=os.environ["A7W_API_KEY"],
)

resp = client.chat.completions.create(
    model="DeepSeek-V4-Flash",          # 换成模型清单里的任意一个
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
```

**只换 `model` 就能横向比价**：同一个问题丢给三家的模型，代码结构完全一样。

```python
for name in ("DeepSeek-V4-Flash", "Qwen3.6-Flash", "GLM-5"):
    r = client.chat.completions.create(
        model=name, messages=[{"role": "user", "content": "用一句话解释 RAG"}])
    print(name, "→", r.choices[0].message.content[:60])
```

## 换成 `curl` / HTTP 工具节点

不带 SDK 的运行时（定时任务、HTTP 请求节点、工作流里的 HTTP 节点、低代码平台）
按标准 OpenAI HTTP 形态发请求即可：

```bash
curl -sS -X POST "https://api.a7w.cn/api/v1/chat/completions" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"DeepSeek-V4-Flash","messages":[{"role":"user","content":"你好"}]}'
```

在图形化配置里对应三个字段：

| 字段 | 填什么 |
|---|---|
| API Base / Base URL / 接口地址 | `https://api.a7w.cn/api/v1` |
| API Key / 令牌 | 你自己的 `sk-...` |
| 模型 / Model | 从 `/api/v1/models` 里选 |

## 本地 `curl` 与 PowerShell 的差别

```powershell
# Windows PowerShell
$env:A7W_API_KEY = "sk-你的key"
curl.exe -sS -X POST "https://api.a7w.cn/api/v1/chat/completions" `
  -H "Authorization: Bearer $env:A7W_API_KEY" `
  -H "Content-Type: application/json" `
  -d '{\"model\":\"DeepSeek-V4-Flash\",\"messages\":[{\"role\":\"user\",\"content\":\"你好\"}]}'
```

> PowerShell 会吃掉双引号。复杂请求体**写进文件**再传（`--json-file body.json` 或
> `--body (Get-Content body.json -Raw)`），比跟转义较劲省事。

## 零依赖客户端

不想装任何 SDK 时，用包里的 `scripts/a7w.py` —— 只用 Python 标准库，
`login` / `apps` / `schema` / `call` / `task` 一条命令搞定：

```bash
python3 scripts/a7w.py call file_qa ask --body '{"file_url":"https://…","question":"要点是什么"}'
```

## 自检三问

1. `base_url` 是不是 **`https://api.a7w.cn/api/v1`**（不是裸域，也不是 `/api/v1/`）？
2. `model` 是不是**从模型清单接口拿的**，不是凭印象写的？
3. Key 是不是**走环境变量**，没有硬编码进代码或提交进 Git？
