# 三剪客 · 多平台 IM 机器人接入 Skill

把大模型接进微信、飞书、钉钉、企微、QQ、Telegram、Slack、Discord 等聊天工具的落地指引。

---

## 前置条件

- 一台**可信**的运行环境：本地电脑或自建服务器（Linux / macOS / Windows），或 Docker 环境。
  - 这一点是硬要求：该助手具备读写文件与执行终端命令的能力，上游明确要求只在可信环境部署。
- 源码部署需要 Python 运行环境，具体版本要求**以官方文档为准**。
- 至少一个大模型服务的 API Key；也可以用聚合渠道的单一 Key 接多家模型。
- 目标渠道的接入凭据：微信 / 飞书 / 钉钉 / 企微 / QQ / Telegram / Slack / Discord 等各自的机器人或应用配置。
- 若要 7×24 常驻：一台不断电、能出网的机器（或容器编排），并准备好 Token 预算。
- 若要从公网访问控制台：需要在配置里开启监听地址并设置访问口令，同时放行端口。

---

## 使用

按「部署 → 打开控制台 → 配模型 → 接渠道 → 装技能」的顺序推进。

1. **部署**，三选一：
   - Linux / macOS 一键脚本：
     ```bash
     bash <(curl -fsSL https://cdn.link-ai.tech/code/cow/run.sh)
     ```
   - Windows PowerShell：
     ```powershell
     irm https://cdn.link-ai.tech/code/cow/run.ps1 | iex
     ```
   - Docker：
     ```bash
     curl -O https://cdn.link-ai.tech/code/cow/docker-compose.yml
     docker compose up -d
     ```
   - 也可以用官方桌面客户端（macOS / Windows），内置运行环境。
2. **打开控制台**：`http://localhost:9899`。模型、渠道、技能、记忆都在这一个界面里配。
3. **公网访问加固**（只在需要外部访问时）：`config.json` 里把 `web_host` 设为 `0.0.0.0`，**同时设置 `web_password` 开启鉴权**，并放行 `9899` 端口。
4. **配模型**：在控制台里选厂商、填密钥。文本、图像理解、图像生成、语音识别 / 合成、向量可以分别指向不同厂商；也支持自定义厂商接本地模型或三方代理。
5. **接渠道**：多数渠道在控制台里接入；飞书、企微智能机器人支持扫码一键接入、不需要公网 IP。其余渠道的配置项以官方文档为准。
6. **装技能**：
   ```bash
   cow skill install <名称>
   ```
   或在对话里用 `/skill list`、`/skill search <关键词>`、`/skill install <名称>`。
7. **日常运维**：
   ```bash
   cow start | stop | restart
   cow status | logs
   cow update
   cow install-browser      # 需要浏览器自动化时
   ```

上述命令之外的细节（各渠道逐项配置、源码安装步骤）随版本变化，写在 `SKILL.md` 的「安装」「常用操作」「常见坑」三节，并统一以官方文档为准。

## 依赖

- 运行环境：Linux / macOS / Windows 本机，或 Docker + Docker Compose。
- 源码部署：Python 运行环境（版本要求以官方文档为准）。
- 模型侧：至少一个厂商的 API Key；或用聚合渠道的单一 Key 覆盖多家模型。
- 渠道侧：目标 IM 平台的机器人 / 应用凭据（应用 ID、密钥、令牌、回调地址等）。
- 可选能力：
  - 浏览器自动化需要额外安装浏览器运行时（`cow install-browser`）。
  - 语音识别 / 合成需要目标厂商支持该能力。
  - 图像理解与生成需要对应模型支持。
- 常驻要求：进程需要 7×24 存活，容器部署需配置重启策略。

## 安全

- 不内嵌任何密钥。
- **只在可信环境部署。** 该助手可以读写本地文件、执行终端命令、操作浏览器，权限等同于运行它的账号。
- Web 控制台要暴露到公网时，必须同时完成三件事：监听地址设为 `0.0.0.0`、设置 `web_password` 访问口令、仅放行必要端口。只改监听不改口令等于把控制台敞开。
- 模型 API Key、渠道应用密钥与令牌、控制台口令都属于敏感信息，不要提交到版本库，也不要贴进公开日志；`cow logs` 输出在分享前先过一遍。
- 记忆、知识库、会话记录都会落盘在工作目录，备份与迁移时同样按敏感数据处理；不需要长期保留时应主动清理。
- 一键脚本是从网络地址直接执行的形式，属于对上游分发通道的信任操作；有条件时优先使用容器或源码方式，并在执行前核对内容。
- 该助手能读取到的信息范围取决于部署机器的权限，建议用容器或独立主机隔离，限制其可访问的目录与网络出口。
- 上游声明本项目仅供技术研究与学习，使用时需遵守所在地法律法规；因使用产生的后果由使用者承担。
