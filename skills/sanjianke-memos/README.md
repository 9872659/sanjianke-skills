# 三剪客 · 碎片笔记速记 Skill

Memos：碎片笔记速记 的安装、常用命令与避坑要点

---

## 前置条件

- 一台装好 Docker 的机器（容器方式是官方主推路径）；或按二进制方式准备宿主级服务管理。
- 一台**长期在线**的运行环境——它是常驻服务，客户端与 API 都需要实例一直在。
- 数据目录要映射到宿主固定路径，并纳入备份范围。
- 对外提供服务时准备反向代理与 HTTPS，并把规范地址配好。
- 切换数据库时需要已有的 MySQL 或 PostgreSQL 实例；使用 API 与 MCP 需要先创建个人访问令牌。

---

## 使用

1. 用 `docker run` 起一个容器，映射端口 `5230` 与数据目录 `/var/opt/memos`。
2. 打开界面，**第一个注册的用户即主机管理员**，创建后按需决定注册是否开放。
3. 在实例设置里选定访问策略（私密或公开），并单独配置规范地址，两件事不要混为一谈。
4. 日常记录直接用 Markdown 写，靠标签、搜索、置顶做检索；需要分享的单条用可见性与分享链接控制。
5. 需要程序化访问时，在用户设置里创建个人访问令牌，用 Bearer 方式调接口；接 AI 助手则指向内置 MCP 入口。
6. 升级时拉新镜像、替换容器、沿用同一数据目录，并先做备份。

完整的变量表、数据库切换方式与排错清单见 `SKILL.md`。

## 依赖

- Docker（容器方式），或二进制方式下的宿主服务管理工具。
- 数据库：默认内置 SQLite；可选 MySQL 或 PostgreSQL。
- 存储：数据目录所在宿主路径的可用空间（含数据库与本地附件）。
- 可选：反向代理与 TLS 证书（对外服务）、Webhook 目标、SMTP 与 OAuth 配置（按需）。
- 集成侧：一个支持 Streamable HTTP 的 MCP 客户端（接 AI 助手时）。

---

## 安全

- 不内嵌任何密钥
- 个人访问令牌以用户身份生效，明文只在创建时显示一次；按集成分别创建，便于单独吊销。
- 数据库连接串等敏感值优先用 `*_FILE` 从文件或编排密钥注入，不要写死在命令行历史与镜像里。
- 第一个注册用户即主机管理员，部署后应立即创建并视情况关闭开放注册。
- 默认访问策略影响匿名可见性：新实例的初始策略与规范地址的配置相互独立，公开前请显式确认策略设置。
- 指向私网的 Webhook 默认被拒，用白名单变量精确放行，不要启用已弃用的整体开关。
- 数据目录包含全部笔记与附件，备份文件同理，不要暴露在公网可访问的位置。
