# 三剪客 · 头像写真工坊

给人像照或一段人设描述 + 一个内置风格包，**批量产出成套的头像与写真**——
头像 1:1、社交封面 3:4、横版 16:9，按「风格包 × 比例 × 变体」展开成矩阵，
**跑之前先告诉你花多少钱**。

```
styles →  看六个内置风格包（零网络、零成本）
plan   →  出拍摄方案（零网络、零成本，本地矩阵展开）
cost   →  只算钱不出图（零网络）
models →  列出在架应用与模型
gen    →  真花钱，先报价再确认
verify →  复核已有图片的比例真伪（零网络）
```

## 30 秒上手

```bash
# 1) 拿 Key（新用户有赠送点数）
#    到 https://api.a7w.cn/ 注册，创建一个 API Key

# 2) 配 Key
export A7W_API_KEY=sk-你的key          # Windows: $env:A7W_API_KEY="sk-你的key"

# 3) 看风格包（免费，不联网）
python3 scripts/run.py styles

# 4) 出方案（免费，不联网）
python3 scripts/run.py plan --style business --out plan.json

# 5) 先看要花多少钱
python3 scripts/run.py cost --count 3
#   预估成本：3 张 × 24 点 = 72 点 = 0.72 元

# 6) 出图（先不带 --yes 报价，确认了再加）
python3 scripts/run.py gen --plan plan.json --outdir ./out
python3 scripts/run.py gen --plan plan.json --outdir ./out --yes --snap
```

**零依赖**，只要 Python 3.7+，不用 `pip install` 任何东西。

`scripts/a7w.py` 是**所有 Skill 包共用**的零依赖客户端（我们靠 SHA256 校验各包副本是否一致），
本包没有改它；「读图片真实像素」这个私有能力放在独立模块 `scripts/imgprobe.py` 里。

## 三种交付形态

| preset | 形态 | 比例 | 排版目标像素 | 上游 1K 实测像素 |
|---|---|---|---|---|
| `avatar` | 头像 | 1:1 | 1024x1024 | 1024x1024（偏差 0.00%） |
| `cover34` | 社交封面 | 3:4 | 1080x1440 | 864x1184（偏差 2.70%） |
| `wide` | 横版 | 16:9 | 1280x720 | 1344x768（偏差 1.56%） |

加 `--snap` 会在本地居中裁准：3:4 → 864x1152、16:9 → 1344x756，裁后偏差都是 0.00%。
原始文件保留不删，两份都在，便于对账。

## 六个内置风格包

| 风格包 | 名称 | 适用场景 |
|---|---|---|
| `business` | 商务精英 | 个人 IP 主页、名片、简历、团队介绍页 |
| `literary` | 文艺清新 | 生活方式账号、书评影评、独立创作者主页 |
| `studiobw` | 黑白棚拍 | 设计师、摄影师、品牌主理人的高级感形象 |
| `neon` | 赛博霓虹 | 科技类账号、游戏与音乐人主页、潮流品牌形象 |
| `film` | 复古胶片 | 怀旧叙事内容、播客封面、独立杂志与访谈栏目 |
| `guofeng` | 国风雅致 | 传统文化内容、茶与香道、文博与文旅账号 |

每个风格包把**光线方向、背景材质、服装质地、后期调性**四件事钉死——
这是「一套图看起来像一组作品」而不是「从五个人的相册里各拿一张」的关键。
`--variants N` 在同一个「风格 × 比例」格子里**只轮换姿态**，所以多拍几张仍然是一套。

## 六道硬闸门

闸门都**拦截**（不是警告），因为出图是按次扣费的，而人物合规出问题的代价是账号：

1. **比例真伪** —— 把图下载回来**读文件头真实像素**再算比例，不信接口自报字段；
   容差内也照样打印真实像素与偏差
2. **人物合规**（本包特有）—— 公众人物 / 政治人物 / 明星的姓名与特征词拦截；
   **未成年人一律不做**，年龄数字 < 18 也拦
3. **恶俗 / 违背物理** —— 低俗、暴力违禁、解剖与物理不可能的表述
4. **成本上限** —— 超 `--budget` 不提交任何任务；每张提交前再核一次
5. **`prompt_echo`** —— 出图提示词与提示词里的示例**去标点后相等**、
   **Jaccard ≥ 0.75**、或**示例二元组覆盖度 ≥ 0.60**，三条任一命中即拦
   （模型会照抄提示词里的示例，哪怕示例标着"这是错的写法"）。
   第三条是补漏：写真提示词 60~150 字、示例只有 25 字，Jaccard 会被长度差摊薄——
   示例原样嵌进 102 字提示词里实测只有 0.245（放行），覆盖度是 1.00（拦下）。
6. **`--outdir` 在包内 → 退出码 2** —— 包只收文本文件，图片会让上传失败

## 成本

| 项 | 实测 |
|---|---|
| `nano_banana` 1K 出图 | **24 点/张** = 0.24 元 |
| 充值 | 1 元 = 100 点 |
| 提交时冻结 | 实测 `frozen_points = 31.2`（**预冻结，不是最终扣费**） |
| 完成后结算 | `usage.points_cost = 24` |
| 2K / 4K | **无实测单价** → 拒绝估算（退出码 3），除非给 `--points-per-image` |

**只信任务返回的 `usage.points_cost`。** 平台的 `pricing_matrix` / `tenant_*` 字段
我们验证过半数不可信（`image_human` 写 1.5/2/4/8 点/秒、实测 2/3/6/12；`voice_tts/stt` 写 30、实扣 40）。

## 断点续跑

出图中断后原样重跑即可，**提示词没变就不会重复扣费**（断点 key 含提示词，改了会重出重扣）：

```
[1/3] #1 已完成，跳过（上次扣费 24.0 点，不再重复扣）
[2/3] #3 发现未完成的 task_id=task_xxx，续查而不重新提交
```

## 图生图要自己先把照片放到公网

```bash
python3 scripts/run.py gen --plan plan.json --outdir ./out \
    --photo-url "https://你的图床/portrait.jpg" --yes
```

上游**只接受公网可访问的 HTTP/HTTPS 图片地址**，nano_banana 插件只有 `submit` 与 `query`
两个接口，**没有本地上传接口**。用别人的照片做图生图必须事先取得本人授权。

## 图片放哪里

**必须放在 Skill 包外**（默认 `%TEMP%\portrait-studio-out`）。包只收文本文件，
图片会让上传失败——脚本也会拒绝把 `--outdir` 指到包内（退出码 2）。
