# 风格包与提示词写法

> 本文件说明三剪客 · 头像写真工坊内置的六个风格包怎么用、出图提示词怎么写，
> 以及**提示词里绝对不该出现什么**（合规红线）。

## 一、风格包解决的是什么问题

出「成套」头像写真时，最怕的不是单张不好看，是**五张图来自五个世界**：
这张暖光那张冷光，这张纯色背景那张街景，这张西装那张卫衣。
拼在一起不像一组作品，倒像从五个人的相册里各拿了一张。

所以风格包把四件事**钉死**，让同一套里的每张图共享同一套视觉语汇：

| 字段 | 钉住什么 | 为什么必须钉死 |
|---|---|---|
| `light` | 光线方向、软硬、反差 | 光线方向一变，同一个人的脸型看起来都不一样 |
| `bg` | 背景材质、色调、虚化程度 | 背景是「一组感」最强的锚点 |
| `wardrobe` | 服装质地、色系 | 换一件衣服就是换一个场景，成套感立刻断 |
| `grade` | 后期调性：饱和度、色温、颗粒 | 后期不统一时，两张图并排会明显「不是一套」 |

另外两个字段 `scene`（适用场景）和 `tail`（收尾约束：无文字、无水印、无标识）是辅助说明。

## 三、提示词是怎么拼出来的（六段式）

本包的提示词是**本地确定性拼装**的，不经过大模型。结构固定为：

```
人设（--subject）
  → 机位（来自 preset：头像近景 / 3:4 半身 / 16:9 横构，含安全区说明）
  → 光线（来自风格包）
  → 背景（来自风格包）
  → 着装（来自风格包）
  → 后期（来自风格包）
  → 姿态（按 --variants 在 4 个姿态变体间轮换）
  → 收尾约束（无文字、无水印、无标识）
```

关于 `--variants`：同一个「风格 × 比例」要出多张时，**只有姿态会变**，光线/背景/着装/后期一律不变。
这是刻意的——变姿态是「多拍几张挑一张」，变光线是「换了个人设」，前者才能拼成套。

`--subject` 决定「是谁」。写得越具体，出图越稳定：

```bash
# 偏笼统（可以跑，但每张的年龄感会飘）
python3 scripts/run.py plan --style business --out plan.json

# 偏具体（推荐）
python3 scripts/run.py plan --style business \
    --subject "三十五岁男性，短发微卷，细框眼镜，气质沉稳，东亚面孔" \
    --preset avatar --preset cover34 --out plan.json
```

## 四、人像提示词的常见坑

| 坑 | 现象 | 怎么绕 |
|---|---|---|
| 描述太短 | 模型自由发挥，每张脸都不一样 | 把人设写足（年龄 + 性别 + 发型 + 气质 + 面孔类型） |
| 手部入镜 | 手指数量与关节容易出错 | 头像预设默认让「双手收在画面下缘之外」；真需要手部动作时人工复核 |
| 背景太满 | 主体被背景抢戏 | 风格包的 `bg` 里已写了虚化程度与材质，别在自建风格里加「繁华街道」这类高熵背景 |
| 光线方向冲突 | 同一套里有的左脸亮有的右脸亮 | 别改风格包的 `light`；要换光就换风格包 |
| 要求画面带字 | AI 生成的中文字几乎必错 | 收尾约束里已写死「无文字、无水印、无标识」，标题留给排版阶段叠 |
| 想要「证件照」但不当 | 生成结果偏艺术化 | 用 `studiobw`（黑白棚拍）或自建一个纯白背景风格包，别用 `neon` / `film` |

## 五、提示词里不许出现什么（合规红线）

出图提示词与最终画面强相关：**提示词里写了什么，画面和物料大概率就是那个调性**。
所以本包把下面五类做成**本地硬闸门**，命中即拦截、标红、退出码 3，不提交任何任务。

### 1. 别人的脸（人物合规，本包特有）

| 拦什么 | 例子 |
|---|---|
| 政治人物的职衔与类别词 | 主席、总统、总理、首相、总书记、领导人、议员、州长、政要、教皇、国王 |
| 公众人物 / 明星的类别词 | 明星、名人、公众人物、艺人、演员、歌手、影帝、球星、网红、主播、爱豆 |
| 指代结构 | 「像 ○○ 的脸」「○○ 同款脸」「撞脸」「换脸 / 人脸替换 / face swap」 |
| 姓名＋职衔 | 「○○ 主席」「○○ 总统」这类写法 |
| 外挂名单 | `--person-blocklist <文件>`，一行一个名字，命中即拦 |

> 关于「具体姓名」的说明见 SKILL.md 的「已知取舍」：
> 本包**不内嵌任何在世真实个体的姓名**，个体名拦截走 `--person-blocklist`。

### 2. 未成年人（**一律不做**，不留后门）

本包不做未成年写真类生成。命中以下任一种即拦：

- 词：未成年、儿童、孩童、幼儿、宝宝、婴儿、小孩、孩子、小朋友、少儿
- 年龄段词：少男、少女、少年、青少年、幼儿园、小学生、中学生、初中生、高中生
- 场景词：校服、校园风、童装、童星、萌娃、萝莉、正太、亲子照
- **年龄数字 < 18**：「12 岁」「15 周岁」「16 years old」

这条**刻意偏严**：「少年感」这类用于成年人的描述也会被拦。
理由很直接——写真场景下的年龄误判代价太高，宁可让人改一次措辞。

### 3. 恶俗与违背物理

- 低俗：色情、裸露、半裸、走光、情趣内衣、内衣写真、湿身、艳照、挑逗、擦边、大尺度、制服诱惑
- 暴力违禁：血腥、暴力、尸体、自杀、枪械、毒品、管制刀具、恐怖袭击
- 解剖不可能：三只手、六指、双头、两张脸、多臂、断肢、断头、穿模、关节反向
- 物理不可能：水往高处流、反重力、影子方向不一致、无视透视

### 4. 广告法违禁词

绝对化用语（国家级 / 最佳 / 最好的 / 第一品牌）、绝对化承诺（100% / 全网最低）、
虚构权威背书（国家认证 / 央视推荐）、医疗功效（根治 / 治愈 / 无副作用）、
投资承诺（稳赚 / 保本 / 零风险）、站外导流（扫码加 / 加微信 / 私信我）。

### 5. 照抄提示词示例

提示词里登记过的示例（见 `scripts/run.py` 的 `PROMPT_SAMPLES`），
只要产出的提示词与它**去标点后相等**、或**字符二元组 Jaccard ≥ 0.75**、
或**示例二元组的覆盖度 ≥ 0.60**（归一化后过短的按 `max(6, 示例长度/2)` 跳过），即拦。

第三条是补漏：写真提示词通常 60~150 字而示例只有 25 字，Jaccard 会被长度差摊薄
（示例原样嵌进 102 字提示词里只有 0.245，放行；覆盖度是 1.000，拦下）。

含义是：不要把你从别处抄来的一条完整示例直接当提示词用——排出来的图会和测试用例长得一样。
登记在案的示例都是**跨主题**的（音箱、图标），与真实人像业务明显不搭，
所以正常的人像提示词与它们相似度都远低于 0.1、覆盖率最大也只有 0.547，不会误伤。

## 六、自建风格包

风格包就是 `scripts/run.py` 里的一个字典（`STYLE_PACKS`）。复制一条改字段即可：

```python
"mystyle": {
    "name": "我的风格",
    "scene": "用在什么地方",
    "light": "光线方向、软硬、反差，一句话说清",
    "bg": "背景材质、色调、虚化程度",
    "wardrobe": "服装质地与色系，写清有没有图案",
    "grade": "后期调性：饱和度、色温、颗粒",
    "tail": "构图与神态的收尾约束，无文字、无水印、无标识",
},
```

加完之后 `styles` / `plan` / `gen` 都能立刻用 `--style mystyle`。
**注意**：新风格包的文案会被 `prompt_gate` 扫一遍，
所以别在字段里写真人指代、未成年词或违禁词——写了会在 plan 阶段就被标红。

## 七、图生图（`--photo-url` / `action=edit`）

想以一张真实人像照为基础改风格，用 `--photo-url`：

```bash
python3 scripts/run.py gen --plan plan.json --outdir ./out \
    --photo-url "https://你的图床/portrait.jpg" --yes
```

给了 `--photo-url` 就是 `action=edit`（图生图），`image_urls` 直接透传给上游。

> ⚠️ **上游只接受公网可访问的 HTTP/HTTPS 图片地址。**
> 算力集市 api.a7w.cn 的 nano_banana 插件**没有提供本地文件上传接口**
> （它的 2 个接口是 `submit` 与 `query`，没有 upload）。
> 所以本地照片必须**先自己放到一个公网可访问的位置**（对象存储、图床等）再传 URL。
> 这一点在 SKILL.md 的「没能确认的事」里也如实列出了。

**肖像授权**：用别人的照片做图生图，必须事先取得本人授权。
本包的闸门拦的是「公众人物 / 未成年人」这类明显不该做的情形，
**它不能替你判断你有没有权利使用某张照片**——那是使用者的责任。
