# 声音、音乐、字体与肖像的授权

短剧二创除了原片版权，还有四类容易被忽略的权利。它们单独拎出来都能让内容下架。

---

## 1. AI 音色与配音

越来越多的二创用 AI 配音或解说。这块风险比想象中高。

| 情形 | 风险 | 处理方式 |
|---|---|---|
| **克隆真人音色**（本人、同事、配音演员） | **高**——声音权益受法律保护 | 必须取得本人**书面**授权，注明用途与期限 |
| 使用平台内置音色 | 中 | 确认该音色的使用条款允许你的用途（商业/非商业） |
| 使用开源模型合成 | 中 | 确认模型许可证允许商用 |
| 直接使用影视原声片段 | 中 | 属于原片素材，随原片授权一同确认 |

### 红线

> **不要克隆名人、主播、演员的音色**，即使技术上做得到。
> 这类内容一旦被发现，处理速度远快于普通侵权投诉。

### 授权记录字段

如果你做过音色克隆，至少记录：

- 被克隆人姓名与联系方式
- 授权书签署日期
- 授权用途范围（哪些平台、是否商业）
- 授权期限
- 音色文件的存放位置

## 2. BGM / 背景音乐

| 来源 | 风险 |
|---|---|
| 平台自带音乐库 | 低——但要注意平台的"仅限站内使用"条款，跨平台分发可能超范围 |
| 免费商用曲库 | 低——保留授权凭证 |
| 自行购买授权 | 低——保留合同 |
| 从影视原片截取 | **中高**——属于原片素材，需看原片授权范围 |
| 网上下载的热门歌曲 | **高**——绝大多数没有商用授权 |

**做法**：建立自己的 BGM 池，每首标注「来源 / 授权类型 / 授权凭证位置」。用之前查表，不要凭印象。

---

## 3. 字体

字幕、封面、标题都会用到字体。**系统自带字体通常不可商用。**

| 类型 | 风险 |
|---|---|
| 系统默认字体（微软雅黑、苹方等） | **高**——商用需授权 |
| 明确标注"免费可商用"的开源字体 | 低 |
| 已购买商用授权的字体 | 低 |
| 从网上下载的"免费字体包" | **高**——来源不明，常常是盗版 |

**建议**：固定使用 2–3 款开源可商用字体（如思源系列），在项目里统一，避免每次现挑。记录字体名称与许可证。

---

## 4. 肖像与素材

| 情形 | 说明 |
|---|---|
| 演员剧照用于二创 | 随原片授权；但**单独截取用于商品宣传**可能超出范围 |
| 使用明星照片做封面 | 高风险，需单独取得肖像权授权 |
| 用户 UGC 素材（如他人拍摄的街景） | 需确认来源，避免使用未授权素材 |
| AI 生成的图像 / 视频 | 确认生成工具的商用条款；涉及真人形象的还需肖像授权 |

## 5. 一张表管住四类风险

建议为每个项目建一张"素材授权台账"：

| 素材类型 | 名称 | 来源 | 授权类型 | 授权期限 | 凭证位置 |
|---|---|---|---|---|---|
| 音色 | （填写） | （平台/自训） | （商用/非商用） | | |
| BGM | （填写） | （曲库名） | | | |
| 字体 | （填写） | （开源/已购） | | | |
| 肖像 | （填写） | （授权方） | | | |

**填不满就说明有缺口。** 缺口项要么补授权，要么换素材。
