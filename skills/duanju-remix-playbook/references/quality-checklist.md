# 成片质检清单

发布前逐项过一遍。**这些是通用参考值**，具体阈值以你锁定的口径为准
（见 `workflow-overview.md` 第 1 节）。

---

## 1. 封装与轨道

- [ ] **单视频轨 / 单音频轨**（多轨会在部分平台上传失败）
- [ ] 音视频时长差 **< 0.05s**（差太多会出现结尾黑屏或声音被截断）
- [ ] 像素格式 `yuv420p`（兼容性最好）
- [ ] 音频 **48 kHz** 立体声
- [ ] 分辨率与目标平台一致（竖版常见 1080×1920）
- [ ] 帧率与素材一致或统一归一化过

> 多段素材参数不一致时，**先逐段归一化再拼接**。直接拼会在接缝处出现音画不同步。

---

## 2. 声音

- [ ] 整条响度在 **-14 LUFS 左右**（社交平台通用标准）
- [ ] 峰值**不削波**（听感上表现为破音）
- [ ] 口播音量与配乐音量比例正常——**人声清晰压得住配乐**
- [ ] 段落衔接处无爆音、无突然的音量跳变
- [ ] 淡入淡出到位（口播切入、配乐进出）

### 一个容易踩的坑

音量的处理**不是各自设一个数就完了**。如果淡入淡出和区域音量是叠加处理的，
最终听到的音量可能是几个系数的**乘积**，而不是你设的那个值。

改音量参数后，**一定要导出听一遍**，不要只看参数表。

---

## 3. 画面

- [ ] 无黑帧、无花屏、无卡顿
- [ ] 转场自然，无跳帧
- [ ] 画面比例正确，无拉伸变形
- [ ] 字幕不遮挡关键画面
- [ ] 水印/角标位置不影响观看

---

## 4. 内容

- [ ] **开头三秒有钩子**（观众凭什么留下）
- [ ] 叙事完整：看完能说清发生了什么
- [ ] 结尾有明确引导（不要戛然而止）
- [ ] 解说与画面**对得上**（说的是这段，画面也是这段）
- [ ] 字幕无错别字，时间轴与解说同步
- [ ] 没有超出授权的素材使用，见 `rights-checklist.md`

---

## 5. 合规

- [ ] `duanju_compliance.py` 扫描无高风险命中
- [ ] AI 生成 / 合成的内容已按平台要求**主动标注**
- [ ] 无站外联系方式、无外站平台名
- [ ] 无绝对化用语、无疗效 / 收益承诺
- [ ] 素材有授权、音色有授权、BGM 与字体有商用授权

---

## 6. 批量质检

单条合格不代表整批合格。整批还要过这两关：

### 抽帧查重

```bash
python3 scripts/frame_dedup.py --dir "输出目录" --threshold 0.40
```

- [ ] 无超过阈值的相似对
- [ ] 有超阈值的对 → **重做**，而不是改个标题再发

### 发布规划

- [ ] 相似度超阈值的片子没有都发
- [ ] 同题材未在短时间内密集发布
- [ ] 每条片子在发布前都想清楚了：**它对看过原片的观众提供了什么新东西**

---

## 7. 记录

质检结论要写进出片记录（见 `workflow-overview.md` 第 6 节）：

```
批次：<日期 / 编号>
条数：<产出> / <重做>
质检：<通过 / 不通过项>
抽帧查重：<最高相似度> / <超阈值对数>
```

**下次开工前先看这条记录。**
