# 差异化规则

批量出片最容易出的问题是：**做出来的片子互相雷同**。

这不只是平台判定的问题——观众刷到第三条同类内容时也会划走。本文件讲清楚
「该在哪些维度上做出差别」，以及一个更根本的判断标准。

---

## 1. 先明确一件事：差异化不是技术问题

很多人把差异化理解成「让机器算出来不一样」。这是错的方向。

**真正的问题是：如果观众已经看过原片，我这条内容还提供了什么？**

- 提供了新的解读角度、人物关系梳理、背景知识 → **有增量**
- 只是把原片切碎重排、换个标题 → **没有增量**

平台打击的是后者；即使侥幸没被判定，后者长期也做不出账号价值。

技术手段（下面四条）只是保证「有增量的内容不因为形式雷同而被误伤」，
**不是用来掩盖内容本身没有增量的**。

---

## 2. 四条差异化

### ① 解说稿：每条独立撰写

不要用一套模板换几个词复读。每条的切入角度应该不同：
这条讲人物动机，那条讲剧情反转，另一条讲细节伏笔。

**这是四件事里最重要的一件。** 解说稿决定了观众听到的内容是否重复；
其余三条只影响画面和听觉的相似度。

### ② 配乐：按段落情绪切换

同一批片子反复用同一首 BGM，会让观众产生「又是这个」的直觉反应。

做法：按段落情绪从一个小池子里挑（如 燃 / 紧张 / 温情 / 叙事 各备几首），
**同一条片子内不同段落用不同的曲子**。

> 注意版权：BGM 必须有商用授权，见 `license-areas.md`。

### ③ 顺序：首尾固定、中间打乱

开头给进入点、结尾给收束，这两段保持稳定；中间段落的顺序可以打乱。

这条同时服务两个目的：结构不雷同 + 观众仍跟得上叙事。

### ④ 开头三秒：保证不同

开头三秒决定观众会不会留下。多条片子用同一个开头画面，是最容易被识别为
批量内容的特征之一。

做法：从素材的不同位置各取一小段做开头，而不是都从第一集第一秒开始。

**更进阶的做法是用音频能量找"最燃"的位置做片头**——原理与实现要点见
`params-example.md` 第 8 节（高燃片头 / 片尾）。

> 取材的具体做法（首段 / 中间段 / 末段各取什么、复用素材怎么换段）见
> `params-example.md` 第 7 节。

## 3. 复用系数：克制的艺术

```
可用素材量 ÷ 单条消耗 = 不复用时的条数上限
再乘一个「复用系数」，就是这一批的总条数
```

| 复用系数 | 含义 | 建议 |
|---|---|---|
| 1–2 | 基本不复用 | 安全，但产出少 |
| 3 | 每段素材平均出现 3 次 | 需要四条差异化全部生效 |
| 5 | 平均出现 5 次 | 风险明显上升，**不建议** |
| 8+ | 高度复用 | 不要做 |

**这张表的用法不是「选一个数」，而是「知道自己在冒什么风险」。**

---

## 4. 自检：用数字而不是感觉

人眼比对几十条片子不现实。用抽帧指纹查重把相似度算出来：

```bash
python3 scripts/frame_dedup.py --dir "输出目录" --threshold 0.40
```

它输出两两之间的画面相似度。**超过阈值的对就是需要重做的**：
换一段素材、换个切入时间点，而不是把同一条片子改个标题再发。

详细用法见脚本内的 `--help`。

---

## 5. 发布节奏

- **相似度超阈值的两条不要都发**——重做其中一条
- 同一题材不要在短时间内密集发布

批量内容的问题**不会因为换了发布方式而消失**。把力气花在让每条片子都有增量上，
比研究怎么发更有效。

---

## 6. 一张自检表

一批片子在发布前，逐条问：

- [ ] 每条的解说角度是否真的不同？（不是换词，是换角度）
- [ ] 同一首 BGM 是否在整批里反复出现？
- [ ] 中间段落是否打乱了？
- [ ] 开头三秒是否有变化？
- [ ] `frame_dedup.py` 是否跑过，超阈值的是否已重做？
- [ ] 相似度超阈值的片子是否**没有都发**？
- [ ] **最重要的一条**：每条片子对看过原片的观众，是否都提供了新东西？
