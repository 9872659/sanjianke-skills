# 出片流程与口径管理

## 1. 先定口径，再动手

一段成片涉及几十个参数：时长、取材长度、分组方式、音量、响度、字幕、转场、片头片尾……
它们不是独立的，**改一个会牵动另一个**。

所以开工第一件事不是打开剪辑软件，而是**把这一批要用的参数组合命名并锁定**：

```
本批口径：<自己起的名字>  ｜ 依据：<谁定的 / 什么场景>  ｜ 出片人：<谁>
```

命名可以是 `2分钟版`、`12分钟解说版`、`高燃钩子版`——名字不重要，**重要的是批次内不混用**。

### 为什么必须这么做

同一批片子里，如果 A 条用一套音量、B 条用另一套，会出现两种后果：

- 听感忽大忽小，观众直接划走
- 事后发现问题，你无法判断是哪几个参数的组合出的错

**改口径是可以的，但要整批改，并且改完在记录里写明新口径。**

## 2. 标准出片流程

```
① 授权核验          ← 未通过不出片，见 rights-checklist.md
      ↓
② 素材盘点          集数、每集时长分布、画面质量、有无自带字幕
      ↓
③ 目标确定          成片时长、目标条数、发布平台
      ↓
④ 口径锁定          按第 1 节写下本批口径
      ↓
⑤ 取材规划          每条用哪些素材、如何打散（见 differentiation-rules.md）
      ↓
⑥ 脚本 / 解说       每条独立撰写，不套模板复读
      ↓
⑦ 合成              按锁定口径输出
      ↓
⑧ 质检              见 quality-checklist.md
      ↓
⑨ 发布              控频率、不密集发布
```

---

## 3. 素材盘点要问清楚的几件事

| 项 | 为什么重要 |
|---|---|
| 总集数 | 决定能覆盖多少条成片 |
| 每集时长分布 | 时长不均匀时，「按集数估时长」会系统性偏差 |
| 画面质量 | 分辨率、帧率是否统一；不统一要先归一化再拼 |
| 有无自带字幕 | 有官方字幕可以直接当台词用，省掉语音识别 |
| 素材来源 | 决定授权是否成立，见 `rights-checklist.md` |

> **常见坑**：用「集数 × 每集固定秒数」估成片时长，而实际每集时长差异很大
> （短剧单集从 40 秒到 90 秒都常见）。估出来的时长会偏短或偏长。
> **正确做法**：先按目标时长取材，再按差额精确补足，而不是按集数反推。

---

## 4. 取材的三个原则

**一、首尾要稳**
开头给观众一个进入点，结尾给一个收束。这两段不要打乱。

**二、中间要乱**
中间段落打乱顺序，避免每条成片都是同样的叙事线。

**三、复用的素材要换段**
同一段素材被多条成片用到时，**取不同的片段**——换切入时间点、换取哪一段。
这是避免「多条片子看起来一样」最直接的办法。

---

## 5. 时间预算

先算清楚再开剪：

```
可用素材总时长 = Σ(每集可用时长)
单条消耗       = 目标成片时长
最多条数       ≈ 可用素材总时长 ÷ 单条消耗 × 复用系数
```

**复用系数越大，条数越多，但同质风险越高。** 这是整个流程里最需要克制的一个数——
系数拉到 5 以上时，即使做了所有差异化，同一段素材仍会反复出现。

**宁可少出几条，也不要把一批片子做成互相的复制品。** 平台对批量同质内容的识别能力
远强于个人肉眼比对，而账号被限流的代价远大于多发几条的收益。

---

## 6. 记录与复盘

每一批出片留一行记录：

| 字段 | 说明 |
|---|---|
| 批次号 / 日期 | |
| 素材 | 剧名、集数、来源 |
| 口径 | 第 1 节锁定的名字 |
| 条数 | 实际产出 |
| 质检结论 | 见 `quality-checklist.md` |
| 发布计划 | 哪些账号、什么频率 |

**下一批开工前先看上一批的记录。** 这是唯一能让出片质量随时间上升的机制。
