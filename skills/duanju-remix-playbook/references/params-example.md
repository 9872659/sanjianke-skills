# 成片参数示例口径

## 1. 为什么先讲「口径」

一段成片涉及几十个参数：分辨率、帧率、编码、响度、音量、取材秒数、分段结构、
转场、片头片尾、CTA……**它们不是独立的，改一个会牵动另一个。**

更麻烦的是：**同一件事会有好几套都说得通的口径。** 它们各自内部自洽，
但**混着用就会打架**——比如一套口径把配乐压得很低、另一套调得很高，
同一批片子里两种都用，听感就会忽大忽小，而且事后你无法判断是哪几个参数的组合出的错。

所以本文件给的是**五套示例口径**，用来演示「口径」长什么样。
**你可以直接照抄其中一套开工，也可以改成自己的——但必须选定一套并锁定。**

---

## 2. 五套示例口径总表

| 口径 | 成片时长 | 分组方式 | 素材处理 |
|---|---|---|---|
| **A · 标准版** | ≈2.96 分钟 | 每 3 集一条 | 每集取 **58s**；首段取第 1 集开头、末段取最后一集结尾、中间段取全片高能 58s |
| **B · 解说版** | ≈3 分钟 | 指定集数列表 | 每集 **39s × 4 集** = 主体 156s + 片头 10s + 片尾 12s + CTA |
| **C · 长视频版** | ≈12 分钟 | 每条随机抽 26 集 | 每集 **28s**，正片截到 **720s** |
| **D · 钩子版** | ≈12:24（744s） | 每条 15 集 | 每集 **48s**（15×48=720s 主体）+ 高燃片头 10s + 高燃片尾 12s |
| **E · 档位版** | 2~15 分钟全覆盖 | 按排期表 | 按目标时长**精确补集**，同一段素材换段取材 |

> **C 与 D 都是「12 分钟」，但素材口径完全不同**（26 集 × 28s vs 15 集 × 48s）。
> 同一条剧用错口径，成片节奏完全不同——**这不叫灵活，这叫失控**。

## 3. 视频参数

| 项 | 建议值 | 说明 |
|---|---|---|
| 分辨率 | **1080×1920**（竖屏 9:16） | 也可跟随源片；源片低于此值时不建议放大 |
| 帧率 | **30fps** | 与素材一致；多素材帧率不同时先统一 |
| 编码 | **H.264 + AAC**，音频 `-b:a 192k` | 兼容性最好的组合 |
| 画质 | `CRF 16~20` | 数值越小越清晰、体积越大。16 偏高画质，20 偏体积 |
| 滤镜 | 可选电影感调色，例如<br>`eq=contrast=1.18:brightness=-0.02:saturation=1.05,vignette=PI/4` | 不要每条换一套；统一或按内容类型区分 |
| 轨道 | **单视频轨 / 单音频轨** | 多轨会在部分平台上传失败 |
| 像素格式 | `yuv420p` | 兼容性最好 |
| 音频采样 | **48 kHz 立体声** | |
| 音视频时长差 | **< 0.05s** | 差太多会出现结尾黑屏或声音被截断 |
| ASR 采样率 | 16 kHz 单声道 | 做语音识别时的输入规格 |

> **多段素材参数不一致时，先逐段归一化再拼接。** 直接拼会在接缝处出现音画不同步。

## 4. 音频与响度

### 4.1 核心参数

| 项 | 建议值 | 说明 |
|---|---|---|
| 整条响度 | **-14 LUFS** 左右 | 社交平台通用标准；偏离太多会被平台二次压缩，听感反而更差 |
| 峰值 | 不削波（加限幅器，如 `alimiter`） | 削波表现为破音，不可逆 |
| 口播人声 | 明显高于配乐 | 人声必须压得住配乐，具体倍数按素材试听定 |
| 口播淡入 | 0.15s 左右 | 突然切入会"炸"一下 |
| 配乐淡入/淡出 | 0.8s / 1.2s 左右 | 按段落裁剪后拼接 |
| 配乐数量 | **每段一首，同一条内不重复** | 整条反复一首会让观众产生"又是这个"的直觉 |
| 原声处理 | 口播段压低或静音，非口播段保留 | 口播时原声会盖住人声 |

### 4.2 不同口径的配乐音量本来就不同

这是最容易出错的地方。示例：

| 口径 | 放原片时段配乐 | 口播时段配乐 |
|---|---|---|
| 标准版 | 0.02 | 0.02 |
| 解说版 | 0.01 | 0.5 |
| 长视频版 | 0.13 | 0.32 |

**它们不是「哪个对」，而是「哪个配哪套口径」。**
引用音量参数时，必须连着口径一起说，否则就是错的。

### 4.3 一个真实的坑：音量是相乘的

如果淡入淡出和区域音量是**串联**处理的，最终音量是几个系数的**乘积**，不是你设的那个值。

```
volume=0.01, volume=0.9:enable='between(口播时段)'
→ 实际音量 = 0.01 × 0.9 = 0.009
```

**正确做法**：第二段用**比值**，而不是绝对值。

```
0.5 / 0.01 = 50   →  volume=50:enable='...'
0.9 / 0.01 = 90   →  volume=90:enable='...'
```

**改完音量参数，一定要导出听一遍**，不要只看参数表。

## 5. 字幕 / 水印 / 转场 / CTA

| 项 | 建议做法 |
|---|---|
| 字幕 | 口播段可遮挡原字幕；非口播段保留原字幕。字幕内容与原音不对齐是最伤的体验问题 |
| 字幕优先 | 素材自带字幕文件时**优先直接用**，比语音识别准且省时间 |
| 水印 | 剧名文字，**透明度调低**（1% 量级）、左下静态即可；不要压住画面主体 |
| 转场 | 段间 `xfade` fade **0.4s**；同一条内保持一致 |
| CTA 时长 | **4.2s** 左右（或配音时长 + 0.7s） |
| CTA 取帧 | 从成片靠后位置取一帧做背景（成片 60% 处是常见选择）；取不到时按多个时间点回退 |
| CTA 配音 | 一句短引导语即可，不要长 |

## 6. 时长与分段结构（含实算例）

### 6.1 结构公式

```
成片总时长 = 主体时长 + 片头 + 片尾 + CTA
主体时长   = 取材段数 × 单段秒数
```

以 **A 口径**为例：

```
主体   = 3 段 × 58s        = 174s
CTA    = 4.2s
转场   = 0.4s × 若干段
合计   ≈ 177.8s ≈ 2.96 分钟
```

### 6.2 差额补足（避免档位偏差）

**不要用「集数 × 每集固定秒数」估成片时长**——短剧单集时长从 40s 到 95s 都常见，
按固定值估会系统性偏短或偏长。

正确做法：

```
TARGET_SEC = 目标分钟数 × 60 − 5     # 留 CTA 与转场余量
取完初始素材后，按差额精确补足
```

实测效果（档位版）：

| 目标档位 | 目标秒数 | 实际成片 |
|---|---|---|
| 2 分钟 | 120s | **120.7s = 2.01 分钟** |
| 3 分钟 | 180s | **180.7s = 3.01 分钟** |

**误差控制在 1 秒内**，观众感知不到，平台也认。

### 6.3 实算例：40 集能出多少条

```
素材：40 集，平均每集 63s（实际 42.9~95.6s）
目标：3 分钟档（约 177.8s），三段式
```

**第一步：算单条消耗**

```
每条约用 3 集（3 段 × 58s）
```

**第二步：算不复用时的条数上限**

```
40 集 ÷ 3 集/条 ≈ 13 条
```

**第三步：乘复用系数，并对照风险**

| 复用系数 | 条数 | 风险 |
|---|---|---|
| 1 | 13 条 | 零复用，安全 |
| 2 | 26 条 | 低——每段素材出现 2 次 |
| 3 | 40 条 | 中——需要四条差异化全部生效 |
| 5 | 66 条 | **不建议**：同质风险已经高到不划算 |

> **宁可少出几条，也不要把一批片子做成互相的复制品。**

## 7. 素材取材结构

### 7.1 三段式

| 位置 | 取什么 | 解说该做什么 |
|---|---|---|
| 第 1 段 | 第 1 集**正片开头** | **开篇**：交代人物处境与矛盾起因 |
| 中间段 | 各集**高能段落** | **承接/推进/高潮**：矛盾加码、反转爽感 |
| 末段 | 最后一集**结尾** | **收束**：收束情绪、点题、留回味 |

**首尾稳定、中间打乱**——既保证结构不雷同，观众又跟得上叙事。

### 7.2 叙事主线的做法

先让模型写一份「**全片主线 + 人物成长弧线**」，再把这条主线喂给每一段的解说生成。
这样即使段落顺序被打乱，整条片子仍然是一条线。

每段解说带上位置引导语，保证观众不会迷失：

- **开篇**：交代人物处境与矛盾起因
- **承接**：点出新的变数或压力
- **推进**：矛盾加码，主角被逼到墙角
- **高潮**：反打/翻盘的爽感，节奏要快
- **收束**：收束情绪、点题、留回味

### 7.3 同一段素材被复用时要换段

同一段素材出现在多条成片里时，**取不同的片段**：

- 首集：在**正片前段区域**里换不同的活跃段
- 末集：在**片尾区域**里换不同的活跃段
- 中间集：换活跃段 + 让锚点位置抖动

这是「多条片子看起来不一样」最直接的办法，而且不需要额外的素材。

## 8. 高燃片头 / 片尾（思路）

原理很简单：**用音频能量找"最燃"的位置。**

```
① 对每条要用的素材，测音频峰值（volumedetect 之类的响度分析）
② 按峰值排序，取最高的若干段
③ 在选中的素材里用**滑动窗**扫描，找能量最集中的那个窗口
④ 用这个窗口做片头 / 片尾
```

**做法要点**：

- 片头与片尾**取自不同的素材段**，避免两头重复
- 位置要落在素材的**中段**，不要取开头——开头往往是铺垫，不燃
- **必须准备降级路径**：检测失败时退化成无钩子的标准拼法，**不要中断出片**
- 钩子时长：片头 10s 左右、片尾 12s 左右（够勾起兴趣，又不至于喧宾夺主）

> 具体的窗口长度、步长、锚点时间范围取决于你的素材特性，建议自己跑几轮标定，
> 不要照抄别人的数值。

## 9. 音色选择（按品类）

按**内容类型**选音色，而不是按"好听"选：

| 品类 | 适合的解说什么 |
|---|---|
| **磁性男声** | 悬疑、权谋、男频逆袭——叙述感强，压得住紧张剧情 |
| **温暖女声** | 情感、家庭、治愈——亲和力强，适合共鸣型内容 |
| **叙述型（中性）** | 剧情梳理、人物关系——信息密度高的段落 |
| **情绪型（起伏大）** | 高燃混剪、反转集锦——需要跟着画面走 |

**选择依据**：

- 与**目标观众**匹配（男频/女频的内容，音色性别通常也跟着走）
- 与**内容情绪**匹配（温情内容用冷硬音色会割裂）
- **同一条片子内保持一种音色**，不要中途换

> 音色是否可商用、是否需要授权，见 `license-areas.md`。**克隆真人音色必须取得书面授权。**

## 10. 一套可直接照抄的完整示例（A 口径）

```
【口径名】标准版-3集-58s

【结构】
  第 1 段：第 1 集正片开头 58s
  第 2 段：第 2 集高能段落 58s
  第 3 段：第 3 集结尾 58s
  CTA：4.2s，转场 xfade fade 0.4s

【视频】
  1080×1920 / 30fps / H.264 / AAC 192k / CRF 18
  yuv420p / 单视频轨 / 单音频轨 / 音视频差 < 0.05s

【音频】
  整条响度 -14 LUFS，限幅防削波
  口播人声明显高于配乐
  配乐：3 段各一首，不重复；放原片段 0.02，口播段 0.02
  口播淡入 0.15s；配乐淡入 0.8s / 淡出 1.2s

【字幕】
  口播段遮挡原字幕；非口播段保留原字幕
  有自带字幕文件时优先使用

【水印】
  剧名，透明度 1% 量级，左下静态

【成片】
  约 177.8s（2.96 分钟）
```

**照抄这一套就能开工。** 跑几条之后，按你素材的实际情况调参数，
然后把调完的版本**命名并记录下来**——那才是你自己的口径。

## 11. 参数会过时：维护一份黑名单

工具链、上游模型、客户端版本都会变。**上次验证通过的参数，这次可能已经失效。**

建议维护一份「**过时参数黑名单**」，把不再适用的记下来：

| 记什么 | 为什么 |
|---|---|
| 已下线的服务 / 模型 | 避免照抄旧文档时踩空 |
| 变更过的默认值 | 旧值写在新版上会出问题 |
| 已失效的素材地址 | 上游链接会 404 |

**每次发现一个失效项就补一条。** 这份黑名单的价值会随时间增长——
它是你团队唯一能避免"重复踩同一个坑"的东西。
