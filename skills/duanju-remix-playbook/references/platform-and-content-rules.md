# 平台原创性要求与内容红线

本文件讲两件事：**平台在打击什么样的二创**，以及**怎么做才站得住**。

> 说明：平台的判定规则不公开且持续调整，本文是公开信息与经验的整理，不构成对任何平台规则的权威解释。

---

## 1. 平台在打击什么

各平台对「搬运」和「低质二创」的治理方向基本一致，常见判定维度：

| 维度 | 风险表现 |
|---|---|
| **画面重复度** | 多条内容大量使用相同画面片段 |
| **解说占比低** | 几乎只有原片原声，缺少自己的表达 |
| **包装雷同** | 标题、开场、封面高度相似 |
| **发布密度** | 同一账号短时间内大量同质内容 |
| **素材来源** | 使用了平台已认定侵权的素材 |
| **AI 内容未标注** | 使用 AI 生成/合成内容但未声明 |

---

## 2. 正向做法

**核心原则：原创性来自你的表达，不是来自绕开比对。**

| 维度 | 该怎么做 |
|---|---|
| 画面重复 | 使用**已授权**素材；把力气花在解说、剪辑思路、观点上，让每条内容有自己的表达 |
| 解说占比 | 提高**你自己的**解说与评论比例，把原片当素材而不是成品 |
| 包装雷同 | 每条重新写标题与开场，不复用同一套模板文案 |
| 发布密度 | **少而精**——同题材短时间大量产出，本身就是低质信号 |
| 素材来源 | 只用授权素材（见 `rights-checklist.md`） |
| AI 标注 | 用了 AI 配音、AI 画面、AI 文案，按平台要求**主动声明** |

### 一条重要的判断标准

问自己一句：**"如果观众已经看过原片，我这条内容还提供了什么？"**

- 提供了新的解读角度、背景知识、人物关系梳理 → 有增量
- 只是把原片切碎重排、换个标题 → 没有增量

平台打击的是后者。而后者即使侥幸没被判定，长期也做不出账号价值。

---

## 3. AI 生成内容的标注

这是近两年新增且趋严的要求。以下是**需要主动声明**的典型情形：

- 使用 AI 克隆或合成的配音
- 使用 AI 生成或大幅修改的画面
- 使用 AI 生成的解说文案并直接采用
- 使用 AI 换脸、数字人等技术

**做法**：发布时按平台提供的标注入口勾选对应项；没有入口时，在文案或评论区说明。

> 未标注的 AI 内容一旦被平台识别，处理方式通常比普通违规更重——因为它同时涉及"内容真实性"和"未如实声明"。

## 4. 短剧推广高危话术与替换

短剧赛道有一套自己的高危词，和普通带货完全不同。发布前用脚本扫一遍：

```bash
python3 scripts/duanju_compliance.py --file script.txt --strict
python3 scripts/duanju_compliance.py --file script.txt --category promotion
```

### 4.1 全集 / 完整度承诺

| 高危表述 | 问题 | 建议替换 |
|---|---|---|
| 全集免费 / 免费看全集 | 与实际可看范围不符即属虚假宣传 | 「点击下方观看」等中性引导 |
| 完整版 / 完整全集 | 完整度承诺 | 删除 |
| 未删减 / 无删减 | 平台敏感表述 | 删除 |
| 一口气看完 | 完整度暗示 | 「继续看下去」 |

### 4.2 独家 / 首发宣称

| 高危表述 | 问题 | 建议替换 |
|---|---|---|
| 全网独播 / 独家播出 | 无独家授权不得使用 | 删除，或改为具体上线时间 |
| 独家资源 | 需可核实授权 | 删除 |
| 全网首发 / 首播 | 需可核实 | 改为具体时间描述 |

### 4.3 擦边引流

| 高危表述 | 处理 |
|---|---|
| 大尺度 / 激情 / 暧昧 / 香艳 / 露骨 / 限制级 / 少儿不宜 | **直接删除**，属平台重点打击 |

### 4.4 暴力血腥

| 高危表述 | 处理 |
|---|---|
| 血腥 / 残肢 / 虐杀 | 删除，剪辑时也应避开对应画面 |

### 4.5 盗版与站外导流

| 高危表述 | 问题 | 建议替换 |
|---|---|---|
| 网盘 / 资源分享 / 无删减资源 | 盗版暗示 | 删除 |
| 微信 / 公众号 / 加V / 私信我 | 站外导流 | 引导平台内观看 |
| 手机号 / 邮箱 / 站外链接 | 联系方式泄露 | 删除 |

### 4.6 收益与诱导

| 高危表述 | 处理 |
|---|---|
| 看剧赚钱 / 边看边赚 / 日入过万 | 收益承诺，删除 |
| 不点后悔 / 点进去就送 | 诱导性话术，改中性引导 |
| 最后一天 / 仅此一天 / 限时 | 需有真实活动依据，否则删除 |

### 4.7 极限词

沿用广告法口径：最好看、第一、史上最、绝对、100% 等一律避免。改为可验证的具体事实或主观感受。

## 5. 发布前自检清单

- [ ] 原片授权已核验（`rights-checklist.md` 第 2 节）
- [ ] 音色 / BGM / 字体 / 肖像均无缺口（`license-areas.md`）
- [ ] `duanju_compliance.py` 无高风险命中
- [ ] AI 生成内容已按平台要求标注
- [ ] 标题与开场不复用同一套模板
- [ ] 同题材未在短时间内密集发布
- [ ] 文案里无站外联系方式与外站平台名
