# 短剧二创授权核验清单

短剧二创与普通内容创作最大的区别：**它首先不是"做得好不好"的问题，而是"能不能做"的问题。**

本文件是开工前的第一道门禁。未通过的素材，不要进入制作流程。

> 本文是作业规范与经验整理，**不构成法律意见**。具体授权范围以你与版权方签署的正式合同为准。

---

## 1. 需要哪几项权利

二创至少触及三项权利，**缺一项都不能做**：

| 权利 | 说明 | 缺失后果 |
|---|---|---|
| **信息网络传播权** | 在平台上传播该作品 | 直接侵权，投诉即下架 |
| **改编权 / 剪辑权** | 对原片进行剪辑、重组、加解说 | 即使有传播权，剪辑本身仍可能侵权 |
| **素材使用权** | 拿到可供剪辑的原始文件 | 素材来源不明 = 授权链断裂 |

### 最常见的坑

> **只拿到「推广授权」，就以为可以任意剪辑。**

推广授权往往只允许**原片直发**或**平台内嵌推广**，不等于允许二创。
签之前一定要问清："这个授权包含**剪辑、改编、二次创作**吗？"

---

## 2. 授权核验清单

每一部剧开工前，逐项确认：

- [ ] **授权方主体名称**——公司全称，不是个人微信昵称
- [ ] **授权编号 / 合同编号**
- [ ] **授权类型**：是否**明示**包含剪辑、改编、二次创作
- [ ] **授权平台范围**：抖音 / 快手 / 视频号 / 小红书 / B站……是否覆盖你要发的平台
- [ ] **授权地域范围**
- [ ] **授权期限**：起止日期
- [ ] **素材交付方式**：版权方直供 / 官方分销平台后台下载
- [ ] **是否允许商业推广**（挂载、分账、带货）
- [ ] **是否有独家 / 排他条款**（会影响你的多平台分发策略）
- [ ] **是否允许二次授权**（转授给合作方）

任一项答不上来，先别开工。

## 3. 留痕模板

每条（或每批）成片记录一行，存档备查：

| 字段 | 示例 |
|---|---|
| 剧名 | （填写实际剧名） |
| 授权方 | xx 文化传媒有限公司 |
| 授权编号 | SQ-2026-xxxx |
| 授权类型 | 剪辑/改编 + 信息网络传播 |
| 授权平台 | 抖音、小红书 |
| 授权期限 | 2026-01-01 ~ 2027-01-01 |
| 素材来源 | 版权方直供 / 分销平台后台导出 |
| 制作日期 | 2026-xx-xx |
| 制作人 | （填写） |

> **这张表就是你的合规资产。**
> 被投诉时能拿出完整链条，和拿不出，是完全不同的两种结果。

建议按月归档，保留原始授权文件（扫描件/电子合同）的存放位置。

## 4. 开工前四道门禁

```
素材到手
  │
  ├─ 第 1 关：版权授权核验（本文第 2 节清单）
  │    未通过 → 停，不进入制作
  │
  ├─ 第 2 关：声音 / 音乐 / 字体授权（见 license-areas.md）
  │    未通过 → 更换素材
  │
  ├─ 第 3 关：文案合规扫描
  │    python3 scripts/duanju_compliance.py --file script.txt --strict
  │    有高风险命中 → 改文案
  │
  └─ 第 4 关：全部通过 → 填写第 3 节留痕行 → 进入制作
```

**这四关的结论要写进你的制作记录**，而不是只在心里过一遍。

## 5. 常见误区

| 误区 | 实际情况 |
|---|---|
| 「网上到处都是，应该没事」 | 别人没被投诉不等于你合规；投诉是按量触发的 |
| 「我做了改动就不算侵权」 | 是否侵权看**授权**，不看改动量；改动量影响的是平台判定，不是法律定性 |
| 「标注了来源就没问题」 | 标注来源是尊重，但不等于获得授权 |
| 「版权方默认允许」 | 授权必须**明示**，默示同意在法律上站不住 |
| 「只发一条，量小没关系」 | 一条也构成侵权，且量小通常只影响赔偿额 |
| 「分销平台给了素材就能随便用」 | 素材交付 ≠ 剪辑授权，要看协议条款 |
