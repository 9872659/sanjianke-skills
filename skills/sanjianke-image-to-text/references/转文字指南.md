# 图片与文档转文字指南

本文只说**怎么把字读准、把信息整对**。接口参数看 `api-file_qa.md` 与 `api-模型网关.md`，
计费口径看 `通用说明.md`。

---

## 一、先选路，再动手

```
输入是图片（截图 / 海报 / 票据 / 照片 / 扫描图）  → 模型网关 · 视觉大模型
输入是文档（PDF / DOC / DOCX / TXT / MD）        → file_qa/chat（文档解析问答）
两者都要，且文档里夹着图                          → 文档走 file_qa，图单独走视觉模型
```

判断口诀：**能直接「看」的走视觉模型，需要先「解析」的走文档接口。**

---

## 二、图片：指令模板（直接抄）

**1）纯文字提取**

```
按阅读顺序提取图中所有文字，保留原始换行与标点。
不要翻译、不要解释、不要补全看不清的内容；无法辨认的字用 [模糊] 标记。
```

**2）表格 → Markdown**

```
把图中的表格转成 Markdown 表格，列名原样保留，空单元格留空，
不要合并同类项，不要改数字格式。
```

**3）票据 / 发票 → JSON**

```
提取以下字段并输出 JSON：开票日期、发票号码、购买方名称、销售方名称、
金额合计、税额合计。字段缺失给 null。只输出 JSON，不要解释。
```

**4）商品标签 / 价签 → JSON 数组**

```
提取图中所有商品名称与价格，输出 JSON 数组，每项含 name 与 price 两个字段。
价格保留原样（含货币符号）。只输出 JSON。
```

**5）截图 → 可编辑文案**

```
提取图中所有文字。如果原文是分点或分段的，保持原有层次；
不要改写语气，不要合并段落。
```

**6）翻译对照**

```
先提取全部文字，再逐段给出中文翻译，用「原文 / 译文」两列对照输出。
```

## 三、文档：问法模板

**1）全文文字化（最常用）**

```
把全文整理成结构化文本：保留标题层级、有序/无序列表、表格（转 Markdown 表格），
不要概括、不要漏段、不要改写措辞。
```

**2）摘要 + 结论**

```
用 300 字总结核心内容，再列出 5 条关键结论，每条一句话。
```

**3）字段抽取**

```
提取合同编号、签订日期、甲方名称、乙方名称、合同金额、有效期，
输出 JSON，缺失字段给 null。
```

**4）多份对比**

```
对比这几份文档的差异，用 Markdown 表格呈现：行是差异项，列是各文档。
重点对比金额、时间、责任条款。
```

**5）会议纪要**

```
按「议题 / 结论 / 待办」三段整理。待办事项要带负责人和截止时间，
没提到的写「未指定」。
```

## 四、把准确率提上去的六个动作

| 动作 | 为什么有效 |
|---|---|
| **原图先转正、去倾斜** | 倾斜会让行序判断出错 |
| **长截图分块问** | 一次一张图比一张超长图稳；分块后按顺序拼接 |
| **低对比度先增强** | 灰底黑字、反光照片先调对比度再传 |
| **明确「不要补全」** | 防止模型对模糊字符进行「合理猜测」 |
| **要 JSON 就说清缺字段怎么办** | 避免模型自由发挥字段名 |
| **关键字段二次复核** | 金额、编号、专有名词抽 5% 人工核对，比调提示词划算 |

## 五、批量做法

**图片批量（一个循环）**

```python
import json, os, urllib.request

API = "https://api.a7w.cn/api/v1/chat/completions"
KEY = os.environ["A7W_API_KEY"]
PROMPT = "按阅读顺序提取图中所有文字，保留原始换行，不要翻译、不要解释。"


def read_image(url, model="Qwen3-VL-30B-A3B-Instruct"):
    body = {"model": model, "messages": [{"role": "user", "content": [
        {"type": "text", "text": PROMPT},
        {"type": "image_url", "image_url": {"url": url}}]}]}
    req = urllib.request.Request(API, data=json.dumps(body).encode(), method="POST",
                                headers={"Authorization": "Bearer " + KEY,
                                         "Content-Type": "application/json"})
    with urllib.request.urlopen(req, timeout=180) as r:
        return json.load(r)["choices"][0]["message"]["content"]


with open("out.jsonl", "w", encoding="utf-8") as out:
    for url in (l.strip() for l in open("urls.txt", encoding="utf-8") if l.strip()):
        out.write(json.dumps({"url": url, "text": read_image(url)}, ensure_ascii=False) + "\n")
        out.flush()
```

**文档批量（先提交、后收结果）**

```bash
# 一次提交一份，拿 task_id，记下与文件名的对应关系
python3 scripts/a7w.py call file_qa chat \
  --body '{"file_urls":["https://你的存储/合同.pdf"],"question":"提取合同编号、签订日期、金额，输出 JSON","mode":"async"}'

# 之后按 task_id 收结果（免费）
python3 scripts/a7w.py task <task_id>
```

> **并发建议**：一次别发太多，图片建议不超过 4～8 路并发，
> 文档问答按平台队列情况从 2～4 路起步，跑稳了再加。

## 六、常见问题快查

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 报参数错误 | 用了本地路径或 Base64 | 换成公网 HTTP(S) 直链 |
| 图片读不出字 | 把图塞给了 `file_qa` | 图片走 `chat/completions` 视觉模型 |
| 模型名报不存在 | 照抄了旧文档 | 先 `GET /api/v1/models` 拿当期清单 |
| 返回一段话而不是 JSON | 指令没说要 JSON | 明确「只输出 JSON，不要解释」 |
| 多图结果串了 | 一次传了多张图 | 一次一张，分次问 |
| 文档问答等很久 | 用了同步模式 | `mode` 传 `async`，拿 `task_id` 再查 |
| 数字读错 | 图太糊 / 字体特殊 | 放大分块、提高原图清晰度，关键字段人工复核 |
