# 合成与导出 · ffmpeg 全流程

前面六步产出的是**一堆零件**：每镜的视频、每镜的配音、一首 BGM。
这一篇把它们拼成成片。**所有命令都可直接复制**，按顺序跑即可。

```
normalize  统一画幅 / 帧率 / 像素格式   →  norm/*.mp4
dub        每条镜头贴上自己的台词音轨   →  dubmix/*.mp4
concat     按分镜表顺序拼接             →  ep01-dub.mp4
srt        由分镜表 + 配音时长生成字幕   →  ep01.srt
subtitle   烧录字幕                     →  ep01-sub.mp4
mix        叠 BGM 并做响度归一          →  ep01-mixed.mp4
deliver    交付转码（H.264 + faststart）→  ep01-deliver.mp4
```

先确认工具可用：

```bash
ffmpeg -version
ffprobe -version
```

---

## 一、统一规格（拼接前的必要一步）

**ffmpeg 拼接要求所有片段的编码参数一致**，否则要么失败，要么拼接处花屏。
所以先做一遍归一化，把你的目标规格写死在这里，全片不再改。

| 参数 | 竖屏短剧 | 横屏 |
|---|---|---|
| 分辨率 | `1080x1920` | `1920x1080` |
| 帧率 | `30` | `25` 或 `30` |
| 像素格式 | `yuv420p` | `yuv420p` |
| 音频 | `aac` / `44100` / 双声道 | 同 |

### 1.1 单条归一化（竖屏 1080×1920）

```bash
mkdir -p norm
ffmpeg -y -i shots/S01-003.mp4 \
  -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2:color=black,fps=30,format=yuv420p" \
  -c:v libx264 -crf 18 -preset medium \
  -c:a aac -b:a 192k -ar 44100 -ac 2 \
  norm/S01-003.mp4
```

- `force_original_aspect_ratio=decrease` + `pad` = **等比缩放 + 补黑边**，绝不拉伸
- `format=yuv420p` 是社媒平台兼容性的关键
- `crf 18` 是中间素材档，画质余量足够，最后交付再压一次

### 1.2 批量归一化（bash）

```bash
mkdir -p norm
for f in shots/*.mp4; do
  b=$(basename "$f")
  ffmpeg -y -i "$f" \
    -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2:color=black,fps=30,format=yuv420p" \
    -c:v libx264 -crf 18 -preset medium \
    -c:a aac -b:a 192k -ar 44100 -ac 2 \
    "norm/$b"
done
```

### 1.3 批量归一化（PowerShell）

```powershell
New-Item -ItemType Directory -Force norm | Out-Null
Get-ChildItem shots\*.mp4 | ForEach-Object {
  ffmpeg -y -i $_.FullName `
    -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2:color=black,fps=30,format=yuv420p" `
    -c:v libx264 -crf 18 -preset medium `
    -c:a aac -b:a 192k -ar 44100 -ac 2 `
    "norm\$($_.Name)"
}
```

> **没有音轨的镜头**（纯画面）加上 `-an`，避免生成一条静音轨影响后面拼接。

## 二、贴上每镜的台词音轨

配音文件按 `shot_id` 命名（`dub/S01-003.mp3` 对应 `norm/S01-003.mp4`），
一镜一条，直接贴上去：

```bash
mkdir -p dubmix
ffmpeg -y -i norm/S01-003.mp4 -i dub/S01-003.mp3 \
  -map 0:v:0 -map 1:a:0 \
  -af "apad" \
  -c:v copy -c:a aac -b:a 192k -ar 44100 -ac 2 \
  -shortest dubmix/S01-003.mp4
```

- `apad` 把配音补静音到与画面等长，`-shortest` 让输出以画面长度结束
- 配音**比画面长**时不要用 `-shortest`（会剪掉画面）。两种处理：
  - **首选**：回到配音那一步调 `prosody.speed` 或改台词，让它贴住镜头时长
  - 实在要保画面，用冻结末帧补足：把 `-c:v copy` 换成
    `-vf "tpad=stop_mode=clone:stop_duration=2" -c:v libx264 -crf 18 -preset medium`

### 批量贴音轨（bash）

```bash
mkdir -p dubmix
for f in norm/*.mp4; do
  b=$(basename "$f" .mp4)
  if [ -f "dub/$b.mp3" ]; then
    ffmpeg -y -i "$f" -i "dub/$b.mp3" \
      -map 0:v:0 -map 1:a:0 -af "apad" \
      -c:v copy -c:a aac -b:a 192k -ar 44100 -ac 2 -shortest "dubmix/$b.mp4"
  else
    cp "$f" "dubmix/$b.mp4"        # 无声镜头直接过
  fi
done
```

## 三、拼接

### 3.1 生成拼接清单（严格按分镜表顺序）

清单里的顺序**必须与 `shots.csv` 的 `shot_id` 顺序一致**。

```bash
: > list.txt
while IFS= read -r sid; do
  echo "file 'dubmix/$sid.mp4'" >> list.txt
done < <(python3 -c "
import csv
for r in csv.DictReader(open('shots.csv', encoding='utf-8-sig')):
    print(r['shot_id'].strip())
")
cat list.txt
```

生成出来是这样：

```
file 'dubmix/S01-001.mp4'
file 'dubmix/S01-002.mp4'
file 'dubmix/S01-003.mp4'
```

### 3.2 无损拼接（推荐，参数已统一时用）

```bash
ffmpeg -y -f concat -safe 0 -i list.txt -c copy ep01-dub.mp4
```

`-c copy` 不重编码，**几秒完成、零画质损失**。前提是第三步的归一化做过了。

### 3.3 重编码拼接（参数不完全一致时兜底）

文件多的时候用 `concat` filter 会很长的命令行，这里给两条的写法，
更多条请先用 1.1 统一规格后再走 3.2：

```bash
ffmpeg -y -i norm/S01-001.mp4 -i norm/S01-002.mp4 \
  -filter_complex "[0:v][0:a][1:v][1:a]concat=n=2:v=1:a=1[v][a]" \
  -map "[v]" -map "[a]" \
  -c:v libx264 -crf 18 -preset medium -c:a aac -b:a 192k ep01-dub.mp4
```

### 3.4 校验拼接结果

```bash
# 总时长
ffprobe -v error -show_entries format=duration -of csv=p=0 ep01-dub.mp4

# 与分镜表核对（应为一致）
python3 -c "
import csv
print(sum(float(r['duration']) for r in csv.DictReader(open('shots.csv', encoding='utf-8-sig'))))
"

# 有没有音轨、参数对不对
ffprobe -v error -show_streams -select_streams v:0 ep01-dub.mp4
ffprobe -v error -show_streams -select_streams a:0 ep01-dub.mp4
```

## 四、字幕：由分镜表生成 SRT

**不要手数时间轴。** 配音时长有了、分镜时长有了，SRT 是算出来的。

### 4.1 生成脚本

存成 `make_srt.py`，与 `shots.csv`、`dub/` 同目录：

```python
# -*- coding: utf-8 -*-
"""按 shots.csv 生成 SRT。优先用配音的真实时长，缺失时回退到分镜时长。只用标准库。"""
import csv, os, subprocess, sys, textwrap

CSV_PATH = sys.argv[1] if len(sys.argv) > 1 else "shots.csv"
DUB_DIR = sys.argv[2] if len(sys.argv) > 2 else "dub"
OUT = sys.argv[3] if len(sys.argv) > 3 else "ep01.srt"
WRAP = 14          # 每行最多多少字，中文竖屏建议 12~16


def audio_duration(path):
    """用 ffprobe 取音频时长；取不到返回 None。"""
    try:
        r = subprocess.run(
            ["ffprobe", "-v", "error", "-show_entries", "format=duration",
             "-of", "csv=p=0", path],
            capture_output=True, text=True, check=True)
        return float(r.stdout.strip())
    except Exception:
        return None


def stamp(t):
    """秒 → SRT 时间戳 00:00:01,000"""
    ms = max(0, int(round(t * 1000)))
    return "%02d:%02d:%02d,%03d" % (ms // 3600000, ms % 3600000 // 60000,
                                    ms % 60000 // 1000, ms % 1000)


def wrap(text):
    """按标点断行，避免一行太长。"""
    text = " ".join(text.split())
    if len(text) <= WRAP:
        return [text]
    lines, cur = [], ""
    for ch in text:
        cur += ch
        if ch in "，。！？；：、,.!?;:" and len(cur) >= WRAP // 2:
            lines.append(cur)
            cur = ""
    if cur:
        lines.append(cur)
    out = []
    for ln in lines:                      # 单段仍过长就硬折
        out.extend(textwrap.wrap(ln, WRAP) or [ln])
    return out[:2]                        # 一行字幕最多两行


def main():
    with open(CSV_PATH, encoding="utf-8-sig", newline="") as f:
        rows = list(csv.DictReader(f))
    blocks, cursor, idx = [], 0.0, 0
    for r in rows:
        sid = (r.get("shot_id") or "").strip()
        try:
            shot = float(r.get("duration") or 0)
        except ValueError:
            shot = 0.0
        line = (r.get("dialogue") or "").strip()
        if line:
            idx += 1
            # 优先用真实配音时长，且不超过本镜时长
            real = audio_duration(os.path.join(DUB_DIR, sid + ".mp3")) \
                or audio_duration(os.path.join(DUB_DIR, sid + ".wav"))
            # 字幕终点：优先用真实配音时长，但绝不跨到下一镜
            span = real if real else shot
            if real and shot:
                span = min(real, shot)
            end = cursor + span
            if end <= cursor:                 # 兜底：给一个最小可见时长
                end = cursor + 1.0
            body = "\n".join(wrap(line))
            blocks.append("%d\n%s --> %s\n%s\n" % (idx, stamp(cursor), stamp(end), body))
        cursor += shot
    with open(OUT, "w", encoding="utf-8", newline="\n") as f:
        f.write("\n".join(blocks))
        if blocks:
            f.write("\n")
    print("✓ 已生成 %s（%d 条字幕 · 时间轴总长 %.1f 秒）" % (OUT, idx, cursor))


if __name__ == "__main__":
    main()
```

```bash
python3 make_srt.py shots.csv dub ep01.srt
```

生成的 SRT 长这样：

```
1
00:00:00,000 --> 00:00:04,000
这雨，下了整整十年。

2
00:00:09,000 --> 00:00:13,500
你要是再晚一步，
我就走了。
```

**时间轴口径**：每镜的起点 = 前面所有镜的 `duration` 累加；字幕终点取
「该镜配音的真实时长」与「该镜时长」中的较小值，绝不会跨到下一镜。

## 五、字幕烧录

### 5.1 硬字幕（烧进画面，兼容性最好）

```bash
ffmpeg -y -i ep01-dub.mp4 \
  -vf "subtitles=ep01.srt:force_style='FontName=Microsoft YaHei,FontSize=16,PrimaryColour=&H00FFFFFF,OutlineColour=&H00000000,BorderStyle=1,Outline=2,Shadow=0,MarginV=90,Alignment=2'" \
  -c:v libx264 -crf 18 -preset medium -c:a copy \
  -movflags +faststart ep01-sub.mp4
```

| 参数 | 含义 |
|---|---|
| `FontName` | Windows 用 `Microsoft YaHei`，macOS 用 `PingFang SC`，Linux 装一款中文字体后填其名 |
| `FontSize` | 1080×1920 竖屏建议 `14~18`；1920×1080 用 `20~26` |
| `PrimaryColour` | `&HAABBGGRR` 顺序，`&H00FFFFFF` = 不透明白色 |
| `Outline` / `OutlineColour` | 描边宽度与颜色，深色背景上必须有描边 |
| `MarginV` | 距底部像素，竖屏建议 `90~140`（避开平台 UI 与进度条） |
| `Alignment` | `2` = 底部居中（ASS 编号） |

> **需要 `libass`**。`ffmpeg -version` 的构建配置里能看到 `--enable-libass`。
> 若提示 `No such filter: 'subtitles'`，请换带 libass 的 ffmpeg 构建。

### 5.2 Windows 路径转义

`subtitles` 滤镜运行在 filtergraph 里，`:` 和 `\` 会被当成语法。
**最简单的办法：切到字幕所在目录，用相对文件名**（上面就是这么写的）。
确实要用绝对路径时这样写：

```bash
ffmpeg -y -i ep01-dub.mp4 \
  -vf "subtitles='C\:/work/ep01.srt':force_style='FontName=Microsoft YaHei,FontSize=16'" \
  -c:v libx264 -crf 18 -c:a copy ep01-sub.mp4
```

### 5.3 软字幕（外挂，可开关）

```bash
ffmpeg -y -i ep01-dub.mp4 -i ep01.srt \
  -map 0 -map 1 -c:v copy -c:a copy -c:s mov_text \
  -metadata:s:s:0 language=chi -movflags +faststart ep01-softsub.mp4
```

交付母版用软字幕，投放到社媒用硬字幕 —— 平台不一定认软字幕。

## 六、叠 BGM 与混音

### 6.1 侧链压缩（推荐：台词一响，BGM 自动闪避）

```bash
ffmpeg -y -i ep01-sub.mp4 -stream_loop -1 -i music/bgm-ep01.mp3 \
  -filter_complex "\
[1:a]volume=0.25[bg];\
[bg][0:a]sidechaincompress=threshold=0.03:ratio=8:attack=20:release=400[bgduck];\
[0:a][bgduck]amix=inputs=2:duration=first:normalize=0[mix];\
[mix]loudnorm=I=-16:TP=-1.5:LRA=11[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -ar 44100 \
  -movflags +faststart ep01-mixed.mp4
```

- `-stream_loop -1` 放在 BGM 输入的 `-i` **之前**，BGM 短于成片时自动循环
- `volume=0.25` 是 BGM 的基准电平；觉得还不够轻就继续调小
- `sidechaincompress` 用台词轨当触发器，台词一响就把 BGM 压下去
- `duration=first` 让混音输出以视频长度为界
- `normalize=0` 关闭 amix 的自动增益，避免音量忽大忽小
- `loudnorm=I=-16:TP=-1.5:LRA=11` 是社媒交付的响度口径

### 6.2 简单叠加（不想上侧链时）

```bash
ffmpeg -y -i ep01-sub.mp4 -stream_loop -1 -i music/bgm-ep01.mp3 \
  -filter_complex "[1:a]volume=0.22[bg];[0:a][bg]amix=inputs=2:duration=first:normalize=0,loudnorm=I=-16:TP=-1.5:LRA=11[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -ar 44100 \
  -movflags +faststart ep01-mixed.mp4
```

### 6.3 音效轨怎么进

`mmaudio` 的产出是**带音效的视频**，所以音效在第三步之前就已经贴在画面上了。
流程调整成：

```
norm/ → mmaudio 出 shots/*-sfx.mp4 → dubmix/（贴台词）→ concat → 叠 BGM
```

如果音效是独立音频文件，按 6.2 的方式再多一个输入即可：

```bash
ffmpeg -y -i ep01-sub.mp4 -stream_loop -1 -i music/bgm-ep01.mp3 -i sfx/sfx.wav \
  -filter_complex "[1:a]volume=0.22[bg];[2:a]volume=0.8[sfx];[0:a][sfx][bg]amix=inputs=3:duration=first:normalize=0,loudnorm=I=-16:TP=-1.5:LRA=11[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k ep01-mixed.mp4
```

### 6.4 检查响度与峰值

```bash
ffmpeg -i ep01-mixed.mp4 -af loudnorm=print_format=summary -f null - 2>&1 | grep -E "Input (Integrated|True Peak)"
```

目标：`Integrated ≈ -16 LUFS`、`True Peak ≤ -1.5 dBTP`。

## 七、交付转码

```bash
ffmpeg -y -i ep01-mixed.mp4 \
  -c:v libx264 -crf 20 -preset slow -profile:v high -level 4.1 \
  -pix_fmt yuv420p -r 30 \
  -c:a aac -b:a 192k -ar 44100 -ac 2 \
  -movflags +faststart \
  ep01-deliver.mp4
```

| 参数 | 作用 |
|---|---|
| `-crf 20 -preset slow` | 同画质下体积更小；想更小用 `-crf 22~23` |
| `-profile:v high -level 4.1` | 主流平台与手机的兼容档 |
| `-pix_fmt yuv420p` | 社媒平台硬性要求，缺了会发黑或发绿 |
| `-movflags +faststart` | moov 前置，网页与 App 可边下边播 |
| `-r 30` | 全片统一帧率 |

**封面（第一帧）**

```bash
ffmpeg -y -ss 1 -i ep01-deliver.mp4 -frames:v 1 -q:v 2 cover.jpg
```

**体积与时长核对**

```bash
ls -lh ep01-deliver.mp4
ffprobe -v error -show_entries format=duration,size -of default=nw=1 ep01-deliver.mp4
```

## 八、需要母版时才超分

超分在**最后一步**做，直接吃成片，不要对每一镜单独做（成本翻倍且没必要）：

```bash
python3 scripts/a7w.py call flashvsr submit \
  --body '{"input_url":"https://你的存储/ep01-deliver.mp4"}' \
  --out ep01-4k.mp4
```

- `input_url` **必填**，必须是**公网可访问的 URL**；`duration` 不传由平台自行探测
- 计费按用量，**只有要交付母版时才做** —— 目标平台会二次压缩时（竖屏短剧发抖音/小红书/视频号），
  超分收益很有限

## 九、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 拼接处花屏 / 音画错位 | 片段参数不一致就用了 `-c copy` | 先做第一步的归一化，全片统一分辨率、帧率、像素格式、音频参数 |
| `No such filter: 'subtitles'` | ffmpeg 没编 `libass` | 换带 `--enable-libass` 的构建 |
| 字幕路径报错 | filtergraph 里 `:` `\` 需要转义 | 切到字幕目录用相对文件名，或用 `'C\:/work/ep01.srt'` |
| 中文字幕是方框 | 指定的字体系统里没有 | 换成系统里确实存在的中文字体名 |
| 台词被剪掉半句 | 用了 `-shortest` 而配音比画面长 | 回调配音语速/台词，或改配音那一步重生成 |
| 声音忽大忽小 | amix 的自动增益 | 加 `normalize=0`，最后统一 `loudnorm` |
| BGM 盖住台词 | BGM 电平过高 | 降到 `0.2~0.25`，或上 `sidechaincompress` 自动闪避 |
| 发到平台后画面发绿/发黑 | 像素格式不是 `yuv420p` | 交付转码加 `-pix_fmt yuv420p` |
| 网页里要缓冲很久才播 | moov 在文件尾 | 加 `-movflags +faststart` |
| 成片比分镜表长/短 | 有镜头漏拼或重复拼 | 用 3.4 的命令与分镜表总时长核对 |
| PowerShell 里命令引号报错 | PowerShell 会吃掉内层双引号 | 用单引号包整体，或把滤镜串写进 `.txt` 用 `-filter_complex_script` |
