# 提示词范式 · 图像与视频的结构拆解

提示词不是「把想到的形容词都写上」。它是一份**有固定槽位的规格书**：
每个槽位填一句，模型才有稳定的输出。这一篇给出可复用的结构、模板和正反例。

---

## 一、图像提示词：八个槽位

```
主体 + 身份锚点 + 动作/情绪 + 服装 + 环境 + 光线 + 镜头 + 风格画质
```

| # | 槽位 | 写什么 | 示例 |
|---|---|---|---|
| 1 | **主体** | 谁 / 什么，加上人数 | `一位 25 岁中国女性` |
| 2 | **身份锚点** | 只在**定妆图那一次**写；后续出镜一律删掉，改用参考图 | `齐肩黑色短发，杏眼，鹅蛋脸` |
| 3 | **动作 / 情绪** | **一镜一个动作** | `撑着黑伞站立，神情疲惫` |
| 4 | **服装** | 基础款 + 颜色 | `米色风衣，内搭白衬衫` |
| 5 | **环境** | 地点 + 时间 + 天气 | `雨夜老城区街道，路灯昏黄` |
| 6 | **光线** | 光位 + 色温 | `路灯侧逆光，暖黄与冷蓝对比` |
| 7 | **镜头** | 景别 + 角度 + 焦段感 | `中景，平视，35mm 电影感浅景深` |
| 8 | **风格画质** | 画风 + 质感 | `写实电影感，皮肤质感真实，细节丰富` |

**完整示例（首帧图）**

```
一位 25 岁中国女性，撑着黑伞站立，神情疲惫，米色风衣内搭白衬衫，
雨夜老城区街道，路灯昏黄，地面湿反光，路灯侧逆光，暖黄与冷蓝对比，
中景，平视，35mm 电影感浅景深，写实电影感，皮肤质感真实
```

**加了参考图之后（这才是每镜该写的）**

```
保持人物长相与发型不变，改为：撑着黑伞站在路灯下，雨滴沿伞沿滑落，
米色风衣，雨夜老城区街道，路灯侧逆光暖黄，中景，35mm 电影感浅景深，写实电影感
```

> 对比一下：第 2 段里**「25 岁中国女性、齐肩黑色短发、杏眼、鹅蛋脸」全部消失了**。
> 那些信息由参考图承担，文字再写一遍只会让脸漂。

## 二、视频提示词：五个槽位

视频提示词**只描述「怎么动」**，不描述人物长相，也不描述台词与配乐。

```
主体动作（起 → 止） + 运镜 + 速度 + 环境动态 + 氛围光影
```

| # | 槽位 | 写什么 | 示例 |
|---|---|---|---|
| 1 | **主体动作** | 写清**起点和终点**，中间让模型补 | `从低头看地 → 缓缓抬头看向路灯` |
| 2 | **运镜** | 一镜一种 | `镜头缓慢推近` |
| 3 | **速度** | 只有三档：极其缓慢 / 缓慢 / 匀速 | `缓慢` |
| 4 | **环境动态** | 画面里会动的自然元素 | `雨滴打在伞面上，水洼泛起涟漪` |
| 5 | **氛围光影** | 光的变化，不是镜头变化 | `路灯闪烁一下，暖光在雨幕里散开` |

**完整示例**

```
镜头缓慢推近，人物从低头看地缓缓抬头看向路灯，雨滴打在伞面上，
路灯闪烁一下，暖光在雨幕里散开，夜晚冷调，氛围沉静
```

**视频提示词里绝对不要写的三类内容**

| 不要写 | 为什么 | 该写在哪 |
|---|---|---|
| 长相、服装、场景的静态描述 | 已经由首帧图决定了，再写会与图打架 | 首帧图的 prompt（`nano_banana`） |
| 台词 / 对白 | 视频接口不管口型 | `voice_tts` 配音 + `lipsync` / `image_human` |
| 配乐 / BGM / 背景音乐 | 会与后面的独立配音配乐工序冲突 | `music_generation/create` |
| 画面里的文字（字幕、招牌字、logo） | 生成的中文字一定是乱的 | 字幕用 ffmpeg 后期烧（见 `合成与导出.md`） |

## 三、正反例对照

### 3.1 图像提示词

| | 写法 | 结果 |
|---|---|---|
| ❌ 反例 | `一个很漂亮的女生，超美，高清，8K，杰作，最好的质量，氛围感拉满，电影级，史诗，震撼` | 全是评价词，没有一个具体画面要素。出图随机，且**每次都换脸** |
| ✅ 正例 | `一位 25 岁中国女性，撑着黑伞站立，神情疲惫，米色风衣，雨夜老城区街道，路灯侧逆光暖黄，中景，35mm 电影感浅景深，写实电影感` | 八个槽位齐全，画面要素可复现 |

| | 写法 | 结果 |
|---|---|---|
| ❌ 反例 | 一镜里写三件事：`她推开门，走进屋，坐下，拿起杯子喝水` | 图里会出现「门 + 人 + 杯子」的混乱组合，动作全错 |
| ✅ 正例 | 只写一个瞬间：`她一只手扶在门把上，正要推门，门缝透出暖光` | 图有一个明确动作瞬间，后续视频也从这里起 |

| | 写法 | 结果 |
|---|---|---|
| ❌ 反例 | 锁了参考图，又把长相复述一遍：`25 岁女性，齐肩黑短发，杏眼……站在雨里` | 文字条件与参考图互相拉扯，脸会漂 |
| ✅ 正例 | `保持人物长相与发型不变，改为：站在雨里，撑黑伞，中景` | 参考图负责身份，文字只负责变化 |

### 3.2 视频提示词

| | 写法 | 结果 |
|---|---|---|
| ❌ 反例 | `一个人非常开心地跑着，镜头快速推进又拉远，然后环绕，最后升起来` | 一镜三种运镜，模型会做出旋转扭曲的画面 |
| ✅ 正例 | `镜头缓慢推近，人物从站着 → 转身跑向街口，雨滴打在肩头` | 一种运镜 + 明确的动作起止 |

| | 写法 | 结果 |
|---|---|---|
| ❌ 反例 | `她说：「这雨下了整整十年」，背景音乐很悲伤，屏幕出现字幕` | 视频接口不管台词、配乐、字幕，写了只会干扰画面 |
| ✅ 正例 | `镜头固定，人物嘴唇轻动，眼神下移，雨丝斜落` + 后期配 `voice_tts` 台词 | 画面与声音各走各的专业工序，都可控 |

| | 写法 | 结果 |
|---|---|---|
| ❌ 反例 | `剧烈晃动的手持镜头，人物疯狂奔跑，动作很快很猛` | 速度词过头 → 画面糊、穿模、肢体崩坏 |
| ✅ 正例 | `轻微手持晃动，人物匀速小跑向前，动作幅度克制` | 动作幅度可控，成片率明显更高 |

## 四、可直接套用的填空模板

### 4.1 首帧图（第一次出现这个场景时）

```
[人数][年龄/性别][身份锚点]，[一个动作瞬间]，[情绪]，
[服装]，[地点]，[时间/天气]，[光线与色温]，
[景别]，[角度]，[焦段/景深]，[画风]，[画质质感]
```

### 4.2 首帧图（用参考图锁角色时）

```
保持人物长相、发型与服装不变，改为：[一个动作瞬间]，[情绪]，
[新地点或新光位]，[景别]，[角度]，[景深]，[画风]
```

### 4.3 尾帧图（为下一镜搭桥）

```
保持人物长相、服装与场景不变，改为：[交镜时的姿态与位置]，
[人物在画面中的位置]，[景别]，[光线]
```

### 4.4 视频提示词

```
[一种运镜] + [速度词]，人物从 [起始姿态] → [结束姿态]，
[环境里的动态元素]，[光影变化]，[整体氛围]
```

### 4.5 音效描述（喂 `mmaudio`）

```
[空间]，[具体声源 1]，[具体声源 2]，[整体强弱]，不出现人声
```

例：`室内办公室，空调低鸣，远处键盘敲击声，整体安静，不出现人声`

## 五、按画风调语气

同一个槽位结构，画风不同，**风格槽位**的写法不同：

| 画风 | 风格槽位写法 |
|---|---|
| 写实电影感 | `写实电影感，皮肤质感真实，浅景深，低饱和，胶片颗粒` |
| 都市甜宠 | `明亮清新，高调光，奶油色调，皮肤通透，轻胶片感` |
| 古装 / 权谋 | `古典写实，冷调，厚涂质感，布光考究，质感厚重` |
| 国漫 / 漫画 | `国漫风格，明确线条，赛璐珞上色，平涂阴影，画面干净` |
| 悬疑 / 惊悚 | `低照度，高对比，冷绿调，硬光，颗粒感强` |
| 3D 动画 | `3D 渲染，次表面散射，柔和区域光，材质细节丰富` |

> **一部片子只用一种画风**，并把风格槽位的措辞**逐字固定**写进每一镜的提示词。
> 措辞一变，画风就会跟着变。

## 六、负面提示词与参数

| 手段 | 怎么用 |
|---|---|
| `negative_prompt` | `wan` 支持。写 `低清晰度、畸形、多手指、文字水印、闪烁` 这类**画面缺陷**，不要写评价词 |
| `aspect_ratio` | 竖屏短剧统一 `9:16`，横屏 `16:9`。全片一致，中途别改 |
| `resolution` | 普通 `nano-banana` 模型只吃 `1K`；要 `2K`/`4K` 换 `:official` 高清模型 |
| `seed` | `wan` / `happy_horse` / `seedance` 支持。同一种子便于复现，调参时先固定种子看变化 |
| `temperature` 类发散参数 | 分镜与结构化文本任务压到 0.2~0.4；创意文案可用 0.7~0.9 |

## 七、上手顺序

1. 只写**一镜**的图提示词，出 3 张挑 1 张，确认八个槽位够用
2. 拿这张图跑一次视频提示词，确认五个槽位能控制住动作
3. 把这一镜的**两段措辞逐字固定下来**，当成全片的模板
4. 再铺开到整集 —— 中途不要改模板措辞

> 一镜验证成本几块钱。**先跑通一镜，再铺开一集**，是这套流程里最值钱的一条纪律。
