# 人物一致性 · 定妆图 → 参考图 → 首尾帧

AI 出图最大的坑不是画得不好看，是**同一个角色每一镜都变一张脸**。
这一篇只讲一件事：怎么用三层锁定，让角色从第 1 镜到第 30 镜都是同一个人。

---

## 一、先说清楚：为什么每镜重述人物一定会跑形

很多人是这样写的 —— 每一镜都在提示词里把人物描述一遍：

```
S01-002：25 岁女性，黑色短发，杏眼，皮肤白，米色风衣，站在雨里
S01-007：25 岁女性，短黑发，大眼睛，肤色白皙，米色外套，在咖啡馆
```

**结果一定是两张脸。** 原因有三层：

| 原因 | 说明 |
|---|---|
| **文字描述是「条件」，不是「身份」** | 模型是按文字条件在特征空间里**采样**。「25 岁女性 + 短发 + 杏眼」是一大片区域，每次采样落在区域里不同的点上，得到不同的脸 |
| **采样是独立的** | 每镜是一次独立生成，没有「上一镜那个人的记忆」。同一句描述跑两次都能出两张脸 |
| **复述会漂移** | 第二镜的措辞必然和第一镜不完全一样（「黑色短发」→「短黑发」、「米色风衣」→「米色外套」），条件一变，采样区域就变，脸就跟着变 |

**再补一条**：越是把描述写细（加年龄、脸型、眉形、唇形），跑形越明显 ——
因为细化的文字条件反而给了模型更多「自由解释」的空间，而不是更少。

> **结论：人物一致性不能靠文字描述，只能靠图像锚点。**

---

## 二、三层锁定法

三层各管一段，缺哪一层，哪一段就会崩。

```
第 1 层  定妆图      每个角色 1 张，全片只做一次     →  锁定「这个人长什么样」
第 2 层  参考图      每镜出首帧时作为 image_urls     →  锁定「这一镜里的还是这个人」
第 3 层  首尾帧      上一镜尾帧 = 下一镜首帧         →  锁定「镜头之间是同一个人」
```

### 第 1 层 · 定妆图（角色锚点）

**每个角色只做一次，做完存好当资产。** 用 `nano_banana` 的文生图。

```bash
python3 scripts/a7w.py call nano_banana submit \
  --body '{"prompt":"25 岁中国女性，齐肩黑色短发，杏眼，鹅蛋脸，米色风衣内搭白衬衫，正面半身像，面向镜头，表情平静，影棚均匀柔光，纯中性灰背景，无配饰，写实电影感，皮肤质感真实","resolution":"1K","aspect_ratio":"9:16"}' \
  --out chars/LIN-face.png
```

定妆图的**六条硬要求**：

| # | 要求 | 为什么 |
|---|---|---|
| 1 | **正面 + 半身 + 看向镜头** | 后续当参考图时，模型最容易对齐的是正面构图 |
| 2 | **均匀柔光 + 纯中性背景** | 别让定妆图自带戏剧光效与场景，否则会污染每一镜的环境 |
| 3 | **无配饰、无夸张妆容、无遮挡** | 刘海遮眼、围巾挡脸会让参考失效 |
| 4 | **只出现一个人** | 两个人在同一张图里，参考会串（A 的脸跑到 B 身上） |
| 5 | **画幅与成片一致**（竖屏短剧用 `9:16`） | 避免后续反复裁切 |
| 6 | **服装写基础款** | 服装要随剧情换；脸和发型才是身份 |

**建议一次多出几张挑一张**：`nano_banana` 1K 普通模型 24 点/张，出 3 张挑 1 张不到 1 元，
比后面 25 镜全部返工便宜得多。

**归档约定**

```
chars/
├── LIN-face.png       # 女主定妆图（唯一锚点）
├── YE-face.png        # 男主定妆图
├── LIN-wardrobe-1.png # 女主第 1 套服装（可选，见第三节）
└── chars.csv          # 角色代号 / 定妆图 URL / 音色 ID
```

```csv
code,name,face_url,voice_model_id,notes
LIN,林晚,https://你的存储/chars/LIN-face.png,model_xxxx,齐肩黑短发/米色风衣
YE,叶铮,https://你的存储/chars/YE-face.png,model_yyyy,短寸黑发/深灰大衣
```

> `voice_model_id` 这一列存的是 `clone_voice` 返回的 `model_id`。
> 调 `voice_tts` 合成台词时，把它填进参数 **`reference_id`**（参数名不是 `voice_id`）。

### 第 2 层 · 参考图（每镜锁人）

**出每一镜首帧时，把定妆图作为参考图传进去 —— 不要再用文字描述人物长相。**

```bash
python3 scripts/a7w.py call nano_banana submit \
  --body '{"action":"edit","prompt":"保持人物长相与发型不变，改为：雨夜街头，她撑着黑伞站在路灯下，雨滴沿伞沿滑落，中景，冷色调，写实电影感","model":"nano-banana","resolution":"1K","aspect_ratio":"9:16","image_urls":["https://你的存储/chars/LIN-face.png"]}' \
  --out shots/S01-002.png
```

**三条纪律**

| 纪律 | 反例 | 正例 |
|---|---|---|
| **文字只写「变化的部分」** | 「25 岁女性，黑色短发，杏眼……站在雨里」 | 「保持人物长相与发型不变，改为：站在雨里」 |
| **一镜一张参考图，别串人** | 把两个角色的定妆图塞进同一个 `image_urls` | 双人镜先用两人**同框图**当参考（见下） |
| **服装变化写进文字，不加参考图** | 用服装图当第二张参考，脸也跟着漂 | 「换穿深灰大衣」写在 prompt 里 |

> **双人同框镜怎么锁**：先用定妆图做一张「两人同框合影」当**新的参考图**，
> 之后所有双人镜都以这张合影为参考。这样两个角色的相对长相与身高差会被一起锁住。

**出完首帧立刻验收**

| 检查项 | 通过标准 |
|---|---|
| 脸 | 与定妆图是同一个人（眉形、眼型、脸型、发型边界） |
| 服装 | 与本镜设定一致，无随机换色 |
| 画幅 | 与全片一致，构图给运动留了空间 |
| 场景 | 与本镜 `scene` 的其它镜不冲突（时间、天气、光位） |

不合格**当场重出这一张**（24 点），不要带着问题往下走 —— 视频生成的成本是图的好几倍。

### 第 3 层 · 首尾帧（镜间锁人）

图对了，镜与镜之间还要接得上。规则只有一条：

> **上一镜的尾帧 = 下一镜的首帧。**

有两种做法，按镜头运动幅度选：

| 做法 | 怎么做 | 适用 |
|---|---|---|
| **A. 复用首帧**（首选） | 下一镜的首帧直接复用上一镜的首帧图（在 `image_urls` 里继续传它） | 固定机位、景别不变、动作连续的对话戏 |
| **B. 出尾帧再接** | 为上一镜单独出一张尾帧图（可以用上一镜首帧 + 尾帧描述做 `action=edit`），把它作为下一镜的首帧 | 有位移、有转身、景别要变的镜头 |

```bash
# 做法 B：给上一镜出一张尾帧（构图变化大时用）
python3 scripts/a7w.py call nano_banana submit \
  --body '{"action":"edit","prompt":"保持人物长相、服装与场景不变，改为：她已抬头看向路灯，人物在画面偏右，中景，冷色调","aspect_ratio":"9:16","image_urls":["https://你的存储/shots/S01-002.png"]}' \
  --out shots/S01-003-head.png
```

出片时把首帧（和尾帧）交给视频接口：

```bash
python3 scripts/a7w.py call full_video submit \
  --body '{"content":[{"role":"first_frame","type":"image_url","image_url":{"url":"https://你的存储/shots/S01-003-head.png"}},{"role":"last_frame","type":"image_url","image_url":{"url":"https://你的存储/shots/S01-003-tail.png"}},{"type":"text","text":"固定机位，人物缓缓抬头看向路灯，雨滴打在伞面上"}],"ratio":"9:16","resolution":"720P","duration":5}' \
  --out shots/S01-003.mp4
```

> `full_video` 的**首尾帧模式不能与参考媒体模式混用**；首帧尾帧各最多 1 张。
> 需要多张参考图时改用 `seedance`（参考图最多 9 张）或 `wan`（`image_with_roles`）。

## 三、三层之外的三个补强

| 补强 | 做法 | 解决什么 |
|---|---|---|
| **场景图复用** | 同一 `scene` 先出一张「空镜场景图」，同场景各镜都拿它当第二张参考 | 同一场景的光线、色调、道具位置不跳 |
| **服装表** | 把每个角色的服装按场次固定写进 `chars.csv`，多套服装各出一张「换装定妆图」 | 服装在同一场戏里随机变化 |
| **音色也一起锁** | 每个角色克隆一个音色，把 `model_id` 记进 `chars.csv` 的 `voice_model_id` 列，全剧复用 | 声音一集一个样 |

音色克隆每个角色只做一次：

```bash
python3 scripts/a7w.py call voice_tts clone_voice \
  --body '{"title":"LIN-林晚-清冷","audio_url":"https://你的存储/chars/LIN-voice-ref.mp3","description":"女主，清冷，语速偏慢"}'
# 返回 model_id，把它当成全剧的 reference_id 用
```

细节与分段配音原则见 `配音与配乐.md`。

## 四、开工前与收工后的自检清单

**开工前（每个角色一次）**

- [ ] 每个出场角色都有一张定妆图，正面、单人、中性背景、画幅与成片一致
- [ ] 定妆图已上传到公网可访问的地址，URL 记进 `chars.csv`
- [ ] 每个角色都有克隆好的音色，`model_id` 已记进 `chars.csv` 的 `voice_model_id` 列
- [ ] 双人戏有「同框合影参考图」
- [ ] `chars.csv` 与 `shots.csv` 的角色代号对得上

**每一镜出图后**

- [ ] 用的是 `action=edit` + `image_urls=[定妆图]`，**prompt 里没有重新描述长相**
- [ ] 双人镜只传了该镜实际出场角色的参考图，没有多塞
- [ ] 与上一镜需要衔接时，首帧来自上一镜的首帧或尾帧
- [ ] 服装变化写在 prompt 里，没有被当成第二张参考图

**每集出片后**

- [ ] 抽 5 个不同场次的镜头并排看，像是同一个人演的
- [ ] 台词音色与角色对得上，没有串音
- [ ] 服装在同一场戏内没有无故变化

## 五、常见问题速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 每镜都换脸 | 用文字重述人物，没用参考图 | 改 `action=edit` + 固定 `image_urls` |
| 脸对了但像换了个人演的 | 定妆图本身带戏剧光效/场景，污染了各镜 | 重出一张「均匀布光 + 中性背景」的定妆图 |
| 两个角色脸互相串 | 一张参考图里塞了两个人 | 单镜单参考；双人镜用同框合影图 |
| 换场次后发色/发型变了 | prompt 里又描述了发型 | 删掉长相与发型描述，只写「保持人物长相与发型不变，改为……」 |
| 镜头之间画面跳 | 首尾帧没衔接 | 上一镜尾帧 = 下一镜首帧，或改用固定机位 |
| 人物越走越小 / 比例怪 | 单镜时长太长，动作崩坏 | 单镜控制在 5~8 秒，长动作拆成多镜 |
| 报「未命中可用计费规格」 | 普通模型只吃 `1K`，却传了 `2K`/`4K` | 普通模型用 `1K`；要高清换 `:official` 模型 |
| 图片拉不到 / 报参数错误 | 传了本地路径 | 图片一律用**公网可访问的 URL** |
