# 配音与配乐 · voice_tts / music_generation / mmaudio

声音分三条独立的线，**不要混在一起做**：

```
台词   →  voice_tts          （按镜分段，一句一文件）
BGM    →  music_generation   （一集一首，可跨集复用）
音效   →  mmaudio            （按镜补环境音）
```

> **不要在视频生成接口里要求配乐或对白。** 视频提示词只写画面与动作，
> 声音一律后期单独做 —— 这样每一轨都可单独调、单独换、单独重做。

---

## 一、台词配音：`voice_tts`

| 接口 | 路径 | 用途 |
|---|---|---|
| `list_voices` | `GET /api/v1/apps/voice_tts/list_voices` | 查已有音色（**免费**） |
| `clone_voice` | `POST /api/v1/apps/voice_tts/clone_voice` | 克隆专属音色，拿 `model_id` |
| `tts` | `POST /api/v1/apps/voice_tts/tts` | 同步合成，**≤500 字**，直接返回音频 URL |
| `tts_async` | `POST /api/v1/apps/voice_tts/tts_async` | 异步合成，**长文本（约 1 万字内）**，返回 `task_id` |
| `tts_live` | `POST /api/v1/apps/voice_tts/tts_live` | 边说边出的流式场景 |
| `stt` | `POST /api/v1/apps/voice_tts/stt` | 已有音频转文字（做字幕或校对台词） |

### 1.1 音色克隆（每个角色只做一次）

```bash
python3 scripts/a7w.py call voice_tts clone_voice \
  --body '{"title":"LIN-林晚-清冷","audio_url":"https://你的存储/chars/LIN-voice-ref.mp3","description":"女主，清冷，语速偏慢","enhance_audio_quality":true}'
```

返回：

```json
{ "code": 1, "msg": "success",
  "data": { "id": "model_xxxxxxxxxxxx", "model_id": "model_xxxxxxxxxxxx",
            "title": "LIN-林晚-清冷", "type": "tts" } }
```

**把 `model_id` 记进 `chars.csv` 的 `voice_model_id` 列**，全剧都用它当 `reference_id`。

参考音频的要求：

| 项 | 要求 | 说明 |
|---|---|---|
| 时长 | **10 秒 ~ 5 分钟** | 太短学不像；2~3 分钟的干声最稳 |
| 格式 | `mp3` / `wav` / `ogg` / `flac` | 用公网 URL 传（`audio_url`），或 multipart 上传 `voices` 文件 |
| 内容 | **纯干声**：无 BGM、无混响、无第二个人说话 | 带背景音乐的参考会连 BGM 一起学进去 |
| `title` | **必填** | 音色名称，用「角色-风格」的命名便于归档 |
| 计费 | **200 点/次**（1 元 = 100 点，即 2 元） | 一个角色只需一次 |

**克隆完先试听**：合成一句台词听一下再铺开。克隆错了，后面几十段配音都要重做。

### 1.2 分段配音：一镜一句一文件

**核心原则：按分镜表逐镜出，一句台词一个音频文件，文件名与 `shot_id` 对齐。**

```
dub/
├── S01-001.mp3
├── S01-002.mp3      ← 与 shots.csv 的 shot_id 一一对应
├── S01-003.mp3
└── dub.csv          ← 记录每段的时长，生成 SRT 时直接读
```

为什么必须分段：

| 原因 | 说明 |
|---|---|
| **镜头要对齐** | 每镜时长由分镜表定，配音必须按镜切，才能和画面对上 |
| **改一镜不用全重做** | 改一句台词只重合成那一段 |
| **音量与语速可逐段调** | 不同情绪的镜头语速不同，整段合成做不到 |
| **时间轴可算** | 每段时长累计起来就是 SRT 的时间轴（见 `合成与导出.md`） |

```bash
# 短句（≤500 字）走同步接口
python3 scripts/a7w.py call voice_tts tts \
  --body '{"text":"这雨，下了整整十年。","reference_id":"model_xxxxxxxxxxxx","format":"mp3","sample_rate":44100,"mp3_bitrate":128}' \
  --out dub/S01-002.mp3

# 长旁白走异步接口（提交后自动轮询）
python3 scripts/a7w.py call voice_tts tts_async \
  --body '{"text":"<整段旁白，约 1 万字内>","reference_id":"model_xxxxxxxxxxxx","format":"mp3"}' \
  --out dub/narration-01.mp3
```

### 1.3 常用调音参数

| 参数 | 取值 | 用途 |
|---|---|---|
| `format` | `mp3`（默认）/ `wav` / `pcm` / `opus` | 交付用 `mp3`；要再进混音可用 `wav` |
| `sample_rate` | `8000` / `16000` / `22050` / `44100`（默认） | 与后期工程一致，统一 `44100` |
| `mp3_bitrate` | `64` / `128` / `192` | 台词用 `128` 足够；母版可 `192` |
| `prosody` | 对象：`speed` / `volume` / `normalize_loudness` | **逐段调语速**，让配音长度贴住镜头时长 |
| `temperature` | 0~1，默认 0.7 | 越低越稳，情绪戏可略高 |
| `normalize` | 默认 `true` | 文本规范化，数字、符号读法更自然 |
| `reference_id` | 音色 ID（`clone_voice` 返回的 `model_id`） | 不传则用系统默认音色 |

**语速与时长怎么调**：分镜表里这一镜 4 秒，合成出来 6 秒 ——
先把 `prosody.speed` 提到 1.1~1.15 试一遍；还超就**改台词**（删字比加速好听）。

**计费**：`tts` / `tts_async` 按 **50 点 / 1k tokens** 结算（租户价口径），
一集台词通常几百到一两千字，成本在**几毛钱**量级。查询类接口免费。

## 二、BGM：`music_generation`

```bash
# 一集一首纯伴奏 BGM
python3 scripts/a7w.py call music_generation create \
  --body '{"type":"generate","prompt":"情绪克制、紧张感逐渐累积的都市悬疑氛围，低音弦乐铺底，不要鼓点，不要人声","style":"cinematic tension, low strings, no drums","instrumental":true,"custom":false}' \
  --out music/bgm-ep01.mp3
```

关键参数：

| 参数 | 说明 |
|---|---|
| `type` | `generate` 生成原创（65 点/次）；另有 `extend` 续写、`cover` 风格翻唱、`all_stems` 分轨等 |
| `prompt` | **写情绪与氛围，不要写乐器清单** —— `克制、紧张感渐强` 比 `小提琴 + 大提琴` 好用 |
| `instrumental` | `true` = **纯伴奏**，会忽略歌词。做 BGM 一定打开 |
| `custom` | `false` 按 `prompt` 生成；`true` 则按 `lyric` + `style` 生成（做主题曲用） |
| `style` | 风格描述，常规模型上限 200 字符 |
| `style_negative` | 不希望出现的风格（如 `no drums, no vocal`） |
| `vocal_gender` | `m` / `f`，人声性别偏好（做主题曲时才用） |

```bash
# 查任务（免费）
python3 scripts/a7w.py task <task_id>
```

**一集只用一首 BGM，跨集复用完全可以接受。** 省下的不只是 65 点，
更是每集都要重新试听、重新对情绪的沟通成本。同一部剧建议：
**主 BGM 一首 + 情绪变奏 1~2 首**（用 `extend` 或换 `prompt` 里的情绪词）就够。

其余可用接口：`lyrics`（先出歌词）、`style`（风格建议）、`persona`（歌手风格）、
`timing`（歌词卡点时间轴，**免费**）、`voice_clone`（歌声音色）、`wav` / `mp4` / `midi`（导出交付）、
`upload_audio`（换音频 ID）、`query`（查任务）。
找现成曲子用 `music_search` 的 `search` 接口。

## 三、音效与环境音：`mmaudio`

给画面补上环境音，**这是性价比最高的一步** —— `submit` 只要 **0.1 点/次**。

```bash
python3 scripts/a7w.py call mmaudio submit \
  --body '{"input_url":"https://你的存储/shots/S01-003.mp4","prompt":"雨夜城市街道，雨打伞面，远处车流驶过，整体安静，不出现人声","duration":5}' \
  --out shots/S01-003-sfx.mp4
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `input_url` | **是** | 输入视频的公网 URL |
| `prompt` | 否 | 音效描述，不传则用系统默认提示词 |
| `duration` | 否 | 视频时长（秒）；不传由平台从 `input_url` 探测 |
| `audio_url` | 否 | 参考音频 URL，用于对齐配音风格 |

**音效描述的四段式**：`空间 + 具体声源 + 强弱 + 排除项`

| 写法 | 效果 |
|---|---|
| ✅ `室内办公室，空调低鸣，远处键盘敲击声，整体安静，不出现人声` | 声源明确，且**明确排除人声**，不会跟台词打架 |
| ❌ `好听的背景音乐，气氛紧张` | 这类描述会生成类音乐内容，和你的 BGM 打架 |
| ✅ `雨夜街道，雨打伞面，远处车流，音量偏低，无对白` | 情绪、空间、电平都交代了 |

**一条硬规则：`mmaudio` 只做环境音与音效，不做 BGM。**
要 BGM 走 `music_generation`，两条线分开混。

## 四、三条线怎么合到一起

```
dub/S01-00N.mp3   ─┐
shots/S01-00N.mp4 ─┼→ ffmpeg 对齐、混音 → 成片
music/bgm-ep01.mp3 ─┘
```

顺序与口径：

| 步 | 做什么 | 口径 |
|---|---|---|
| 1 | 台词配音逐段生成，记录每段时长 | 与分镜时长对齐，超了就调 `speed` 或改台词 |
| 2 | 视频片段补齐到与配音等长 | 用 `apad` 补静音，不要拉伸画面 |
| 3 | **先混台词 + 音效**，再叠 BGM | 音效本来就贴在画面上，先合更自然 |
| 4 | BGM 压低后叠入 | BGM 比台词低 **12~18 dB**；用侧链压缩自动闪避 |
| 5 | 整体响度归一 | `loudnorm=I=-16:TP=-1.5:LRA=11`（社媒交付口径） |

完整的 ffmpeg 命令（含侧链压缩与响度归一）见 `合成与导出.md`。

## 五、配音配乐常见坑

| 坑 | 表现 | 怎么避 |
|---|---|---|
| 整段一次性合成 | 镜头对不上，改一句要全部重做 | **按镜分段**，一镜一文件，文件名用 `shot_id` |
| 克隆参考带 BGM | 合成的语音里带背景音乐 | 参考音频必须是**纯干声**，10 秒 ~ 5 分钟 |
| 忘了 `title` | `clone_voice` 报参数错误 | `title` 是必填项 |
| 拿 `voice_id` 当参数名 | 报参数不合法 | 音色参数名是 **`reference_id`**，值是 `clone_voice` 返回的 `model_id` |
| 用 `tts` 合成超长文本 | 报错或截断 | ≤500 字用 `tts`；长文用 `tts_async` |
| 在视频提示词里要求配乐 | BGM 和台词互相压，还想重做就得重出视频 | 视频只出画面，声音后期独立做 |
| 一集一首新 BGM | 成本和时间都浪费 | 一集复用同一首；变奏用 1~2 首覆盖 |
| BGM 盖过台词 | 观众听不清对白 | BGM 压低 12~18 dB，或上侧链压缩自动闪避 |
| `mmaudio` 里写「背景音乐」 | 生成了类音乐内容，和 BGM 轨冲突 | `mmaudio` 只写环境音与音效，并写「不出现人声」 |
| 重复提交 | 扣两次钱 | 先记 `task_id`，用 `query` / `task`（免费）确认状态 |
| 拿 `code == 0` 判成功 | 明明成功却判失败 | 平台成功码是 **`1`**（`{"code":1,"msg":"success"}`） |
