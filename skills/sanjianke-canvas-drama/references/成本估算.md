# 成本估算 · 各环节点数与一集预算

**1 元 = 100 点，1 点 = 0.01 元。按点数计费，用多少扣多少，没有月费。**

这一篇给三样东西：每个环节的**真实点数口径**、一集 2 分钟（约 25 镜）的**完整测算**、
以及**省钱顺序** —— 知道先砍哪里，比记住一堆单价更重要。

---

## 一、计费的基本规则（先记住这四条）

| 规则 | 说明 |
|---|---|
| **先冻结后结算** | 提交异步任务时按预估价**冻结点数**，任务完成后按实际用量**多退少补** |
| **失败全额退回** | 任务失败会把冻结的点数**全额退回**，只有成功产出才结算 |
| **查询免费** | 各类 `query` / `task` 接口不计费，可以放心轮询 |
| **对账看 `data.usage.points_cost`** | 每次调用返回里它就是**本次真实扣费**；任务级用量在 `GET /api/v1/tasks/{task_id}` 的 `usage` 字段；账号级流水在用户中心 |

平台同时给出**两套价格**：

| 字段 | 含义 | 能不能用来做预算 |
|---|---|---|
| `fixed_price` / `input_price` | 标准价（对外公示） | ❌ 可能偏差很大 |
| `tenant_fixed_points` / `tenant_points_per_1k_input` | **你所在租户的实际结算价** | ✅ **只能用这个** |

```bash
# 现查你自己的真实价（强烈建议每次开工前跑一遍）
python3 scripts/a7w.py schema nano_banana
python3 scripts/a7w.py schema full_video
python3 scripts/a7w.py schema voice_tts
python3 scripts/a7w.py points          # 看最近任务的实际消耗
```

## 二、各环节点数（快照口径）

> 下表是某次快照的**租户价**，用来说明量级与相对关系。
> **你自己的真实价请用 `schema <app>` 现场读**，最终以实际扣费为准。

### 2.1 图像

| 环节 | 应用 · 接口 | 口径 | 点数 |
|---|---|---|---|
| 定妆图 / 首帧 / 尾帧 / 场景图 | `nano_banana` · `submit` | 点 / 张（1K 普通模型） | **24** |
| 同上（升级模型） | 同上 | 点 / 张 | 38 / 45 |
| 同上（高清模型） | 同上 | 点 / 张（按 1K/2K/4K 分档） | 28.03 / 35.76 / 61.52 |
| 查图任务 | `query` | **免费** | 0 |

**注意**：普通模型只吃 `1K` 分辨率；传 `2K`/`4K` 会报「未命中可用计费规格」，
要高清就换 `:official` 高清模型。**先用 1K 跑通，确认效果再上高清。**

### 2.2 视频（成本大头）

| 应用 · 接口 | 口径 | 点数 |
|---|---|---|
| `full_video` · `submit` | 480P | **10 点/秒** |
| 同上 | 768P | 20 点/秒 |
| 同上 | 1080P / 2K / 4K | **40 点/秒** |
| `happy_horse` · `submit` | 720P | 0.9 点/秒 |
| 同上 | 1080P | 1.6 点/秒 |
| `wan` / `seedance` / `grok_video` | 按秒或按 tokens 分档 | `schema <app>` 现查 |
| `seedance` · `create` | 按输出 tokens 与定价矩阵 | 分档：480p 3000/5000 · 720p 3200/5500 · 1080p 3500/6000（点/百万 tokens） |

**分辨率是最大的杠杆**：480P 到 1080P 差 **4 倍**。
竖屏短剧投抖音 / 小红书 / 视频号会被二次压缩，**480P~720P 起步通常够用**。

### 2.3 声音

| 环节 | 应用 · 接口 | 口径 | 点数 |
|---|---|---|---|
| 音色克隆 | `voice_tts` · `clone_voice` | 点 / 次（每角色一次） | **200** |
| 台词合成 | `voice_tts` · `tts` / `tts_async` | 点 / 千 tokens | **50 / 1k** |
| 查音色 | `voice_tts` · `list_voices` | **免费** | 0 |
| BGM | `music_generation` · `create` | 点 / 次（`generate`） | **65** |
| 歌词卡点时间轴 | `music_generation` · `timing` | **免费** | 0 |
| 音效 / 环境音 | `mmaudio` · `submit` | 点 / 次 | **0.1** |

> 声音整体只占一集成本的 **20% 左右**，其中音效几乎可以忽略。
> **这不是该省钱的地方**（详见第五节的省钱顺序）。

### 2.4 数字人 / 口型 / 后期

| 环节 | 应用 · 接口 | 口径 | 点数 |
|---|---|---|---|
| 全驱动数字人 | `image_human` · `submit` | 点 / 秒（按驱动音频时长，`mode` 分档） | fast 1.5 · standard 2 · 2k 4 · 4k 8 |
| 图片对口型 | `pic_lipsync` · `submit` | 以站内计费为准 | `schema pic_lipsync` 现查 |
| 视频对口型 | `lipsync` · `submit` | 以站内计费为准 | `schema lipsync` 现查 |
| 视频超分 | `flashvsr` · `submit` | 固定 + 按用量 | 0.1 + 3 点/单位 |
| 混剪 | `smart_clip` | 点 / 秒 | 720p 0.2 · 1080p 0.3 |
| 动作迁移 / 人物替换 | `action_transfer` / `person_replacement` | 点 / 秒（分档） | 1 / 2 / 3 |

**`image_human` 的四档价差 5.3 倍**（1.5 → 8 点/秒）。
先算钱再选档：60 秒口播走 `fast` 是 90 点（0.9 元），走 `4k` 是 480 点（4.8 元）。

### 2.5 文本（剧本 / 分镜）

模型网关按 **点 / 百万 tokens** 计，输入输出分别计价。
实测一次普通问答约 **0.74~0.99 点**。

**拆一部剧的剧本与分镜通常十几到几十次调用，总成本在几毛钱量级** ——
这是全流程里最便宜的一环，**不要在提示词上省钱**，分镜写得细一点省下的是后面几倍的返工。

## 三、一集 2 分钟的完整测算

**测算前提**（竖屏 `9:16`，`full_video` 出片）：

| 项 | 假设 |
|---|---|
| 镜头数 | 25 镜 |
| 单镜时长 | 平均 5 秒（**总视频时长 125 秒 ≈ 2 分 05 秒**） |
| 角色数 | 3 个（各 1 张定妆图 + 1 次音色克隆） |
| 有台词镜头 | 18 镜，总台词约 900 字 |
| 需要尾帧的镜头 | 10 镜 |
| 场景空镜图 | 5 张 |

### 3.1 分项明细

| # | 环节 | 计算 | 点数 | 折合 |
|---|---|---|---|---|
| 1 | 剧本 + 分镜（模型网关） | 约 20 次调用 | 20 | 0.20 元 |
| 2 | 定妆图 | 3 张 × 24 | 72 | 0.72 元 |
| 3 | 首帧图 | 25 张 × 24 | 600 | 6.00 元 |
| 4 | 尾帧图 | 10 张 × 24 | 240 | 2.40 元 |
| 5 | 场景空镜图 | 5 张 × 24 | 120 | 1.20 元 |
| 6 | 音色克隆 | 3 次 × 200 | 600 | 6.00 元 |
| 7 | 台词合成 | 约 1800 tokens × 50/1k | 90 | 0.90 元 |
| 8 | BGM | 1 次 × 65 | 65 | 0.65 元 |
| 9 | 音效 | 15 镜 × 0.1 | 2 | 0.02 元 |
| | **小计（不含视频）** | | **1809** | **18.09 元** |
| 10 | 视频生成 | 见下三档 | — | — |

### 3.2 三档预算（差异全部来自视频）

| 口径 | 视频单价 | 视频点数（125 秒） | 总计 | 折合 | 适用 |
|---|---|---|---|---|---|
| **极简 · 静帧 + 口型** | 不做视频生成，改走 `image_human` `fast` 1.5 点/秒 × 72 秒＝108 点 | 108 | **1917** | **约 19 元** | 对话戏、情绪戏、内心独白 |
| **标准 · 480P** | 10 点/秒 | 1250 | **3059** | **约 31 元** | **默认推荐**；社媒投放够用 |
| **高清 · 1080P** | 40 点/秒 | 5000 | **6809** | **约 68 元** | 需要母版 / 大屏 / 二次剪辑 |
| 超分（可选） | `flashvsr`，固定 0.1 + 3 点/单位 | 按成片用量 | 现场 `schema flashvsr` 读 | — | 只在对成片做交付母版时加 |

> 极简档里视频生成被替换成数字人口型，所以第 4 项「尾帧图」通常也可以省掉 240 点，
> 实际约 **1677 点 ≈ 17 元**。

### 3.3 单镜成本（用来快速心算整集）

| 口径 | 出图 | 视频（5 秒） | 单镜合计 | 25 镜 |
|---|---|---|---|---|
| 极简（图 + 口型） | 24 | 5 秒 × 1.5 = 7.5 | ≈ 32 点 | ≈ 800 点 |
| 标准 480P | 24 | 5 秒 × 10 = 50 | **≈ 74 点** | ≈ 1850 点 + 资产 |
| 高清 1080P | 24 | 5 秒 × 40 = 200 | ≈ 224 点 | ≈ 5600 点 + 资产 |

**一句话口径**：**每镜 5 秒 480P 大约 0.74 元**（含出图）。
报预算时用这个数乘镜头数，再加 18 元左右的固定资产与声音成本，就接近全集成本。

### 3.4 预算试算脚本

存成 `budget.py`，开工前跑一遍：

```python
# -*- coding: utf-8 -*-
"""按分镜表估算一集成本。只用标准库。"""
import csv, sys

# 租户价快照，用前请用 `python3 scripts/a7w.py schema <app>` 核对
PRICE = {
    "image": 24,             # nano_banana submit / 张
    "video_480p": 10,        # full_video submit / 秒
    "video_768p": 20,
    "video_1080p": 40,
    "clone_voice": 200,      # voice_tts clone_voice / 次
    "tts_per_1k": 50,        # voice_tts tts / 千 tokens
    "bgm": 65,               # music_generation create / 次
    "sfx": 0.1,              # mmaudio submit / 次
    "lip_fast": 1.5,         # image_human submit / 秒（fast）
    "llm_call": 1.0,         # 模型网关 / 次（估算）
}


def main(path="shots.csv", tier="480p", characters=3, llm_calls=20):
    rows = list(csv.DictReader(open(path, encoding="utf-8-sig")))
    n = len(rows)
    total_sec = sum(float(r.get("duration") or 0) for r in rows)
    lines = [r for r in rows if (r.get("dialogue") or "").strip()]
    tail = sum(1 for r in rows if (r.get("transition") or "").strip())
    words = sum(len((r.get("dialogue") or "").strip()) for r in rows)

    # 极简档：有台词的镜头走口型，其余镜头只出图
    lip_sec = sum(float(r.get("duration") or 0) for r in lines)

    cost = {
        "剧本 + 分镜": llm_calls * PRICE["llm_call"],
        "定妆图": characters * PRICE["image"],
        "首帧图": n * PRICE["image"],
        "尾帧图": tail * PRICE["image"],
        "音色克隆": characters * PRICE["clone_voice"],
        "台词合成": max(1, words * 2) / 1000.0 * PRICE["tts_per_1k"],
        "BGM": PRICE["bgm"],
        "音效": len(rows) * PRICE["sfx"],
    }
    if tier == "lite":
        cost["口型（image_human fast）"] = lip_sec * PRICE["lip_fast"]
    else:
        cost["视频生成 %s" % tier] = total_sec * PRICE["video_" + tier]

    print("镜头 %d 个 · 视频总时长 %.1f 秒 · 台词 %d 字\n" % (n, total_sec, words))
    for k, v in cost.items():
        print("  %-26s %9.1f 点   %7.2f 元" % (k, v, v / 100.0))
    s = sum(cost.values())
    print("  %-26s %9.1f 点   %7.2f 元" % ("合计", s, s / 100.0))
    print("\n每镜均值 %.1f 点（%.2f 元）" % (s / max(1, n), s / max(1, n) / 100.0))


if __name__ == "__main__":
    main(*sys.argv[1:])
```

```bash
python3 budget.py shots.csv 480p        # 标准档
python3 budget.py shots.csv lite         # 极简档（图 + 口型）
```

## 四、省钱顺序

**顺序不能颠倒。** 按下面的顺序砍，效果依次递减；反过来砍，钱没省多少、成片还变差。

```
① 砍视频秒数（最大项，占一集 40% 以上）
        ↓
② 复用已生成的图片与音乐资产
        ↓
③ 最后才考虑配音配乐（本来就不贵）
```

### ① 先砍视频秒数

视频生成是唯一的大头。四条做法，按性价比排序：

| 做法 | 省多少 | 怎么做 |
|---|---|---|
| **静帧戏走「图 + 口型」** | 单镜从 50 点降到 7.5 点，**省 85%** | 对话、情绪、内心独白这类没有连续真人动作的镜头，**不要用视频生成**。出图 + `image_human` `fast` 即可 |
| **单镜压到 5 秒** | 时长直接线性省钱 | 单镜 5 秒 vs 10 秒差一倍。长动作拆成多镜，每镜 4~5 秒 |
| **降分辨率档** | 480P → 1080P 差 **4 倍** | 社媒会被二次压缩，**480P/720P 起步**；要母版再超分 |
| **镜头复用** | 省下一整镜 | 空镜、场景过渡、回忆闪回可以在同场景镜头之间复用素材（换配乐与字幕即可） |

**换算一下**：25 镜里如果 12 镜走「图 + 口型」、13 镜走 480P 视频生成，
视频成本从 1250 点降到 650 + 90 = **740 点**，一集立省约 **5 元（17%）**。

### ② 再复用图片与音乐

图片是**一次性资产**，复用是零边际成本：

| 复用对象 | 做法 | 省多少 |
|---|---|---|
| **定妆图** | 一个角色只出一次，跨集、跨项目都能用 | 每集省 72 点 |
| **场景空镜图** | 同场景先出一张空镜，各镜都拿它当第二张参考图 | 每集省 120 点，同时提升场景一致性 |
| **尾帧 = 下镜首帧** | 上一镜尾帧直接当下一镜首帧，**不重复出图** | 每集省 240 点 |
| **BGM 跨集复用** | 一部剧主 BGM 一首 + 情绪变奏 1~2 首 | 每集省 65 点 |
| **音色克隆** | 每个角色只克隆一次，跨集复用 | 每集省 600 点（首集之后为 0） |

> **首集之后，第 2 集的资产成本几乎为 0** —— 定妆图、音色、场景图、BGM 都能直接拿过来用。
> 这就是「一部剧一次投入、多集摊薄」的算法。

### ③ 最后才动配音配乐

| 环节 | 一集点数 | 占比 |
|---|---|---|
| 音色克隆 | 600 | 19.6% |
| 台词合成 | 90 | 2.9% |
| BGM | 65 | 2.1% |
| 音效 | 2 | 0.1% |
| **声音合计** | **757** | **约 24.7%** |

声音里**真正能省的是音色克隆（600 点）**，而它的省钱方式是**复用**（每个角色只做一次），
不是换便宜方案 —— 音色是观众认角色的关键，这里省下来的是观感。

**BGM 与音效已经便宜到不该考虑**：一集 BGM 65 点（0.65 元）、音效 2 点。
**在这上面省钱的性价比是最低的。**

### 省钱的四条纪律

| 纪律 | 说明 |
|---|---|
| **先跑一镜验证** | 一个镜头的成本几块钱。**验证完配方再铺开**，比事后整集重做便宜几十倍 |
| **给 Key 设消费上限** | 批量前把 quota 设成预算的 1.2 倍，参数写错时能止损 |
| **提交前先估算** | 用 `budget.py` 或第三节的口径算一遍；**不计成本就开跑是最贵的习惯** |
| **别重复提交** | 异步任务提交时就会预冻结点数。超时先查 `task_id` 再决定是否重提 |

## 五、台账与对账

### 5.1 每步都记一行

```csv
shot_id,stage,app,api,task_id,status,points,input_url,output_url,updated_at
S01-003,image,nano_banana,submit,task_aaa,completed,24,,"https://.../S01-003.png",2026-01-01T10:00:00
S01-003,dub,voice_tts,tts_async,task_bbb,completed,3,,"https://.../S01-003.mp3",2026-01-01T10:02:00
S01-003,video,full_video,submit,task_ccc,completed,50,,"https://.../S01-003.mp4",2026-01-01T10:09:00
```

- `status` 只认 `pending` / `completed` / `failed`
- 重跑时**只补 `status != completed` 的行**
- `points` 回填真实扣点，用来看钱花在哪个应用上

### 5.2 按应用汇总（bash）

```bash
python3 -c "
import csv, collections
d = collections.defaultdict(float)
for r in csv.DictReader(open('tasks.csv', encoding='utf-8-sig')):
    d[r['app']] += float(r['points'] or 0)
for k, v in sorted(d.items(), key=lambda x: -x[1]):
    print('%-22s %8.1f 点  %7.2f 元' % (k, v, v / 100.0))
print('%-22s %8.1f 点  %7.2f 元' % ('合计', sum(d.values()), sum(d.values()) / 100.0))
"
```

### 5.3 三处数字对账

| 层 | 来源 | 字段 |
|---|---|---|
| **单次调用** | 接口返回 | `data.usage.points_cost` |
| **单个任务** | `GET /api/v1/tasks/{task_id}` | `usage` |
| **账号账** | 用户中心流水 | 实际扣点 |

三者对不上时，常见原因是：
**同一任务重复提交**（同一 `task_id` 出现两条流水）、
**回调重试导致下游重复登记**（流水只有一条，你的台账有两行）、
**拿标准价当实收价做预期**。

对账脚本：

```bash
python3 -c "
import csv
est = 0.0; real = 0.0
for r in csv.DictReader(open('tasks.csv', encoding='utf-8-sig')):
    real += float(r['points'] or 0)
print('台账实际扣点合计 %.1f 点 = %.2f 元' % (real, real / 100.0))
"
python3 scripts/a7w.py points        # 与平台侧最近任务对一遍
```

> **失败的任务不扣费**，冻结的点数会全额退回 —— 所以台账里 `failed` 的行
> 不该计入成本。上面的汇总脚本只累加已回填 `points` 的行，不会把失败行算进去。

## 六、成本速查卡

```
图像      nano_banana          24 点/张（1K 普通模型）
视频      full_video     480P  10 点/秒   768P  20 点/秒   1080P  40 点/秒
          happy_horse    720P  0.9 点/秒  1080P 1.6 点/秒
口型      image_human          fast 1.5 / standard 2 / 2k 4 / 4k 8  点/秒
音色      voice_tts clone      200 点/次（每角色一次）
台词      voice_tts tts        50 点 / 1k tokens
BGM       music_generation     65 点/次
音效      mmaudio              0.1 点/次
超分      flashvsr             0.1 固定 + 3 点/单位
查询      各家 query          免费

单镜头心算：5 秒 480P ≈ 0.74 元（含出图）
```

**省钱顺序：砍视频秒数 → 复用图片与音乐 → 最后才考虑配音配乐。**
