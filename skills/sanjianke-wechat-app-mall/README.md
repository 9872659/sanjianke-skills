# 三剪客 · 微信小程序商城前端模板 Skill

wechat-app-mall：微信小程序商城前端模板 的安装、常用命令与避坑要点

---

## 前置条件

- **微信开发者工具**（本地调试与上传代码都靠它，从微信官方下载页获取）。
- 一个已注册的**小程序 AppID**，且当前微信号是该小程序的开发者。
- 一个可用的**后端服务**，以及后台分配给你的**专属域名**与**商户 ID**——没有这两个值，打开只会看到示例商户的演示数据。
- 正式发布还需要：已备案域名 + HTTPS 证书 + 微信公众平台的服务器域名白名单。
- 只有需要改依赖时才要求本机有 Node.js 与 npm；仓库已自带 `miniprogram_npm/` 构建产物。

---

## 使用

1. 取代码并导入：

```bash
git clone https://github.com/EastWorld/wechat-app-mall.git
```

2. 微信开发者工具 → 导入项目 → 目录选**仓库根目录**（`project.config.json` 所在层），编译类型 `miniprogram`。
3. 把 `project.config.json` 的 `appid` 换成自己的 AppID。
4. 改 `config.js` 里的 `subDomain`（后台给的专属域名，不是网址）与 `merchantId`（自己的商户 ID）。
5. 本地调试勾上「不校验合法域名、web-view、TLS 版本以及 HTTPS 证书」；发布前把接口域名加进白名单并取消勾选。
6. 编译预览 → 上传代码 → 公众平台提交审核 → 审核通过后发布。用户无需重新扫码，重开小程序即更新。

改依赖时：

```bash
npm install      # 然后在开发者工具里执行「构建 npm」，重新生成 miniprogram_npm
```

更完整的命令、排障顺序与页面定位方法见 `SKILL.md`。

## 依赖

- 运行环境：微信小程序运行时（由微信客户端提供），不需要自建服务器。
- 仓库 `package.json` 中的依赖：`@vant/weapp`、`apifm-wxapi`、`dayjs`、`mp-html`、`wxa-plugin-canvas`、`wxbarcode`。
- 需要一个符合模板约定接口规范的后端服务；商品、订单、优惠券、拼团等数据都在后端。
- 开发期依赖微信开发者工具；改依赖时需要 Node.js 与 npm。
- 发布期依赖已备案域名、HTTPS 证书与公众平台的域名白名单配置。

---

## 安全

- 不内嵌任何密钥；`config.js` 里放的是域名标识与商户 ID，支付等敏感参数应配在后台而不是前端代码里。
- 前端代码是公开可下载的，不要把任何私密凭据写进小程序代码或图片资源。
- 生产环境必须配置服务器域名白名单并关闭「不校验合法域名」，否则接口可被替换、流量可被劫持。
- 用户手机号、地址、订单等信息属于个人信息，需在小程序内提供隐私政策并按规定取得授权。
- 上传代码与发布涉及线上经营，操作前确认类目、资质与备案状态符合平台要求。
