# 三剪客 · 爆款标题工坊

给一个主题或产品，**自动产出 N 个标题并四维打分排序，附 A/B 测试组合建议**。
面向小红书 / 抖音 / 公众号 / 知乎的新媒体运营。

这是产品线里的 **L1 单点生成型**技能包：一个输入 → 一个产出，开箱即用。

## 它解决什么问题

运营每天卡住的不是"想不出标题"，而是**想出 30 个之后不知道该用哪个**。

这个包把判断也一起做了：四个维度打分排序，再把"只差一个变量"的标题配成对，
告诉你这一对测什么、赢了说明什么——这样跑一轮 A/B，
你得到的不是"哪句话好"，而是"你这类受众吃哪一套"，可以复用到之后几十条内容。

## 四件事，一条命令

| 子命令 | 干什么 |
|---|---|
| `gen` | 生成 N 个标题（默认 30）并四维打分，降序输出 |
| `score` | 给已有标题清单打分（不改写原文） |
| `ab` | 给 A/B 测试配对建议（哪两个配对、测哪个变量），纯本地不花 token |
| `models` | 列出 api.a7w.cn 当前在架的模型（免费） |

## 三分钟上手

```bash
# 1) 到 https://api.a7w.cn/ 注册领 Key，然后填进环境变量
export A7W_API_KEY=sk-你的key          # Windows PowerShell: $env:A7W_API_KEY="sk-你的key"

cd sanjianke-title-workshop

# 3) 确认网关通（免费）
python3 scripts/run.py models

# 4) 跑第一个例子
python3 scripts/run.py gen --topic "便携榨汁杯" --platform xiaohongshu --count 12
```

输出是按总分降序的 Markdown 排行表 + 逐条说明。命中广告法违禁词的标题会标红并压分。

完整工作流：

```bash
python3 scripts/run.py gen --topic "便携榨汁杯" --platform xiaohongshu --count 30 \
    --evidence "实测一次榨 350ml、清洗 40 秒、USB-C 充电 90 分钟满" \
    --json --out titles.json

python3 scripts/run.py ab --file titles.json
```

## 打分怎么算

四维各 1~10 分，加权合成总分（满分 100）：

```
总分 = (点击欲望 × 0.35 + 信息量 × 0.25 + 平台适配 × 0.25 + 合规 × 0.15) × 10
```

三个维度是**本地强制**的，模型说了不算：

- **合规**：本地内置广告法违禁词正则表，命中就按风险等级封顶（高=1 / 中=4 / 低=7），
  并标红、把退出码改成 `3`——可以直接进 CI 当发布门禁。
- **模板污染**：标题里混进"编稿脚手架"而不是内容——公式名被当文案
  （`结论前置：xxx`）、公式名＋分隔符起头（`双段式｜xxx`）、占位符没替换
  （`{结论要点}，三个理由`）。合规维封顶到 **3 分**，同样标红、退出码 `3`。
  判定取"模型自报的 formula"与"该平台已知公式名全集"的并集——
  因为模型会在 formula 字段里自己发挥，只信它会漏判。
  **误伤率实测 0/196**（96 条真实标题 + 100 条手写正常标题，含"结论前置条件很重要"
  这类公式名当子串的正常句子）；因此判定要求公式名后必须紧跟分隔符或串尾。
- **抄提示词示例**（`prompt_echo`）：标题与提示词示例**去掉标点后相等**、
  字符二元组 **Jaccard ≥ 0.75**、或**示例二元组的覆盖度 ≥ 0.60**，
  长度门槛是相对的 `max(6, 示例长度/2)`（本包示例 15~17 字 → 门槛 7~8），
  三条任一命中即按模板污染同档处理。第三条是补漏：Jaccard 的分母是并集，
  产出越长示例被摊得越狠——示例原样嵌进 24 字标题里实测只有 0.696（放行），
  而覆盖度是 1.00（拦下）；覆盖度只看"示例被抄了多少"，不看产出有多长。
  由来：实测模型会**锚定提示词里的示例**，曾有一轮
  **最高分 89.0 的标题一字不差就是提示词示例**——最高分变成"抄标准答案"就不是真最优，
  排序就废了。对策是提示词里**不出现任何可复制的完整标题**，举例统一用不同主题。
- **平台适配**：标题字符数超过该平台上限时，这一维强制压到 5 分（超 5 字以上压到 3 分）。

细则见 [`references/scoring-rubric.md`](references/scoring-rubric.md)。

## 平台口径

| 平台 | 上限 | 语感 |
|---|---|---|
| 小红书 | 20 字符 | 口语、真诚、像朋友安利 |
| 抖音 | 15 字符 | 前 3 个字出冲突或悬念，能直接念 |
| 公众号 | 25 字符 | 双段式，偏理性克制，有信息势能 |
| 知乎 | 25 字符 | 专业、有信息密度，提问或结论前置 |

每个平台各有 5 个可套用的标题公式，见 [`references/title-formulas.md`](references/title-formulas.md)。

## 算力接入

只用大模型，端点：`POST https://api.a7w.cn/api/v1/chat/completions`（OpenAI 兼容协议）。
模型清单用 `GET https://api.a7w.cn/api/v1/models` 现查。

- **不留任何密钥在代码或文档里**，Key 从环境变量 `A7W_API_KEY` 读
- **模型名会变，用 `models` 子命令现查，别写死**
- `deepseek-chat` 这个别名**实测可用**（路由到 `deepseek-flash`），
  但它**不在** `/api/v1/models` 的返回列表里——"列表里没有"不等于"不能用"
- 大模型调用带退避重试（网关 `upstream timeout` / HTTP 502 实测很常见）
- JSON 解析用 `json.JSONDecoder().raw_decode()` 扫描第一个完整对象，
  模型在合法 JSON 后多吐字符也不会炸
