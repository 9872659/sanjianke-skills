# 合规红线与违禁词自检

> **先说清楚边界**：本文件与 `run.py` 内置的词表是**启发式自检工具**，
> 来自公开经验整理，**不构成法律意见**，也**不等于任何平台的官方审核结论**。
> 它只能帮你"发布前少踩明显的坑"，最终责任在使用者。
> 高风险类目（医疗、保健品、食品、金融、母婴、特殊化妆品）**必须人工复核或送法务**。
>
> **本文档里的标题片段一律是"违规反例"，是用来说明词表覆盖范围的，不要照抄。**
> 提示词示例若需举例，统一用"电动车充电桩"这类**完全不同的主题**。

`run.py` 的合规自检有两道：

| 道次 | 位置 | 成本 | 能发现什么 |
|---|---|---|---|
| 第一道 | `run.py` 内置 `BANNED_PATTERNS` 正则表 | 零成本、确定性 | 违禁词、绝对化用语、站外导流、标点堆砌 |
| 第二道 | 大模型 `compliance` 维度打分 + `--dry-run` 人工看提示词 | 花 token | 语义层面夸大、谐音规避、暗示性承诺 |

第一道是**闸门**：命中即压分、标红、退出码变 3。第二道是**参考**，会误判。

## 一、《广告法》第九条：绝对化用语

这是标题里最容易踩、也是执法最严的一条。**禁止使用的是"最高级"和"排他性"表述**。

| 类型 | 禁用示例 | 合规写法 |
|---|---|---|
| 最高级 | 最好、最佳、最优、最低价、最快、最强、最先进 | 好用、性价比高、出汁快、比上一代快 |
| 排他性 | 第一、No.1、TOP1、销量第一、唯一、独家、首个 | 之一、少见的、不多见的 |
| 权威性 | 国家级、世界级、全球领先、央视推荐、国家认证 | 删掉，或写"我们实测" |
| 绝对化 | 100%、百分之百、绝对有效、保证有效、永不 | 大多数情况下、实测 90% 场景下 |

### 为什么"最"字这么危险

《广告法》第九条第（三）项直接列举了"国家级""最高级""最佳"。
执法实践中，**只要出现"最 + 形容词"且用于描述自身商品/服务，就构成风险**，
不需要证明它是假的。所以规则很简单：

> **描述自家产品时，「最」字一律替换掉。**

例外与注意：「最近」「最后」「最终」这类**不表示程度最高**的词不属于绝对化用语，
但「最后一天」「仅限今天」属于促销时限表述，需与实际活动一致
（见第四节）。`run.py` 的正则已经做了这个区分——它只匹配
`最(好|佳|优|低|便宜|快|强|大|高|先进|新|流行|受欢迎)`。

## 二、医疗与功效类：最重的一类

非药品、非医疗器械、非特殊化妆品**不得宣称医疗功效**。
标题里出现下面任何一个词，风险等级直接判"高"：

```
根治 · 治愈 · 痊愈 · 药到病除 · 包治 · 治疗好 · 疗效 · 无副作用 · 零副作用
```

**常见的擦边写法（同样违规）**：

- 「三天见效」——时间承诺构成的功效暗示
- 「比药还管用」——比较性功效宣称
- 「医生都推荐」——虚构专业背书
- 「排出毒素」「调理体质」——伪科学功效表述

**合规写法**：只描述**使用感受**和**可观察的现象**，不描述**身体机理**。

| 违规 | 合规 |
|---|---|
| 喝了这个，肠胃好了 | 我喝了两周，早上的状态比以前舒服 |
| 美白淡斑，7 天见效 | 关于美白这件事，我研究了 3 个月 |

> 注意：即使只描述主观感受，**食品、保健品、化妆品仍受各自专门法规约束**
> （如保健食品不得宣称疾病预防、治疗功能）。这类内容建议直接人工过一遍。

## 三、投资与收益承诺

金融、理财、副业、带货类内容的高压线：

```
稳赚 · 躺赚 · 包赚 · 零风险 · 一本万利 · 高回报 · 保证收益 · 年化 xx%
```

还有一类是**暗示性**的：用具体金额前后对比（「3 个月从 0 到 10 万」），
即使不写"保证"，也构成收益暗示，需要**真实可举证**且在标题里标明条件
（时间、本金、前提）。拿不出证据就别写。

## 四、促销与时限

`秒杀 · 抢购 · 限时抢 · 最后一天 · 仅限今天 · 免费领 · 0 元购`

这些词**本身不违法**，但要求**表述与实际活动完全一致**。
标题写"限时"而实际长期在做，就是虚假宣传。
`run.py` 把这类判为"中风险"——命中会压合规分并标红，提醒你核对活动真实性。

## 五、站外导流

`点击链接 · 加微信 · 私信我 · 扫码进群 · vx / VX / 微信号`

各平台普遍限制站外导流，轻则限流重则封号。
标题里不要出现任何联系方式，需要引流放到合规的私域承接环节。

> 本包文档里出现的微信号只用于**技术咨询**，不属于内容导流，也不要写进你的标题里。

## 六、标题党与低质判定

平台会把下列特征判为低质内容，影响的是**推荐量**而不是法律风险，
但效果上跟违规差不多——内容发不出去。

| 特征 | 例子 | 脚本等级 |
|---|---|---|
| 标点堆砌 | `真的绝了！！！！`、`为什么？？？` | 低 |
| 惊悚诱导 | 震惊、惊呆、不看后悔、速看、删前必看 | 中 |
| 数字夸张 | `99% 的人都不知道`（无数据来源） | 中（命中 100% 类规则或需人工判断） |
| 空悬念 | `看完你就懂了`（不给出任何信息） | 中（信息量维度会打低分，双重拦截） |

## 七、脚本怎么用这套规则

### 本地自检（零成本，随时跑）

```bash
# 生成时会自动扫，命中就标红、压分、退出码 3
python3 scripts/run.py gen --topic "便携榨汁杯" --platform xiaohongshu --count 12

# 给已有标题单独做合规体检（走大模型 semantic 打分 + 本地词表）
python3 scripts/run.py score --titles "全网最低价，7 天见效" "通勤带它出门真香" --platform xiaohongshu
echo $?     # 3 表示有命中
```

### 在 CI / 批量流程里当门禁用

退出码约定：

| 退出码 | 含义 |
|---|---|
| 0 | 全部干净 |
| 3 | **有标题命中违禁词**（结果已输出，但必须人工复核后才可发布） |
| 4 | 调用失败（网络 / 鉴权 / 点数 / 模型名） |
| 130 | 用户中断 |

```bash
python3 scripts/run.py gen --topic "便携榨汁杯" --count 30 --json --out titles.json
if [ $? -eq 3 ]; then echo "有合规命中，禁止自动发布"; exit 1; fi
```

### 压制规则（脚本强制，模型不能覆盖）

| 命中等级 | 合规维度封顶分 | 例词 |
|---|---|---|
| 高 | **1** | 最、第一、国家级、100%、根治、绝对、稳赚 |
| 中 | **4** | 独家、唯一、纯天然、限时、免费领、震惊、加微信 |
| 低 | **7** | 标点堆砌 |

判定逻辑：`compliance = min(模型给出的分, 封顶分)`。
所以模型"误以为很干净"给 10 分时，命中高风险仍会被压到 1 分，
且该标题会在 Markdown 输出里标红并列出命中原因。

## 八、发布前最后一遍人工清单

脚本过完，发布前再对着这 5 条扫一眼：

1. **每个数字都有出处吗？** 没有就删掉数字，换成定性描述。
2. **有没有在描述自家产品时用了"最"字？** 有就换词。
3. **有没有暗示身体功效、收益、疗效？** 有就删。
4. **标题里的承诺，正文兑现得了吗？** 兑现不了就是标题党，平台会算账。
5. **这个标题让同行看见了，我会不会心虚？** 会，就说明有问题。
