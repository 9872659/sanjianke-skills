# 接口速查 · 短剧产线用到的全部应用

**路径规则：一律 `/api/v1/apps/<应用代号>/<接口代号>`**，
应用代号与接口代号都用**下划线**，而且都可以现场查：

```bash
python3 scripts/a7w.py apps                # 列全部应用
python3 scripts/a7w.py schema <应用代号>    # 看该应用的接口与参数
```

> **不要用平台的 `endpoint_path` 字段拼 URL。** 部分应用给出的路径属于别的路由族
> （例如 `voice_tts` 给的是 `/v1/tts`、`wan` 给的是 `/v1/videos/generations`），
> 直接拿去请求打不通。**只用上面那条规则。**

---

## 一、模型网关（策划 / 编剧 / 分镜）

| 项 | 内容 |
|---|---|
| 路径 | `POST /api/v1/chat/completions` |
| 协议 | OpenAI 兼容，`base_url = https://api.a7w.cn/api/v1` |
| 模型清单 | `GET /api/v1/models` |
| 计费 | 按点数/百万 Token，输入输出分别计价 |

**常用模型**：`DeepSeek-V4-Pro`、`DeepSeek-V4-Flash`、`Qwen3.7-Max`、
`GLM-5.2`、`Kimi-K2.6`、`ERNIE-5.0-Thinking`（推理）。

```bash
curl -sS -X POST "https://api.a7w.cn/api/v1/chat/completions" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"DeepSeek-V4-Pro","messages":[{"role":"user","content":"……"}]}'
```

> 推理模型会把 token 先花在思维链上，`max_tokens` 设太小会只返回 `null`，
> 结构化产出建议 ≥ 200。正文一律取 `choices[0].message.content`。

## 二、出图 · nano_banana

| 接口 | 路径 | 模式 | 计费 |
|---|---|---|---|
| `submit` | `POST /api/v1/apps/nano_banana/submit` | 异步 | 24 点/次起（`nano-banana` · 1K） |
| `query` | `POST /api/v1/apps/nano_banana/query` | 同步 | 免费 |

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `prompt` | string | 是 | 角色形象 / 画面描述 |
| `action` | string | 否 | `generate`（文生图）/ `edit`（基于参考图改，**锁角色长相用这个**） |
| `image_urls` | array | `edit` 必填 | 参考图公网 URL 数组 |
| `model` | string | 否 | `nano-banana`（24 点）/ `nano-banana-2`（38）/ `nano-banana-2-lite`（24）/ `nano-banana-pro`（45）/ 各 `:official` 高清档 |
| `resolution` | string | 否 | `1K` / `2K` / `4K`（普通模型只吃 `1K`） |
| `aspect_ratio` | string | 否 | 短剧竖屏用 `9:16` |

## 三、出片 · 三个视频应用

| 应用 | 接口 | 适合 |
|---|---|---|
| `full_video` | `POST /api/v1/apps/full_video/submit` | **通用首选**：文 / 首尾帧 / 多模态参考都吃 |
| `happy_horse` | `POST /api/v1/apps/happy_horse/submit` | 一阶段声画一起出、多语言对白 |
| `seedance` | `POST /api/v1/apps/seedance/create` | 480p / 720p / 1080p 分档，带素材管理 |

### full_video

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `content` | array | **是** | 内容列表，**须含一项文本**；可按模式传首帧 / 尾帧 / 参考媒体 |
| `ratio` | string | 否 | 画幅，默认 `16:9`；图生视频可用 `adaptive`；短剧竖屏用 `9:16` |
| `duration` | integer | 否 | **4～15 秒整数** |
| `resolution` | string | 否 | `480P` / `768P` / `1080P` / `2K` / `4K`；按分辨率独立按秒 SKU 计价 |
| `aigc_watermark` | boolean | 否 | 是否添加生成标识 |

约束：首帧尾帧各最多 1 张；参考图最多 9 张；参考视频 / 音频各最多 3 个；
**首尾帧模式不能与参考媒体模式混用**；参考媒体模式至少要 1 张参考图或 1 个参考视频。

### happy_horse

必填：`model`、`prompt`（≤2500 字）、`duration`（3～15 秒整数）、`resolution`（`720P` / `1080P`）。
价格档：720P **0.9 点/秒**、1080P **1.6 点/秒**（按 `duration` 计费）。
`media` 是统一参考素材数组，元素形如 `{"url": "...", "type": "image"}`。

### seedance

`create` 的 `content` 支持 文本 + 图片（最多 9）+ 视频（最多 3）+ 音频（最多 3）任意组合，
**不可单独传音频**。`duration` 取 4～15 或 `-1` 由模型自动决定；
`generate_audio` 控制是否生成同步音频。按 token 计费，按分辨率与是否含视频输入分档。

## 四、配音与口型 · voice_tts / lipsync / image_human

### voice_tts（6 个接口）

| 接口 | 路径 | 模式 | 计费 |
|---|---|---|---|
| `clone_voice` | `POST /api/v1/apps/voice_tts/clone_voice` | 同步 | 200 点/次（租户价） |
| `tts` | `POST /api/v1/apps/voice_tts/tts` | 同步 | 50 点/千 Token；短文本（≤500 字） |
| `tts_async` | `POST /api/v1/apps/voice_tts/tts_async` | 异步 | 同上；长文本（≤10000 字） |
| `tts_live` | `POST /api/v1/apps/voice_tts/tts_live` | 异步 | 同上；流式上游 |
| `stt` | `POST /api/v1/apps/voice_tts/stt` | 同步 | 30 点/次 |
| `list_voices` | `GET /api/v1/apps/voice_tts/list_voices` | 同步 | 免费 |

- `clone_voice` 必填 `title`；`audio_url` 与文件上传二选一，支持 mp3 / wav / ogg / flac
- `tts` / `tts_async` 用 `reference_id` 指定音色；`model` 可选 `s1` / `s2-pro`
- `tts` 的 `prosody` 对象可调 `speed` / `volume` / `normalize_loudness`

### lipsync（已有视频换口型）

`POST /api/v1/apps/lipsync/submit` · 必填 `video_url`、`audio_url`；
`model` 支持 `xiaojiayu1.0` / `2.0` / `3.0`（或简写 `1.0` / `2.0` / `3.0`）。

### image_human（只有图，让它开口）

`POST /api/v1/apps/image_human/submit` · 必填 `file_url`（人物图）、`ref_file_url`（驱动音频）。
`mode` 分四档：`fast` **1.5 点/秒** / `standard` **2** / `2k` **4** / `4k` **8**。
**先算钱再选档**：`fast` 到 `4k` 单价差 5.3 倍。

## 五、音乐与音效

| 接口 | 路径 | 模式 | 计费 |
|---|---|---|---|
| `music_generation/create` | `POST /api/v1/apps/music_generation/create` | 异步 | 65 点/次 |
| `music_generation/lyrics` | `POST /api/v1/apps/music_generation/lyrics` | 同步 | 12 点/次 |
| `music_generation/timing` | `POST /api/v1/apps/music_generation/timing` | 同步 | 免费 |
| `music_generation/voice_clone` | `POST /api/v1/apps/music_generation/voice_clone` | 同步 | 20 点/次 |
| `music_generation/mp4` / `wav` / `midi` | 同名路径 | 混合 | 20 / 14 / 14 点/次 |
| `music_search/search` | `POST /api/v1/apps/music_search/search` | 同步 | 10 点/次 |
| `mmaudio/submit` | `POST /api/v1/apps/mmaudio/submit` | 异步 | 按配置 |

`create` 关键参数：`type`（`generate` / `extend` / `concat` / `cover` / `inspo` …）、
`prompt`（灵感模式，≤500 字）、`lyric` + `style`（自定义模式）、
`instrumental`（纯伴奏，开启后忽略歌词）、`vocal_gender`（`m` / `f`）。

> 做短剧 BGM 就用 `type=generate` + `instrumental=true` + `prompt` 描述情绪，
> 一次 65 点，一集用一首甚至复用同一首。

## 七、通用

| 用途 | 路径 |
|---|---|
| 查异步任务 | `GET /api/v1/tasks/{task_id}` |
| 列全部应用 | `GET /api/v1/apps` |
| 看某应用接口与参数 | `GET /api/v1/apps/{app}` |
| 模型清单 | `GET /api/v1/models` |
| 计费规则表 | `GET /api/v1/pricing` |

**响应信封**：`{code, msg, data}`，**`code` 为 `1` 才是成功**
（HTTP 200 不等于业务成功）。异步任务在提交时预冻结点数，完成后按实际用量结算。
