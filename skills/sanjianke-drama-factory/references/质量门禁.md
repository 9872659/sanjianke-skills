# 质量门禁 · 三道关卡

短剧量产最贵的错误不是生成失败，而是**把问题留到了最贵的那一步才被发现**。
改一句话的成本，到分镜阶段是十几张图，到出片阶段是几百块。

所以设三道门禁，**每一道不通过就不许进下一步**。

---

## 门禁一：小说改编可行性（动手前，零成本）

### 1. 看体量与结构

| 看什么 | 判断标准 |
|---|---|
| 章节数 / 字数 | 决定要压缩到多少集；一本 100 万字小说改 100 集以上才够 |
| 是否单线推进 | **短剧要单线**。多线并行的长篇硬改会丢掉大半支线 |
| 是否有明确主角 | 群像戏改短剧要重定主角 |

### 2. 找核心矛盾

写清两件事：**主角的强欲望** 和 **强阻碍**。然后对照矛盾四级阶梯：

| 级别 | 形态 | 判断 |
|---|---|---|
| 1 级 | 口角、误会、小摩擦 | 太淡，撑不起一集 |
| 2 级 | 利益冲突、竞争关系 | 勉强，需要叠加 |
| 3 级 | **生存 / 名誉 / 亲情受威胁** | **及格线**，短剧起步 |
| 4 级 | 生死、身份颠覆、不可逆损失 | 强，但要控制密度别一直顶格 |

**低于 3 级直接打回重设矛盾**，不要靠加事件来凑。

### 3. 看爽点类型与金手指

| 爽点类型 | 特征 | 注意 |
|---|---|---|
| 优势 / 金手指型 | 主角有别人没有的能力、信息、身份 | **必须有约束**（代价、时限、不能对人用） |
| 归属型 | 被认可、被需要、被珍视 | 要有「被误解 → 被看见」的落差 |
| 秩序型 | 讨回公道、惩治恶人、修复规则 | 反派动机要合理，不能只会「纯嫉妒」 |

**金手指没有约束 = 无敌外挂 = 没有张力。** 这一条是打回率最高的。

### 门禁一结论怎么给

直说三种之一，并给理由：**适合改 / 需要大改 / 不适合改**。
不要含糊其辞地说「可以试试」—— 那等于把风险推给下一步。

## 门禁二：故事骨架十二项审查

骨架（分集大纲）出来后，逐条对。**任何一条不过就打回重出骨架**，
不要带着问题进编剧。

- [ ] **压缩比 ≤ 40%** —— 原文 100 章压成 40 集以内，压不动说明结构不适合
- [ ] **每集有集末钩子** —— 抽 3 集看，钩子必须在主线上
- [ ] **章节号能在事件表里找到** —— 对不上说明骨架是「编」出来的，不是从原著来的
- [ ] **大三角贯穿始终** —— 主线冲突从第 1 集到最后一集都在
- [ ] **核心矛盾 ≥ 3 级** —— 用门禁一的四级阶梯量
- [ ] **金手指有约束** —— 有代价、有时限、或有使用条件
- [ ] **人物小传 ≤ 4 人** —— 主要角色超过 4 个，短剧观众记不住
- [ ] **反派动机合理** —— 「纯嫉妒」要打回，给一个站得住的理由
- [ ] **五个付费卡点按 N×10 / 30 / 50 / 70 / 90% 落位** —— 且卡在主线上
- [ ] **前 10 集能剪出约 10 个 30 秒爆点** —— 不够就是节奏太平
- [ ] **结局是爽剧收尾** —— 主要矛盾得到解决，主角拿到他想要的东西
- [ ] **每集字数与时长匹配** —— 2 分钟一集约 1200～1800 字台词

## 门禁三：分镜表铁律

分镜是最容易「看起来没问题、出片全是坑」的一步。

### 六条必查铁律

| 铁律 | 违反的表现 | 为什么致命 |
|---|---|---|
| **台词零删改** | 台词被精简、合并、省略修饰词 | 配音按台词合成，改了就与剧本对不上 |
| **在场人物不能消失** | 剧本没写「离开」，人却在分镜里没了 | 观众会当成穿帮 |
| **人物外观交给图片资产** | 分镜提示词里出现服装 / 发型 / 长相 | 每镜重出一次外观，角色必然变脸 |
| **声音只写环境音 + 音效** | 出现 BGM、配乐、音乐 | 会与第 ⑧ 道工序的 BGM 打架 |
| **长台词超 20 字强制拆镜** | 长台词挤在一个固定镜头里 | 单片段超 15 秒直接提交失败 |
| **单片段 ≤ 15 秒** | 有超长片段 | 生成接口只吃 4～15 秒整数 |

### 片段间过渡：四类桥梁

**这是分镜质量的分水岭。** 每个片段至少要挂上其中一类，
否则成片会「一跳一跳」——单看每段都行，连起来就是不对。

| 桥梁 | 做法 | 分镜里怎么写 |
|---|---|---|
| **动作衔接** | 上一镜的动作延续到下一镜 | `承接上一镜的转身，下一镜从抬头开始` |
| **情绪衔接** | 情绪递进或反差 | `上一镜压抑，本镜情绪开始外放` |
| **空间与视线衔接** | 视线方向 / 空间关系连续 | `本镜人物视线看向画面右侧，下一镜出现她看的东西` |
| **台词与动作的黏合** | 台词落在具体动作上，不是干说 | `说到「十年」时把手里照片按在桌上` |

检查方法：把分镜表按顺序读一遍 `transition` 字段，
**连着两段都没有桥梁的地方，就是成片会跳的地方。**

### 九条常见红线（自检）

- [ ] 没有台词被删改
- [ ] 没有人物凭空消失 / 凭空出现
- [ ] 没有在分镜里描述服装、发型、长相
- [ ] 没有在分镜里写 BGM
- [ ] 没有超过 20 字的台词挤在单镜里
- [ ] 没有超过 15 秒的片段
- [ ] 每个片段都挂了四类桥梁之一
- [ ] 每个片段都有明确首帧（能对应到④出图的一张图）
- [ ] 每个片段都有对应的台词音频或明确「无台词」

## 上线前的资产审查

出片之前再过一遍这些**非技术**事项：

| 项 | 说明 |
|---|---|
| **改编授权** | 改编他人作品需取得授权，开工前确认权利归属 |
| **素材授权** | 用到的图片、音乐、音效各自的授权范围要能覆盖发布渠道 |
| **内容合规** | 生成内容的标识要求与平台规则，按发布渠道逐项确认 |
| **AI 生成标识** | 需要加标识时，出片接口有 `aigc_watermark` 一类的开关 |
| **肖像与声音** | 克隆音色、真人形象需取得本人同意 |

## 自检清单（交付前）

- [ ] 门禁一给了明确结论，不是「可以试试」
- [ ] 骨架十二项逐条对过，不是泛泛说「还行」
- [ ] 分镜专门查了片段间过渡
- [ ] 给成本数字时说明了那是**参考默认值**、需要换真实单价
- [ ] 涉及改编他人小说时，提示了版权授权是前提
- [ ] 没有把方法论说成「保证出片质量」
