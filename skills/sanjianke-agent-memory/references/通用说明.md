# 通用说明

## 一、这个 Skill 会做什么

| 能力 | 是否申请 | 用途 |
|---|---|---|
| 网络访问 | **申请** | 调用 `api.a7w.cn` 的网关与应用接口（唯一的联网行为） |
| 读取文件 | 仅读取你指定的输入文件与 `--json-file` 请求体 | 作为接口入参 |
| 写入文件 | 仅在传入 `--out` 时 | 保存返回的 JSON 或产物 |
| 凭证 | 读取**你自己**提供的 API Key | 从环境变量或 `~/.a7w/config.json` 读取 |
| 子进程 / 后台常驻 | 不申请 | 脚本执行完即退出，不注册服务、不常驻 |

**不内嵌任何密钥。** 请求只发往 `api.a7w.cn`，不发送到其他任何地址。

---

## 二、运行环境

- **Python 3.8+**，只用标准库（`urllib` / `json` / `mimetypes`），无需 `pip install`。
- 一个 `api.a7w.cn` 账号与 API Key。
- 能访问 `https://api.a7w.cn` 的网络出口。

---

## 三、客户端用法

```bash
python3 scripts/a7w.py login --key sk-xxx     # 验证并保存 Key
python3 scripts/a7w.py whoami                 # 看这把 Key 能用多少能力
python3 scripts/a7w.py apps                   # 列出全部应用
python3 scripts/a7w.py schema <app>           # 看某应用的接口与参数
python3 scripts/a7w.py call <app> <api> --body '{...}'
python3 scripts/a7w.py task <task_id>         # 查异步任务
python3 scripts/a7w.py points                 # 看最近的用量
```

也可以当库用：

```python
import a7w
data = a7w.call("voice_tts", "tts", {"text": "你好世界"})
a7w.save(data["result"]["audio_url"], "out.mp3")
```

## 四、计费口径

- **1 元 = 100 点、1 点 = ¥0.01**，点数永久有效。
- **先冻结、后结算**：消费优先扣会员点数，不足再扣充值额度；
  **调用失败直接退款，异步任务失败冻结点数全额退回**。
- 上游调价会同步调整，但**不影响已充值的点数余额**。
- 每次返回的 `data.usage` 就是本次真实用量，可直接对账。
- 平台同时给标准价与租户实际结算价，**做预算用 `tenant_*`，以实际扣费为准**。

## 五、错误的判断口径

1. **业务成败看 `code`，不是 HTTP 状态码。**
   成功码是 **`1`**（`{"code":1,"msg":"success"}`）；
   请求一个不存在的接口可能返回 **HTTP 200** + `{"code":0,...}`。
2. **裸对象端点没有 `code/msg/data` 外壳**（如余额、计费规则接口直接返回对象），
   不能拿「有没有 `data` 字段」判断成功。
3. **402 分两种**：账号余额不足 `insufficient_points`，和 Key 的 quota 打满
   `key_quota_exceeded`。
4. **404 要看是路径拼错还是接口问题**：应用代号是下划线，写成连字符会 404。
5. **不要拿 `endpoint_path` 拼 URL**，一律用
   `/api/v1/apps/<应用代号>/<接口代号>`。

## 六、可靠性建议

- **幂等**：异步任务先记 `task_id`，网络超时先查状态再决定是否重提。
- **退避重试**：只对网络类错误与 5xx 重试；4xx 是业务错误，重试无意义。
- **降并发**：撞 429 说明排队到顶了，等队列消化。
- **留足 `max_tokens`**：推理类模型的思维链也占 token。
- **复杂请求体走文件**：PowerShell / CMD 会吃掉 JSON 里的双引号，
  复杂请求体用 `--json-file body.json`。

## 七、边界

- **不提供 Key、不代付费用**：Key 与点数都必须是你自己的账号。
- **不保证可用性**：接口由平台提供，模型上下架、限流与计费以站内为准。
- **不替代内容合规审查**：生成内容的合规责任由使用者承担。
