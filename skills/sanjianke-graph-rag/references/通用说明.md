# 通用说明：权限、异步、错误码、计费

## 1. 权限与用途

| 能力 | 是否申请 | 用途 |
|---|---|---|
| 网络访问 | **申请** | 调用 `api.a7w.cn` 的网关与接口（本 Skill 唯一的联网行为） |
| 读取文件 | 仅读取你指定的输入文件 | 用作语料与请求体 |
| 写入文件 | 仅在传入 `--out` 时 | 保存返回的 JSON 或本地索引 |
| 凭证 | 读取**使用者自己**提供的 API Key | 从 `~/.a7w/config.json` 或环境变量读取 |
| 子进程 / 后台常驻 | 不申请 | 脚本执行完即退出，不注册服务、不常驻 |

**不内嵌任何密钥。** 脚本只把 Key 发往 `api.a7w.cn`，不发送到其他任何地址。

## 2. 两条调用入口

| 入口 | 怎么调 | 形态 |
|---|---|---|
| **模型网关** | `POST /api/v1/chat/completions`、`POST /api/v1/embeddings` | 同步，直接返回 `choices` / `data` |
| **应用任务** | `POST /api/v1/apps/<应用代号>/<接口代号>` | 多为异步，返回 `task_id` |

⚠️ **永远用 `/api/v1/apps/<应用代号>/<接口代号>` 拼路径。**
两个代号都来自接口返回的 `code` 字段（用 `python3 scripts/a7w.py schema <应用>` 查），
**不要拿文档里写的端点路径去拼 URL** —— 有些应用给出的路径属于别的路由族，实际打不通。

**应用代号用下划线**（如 `file_qa`），不是连字符。

## 3. 异步任务机制

生成类应用是**任务制**，标准四步：

```bash
# 1. 看有哪些应用
python3 scripts/a7w.py apps

# 2. 看某个应用有哪些接口、参数与真实价
python3 scripts/a7w.py schema file_qa

# 3. 提交任务（异步接口会自动轮询到结束）
python3 scripts/a7w.py call file_qa parse --json '{...}'

# 4. 只提交不等，稍后自己查
python3 scripts/a7w.py call file_qa parse --json '{...}' --no-wait
python3 scripts/a7w.py task tsk_xxxxxxxx
```

- 终态看 `status`（`completed` / `failed` / `cancelled`），产物在 `result`，用量在 `usage`。
- **查询任务免费**，可以放心轮询。
- **提交时就预冻结点数**，完成后按实际用量多退少补；失败全额退回。
- **不要重复提交同一个任务** —— 每次提交都可能产生费用。网络超时也先查 `task_id` 再决定要不要重提。

## 4. 错误码

| HTTP | code | 含义 | 怎么处理 |
|---|---|---|---|
| 400 | `invalid_request` | 参数缺失或格式错误 | 用 `python3 scripts/a7w.py schema <应用>` 核对参数名与必填项 |
| 401 | `auth_failed` | API Key 缺失或无效 | 重新配置 Key |
| 402 | `insufficient_points` | 点数余额不足 | 充值；错误里有本次所需点数 |
| 402 | `key_quota_exceeded` | 该 Key 的点数额度打满 | 去用户中心调高 / 重置 quota，**不用充值** |
| 403 | `permission_denied` | 该 Key 无权调用此模型 / 应用 | 检查模型是否已开通、Key 是否被限权 |
| 404 | `not_found` | 模型 / 应用 / 任务不存在 | 核对代码拼写，用 `apps` 与模型清单拿真名 |
| 429 | `queue_limit_exceeded` | 排队任务已达上限 | 降并发，等队列消化后重试 |
| 5xx | `server_error` | 服务异常 | 退避重试；仍失败换模型 / 线路 |

**注意 402 有两种**：账号没钱与 Key 自己的额度打满。查错时先分清是哪一种。

### 成功码是 `1`，不是 `0`

业务成败看响应体里的 `code`：**`{"code":1,"msg":"success"}` 才是成功**。
拿 `code == 0` 去判断成功，会把成功的调用误判为失败。
裸对象端点（没有 `code/msg/data` 外壳）不能用「有没有 `data` 字段」判断成功。

## 5. 计费口径

- 计价单位是**点数**，**1 元 = 100 点、1 点 = ¥0.01**。点数永久有效。
- **先冻结、后结算**；调用失败不计费，异步任务失败冻结点数全额退回。
- 计费口径随能力不同：对话与向量化按**点数 / 百万 tokens**（输入输出分别计价），
  生成类应用按次 / 按秒 / 按时长。
- 平台同时给出**标准价**与**租户实际结算价**两套字段，两者可能差很多：

| 字段 | 含义 |
|---|---|
| `fixed_price` / `input_price` | **标准价**，对外公示用 |
| `tenant_fixed_points` / `tenant_points_per_1k_input` | **你所在租户的实际结算价** |

**做预算一律用租户价，最终以实际扣费为准。**
每次返回里的 `usage`（或 `points_cost`）就是本次真实扣费。

## 6. 客户端速查

```bash
python3 scripts/a7w.py login --key sk-xxx   # 验证并保存 Key
python3 scripts/a7w.py whoami               # 看这把 Key 能用的应用数
python3 scripts/a7w.py apps                 # 列出全部应用
python3 scripts/a7w.py schema <应用>         # 看接口与参数
python3 scripts/a7w.py call <应用> <接口> --json '{...}' [--no-wait] [--out 文件]
python3 scripts/a7w.py task <task_id>       # 查异步任务
python3 scripts/a7w.py points               # 看最近的用量
```

客户端内置**网络抖动退避重试**：长异步任务轮询时连接可能被网关重置
（Windows 上常见 `WinError 10054`），重试可以避免已经预冻结点数的任务白丢。
自己写脚本时记得加同样的重试。

## 7. 安全底线

- Key 只从环境变量或本机配置文件读，**不硬编进代码、不提交进 Git**。
- 只发往 `api.a7w.cn` 一个域名。
- 破坏性操作（删数据、重建索引）执行前先备份。
- 语料内容与生成内容的合规责任由使用者承担。
