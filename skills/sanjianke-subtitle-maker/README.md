# 三剪客 · 离线音视频转字幕 Skill

Buzz：在本机离线把音频、视频甚至视频链接转成字幕，可导出 TXT/SRT/VTT，支持多种推理后端与 GPU 加速。含图形界面与命令行两种用法与避坑要点。

---

## 前置条件

- 系统里要有可用的 `ffmpeg`。
- 走 PyPI 安装路线需要 Python 3.12 环境；桌面路线需要图形运行环境。
- 首次转写要联网下载模型，预留磁盘空间；完全离线的机器需提前把模型准备好。
- 实时转写需要可用的麦克风与系统输入权限。
- 要用 NVIDIA 加速，需额外安装带 CUDA 支持的 torch 与配套 CUDA 库，或使用界面里提供的加速安装入口。
- 素材涉及隐私时，确认选择的是本地模型后端，而不是在线接口后端。

---

## 使用

1. 先按平台装好：Windows / macOS 用官方发布页的安装包，Linux 用 Flatpak 或 Snap，也可以从 PyPI 装。
2. 打开界面导入文件或链接，或在命令行用 `buzz add` 把文件排进任务。
3. 选后端与模型大小：先用小模型快速验证效果，再按需要换更大的模型。
4. 需要更准就开语音分离与逐词时间戳；嘈杂素材效果尤其明显。
5. 选输出格式（TXT / SRT / VTT）与输出目录，导出后在剪辑软件里校验时间轴。
6. 批处理场景直接用命令行把多个文件一次排完；重复性任务可以开监听文件夹。

命令行参数以 `buzz add --help` 的输出为准，界面功能以实际版本为准。

---

## 依赖

- `ffmpeg`
- Python 3.12（仅 PyPI 安装路线）
- 图形运行环境（命令行界面同样基于 Qt）
- 可选：带 CUDA 的 torch 与 CUDA 运行库（NVIDIA 加速）；Apple 芯片与 Vulkan 路线按平台条件
- 预训练模型（首次使用时下载）
- 可选：在线接口后端的访问令牌（仅在该路线下需要）

---

## 安全

- 不内嵌任何密钥；在线接口的访问令牌请在运行时传入或由应用自己保存，不要写进脚本或提交到仓库。
- 本地模型路线素材不出本机；一旦切到在线接口后端，音频会被发往第三方，涉密素材务必确认这一点。
- 下载模型与安装包请只走官方渠道，避免使用来路不明的镜像。
- Windows 安装包未签名，出现安全提示属正常现象，但要确认文件来源可信后再继续。
- 处理他人录音与视频前请确认已获授权；转写文本属于敏感数据，导出文件注意存放位置。
- 用视频链接转写时注意站点服务条款与内容版权。
