## 一、三分钟跑通

### 第一步：拿到你自己的 Key

到 **[api.a7w.cn](https://api.a7w.cn/)** 注册，创建一个 API Key（形如 `sk-...`），填进环境变量：

```bash
export A7W_API_KEY=sk-你的key      # Windows: $env:A7W_API_KEY="sk-你的key"
```

### 第二步：提交转写任务

```bash
curl -sS -X POST "https://api.a7w.cn/api/v1/apps/voice_tts/stt" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"audio_url":"https://你的存储/我的音频.mp3"}'
```

### 第三步：拿结果

返回里带识别出的文字与时间轴信息。**要 SRT 字幕文件**，把时间轴按句切分后写成标准 SRT 即可 ——
`references/字幕排版.md` 给了现成的转换脚本与排版要点。

> **视频要先抽音轨**：`ffmpeg -i 我的视频.mp4 -vn -ac 1 -ar 16000 音频.mp3`
> （16 kHz 单声道是语音识别的推荐输入规格，体积也小）

## 三、素材要求

| 要求 | 说明 |
|---|---|
| 格式 | MP3 / WAV 等常见音频；视频先抽音轨 |
| 访问 | **必须公网可访问的 URL**，不支持本地路径、不支持 Base64 |
| 采样率 | 建议转成 **16 kHz 单声道**，识别更稳、传输更快 |
| 内容 | 单人清晰人声效果最好；多人会议建议先分离说话人 |

## 四、常见坑

| 坑 | 表现 | 怎么避 |
|---|---|---|
| **拿本地路径当入参** | 报参数错误 | 一律用**公网可访问的 URL** |
| **直接传视频** | 需要先抽音轨 | `ffmpeg -vn -ac 1 -ar 16000` 转成音频再传 |
| **背景音乐很响** | 识别率下降 | 有条件先做一次人声分离（见同门的音轨分离 SKILL） |
| **重复提交** | 扣两次钱 | 先记 `task_id`，用查询接口（免费）确认状态 |
| **拿 `code == 0` 判断成功** | 明明成功却判成失败 | 平台成功码是 **`1`** |
