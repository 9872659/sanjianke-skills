# 收敛与决策

发散决定"有没有得选"，收敛决定"选得对不对、事后能不能解释"。这一份把收敛阶段拆成四步：**定权重 → 打分 → 淘汰 → 留痕**，每一步都给可执行的规矩。

---

## 一、开场先立规矩

收敛阶段比发散阶段更容易坏，因为它给人一种"理性"的错觉——有分数、有排序，看起来像在认真比较。实际上大多数打分都是**先有结论，再往回凑分数**。

三条纪律必须在动笔打分之前宣布，写下来，贴在看得见的地方：

1. **权重先定死。**打分前把每个维度的权重写下来。打完分发现结果不合意再回头改权重，是这套方法里最常见也最致命的作弊。
2. **分数后面必须有事实。**每个 1 分或 3 分背后要有一句话，话里要有数字、日期、约束或已发生的事。只有形容词的分数一律记 "?"，不许默认给 2 分。
3. **每个候选必须能说出失败条件。**说不出"它在什么情况下会失败"的候选，说明大家还没真正理解它。退回发散阶段补，不允许带着模糊理解进入排序。

加一条实务纪律：**参与发散的人必须参与收敛**。中途换人，等于用另一把尺子量同一个东西。

---

## 二、五维打分卡

### 1. 五个维度

| 维度 | 问的问题 | 1 分 | 2 分 | 3 分 |
|---|---|---|---|---|
| **有效性** | 它能不能真的解决问题？ | 只缓解症状，主问题还在 | 能解决主问题 | 解决主问题且除掉根因 |
| **成本** | 花多少钱、多少人、多长时间？ | 超预算或需新增人力 | 在预算内但吃满 | 明显低于预算 |
| **风险** | 最坏情况能不能承受？ | 最坏情况不可逆 | 可逆但需要补代价 | 失败只是白干，无后遗症 |
| **可逆性与可验证** | 能不能先小范围试？退得回来吗？ | 一上就难退 | 能退但要停机 | 小范围先试，用数据说话 |
| **杠杆** | 做完之后多出了什么？ | 一次性消耗 | 能复用 | 沉淀成资产或打开后续方案 |

### 2. 为什么是这五个

这五个维度合起来覆盖了三件容易漏的事：

- **有效性**防止"做得漂亮但没用"
- **成本 + 风险 + 可逆性**合起来是"代价面"，防止"对但做不起"或"能做但退了就死"
- **杠杆**防止"这次解决了，下次还得从头来"

如果五维里有一维对你的场景明显不适用（比如纯一次性活动没有杠杆），**不要删掉它**，把它权重定为 1（有则更好）。删维度会让不同轮次的打分无法比较。

### 3. 权重的三档

权重只有三档，**不许出现 1.5、2.7 这类值**——那会制造精确的幻觉：

| 档位 | 倍数 | 什么时候用 | 典型数量 |
|---|---|---|---|
| 必须有 | ×3 | 不满足就直接否决 | 1~2 个 |
| 重要 | ×2 | 明显影响成败但可以让步 | 2~3 个 |
| 有则更好 | ×1 | 加分项 | 0~2 个 |

**"必须有"最多两个。**如果一场景里"必须有"有四个，说明约束没想清楚——约束太多等于没有约束，这时候该做的是回到问题陈述砍约束。

**权重总分固定为 30 分**是一个好用的校准：三个 ×3 + 三个 ×2 + 三个 ×1 正好 18，但真实场景通常只用到 5 个维度，所以总分在 9~12 之间（五维：3+2+2+2+1 = 10 是常见配置）。算出每个候选的加权分后，把它归一化成百分制更容易比较：

```text
归一化得分 = 加权总分 ÷ (3 × 权重总和) × 100
```

例：权重为 有效性×3、成本×2、风险×2、可逆性×2、杠杆×1，权重总和 = 10，满分 = 3 × 10 = 30。
某候选得分 4、2、3、3、2 → 加权 = 12+4+6+6+2 = 30 → 归一化 100 分。
某候选得分 3、1、3、2、2 → 加权 = 9+2+6+4+2 = 23 → 归一化 77 分。

### 4. 权重的定法：从约束里读，不从偏好里读

权重不该投票产生，应该**从问题陈述的真实约束里推**。推法：

1. 把问题陈述里的硬约束逐条列出（预算上限、截止日期、人力、合规要求、不可逆的既有承诺）。
2. 每一条硬约束指向哪个维度？指向风险或成本的，那两个维度至少是"重要"。
3. 有没有一条约束是"违反了就整个作废"？有的话，对应维度定为"必须有"。
4. 剩下的维度按直觉分档，但加起来"必须有"不超过两个。

**先定权重的好处**：它把"我倾向哪个方案"这个问题提前问完了。定权重时人是中立的，因为还没有分数。

### 5. 打分纪律的实操版

打分按**维度逐行**打，不按候选逐个打。

也就是说：先给所有候选的"有效性"打分，再给所有候选的"成本"打分。原因是对同一个维度横向比较时，标准才一致；按候选纵向打完，第一个候选会锚定后面的标准。

每一格填的是 `分数 + 一句理由`：

```text
A3 有效性 2 —— 能把重复率从 12% 降到 5% 以内（上次同类做法的实测值）
B1 成本   1 —— 需要新增 1 个人力，当前编制没有余量（本季度已满编）
C2 风险   3 —— 走现有通道，最坏是被打回重填，重填约半天
```

**哪些理由不合格**：

| 不合格 | 问题 | 改成 |
|---|---|---|
| "感觉可行" | 无事实 | "同类做法在上季度实测把 X 从 12% 降到 5%" |
| "大家都这么做" | 身份论证 | 说出"大家"是谁、他这么做的前提是否与我相同 |
| "成本不高" | 无数字 | "人力 0.5 人月，本季度还有 1.2 人月余量" |
| "风险可控" | 空话 | "最坏情况是被打回，退回成本半天" |

## 三、四步淘汰规则

按顺序执行，不许跳步，不许临时加规则。**每淘汰一个候选，都必须在决策记录里写清它撞的是哪条规则。**

### 第一步 · 硬伤淘汰

砍掉**任何一维得 1 分**的候选。

逻辑：1 分意味着这一维上它是不可接受的，不是"差一点"。成本得 1 分（超预算）的候选，有效性再高也不能选——因为预算不是可以靠努力弥补的。

例外只有一种：**如果所有候选都在同一维上得 1 分**，说明约束有问题（无人能满足），这时应当退回问题陈述，而不是继续淘汰。

### 第二步 · 阈值淘汰

剩下的候选按归一化得分排序，砍掉低于 `最高分 × 0.7` 的。

为什么是 0.7：低于最高分七成的候选，跟主选之间已经隔了一档实质差距，留着只会分散注意力。这个系数不要随意调——调高会把备选也砍光，调低会让候选重新膨胀。如果发现 0.7 砍得太多或太少，真正的问题通常在一维的评分标准上，回去把 1/2/3 的边界定义清楚。

### 第三步 · 僵局处理

如果前两名归一化得分差 ≤ 5 分（约等于加权分差 ≤ 2 分），**不许靠投票定胜负**。

投票在此时是无效的，因为分差落在打分本身的噪声范围内——同样的候选换个人打，差值可能就反过来了。这时按顺序试三种破局法：

| 破局法 | 做法 | 适用 |
|---|---|---|
| **小实验** | 设计一个一周内能做完、成本可控的实验，用真实结果分胜负 | 两个方案都能小范围试，这是首选 |
| **看失败条件** | 比较两者的失败条件哪个更可承受 | 无法做实验，或实验成本太高 |
| **看可逆性** | 选更容易退回来的那个，先上，用数据决定要不要继续 | 时间紧且都不可长期等待 |

**小实验的具体要求**（缺一条就不算合格的分胜负实验）：

- 一周内能出结果
- 成本低于"选错了重做"的成本
- 有**事先定好**的判定指标和阈值（不是事后看哪个好看）
- 两组都做，不是只试其中一个

### 第四步 · 收敛到一个主选 + 一个备选

结果固定为 **1 主选 + 1 备选**，不允许"两个并行做"。

"两个并行"通常是没收敛的伪装，代价是人力翻倍、注意力分散、最后两个都做不彻底。**备选的入选理由必须是"分差接近"，不是"看起来也不错"。**分数差了两档的候选不该当备选，那只是舍不得删。

## 四、决策记录

决策记录的唯一验收标准：**一个没参与这次讨论的人，能不能只看这份记录，判断出这个决定当时合不合理？**

### 模板

```markdown
# 决策记录：〔决定名称〕

日期：YYYY-MM-DD
参与者：（列出名字）
问题陈述：在〔约束〕下，让〔对象〕达到〔结果〕

## 一、定死的权重（打分前确定）
| 维度 | 权重 | 为什么是这个权重 | 依据的约束 |
|---|---|---|---|
| 有效性 | ×3 | 违反即作废 | 结果必须在本季度可观测 |
| 成本 | ×2 | 预算封顶 | 预算 X 元 |
| ... | | | |
权重总和：___ ｜ 满分：___

## 二、打分结果
| 候选 | 一句话 | 有效性 | 成本 | 风险 | 可逆性 | 杠杆 | 加权 | 归一化 |
|---|---|---|---|---|---|---|---|---|
| A3 | | 2（事实） | 2（事实） | 3（事实） | 2（事实） | 1（事实） | 23 | 77 |
| ... | | | | | | | | |

## 三、淘汰记录
| 候选 | 淘汰轮次 | 撞的规则 | 具体原因 |
|---|---|---|---|
| B1 | 第一步 | 硬伤淘汰 | 成本 1 分：需新增 1 人力，本季度编制已满 |
| C2 | 第二步 | 阈值淘汰 | 归一化 62，低于最高分 89 × 0.7 = 62.3 |

## 四、结论
主选：A3
备选：D1（入选理由：与主选归一化分差 4 分，落在噪声范围内）
未选用但保留的候选：（写明保留原因，比如"资源条件变化后可重新评估"）

## 五、翻案条件（必须写）
出现下列任一情况，本决定作废并重新收敛：
- 〔可观测的信号 1，含数字阈值〕
- 〔可观测的信号 2〕
复查时间：YYYY-MM-DD，复查人：___

## 六、主选的失败条件
最可能失败的方式：〔具体场景〕
若发生，退路是：〔具体动作 + 成本〕
```

### 几处容易写坏的地方

**"翻案条件"必须可观测。**写"如果效果不好就重来"等于没写。"效果不好"没有阈值，事后永远可以说"再看看"。

差：如果效果不好就换方案。
好：如果上线 4 周后周活跃提升低于 5%，或出现 ≥ 2 次同类线上问题，则回退到备选 D1。复查时间 5 月 20 日。

**"淘汰记录"要写具体原因，不写"综合考虑"。**"综合考虑"是一个万能借口，它让所有不合理的淘汰都无法被复查。

**参与者要写名字。**不是为了追责，而是为了让后来的人知道该找谁问清楚当时的判断。匿名决策记录的价值会衰减得很快。

## 五、收敛过早的识别与回退

收敛阶段自己也要自查。命中「收敛过早」六体征中 2 条以上，**不要顺着往下执行**，按下面回退：

| 命中体征 | 回退到哪一步 |
|---|---|
| 单方案入洞（只有 1 个候选被认真讨论） | 退回发散阶段，补齐候选池并过阶段门 |
| 身份论证（"一直这么做"/"竞品也这么做"） | 回到第二步，把该候选的合理性理由换成事实；给不出事实则该理由作废、该候选重新打分 |
| 无据淘汰（"感觉不对"） | 回到淘汰记录，为每个被淘汰的候选补一条事实理由；补不出来的候选**恢复出局状态并重新打分** |
| 判据漂移（中途换维度或对不同候选不同标准） | 回到第一步，重新宣读定死的权重，作废本轮所有分数，按维度逐行重打 |
| 只谈好处（没人说主选的失败场景） | 回到第四步，补写"主选的失败条件"；补不出来则退回发散理解该方案 |
| 无备选 / 无翻案条件 | 回到第四步，补齐备选与翻案条件 |

**判据漂移是最严重的一条**，因为它不会被察觉：人在打分时如果对不同候选用了不同标准（比如对喜欢的候选按"理想状态"评成本，对不喜欢的按"最坏情况"评），最终分数看起来完全正常，但排序已经失真。唯一的防线是按维度**逐行**打分，且每一行的理由必须并列可读。

## 六、收敛阶段的完整自检

打分完成后逐条过：

- [ ] 权重在打分前写死了，事后没改过（对比记录时间）
- [ ] 每个分数后面有包含事实的理由，没有纯粹的形容词
- [ ] 打分是按维度逐行进行的，不是按候选逐个进行的
- [ ] 每个候选都写了失败条件
- [ ] 第一步淘汰的都是"某一维 1 分"的候选，没有例外
- [ ] 第二步的阈值用的是最高分 × 0.7，没有临时调整
- [ ] 僵局（分差 ≤ 5 分）是靠小实验/失败条件/可逆性破的，不是靠投票
- [ ] 结果是 1 主选 + 1 备选，没有"两个并行"
- [ ] 备选的入选理由是分差接近，不是舍不得
- [ ] 翻案条件含数字阈值和可观测信号
- [ ] 复查时间和复查人已指定

任何一条打不了勾，回到对应步骤补，不要带着缺口结束收敛。

## 七、一页速查

```text
定权重（从约束推，最多两个"必须有"）
  ↓
按维度逐行打分（每格 = 分数 + 含事实的理由）
  ↓
第一步 砍掉任何一维得 1 分的
第二步 砍掉低于最高分 × 0.7 的
第三步 分差 ≤ 5 分 → 做小实验，不投票
第四步 定 1 主选 + 1 备选
  ↓
写决策记录（权重 / 打分 / 淘汰 / 结论 / 翻案条件 / 失败条件）
  ↓
过一遍「收敛过早」六体征
```
