# 三剪客 · 发散与收敛

先用多个方向把方案铺开，再按统一标尺收敛成一个，专治想到第一个方案就开干

大多数方案事故不是执行不力，而是**第一个想到的东西直接变成了要做的东西**。想清楚一个问题后，脑子里跳出来的那个方案往往只是最熟悉的那一个，不是最合适的那个；它一旦被说出来，后面的讨论就变成了给它找理由。

这套方法把「想清楚」和「选出来」拆成两个物理隔离的阶段：发散阶段只负责把可能性铺开到足够宽，明令禁止评判；收敛阶段只负责用一把统一的尺子把候选砍到只剩一个，并留下能复查的决策记录。中间有一道**阶段门**，过不了不许进下一步。

一句话判据：**在你还没有至少 4 个本质不同的方案之前，任何「就这么干吧」都是猜测。**

## 触发场景

- 「这个事我想了想，就这么做吧」——方案在脑子里已经定了，但你说不清为什么不是别的做法
- 「帮我想几个方案」，或者反过来：「别给我一堆选项，先告诉我怎么比」
- 要做一个重要决定（选型、定价、选题方向、增长打法、架构方案），但候选从来没被真正铺开过
- 会上第一个发言的人提了个方案，之后所有人都在讨论这个方案 —— 需要有人把发散补回来
- 已经有 8 个候选躺在文档里，但没人知道该砍谁，讨论变成各说各话
- 团队里两个人各执一个方案，吵了三轮没有结论 —— 缺的是统一打分维度，不是更多争论

## 快速开始

最小可用路径，四步，一轮 40~60 分钟或一次对话：

1. **写问题陈述**（3 分钟）。一句话，形如「在〔约束〕下，让〔对象〕达到〔可观测的结果〕」。约束必须是真的（时间、预算、人手、合规），不是「尽量」。
2. **发散**（20~30 分钟）。从六类入口里**至少选 3 类**，每类硬性产出 3 个候选，累计 **≥ 15 个**，其中**≥ 4 个属于本质不同的路线**。全程不评判，任何「这个不行」都记到暂存区里，不打断。
3. **过阶段门**。用下面「发散不足的五个体征」自查，命中 2 条以上就回到第 2 步换入口重来。
4. **收敛**（15~25 分钟）。用五维打分卡给**每一个**候选打分，按淘汰规则砍到 1 个主选 + 1 个备选，写下决策记录（选了什么、砍了什么、关键判据是什么、什么条件下翻案）。

产出物固定为三张表：**候选池**（编号 + 一句话 + 来自哪类入口）、**打分卡**（候选 × 五维 + 总分 + 理由）、**决策记录**（主选 / 备选 / 淘汰名单 / 翻案条件）。

完整走一遍看 `references/03-worked-example.md`。

## 两阶段流程

### 阶段一 · 发散（目标：宽度）

**六类发散入口**，任选 3 类以上，每类至少 3 个候选：

| 入口 | 提问句式 | 它专门补的盲区 |
|---|---|---|
| 目标反推 | 如果只看要达到的结果，有哪些互不相干的路径？ | 路径依赖 |
| 现状拆解 | 现在这套做法里，哪一步其实可以整段拿掉？ | 惯性冗余 |
| 类比迁移 | 别的行业/别的问题里，同类难点是怎么解的？ | 视野窄 |
| 反向求解 | 要让它彻底失败，我会怎么做？ | 风险盲区 |
| 维度切分 | 按人群/渠道/时段/场景切开，各切法下最优解是？ | 一刀切 |
| 干系人换位 | 换成用户/审核/运维/财务来看，他要的是什么？ | 单方视角 |

每类入口的完整问句库、扩量技巧和常见卡壳处理，见 `references/01-divergence-methods.md`。

**发散阶段的四条禁令**（违反即阶段作废）：

1. **不许评价**——不说「这个好」「这个不现实」，只说「记下了」。
2. **不许合并**——两个候选像不代表是一个，先都留着，允许重复胜过过早归并。
3. **不许说「已经有了」**——已有的方案也要写进候选池，它要参与公平打分，而不是凭身份直接晋级。
4. **不许中途排序**——发散期间不排名、不打分、不投票。

**数量目标**：≥ 15 个候选；≥ 4 条本质不同路线；≥ 1 个「如果资源翻了十倍会怎么做」的候选；≥ 1 个「什么都不做」的候选（它是最容易被忽略的合法选项）。

### 阶段二 · 收敛（目标：深度）

**五维打分卡**，每维 1~3 分，总分 5~15：

| 维度 | 1 分 | 2 分 | 3 分 |
|---|---|---|---|
| 有效性（能不能真解决问题） | 只缓解症状 | 能解决主问题 | 解决主问题还顺手解决根因 |
| 成本（钱 + 人 + 时间） | 超出预算或要新增人力 | 在预算内但吃满 | 明显低于预算 |
| 风险（最坏情况可承受度） | 最坏情况不可逆 | 可逆但要补代价 | 失败只是白干，无后遗症 |
| 可逆性与可验证 | 一上就难退 | 能退但要停机 | 小范围先试，数据说话 |
| 杠杆（做完多出什么） | 一次性消耗 | 能复用 | 沉淀成资产或打开后续方案 |

**打分纪律三条**：

- 每个分数后面必须跟**一句理由**，理由里必须出现事实（数字、日期、约束），不能只有形容词。写不出事实的分数，先记「?」而不是给 2 分。
- **先定权重再打分**，不许打完分发现结果不合意再回头调权重。权重只有三档：必须有（×3）、重要（×2）、有则更好（×1）。
- 每个候选必须说得出**它会在什么条件下失败**；说不出失败条件的候选，说明还没理解它，退回发散。

**淘汰规则**（按顺序执行）：

1. 先砍**任何一维得 1 分**的候选 —— 那是硬伤，不是短板。
2. 剩下的按加权总分排序，砍掉低于「最高分 × 0.7」的。
3. 若前两名分差 ≤ 2 分，**不靠投票定胜负**，改用一个能在一周内做完、成本可控的小实验来分胜负。
4. 收敛结果固定为 **1 主选 + 1 备选**。不做「两个并行试」，那是没收敛。

完整的权重换算、并列僵局的破局手段、决策记录模板，见 `references/02-convergence-and-decision.md`。

## 两种典型病症的识别信号

这两套信号是这套方法最实用的部分：**在错的那一刻认出来**。

### 发散不足（该宽的时候太窄）

| 体征 | 具体表现 |
|---|---|
| 数量不够 | 候选 < 10 个，或只用了 1 类入口 |
| 同源 | 把候选两两对比，说不出它们在**根本做法**上差在哪，只是换了参数、换了个说法 |
| 无代价 | 没有任何一个候选是「听起来离谱但可能有效」的；全是安全牌 |
| 无前提拆解 | 没有一个候选挑战过问题本身——比如没人问「这事非得做吗」「非得现在做吗」 |
| 太快 | 从「开始想」到「开始比」不足 15 分钟，或者第 5 分钟就有人说「其实重点是这个」 |
| 一言堂 | 只有一个人出方案，其他人只在他给的框架里补充 |

命中 2 条以上 → 不许进收敛，回到发散换入口。

### 收敛过早（该选的时候太急）

| 体征 | 具体表现 |
|---|---|
| 单方案入洞 | 只有一个候选被认真讨论过，其余连一句话记录都没有 |
| 身份论证 | 淘汰理由只有「我们一直是这么做的」「竞品也这么做」「老板倾向这个」 |
| 无据淘汰 | 出现「感觉不对」「不现实」这类没有事实支撑的淘汰 |
| 判据漂移 | 讨论中途换了比较维度，或在同一场里对不同候选用了不同标准 |
| 只谈好处 | 没有任何人说出主选方案最可能失败的场景 |
| 无备选 | 定了主选但没有备选，也没写翻案条件——事后无法判断该不该改 |

命中 2 条以上 → 回退到收敛的**重新定权重**这一步，而不是继续往下执行。

## 能力边界

**覆盖**：

- 把一个问题摊开成一组候选，并把它压到一个可执行的主选
- 六个发散入口的问句库、扩量与卡壳处理
- 五维打分卡、权重三档、四步淘汰规则、并列僵局的破局法
- 「发散不足 / 收敛过早」两套识别信号与阶段门判据
- 决策记录格式，让第三个人事后能复查这个决定合不合理

**不覆盖**：

- 不替你获取事实和数据。打分维度里的成本、风险，需要真实数字时由你和宿主 Agent 去查，本 Skill 只规定「必须写事实、不许写形容词」
- 不做技术选型的最终裁决。它可以告诉你三个候选在同一把尺子下各是多少分，但不保证分数高的一定对
- 不替代严谨的数量化决策方法（如期望值计算、A/B 实验设计、财务模型）。本方法是定性骨架，需要精算时应在收敛后接上专门工具
- 不解决「选完没人执行」的问题——落地执行属于别的方法

## 依赖条件

- 一个说清楚的问题陈述：约束、对象、可观测的结果。三样缺一样就先补问题，不要开始发散
- 至少 2 个参与者（真实的人，或宿主 Agent 扮演的不同视角角色）。单人发散几乎必然同源
- 一场 40 分钟以上不被打断的时间，或一次完整对话。中途换上下文会毁掉发散阶段的不评判氛围
- 不需要任何工具、账号、网络；一张能记下 15 行候选的纸或文档即可

## 已知限制

- **数量目标会偏**：15 个候选对成熟领域可能太少，对全新领域可能过多。数量是下限不是标准，判断标准始终是「有没有 4 条本质不同路线」
- **五维打分是定性尺子**：1/2/3 分之间的边界需要自己定义清楚，不同团队打出的分数不可横向比较
- **无法防止事后合理化**：定完权重再打分这条纪律靠人自觉，方法本身无法强制；想强制就得先写死权重并留痕
- **不适合已经不可逆的决定**：已经签了合同、发了公告的事，发散阶段没有意义，应该直接用收敛段的「验收与翻案条件」做复盘
- **不产生创意本身**：它只保证创意有机会被说出来并被公平比较，不保证你会想到好点子

## 自检清单

发散阶段结束时：

- [ ] 候选总数 ≥ 15，且写下了每个来自哪类入口
- [ ] 至少 4 个候选属于本质不同的路线（能一句话说清它们的根本分歧）
- [ ] 至少用了 3 类不同入口
- [ ] 有一个「什么都不做」候选
- [ ] 发散全程没有出现评价性发言，或出现后被记入暂存区而未打断
- [ ] 「发散不足」六体征一条都没命中

收敛阶段结束时：

- [ ] 权重在打分前已写死，之后没有改动
- [ ] 每个分数后面有一句含事实的理由
- [ ] 每个候选都写了它会在什么条件下失败
- [ ] 淘汰是照四步规则走的，没有一票否决式的临时规则
- [ ] 结果是 1 主选 + 1 备选，且备选不是因为「看起来也不错」而是因为分差接近
- [ ] 决策记录写全了：选了什么、砍了什么、关键判据、翻案条件、谁在什么时候复查
- [ ] 「收敛过早」六体征一条都没命中
