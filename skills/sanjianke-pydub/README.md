# 三剪客 · 音频切片与格式转换 Skill

pydub：音频切片与格式转换 的安装、常用命令与避坑要点

---

## 前置条件

- Python，且版本 **不高于 3.12**。该库依赖标准库的 `audioop` 模块，而这个模块在 Python 3.13 中被移除；包的元数据没有声明版本上限，装的时候不会拦你。
- 处理 **wav / raw** 之外的所有格式，都需要本机装有 `ffmpeg` 或 `libav`，并且能在终端里直接调用。装完 pydub 后记得单独装这一项——这是最容易漏的一步。
- 想用 `pydub.playback.play()` 播放音频，还需额外装一个播放后端（`simpleaudio` 是官方首选）。**只做文件处理不需要。**
- 大文件处理前先估算内存：整段音频会全部读进内存。
- 如果要用到 `pydub.scipy_effects`，另需装 `scipy`。

## 使用

拿到这个 Skill 后，Agent 会按这套顺序干活：

1. **先判断该不该用**。剪辑、切片、拼接、转格式、掐静音、调音量、写标签——用它。专业 DSP、实时流式、音源分离——不用它。
2. **确认环境**：Python 版本 ≤ 3.12；非 wav 素材必须先用 `ffmpeg -version` 验证 ffmpeg 在 PATH 里。
3. **跑最小示例**：读一段几秒的素材 → 切一刀 → 导出，确认三步都通。
4. **注意单位**：所有编辑 API 用毫秒，只有 `from_file` 的 `start_second`/`duration` 用秒。
5. **按需组合**：拼接优先用 `append(crossfade=)` 避免爆音；组合前先统一采样率/声道/位深。
6. **校验结果**：核对时长、响度、拼接处有没有爆音，再决定是否批量跑。

细节命令与完整避坑表见 `SKILL.md`。

## 依赖

- Python 包：`pydub`（当前 PyPI 版本 0.25.1）。
- 第三方运行时依赖：**无**（0.25.1 的包元数据里 `Requires-Dist` 为空）。
- 外部程序：`ffmpeg` 或 `libav`（二选一）。wav/raw 不需要，其它格式必须有。
- 可选播放后端：`simpleaudio` / `pyaudio` / `ffplay` / `avplay`。
- 可选：`scipy`（仅 `pydub.scipy_effects` 需要）。
- 网络：库本身不联网；仅在安装依赖时需要网络。

---

## 安全

- 不内嵌任何密钥，也不需要任何账号或 API Key。
- 全程本地处理，不上传任何音频；库本身不做网络请求。
- 格式转换会以子进程方式调用外部 `ffmpeg`/`libav`。**`export(parameters=[...])` 会把参数原样透传给 ffmpeg 且不做任何校验**，不要用未经验证的字符串去拼这个参数。
- 转换过程中会在系统临时目录写入中间文件，官方说明会自动清理；处理涉密素材前先确认临时目录的清理与访问控制策略。
- 导出路径由调用方给定，注意不要写出到非预期目录（`export()` 的 `format` 默认是 `mp3`，别只靠扩展名判断）。
