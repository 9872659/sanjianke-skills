# 三剪客 · 数字人自动剪辑（网页版）

> **一张人物图片（或一段人物视频）+ 一段文案 → 自动配音、对口型、套模板 → 导出 1080×1920 竖屏成片，封面一起生成。**
> **打开网页就能用：不装软件、不配 API Key。**

---

## 这是什么

平台（aigc.a7w.cn）上的**数字人自动剪辑**工作台。把一条口播短视频要做的四件事——
**配音、对口型、套模板、做封面**——合成一条流水线，你只需要给两样输入：

| 输入 | 说明 |
|---|---|
| **一张人物图片**（或一段人物视频） | 清晰正面/半身人像即可 |
| **一段文案** | 想让它说的话；也可以改成上传你自己的配音 |

输出：**1080×1920 竖屏成片**，带标题、字幕、包装、封面。

**成片固定 999 点/条**（1 元 = 100 点），与时长无关。

## 三步出片

```
① 给人物 ──► ② 给声音和文案 ──► ③ 选模板 / 定封面 / 出片
```

1. **给人物**：上传人物图片（入口①）或人物视频（入口②）。
2. **给声音和文案**：
   - 音色三选一：**公共音色**（小帅 / 云泽大叔 / 解说小美，可试听）· **上传自己的配音** · **克隆专属音色**
   - 写文案，右侧实时显示 **字数 · 预估秒数**（中文约 **5.6 字/秒** → 30 秒约 170 字）
3. **选模板、定封面、出片**：
   - 右侧模板库挑版式（**鼠标悬停即播样片**，点 `⤢` 全屏预览）
   - 「自动生成封面」默认开 —— 成片第一帧就是 AI 封面
   - 勾选肖像权授权 → 点「生成成片 ✦」

## 能力速查

| 能力 | 说明 |
|---|---|
| **模板库** | 三个场景共 **171 套**：真人口播混剪 **94** / 素材混剪 **47** / 新闻体·门店推广 **30**。⚠️ **数字人只能用「真人口播混剪」这组** |
| **样板预览** | 悬停 0.3 秒自动播放；`⤢` 全屏预览；样片分段加载，**可边下边播、可拖动** |
| **声音** | 3 个精选公共音色 + 一键试听 + 上传自己的配音 + 克隆专属音色 |
| **自动封面** | 用人物形象作首帧生成 AI 封面，成片第一帧即封面，可单独下载 |
| **自动包装** | 标题大字、字幕、背景、转场、贴纸、片头片尾 |
| **输出** | 1080×1920 竖屏 |
| **进度与日志** | 三步进度条 + 实时日志（含每笔上游任务号）+ 可取消 |
| **历史创作** | 本机浏览器记录，可回看与重新下载 |
| **速度** | 模板/音色带缓存，二次打开秒开；模板分页渐进上屏 |

## 计价

**1 元 = 100 点。**

| 项目 | 价格 |
|---|---|
| **成片（智能剪辑）** | **固定 999 点/条**（与时长无关） |
| 文案转配音 | 按上游实际点数，实测约 **0.7 点/次**（用自己的配音则不产生） |
| 入口① 数字人（图片线） | 按生成模式分档 × 输入秒数 |
| 入口② 对口型（视频线） | 大师版 21 · 全能版 15 · 体验版 3（点/秒）× 音频时长 |

页面底部「预计消耗」与实际扣款口径一致。

**实测参考**：176 字文案（约 30 秒）→ 提交到出片约 **9~10 分钟** → 成片 1080×1920 / 29.84 秒。

## 常见问题（速查）

| 现象 | 处理 |
|---|---|
| 提示未登录 | 工具页顶栏可点登录 |
| 提交被拦，要求授权 | 必须勾选肖像权授权；不勾选**请求不会发出也不计费** |
| 模板/音色加载失败 | 点右上「刷新」，或刷新页面 |
| 成片时长不对 | 时长由配音（= 字数）决定，按 5.6 字/秒 反推 |
| 数字人这步很慢 | 正常，全链路最慢一段（通常 1~6 分钟），看进度与日志 |
| 数字人用不了某些模板 | 只能用「真人口播混剪」那 94 套；另两个场景不走数字人 |
| 上游报瞬时故障 | **失败不扣费** + 自动重试 3 次；**别同时开多个任务**，串行最快 |
| 能批量吗 | 网页适合单条手动；批量用同系列 `avatar-autoclip` |
| 支持什么格式 | 图 jpg/png/webp · 视频 mp4/mov · 音频 mp3/wav/m4a |
| 选哪个生成模式 | 建议**直接选高清档**，画质最稳 |
| 第一帧没有封面 | 检查「封面」开关是否关闭 |

详见 `references/常见问题.md`。
