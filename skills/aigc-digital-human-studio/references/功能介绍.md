## 1. 两条线：图片数字人 vs 视频对口型

| | 入口① 数字人视频 | 入口② 数字人对口型 |
|---|---|---|
| 页面地址 | `#/tool/digital_human` | `#/tool/lipsync` |
| 上传 | **人物图片**（PNG / JPG，建议竖版半身或全身） | **人物视频**（MP4 / MOV，建议 ≤60 秒，正脸清晰） |
| 原理 | 图片建立形象 → 由文本驱动开口 | 保留原片画面与动作 → 只对齐嘴型 |
| 形象来源 | 你上传的图片 | 你上传的视频 |
| 档位 | 生成模式（快速 / 标准 / …） | 对口型模型（大师版 / 全能版 / 体验版） |
| 适合 | 只有照片；想换人换场景 | 已有真人素材；要保留真实感 |

**切换**：进入任一条线后，页面顶部有分段控件可**就地切换**另一条线，不用回菜单。
切换时会清空已上传的形象（因为类型不同），声音、模板、文案保留。

> **上传的小技巧**：图片建议正面、五官清楚、不带墨镜、光线均匀；
> 视频建议固定机位、正脸对着镜头、不要大幅度走动。

## 2. 成片模板库与样片预览

### 规模与场景

**三个场景，共 171 套版式：**

| 场景 | 套数 | 用途 |
|---|---|---|
| **真人口播混剪** | **94 套** | **数字人出片走这一组**。适合口播、讲解、带货 |
| 素材混剪 | 47 套 | 音频 + 素材，**无数字人** |
| 新闻体 / 门店推广 | 30 套 | 标题 + 素材，**无口播** |

> ⚠️ **必须知道的前提**：**数字人的成片只能提交给「真人口播混剪」这一组模板。**
> 切到另外两个场景时页面会提示 —— 它们走的是另外两条链路，不是数字人。

> 配图（站方公众号图文）：模板库网格，每张卡带封面、名称、9:16 角标，鼠标悬停 320ms 自动播放样片。


### ⭐ 样片预览（这是挑模板时最有用的功能）

**悬停即播**
- 鼠标停在模板卡上约 **0.3 秒**，样片自动在卡片内**静音循环播放**：封面淡出、样片淡入。
- 移开鼠标即暂停。**不用点开就能快速扫一遍版式**。

**全屏弹层预览**
- 点卡片右上角 `⤢` 打开大屏预览，播放**完整样片**。
- 弹层顶部显示**模板名 / 场景 / 画面比例**；底部可「使用此模板」直接选中。

**为什么播放很流畅**
- 样片走平台自己的 CDN 代理，支持 **HTTP 分段（206 Partial Content）**。
- 所以是**边下边播**、**可拖动进度条**，不必等整条下完。

### 其它

- **搜索**：模板面板顶部可按名称搜索。
- **默认预选**：进入页面自动选中第一条，不会卡在"还没选模板"。
- **选中态**：卡片显示紫色勾选与描边；左侧「成片模板」一行显示当前选中项与「更换」按钮。

### 模板决定什么

模板决定的是**包装**，不是内容：

- 标题大字样式与位置
- 字幕样式（字体、描边、位置、动效）
- 背景 / 转场 / 贴纸 / 片头片尾
- 画面比例（常见 9:16 竖屏）

**换模板 = 同一段素材换一套版式，不需要重新录音或重新生成数字人。**

## 3. 声音：音色 / 试听 / 自己的配音 / 克隆

三种来源，按场景选一种：

### 3.1 公共音色（默认，开箱即用）

平台音色池较大（站方图文提到约 38 个平台音色）。**本产品页面精选 3 个**，
覆盖口播常见需求，开箱即用、不占配额：

| 音色 | 定位 |
|---|---|
| **小帅** | 男声 · 年轻口播 |
| **云泽大叔** | 男声 · 成熟沉稳 |
| **解说小美** | 女声 · 解说 |

- 下拉框直接选；旁边的 **「试听」** 会**真合成一小段**播放
  （音色列表本身不带试听地址，所以是真的合成，不是占位音频）。
- 「音色库」页签里也能试听与选择。
- 想用池子里其它音色：走**克隆**（用自己的声音）或**自带音频**两条路更实际。

> 配图（站方公众号图文）：右侧面板——各阶段转圈或打勾，日志滚动显示每一步。


### 3.2 上传自己的配音

- 在「上传自己的配音」区域传一段音频。
- 传了之后就**跳过文案配音**，直接用它驱动数字人 —— 声音 100% 是本人的。
- 此时文案可以留空。

### 3.3 克隆专属音色

- 点「＋克隆音色」，上传一段 **10–60 秒干净人声**（单人、无背景音乐、无混响最佳）。
- 生成后可像公共音色一样直接选用。
- **适合想让"以后每条片子"都用同一个声音**的场景。

| 想达到的效果 | 选哪种 |
|---|---|
| 最省事，随便一个好听的声音 | 公共音色 |
| 这条片子必须是本人的声音 | 上传自己的配音 |
| 以后每条片子都像本人 | 克隆音色 |

## 4. 自动生成封面

- 位置：左栏「封面」区，一个开关，**默认开启**。
- **开启**：以**人物形象**作首帧生成 **AI 封面**，并且**成片第一帧就是它**——
  视频发出去天然就有一张可用封面，不用再单独做图。
- **关闭**：沿用模板默认首帧；结果区标签会显示为「人物形象图」。
- 结果区会**单独展示封面缩略图**，并提供「⬇ AI 封面」单独下载。
- **不用再开一次修图软件** —— 封面在出片时一并生成好了。

> 配图（站方公众号图文）：系统自动生成的 AI 首帧封面。

> 想要"每条片子统一封面风格"时，建议保持开启，并固定使用同一个形象。

## 5. 文案与时长换算

**中文语速实测约 5.6 字/秒。**

| 想要成片时长 | 文案字数（约） |
|---|---|
| 15 秒 | 85 字 |
| 30 秒 | **170 字** |
| 60 秒 | **335 字** |
| 90 秒 | 505 字 |

- 输入框右侧**实时显示**「N 字 · 约 X.X 秒」，不用自己算。
- **成片时长由配音决定**，配音长度由字数决定 —— 所以想控制时长就控制字数。
- 上传了自己的配音时，时长由音频决定，文案可留空。

**实测对照**：176 字文案 → 预估 31.4 秒 → **实际成片 29.84 秒**（偏差约 5%）。

## 6. 生成模式与模型档位

### 入口①（图片线）：生成模式

| 档位 | 取向 |
|---|---|
| 高清模式 | 画质优先 |
| 标准模式 | 均衡 |
| 快速模式 | 速度优先 |
| 本地预放大 | 可选附加：上传前先在本地放大，给上游更清晰的输入 |

> 档位越高，生成越慢、计费越高。页面底部会给出**预计消耗**。

### 入口②（视频线）：对口型模型

| 模型 | 取向 | 计费（点/秒） |
|---|---|---|
| **大师版** | 质量最好 | 21 |
| **全能版** | 均衡 | 15 |
| **体验版** | 最快 | 3 |

> 视频线按**音频真实时长**计点（不是视频时长）。所以"说多久"决定花多少。

## 7. 进度、日志、取消

点「生成成片」后，左栏切换为**进度视图**：

```
文案转配音  ──►  数字人合成  ──►  套模板成片
   ✅              ✅                ⏳ 39s
```

- 每步显示**状态与耗时**。
- **实时日志**：黑底区域滚动输出每一步详情，含**第几次重试**
  （配音 task / 数字人 task / 剪辑 task）—— 出问题时把它发给技术支持，定位最快。
- **取消任务**：跑到一半可取消，当前步骤结束后停止。
- 出错时会在进度下方给出**红色错误详情**，并保留完整日志。

> 配图（站方公众号图文）：右侧面板——各阶段转圈或打勾，日志滚动显示每一步。

### 上游偶发故障时，三件让人踏实的事

数字人服务**会周期性出问题**，日志里能看到这种：

```
task_id=task_xxx（第 1 次尝试）
  [   185s] #8 failed
  [重试] 上游瞬时故障，15 秒后重新提交…
task_id=task_yyy（第 2 次尝试）
```

1. **不是你的参数问题** —— 是弹性 GPU 机器丢失，跟填的内容无关；
2. **失败任务不扣费** —— 出问题那一次不计账；
3. **程序自动重试**，默认 **3 次尝试**，不用手动重来。

日志里的 `task_id` 会显示出来，**万一手滑关了网页，还能拿着 ID 继续查**；
任务记录保存在本机，**刷新页面不丢历史**。

> 🚦 **一条经验：别同时开多个任务。** 并发更容易撞上这个故障，**串行反而最快**。

## 10. 速度与缓存

| 机制 | 效果 |
|---|---|
| 模板/音色本地缓存 | 二次打开**基本秒开**，不必每次重新拉 |
| 模板分页渐进上屏 | 先出第一屏，其余后台补齐（94 套不用一次等全） |
| 样片分段加载 | 悬停预览**立即可播**，可拖动 |
| 服务端边缘缓存 | 模板列表命中缓存时约 **0.05 秒**返回 |

右上角有 **「刷新」** 按钮：忽略缓存重新拉取模板与音色。

## 11. 合规：肖像权授权

- 提交前必须勾选：**「我已获得该肖像权人的授权，并对生成内容的合法性负责」**。
- 这是一道**硬门禁**：未勾选时，提交请求**根本不会发出**，也不产生任何计费。
- 换人像素材后需要重新确认授权。

> 使用他人肖像（尤其是公众人物）务必先取得授权。产品方不承担未授权使用的责任。

## 12. 计价口径

**1 元 = 100 点。**

| 项目 | 价格 | 备注 |
|---|---|---|
| **成片（智能剪辑）** | **固定 999 点/条** | **与成片时长无关**（30 秒与 60 秒同价） |
| 文案转配音 | 按上游实际点数（实测约 **0.7 点/次**） | 用自己的配音则不产生 |
| 入口① 数字人 | 按生成模式分档 × 输入秒数 | 见 §6 |
| 入口② 对口型 | 按模型分档 × 音频真实时长 | 见 §6 |

**页面底部的「预计消耗」与实际扣款口径一致。**

> **实测参考**（约 30 秒成片）：176 字文案，全链路提交到出片约 **9~10 分钟**，
> 成片 1080×1920 / 29.84 秒，H.264 / 6.5 Mbps。
