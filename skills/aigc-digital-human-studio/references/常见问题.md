# 常见问题与报错对照

> 按"现象 → 原因 → 处理"组织。提问题时请带上**任务号**（进度区可复制）与**截图**。

---

## 一、进不去 / 登录

| 现象 | 原因 | 处理 |
|---|---|---|
| 打开页面只有官网首页 | 首页是落地页，工作台在 `/index.html` | 用 `https://aigc.a7w.cn/index.html#/tool/digital_human`，或从首页入口点进「数字人视频」 |
| 顶栏显示「未登录」 | 工具页原先没有登录入口 | 现在顶栏的「未登录」**可点**，点它走正式登录（含图形验证码） |
| 登录后仍提示未登录 | 登录态未落到本地存储 | 刷新页面；仍不行就清缓存后重登 |
| 页面加载失败，出现"页面资源加载失败" | 静态资源 404 或网络中断 | 页面上有「强制刷新」「清缓存并刷新」两个按钮，先点它们 |
| 换设备后登录还在？ | 登录态在**本机浏览器**，不跨设备 | 新设备需要重新登录 |

## 二、提交相关

| 现象 | 原因 | 处理 |
|---|---|---|
| 点「生成成片」没反应 | 缺必填项 | 依次检查：① 是否已上传人物图片/视频 ② 是否已写文案（或已传自己的配音）③ 是否已选模板 ④ **是否勾选了肖像权授权** |
| 提示需要授权 | 合规硬门禁 | 勾选「我已获得该肖像权人的授权」。**未勾选时请求根本不会发出，也不计费** |
| 提示"余额不足" | 点数不够 | 成片固定 999 点/条，另加配音与数字人的费用。到钱包充值（1 元 = 100 点） |
| 切到另一条线后图片没了 | 切换模式会清空已上传形象（类型不同） | 正常行为。声音、模板、文案会保留 |

## 三、列表加载

| 现象 | 原因 | 处理 |
|---|---|---|
| 模板区显示「模板加载失败」 | 登录态失效 / 网络抖动 | 点右上「刷新」重试；仍不行刷新页面 |
| 音色下拉是空的 | 极少见（内置 3 个公共音色，正常会立刻显示） | 刷新页面即可恢复 |
| 模板只有几十个 | 分页渐进上屏，正在后台补齐 | 稍等，或滚动查看；数量会涨到 94 |
| 模板名/封面不对 | 缓存过期 | 点「刷新」强制重新拉取 |

## 四、出片效果

| 现象 | 原因 | 处理 |
|---|---|---|
| **成片时长比预期短/长** | 时长由配音决定，配音长度由字数决定 | 中文约 **5.6 字/秒**。想 30 秒就写约 170 字，60 秒约 335 字 |
| 嘴型有点对不上 | 素材问题居多 | 图片用正面清晰照；视频用固定机位正脸、不要大幅走动 |
| 第一帧没有封面 | 「封面」开关被关了 | 打开「自动生成封面」重新生成 |
| 声音不像本人 | 用的是公共音色 | 改用「克隆音色」（10–60 秒干净人声），或直接上传本人配音 |
| 成片比例不是竖屏 | 由所选模板决定 | 换一套 9:16 的模板重剪（用「数字人原片」重剪，不必重做数字人） |
| 数字人这一步特别慢 | 这是全链路最慢的一段 | 正常，几十秒到几分钟。看进度与日志；实在久可用「取消任务」 |

## 五、性能

| 现象 | 原因 | 处理 |
|---|---|---|
| 第一次打开模板要等几秒 | 首次要回源拉取 | 之后走缓存，基本秒开 |
| 悬停预览要等一下才播 | 样片首次加载 | 已支持分段加载，通常 0.3~1 秒起播；第二次更快 |
| 页面卡顿 | 模板卡较多 | 缩小窗口或滚动到目标区域；也可用搜索缩小范围 |

## 六、计费对不上？

| 疑问 | 说明 |
|---|---|
| 为什么成片 30 秒和 60 秒同价？ | **成片是固定 999 点/条，与时长无关**——这是刻意设计的定价口径 |
| 为什么还有别的扣费？ | 配音与数字人是**另外两步**，各自计费；页面底部「预计消耗」与实扣口径一致 |
| 用自己的配音还要扣配音费吗？ | **不扣**。传了自带音频就跳过配音这一步 |
| 提交失败会扣费吗？ | 上游失败的任务通常**不产生扣费**；未勾选授权时请求根本没发出 |

## 七、要程序化 / 批量出片

网页版适合**手工一条条做**。需要以下场景请用同系列技能 **`avatar-autoclip`**（API + CLI 版）：

- 一条命令跑完整链路
- 本地预检（不花点数先拦下不合规素材）
- `--dry-run` 先看请求体
- 批量矩阵（N 条文案 × M 个形象）
- 无人值守 / 定时任务

## 七点五、其它常问（速答）

| 问题 | 回答 |
|---|---|
| **需要下载安装吗？** | 不用。网页打开就能用，**零依赖**；API Key 只留在服务端，**不会下发到浏览器**。 |
| **文案写多长合适？** | 输入框下方**实时显示字数和预计时长**（中文实测 **5.6 字/秒**）。30 秒约 **170 字**，60 秒约 **335 字**。 |
| **生成模式怎么选？** | 建议**直接选高清档** —— 这是这条链路里画质最稳的一档，省下来的那点时间不值得拿画面换。 |
| **支持什么格式？** | 图片 **jpg / png / webp**；视频 **mp4 / mov**；音频 **mp3 / wav / m4a**。 |
| **一直停在「数字人口播」是卡住了吗？** | 正常，这一步通常 **1~6 分钟**。看日志里的 `#N processing` 有没有在推进就知道。 |
| **会不会做出来都长一个样？** | 不会。模板三个场景共 **171 套**（光真人口播就有 **94 套**），再叠加配音、文案、封面的差异，不会撞脸。 |
| **数字人能用"素材混剪/新闻体"的模板吗？** | **不能。** 数字人成片只能提交给「真人口播混剪」这一组；切到另两个场景页面会提示。 |
| **能不能批量做？** | 网页适合**单条手动出片**；要批量脚本化用同系列 `avatar-autoclip`，两边共用一套逻辑。 |
| **上游报瞬时故障怎么办？** | 不用管：**失败任务不扣费**，且程序自动重试（默认 **3 次**）。但**别同时开多个任务**，串行最快。 |
| **手上只有一张风格参考图，没有正脸照？** | 用 `avatar-autoclip` 的**参考生图**：1 张参考图 → 多张同风格人物图，再挑一张出片。 |
