# 三剪客 · 计划执行与检查点 Skill

把写好的计划一段段执行下去并在关键处停下核对，解决计划完整却跑偏

---

## 前置条件

- 一份已经写好的计划（哪怕只有几行）
- 能读写 Markdown 文件，且有地方放 `progress/` 目录
- 至少一种可执行的检查手段：测试命令、类型检查、grep、构建，或一次人工对照
- 推荐：git 或等价的版本控制（回退点的可靠性直接依赖它）

不需要网络、API Key、数据库、Docker 或任何项目管理软件。

---

## 使用

**第 1 步 · 建留痕目录**

```bash
mkdir -p progress/evidence
touch progress/01-log.md progress/02-checkpoints.md progress/03-open-items.md
# 把现有计划粘进 00-plan.md；这一份从此冻结，改计划时追加变更记录
```

**第 2 步 · 拆段**

计划里的一行要变成一段，必须过四问：单一意图、有可观察产物、有退出检查、失败可回退。粒度按退出检查的时间间隔定——半天任务 30–60 分钟一段最舒服。段号 `S1 S2 S3`，分配后不复用，插入用 `S3.1`。

**第 3 步 · 动工前过门禁**

```text
E1 上一段过了吗（有证据）    E2 一句话说得清目标吗
E3 资源齐吗                  E4 范围圈定了吗
E5 回退点在哪                E6 时间盒设了吗
→ 有不过的：补齐 / 拆段 / 标阻塞先做别的段
```

**第 4 步 · 执行**

只做这一段的事：旁支进清单不现场动手，先跑通再做好，意外先记录不改计划。

**第 5 步 · 退出检查 + 留痕**

产物出来立刻验（命令型优先），不通过就不进下一段。每段留五条固定字段：区间 / 进入条件 / 动作 / 产物 / 退出检查。失败的也要留，含「期望 / 实际 / 证据」三行。

**第 6 步 · 段末分诊 + 交接**

关旁支清单，写交接五件事，然后从进入条件重新过门禁。**遇到 B 类偏离信号立刻停手做 P3**，别绕。

完整流程与三个实战实例见 `SKILL.md` 与 `references/`。

## 安全

- 不内嵌任何密钥
- 不读取、不写入、不转发任何 Token、Cookie 或账号密码
- 模板与示例一律用占位符
- 留痕是长期保留且给他人看的内容：写进 `evidence/` 之前先脱敏，去掉真实密钥、内部域名、客户名、个人手机号
- 证据文件一旦手工编辑就不再是证据，脱敏要在采集时做，不要事后回头改
- 留痕只追加不篡改历史行；要更正就另起一行并注明
