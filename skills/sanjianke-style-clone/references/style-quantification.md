# 风格量化方法：把"调性"变成可以重新数一遍的数

> 这份文档回答一个问题：**凭什么说一个指标测的是"风格"而不是"内容"？**
> 每一条指标都给出：怎么数、为什么这么数、什么情况下它会失效。

## 0. 一条总原则

**风格 = 一个作者在两篇完全不同选题的稿子上，仍然保持不变的那些统计特征。**

反过来就是本包拒收的指标：任何"换个选题就变"的量（关键词、主题词、
具体案例、产品名）都不是风格。一个账号写火锅店和写 4K 超分，
句长可以一样、人称可以一样、段长可以一样，但名词一定不一样。

这条原则直接决定了两个实现细节：

1. **口头禅按"出现在几篇里"排序，不按总频次排序。**
   只在某一篇里重复 8 次的词组是那篇的**内容词**；出现在 4 篇里的词组才是这个作者的**口头禅**。
   实测对比（6 篇样本）：
   - 按总频次排 → top-5 里出现 `30秒`、`视频超清vr` 这种半截词（内容物的残渣）；
   - 按文档频率排 → top-5 变成 `不超过`（6/6 篇）、`用多少`（6/6 篇）这类真正的口癖。
2. **n-gram 必须是纯汉字。** 数字与拉丁字母夹在中文里（`30秒`、`vr`），
   几乎必然是分词边界的产物，不是口头禅。要求全汉字之后这类噪声直接消失。

## 1. 句长分布：用中位数与 IQR，不用"均值 ± 2×标准差"

**怎么数**：切句（在 `。！？；` 与换行处切，**不在逗号处切**）→ 逐句数汉字
（标点、空格、英文、数字都不算）→ 得到句长序列。

**输出**：均值、中位数、标准差、p10/p90、短句（≤12 汉字）占比、长句（≥30 汉字）占比。

**为什么带宽不用"均值 ± 2×标准差"** —— 这是**实测踩出来的坑**：

样本里有对话体（一句一行、7 个字）也有长段落（40+ 字），句长的标准差被拉到 **12.5**，
带宽 ±25.2，允许区间下限算出来是 **−1.4 汉字**。**这个带宽等于没有：任何句长都通过。**
换句话说，一个看起来"统计上很讲究"的公式，实际上让这道闸门失效了。

改用中位数与四分位距（IQR）后：

```
band = clamp(min(1.0 × IQR, 样本内标准差均值 + 篇间中位数离散), 5.0, 15.0)
中心 = 中位数的中位数
下限 = max(4.0, 中心 − band)
```

| 项 | 值（同一批样本） |
|---|---|
| IQR | 18.0 |
| 样本内标准差均值 | 12.7 |
| 篇间中位数离散 | 2.3 |
| **band** | **15.0**（被上限截断） |
| 允许区间 | 8.8 ~ 38.7 |

两点说明：

- **带宽上限 15.0**：防的是"样本句长极其整齐 → 带宽趋近 0 → 正常波动全判偏离"。
- **带宽不能比样本自身的自然波动还宽**：所以取 `min(IQR, inside + outside)`。
  带宽比稿子的自然波动还宽，等于没有判别力——第一版的教训就在这里。

## 2. 段落节奏：平均段长 + 序数开头段占比

**怎么数**：按空行切段（**单换行不切段**——本族样本里单换行大量用于"短句独立成行"），
段长按汉字数算（≥ 4 汉字才算一段）。

**序数开头段占比**：段落以 `一、` / `1.` / `第一，` 开头。
它测的是**分段习惯**——有的作者每节都编号，有的从头到尾不分节。
实测样本里这个值是 3%，说明这个账号基本不编号；一个新稿如果 40% 的段落都带 `一、二、三、`，
那就是换了个人在写。

**平均段长的带宽**取相对值（±35%，下限 8 汉字）：段长的合理波动本来就比句长大。

## 3. 人称分布：占**人称词总次数**的比例，不是字数的比例

**怎么数**：统计 `我/我们/咱/俺`、`你/你们/您`、`他/她/它/他们/她们` 的出现次数，
每一类除以三类之和。

**为什么分母不是字数**：人称占比要回答的是"这篇稿子用谁的视角在说话"，
这与人称密度（每百字出现几次"我"）是两件事。
用总次数做分母，短稿长稿可以直接比。

**主导人称**是单独一条判据：主导人称变了就等于换了叙述视角。
实测样本（自述体）：我/我们 77%、你/你们 7%、他/她 16%，各篇投票 6/6 都是"我"。

**用户例子的"你"占比 41% vs 档案 7%，是真实偏离，不是误伤** ——
这个账号是"我讲我的经历"，改成"你有没有遇到过"就是换了对读者说话的方式。

## 4. 标点密度：先切成"种类"，再按每百字算

**怎么数**：先剔除标点堆砌（`！！！` 只算实际字符），再分九类统计：
叹号 / 问号 / 省略号 / 破折号 / 冒号 / 引号 / 逗号 / 顿号 / 全部，各除以汉字数 × 100。

**为什么要分类**：总标点密度区分度有限，**分类才有判别力**。实测：

| 标点（每百字） | 档案（同账号） | 异风格实测 |
|---|---|---|
| 破折号 | **1.03** | **0.00** |
| 逗号 | 5.74 | 2.83 |
| 顿号 | 1.36 | 1.00 |

破折号是最能说明问题的一项：这个作者平均每 100 字用 1 个破折号
（用来插话、补一句自我解释），而学术论文体的稿子里一个都没有。

**带宽 = max(绝对下限 0.6, 相对 50%, 逐篇标准差)**。
第三项不能省：有的作者"破折号有的篇很多、有的篇一个没有"，
这种波动是**调性的一部分**，不该判违规。

## 5. 词组密度：五类"一眼能看出调性"的词

| 组 | 词 | 测什么 |
|---|---|---|
| 缓和词 | 其实 / 大概 / 差不多 / 应该是 / 可能 / 也许 / 说白了 | 说话留不留余地 |
| 转折词 | 但 / 但是 / 不过 / 然而 / 其实 | 论证节奏 |
| 序数词 | 第一 / 第二 / 第三 / 首先 / 其次 / 最后 | 结构化程度 |
| 顺承词 | 于是 / 然后 / 接着 / 所以 / 因此 / 结果 | 叙事推进方式 |
| 比喻词 | 像 / 似的 / 仿佛 / 好比 | 是否爱打比方 |

同样是每百字密度，带宽取 `max(0.8, 50%)`。

## 6. 开场与结尾：判**类别**，不判具体句子

**开场 8 类**（按优先级匹配，同时判"开场段"的整段而不是切出来的第一句）：

`疑问式` / `场景对白` / `时间切入` / `第一人称叙事` / `共鸣现象式` / `数据切入` / `结论前置` / `定义陈述`

**结尾 7 类**：

`行动召唤` / `鼓励收束` / `价值升华` / `留白反问` / `总结归纳` / `回扣开头` / `平铺收束`

**为什么判"开场段"而不是第一句** —— 又一个实测坑：
样本的正文前有 `## 第 41 篇｜xxx` 这种标题行，切句时标题被并进第一句，
开场句式判定**6/6 篇全落到"陈述式"**，判别力为零。
两处修改：① 切句时排除标题行（`_looks_like_title`）；② 开场判据用整段。

**类别不统一就放开**：样本自己都用好几种开场方式，却要求新稿必须用其中一种，是双重标准。
判据：某位置的类别数 > max(1, 样本数 ÷ 3) 时，这一项标"（任意类别）"，不参与判定。
实测样本：开场有 3 类（6 篇）→ 3 > 6÷3=2 → **放开**；结尾有 2 类 → 2 > 2 为假 → 保持判定。

## 7. 风格指纹与自相似阈值：判"算不算同一个账号"

**怎么算指纹**：切句 → 抹标点 → 逐句抽**汉字二元组** → 丢掉"同一句里重复出现"的二元组
（那是内容词）→ 丢掉含虚词黑名单字符的组合 → 剩下的是"这个作者说话的习惯"。

**怎么用**：把样本两两比一遍（Jaccard），得到分布；取**最小值 × 0.5** 作为自相似阈值。

实测标定（这是阈值取 0.5 的依据）：

| 组合 | 均值 | 最低 | 最高 |
|---|---|---|---|
| 同风格 6 篇（两两） | 0.127 | **0.096** | 0.149 |
| 跨风格（同风格 × 异风格） | 0.010 | 0.005 | 0.019 |
| 5 篇同风格 + 混进 1 篇异风格 | 0.088 | **0.0067** | 0.148 |

- 同风格最低 0.096，跨风格最高 0.019 —— **相差 5 倍以上**，判别力是实的。
- 混样本时最低值掉到 0.0067，低于均值 0.088 的一半 → 触发"疑似混了别人的作者"提示。

**踩过的坑**：第一版把阈值硬编码成 `< 0.10`，结果**同一批 6 篇同风格样本（min 0.096）
被判成"不像同一个账号"并拒绝往下跑**。阈值写死就会犯这种错：
一个数不可能同时适配"公众号长文"和"短句口语"两种稿子的指纹尺度。
改成比例判据（`min < 0.5 × mean`）后，两种尺度都自动成立。

## 8. 会失效的情况（写出来，不藏）

| 情况 | 后果 | 怎么办 |
|---|---|---|
| 样本里混了别的作者的稿子 | 档案变成"几个人平均"，谁都不像 | 看 `baseline` 的相似度最低那一对，剔掉那篇 |
| 样本本身就有两种写法（一个号两个栏目） | 容差被撑宽，判别力下降 | 按栏目分开抽两份档案，别混在一起 |
| 样本每篇都很短（< 300 汉字） | 句长/段长统计噪声大 | 至少 3 篇 × 500 汉字以上；有效样本汉字 < 80 的直接被跳过 |
| 样本是"人设稿"（同一作者在扮不同角色） | 指纹相似度低，被判混样本 | 加 `--force` 强行抽档，但要知道档案是平均值 |
| 文案体裁是诗、歌词、纯对白 | 切句与段长口径不适用 | 本包不承诺这类体裁 |
