# 指标口径、容差自标定与反例判据

> 这份文档回答两个问题：
> **① 容差凭什么定成这个数？**
> **② 怎么证明这个指标能区分"同风格"与"不同风格"（而不是"读起来像"）？**

## 1. 口径表总览

所有指标的口径、带宽公式、`dev_limit` 上下限：

| 指标 | 口径 | 带宽公式 | dev_limit 范围 |
|---|---|---|---|
| 平均句长 | 汉字数/句，切句见量化方法 §1 | `clamp(min(IQR, inside+outside), 5, 15)` | [1.0, 2.0] |
| 平均段长 | 汉字数/段 | `max(8, 35% × 均值)` | [1.0, 2.0] |
| 短句占比(≤12) | 句数占比 | 绝对 `0.15` | [1.0, 2.0] |
| 长句占比(≥30) | 句数占比 | 绝对 `0.15` | [1.0, 2.0] |
| 标点密度 ×9 | 每百字次数 | `max(0.6, 50%, 逐篇标准差)` | [1.0, 2.0] |
| 人称占比 ×3 | 占人称词总次数 | 绝对 `0.20` | [1.0, 2.0] |
| 词组密度 ×5 | 每百字次数 | `max(0.8, 50%)` | [1.0, 2.0] |
| 序数开头段占比 | 段数占比 | 绝对 `0.30` | [1.0, 2.0] |
| 口头禅命中 | 命中 top-N 的个数 | 计数，需 ≥ `min(2, N)` | 计数判据 |
| 开场句式 | 类别 | 类别判据 | 类别 |
| 结尾句式 | 类别 | 类别判据 | 类别 |
| 主导人称 | 类别 | 类别判据 | 类别 |

判定方式：`|实测 − 档案| ≤ band × dev_limit`。

## 2. 容差自标定（dev_limit 怎么来）

**四步**：

1. 按上表算出每个指标的 `band`；
2. 拿**每一篇样本**逐篇与（含它自己在内的）档案比对，记录每项的相对偏差
   `rel = |实测 − 档案| / band`；
3. `dev_limit = clamp(样本观测到的最大 rel × 1.5, 1.0, 2.0)`；
4. 类别型指标：样本内部类别不统一 → 这项放开（`open`）。

**1.5 的余量是给"没见过的稿子"留的**，不是给"随便写"留的。
上限 2.0 防的是：样本里恰好有一篇很怪的稿子，把某些指标的最大相对偏差推到 5，
自标定会把闸门放松到无边。

**结果**（6 篇实测样本，只列 `dev_limit > 1` 的）：

| 指标 | dev_limit | 样本观测到的最大 rel |
|---|---|---|
| 标点密度·破折号 | 1.492 | 0.995 |
| 标点密度·顿号 | 1.129 | 0.753 |
| 其余 11 项 | 1.000 | ≤ 0.67 |

`baseline` 会把整张表打出来。

### 为什么必须自标定

容差写死只有两种结局，**两种都实测踩过**：

| 结局 | 实测案例 |
|---|---|
| 严到"样本自己都过不去" | 第一版硬编码 `自相似阈值 < 0.10 → 拒绝`，把同一批同风格样本（min 0.096）判成"不像同一个账号" |
| 松到"什么都能过" | 第一版句长带宽 ±25.2、下限 −1.4 汉字，任何句长都通过——闸门形同不存在 |

**自标定是唯一能同时避开这两者的依据。** 它的语义很清楚：
**同一个人写的稿子必须先过得去，闸门才有资格拦别人。**

## 3. 反例判据：怎么证明指标有判别力

判"像"很容易，**判"不像"才是判别力的证明。** 本包做了三层验证。

### 3.1 同风格样本必须全过（内建自证）

`profile` 与 `baseline` 都会打印：

```
**样本自己套自己的档案，通过率 6/6 = 100%**
```

实测（6 篇同账号样本，逐篇）：

| 样本 | 一致度 | 偏离项 |
|---|---|---|
| sample-41 ~ sample-46 | 86.0 / 87.5 / 86.0 / 88.1 / 93.0 / 89.1 | 0 / 26（全部） |

### 3.2 异风格必须被拦（外部反例）

反例语料：4 篇**学术论文体**稿子，主题同样在"视频画质 / 内容运营"圈里，**只换调性**。

| 稿子 | 一致度 | 偏离项 | 结论 |
|---|---|---|---|
| 异风格 01 | 10.3 | 10 / 26 | ❌ |
| 异风格 02 | 19.4 | 8 / 26 | ❌ |
| 异风格 03 | 37.7 | 6 / 26 | ❌ |
| 异风格 04 | 38.0 | 6 / 26 | ❌ |

拦下它的项（异风格 01）：

| 指标 | 档案 | 实测 | rel |
|---|---|---|---|
| 人称占比·我/我们 | 0.77 | **0.00** | 3.83 |
| 人称占比·他/她/他们 | 0.16 | 1.00 | 4.18 |
| 平均句长 | 23.75 汉字 | 38.79 汉字 | 1.00 |
| 长句占比(≥30) | 0.32 | 0.64 | 2.15 |
| 平均段长 | 65.43 汉字 | 100.17 汉字 | 1.52 |
| 标点密度·破折号 | 1.03 | 0.00 | 1.71 |
| 标点密度·逗号 | 5.74 | 2.83 | 1.01 |
| 口头禅命中 | 需 ≥2 | **0** | 1.00 |
| 开场/结尾句式 | —— | 类别不同 | —— |

**同风格 6/6 过、异风格 4/4 拦** —— 这就是"可测量"的实证。

### 3.3 独立盲判（不依赖本包指标）

本地指标只能证明"数字对上了"，不能证明"读起来像"。所以另做了一次花 token 的盲判：

- 从 3 篇样本各取开头+结尾片段（共 1283 字）当"作者原文"；
- 三份候选：本包产出 / 别人的稿子 / **同一作者的另一篇样本**（未参与参考片段）；
- 打乱顺序，两轮（不同顺序），问"哪几份同一人写的"并给 0~10 分。

| 候选 | 第 1 轮（顺序 CAB） | 第 2 轮（顺序 BCA） |
|---|---|---|
| 本包产出 | True，8/10 | True，7/10 |
| 别人的稿子 | **False，1/10** | **False，1/10** |
| 作者另一篇原文 | True，9/10 | True，8/10 |

两轮位置不同、结论一致 → 不是位置效应。
本包产出的 7~8 分略低于"作者原文"的 8~9 分，与本地一致度的档位（80.6 vs 86~93）**同序**。

### 3.4 可测量的边界

它测的是**调性**这一层（句长/人称/段落/标点/口头禅/开场结尾），不是**主题**这一层。

| 变化 | 指标表现 |
|---|---|
| 同风格、换选题 | 照样成立（这就是本包的用途） |
| 同选题、换作者调性 | 塌得很明显（3.1 与 3.2 的对比） |
| 同一作者、换体裁（图文→口播稿） | **会塌**。体裁变了，段落与标点习惯也变。这时应该按体裁各抽一份档案 |

## 4. `prompt_echo`：三层判据 + 片段级判据

本包的提示词里**确实放样本**（每个样本的开场句与结尾句，最多 2N 句），
否则模型无从知道这个账号的句式长什么样。代价是"照抄首尾句"变成最省力的写法，
所以这道闸门是**防必然**。

### 4.1 三条基础判据（全族统一口径）

| 判据 | 阈值 | 抓什么 |
|---|---|---|
| `exact` | 去标点后**完全相同** | 直接照抄 |
| `jaccard` | 字符二元组 Jaccard ≥ **0.75** | 长度相当的同构改写 |
| `contain` | 示例二元组**覆盖度** ≥ **0.60** | 把示例夹带进更长的句子（Jaccard 被长度摊薄） |

长度门槛是**相对值** `max(6, 示例长度 // 2)`。

### 4.2 覆盖度必须限定"可比长度"（实测事故）

**第一版没有这条限制，结果整篇正文（1796 字）与示例（16 字）比，覆盖度算出 0.60**：

```
!! 正文有 60% 的内容来自提示词示例「没关系，第一步本来就是这样走出来的。」
```

而正文里与那句示例**唯一的重合只有"第一步"三个字**。
根因：二元组集合的**并集**随文本变长迅速饱和——
只要目标足够长，示例那 16 个二元组几乎总会被"顺带覆盖"到，覆盖度趋近 1 是**必然**。

标定数据（817 组真实非照抄比对）：

| 比对单位 | contain 中位 | contain 最大 |
|---|---|---|
| 逐句比 | 0.000 | **0.200** |
| 整篇比 | **0.302** | **0.600** |

整篇比与阈值 0.60 零余量 → **必然误报**。所以：**覆盖度只在
`目标长度 ≤ 1.5 × 示例长度` 时参与判定**；整篇那一次比对关掉覆盖度，只留 `exact` / `jaccard`。

### 4.3 片段级判据：`_ordered_coverage`

把示例原句后面接几个字：

```
…就是没关系，第一步本来就是这样走出来的这个道理。
```

`exact` 不成立（不是完全相同）、`jaccard` 只有 0.53（够不到 0.75）、
`contain` 被长度窗口挡住（目标 37 字 > 示例 16 × 1.5 = 24）—— **三条全漏，而人眼一看就是抄的。**

补的判据是"等长窗口 + 最长公共子序列（LCS）"：

1. 把示例（归一化后）当模板，长度 `L`；
2. 在目标上滑一个宽度 `L` 的窗口，逐位置算窗口与示例的 LCS 长度 ÷ `L`；
3. 取所有窗口的最大值作为"有序覆盖度"。

**为什么必须是 LCS，不能用集合交**：集合会丢掉顺序，而"整句被抄下来"的本质就是顺序。
实测：`没关系，第一步本来就是这样走出来的这个道理。` 的集合交只有 **0.062**（长句把并集撑大），
LCS 版是 **1.000**。

**还有一个自摆的坑**：第一版用 `list.index()` 贪心顺序匹配，方向对（不回退保证了顺序），
但**在长句上直接爆成 1.000**（非照抄语句 100% 判为照抄，判据等于没有）。
根因不是贪心本身，而是**给二元组分配了递增整数 id**，于是"示例的 16 个二元组"
变成"16 个整数 0..15"，任何长度 ≥ 16 的目标里都必然能找到一串"相似"的整数序列。
改成用二元组字符串本身，匹配才是真匹配。

标定（阈值 0.75）：

| 语料 | n | 最大值 | p99 | 中位 |
|---|---|---|---|---|
| 非照抄（本包产出 74 句 + 异风格 4 篇 + 标题） | 133 | **0.148** | 0.143 | 0.034 |
| 真照抄（6 种改写形态） | 6 | **1.000** | — | — |

| 形态 | 有序覆盖度 | 抓住 |
|---|---|---|
| 原句照抄 | 1.000 | ✅ |
| 原句 + 补 3 字 | 1.000 | ✅ |
| 原句揉进长句开头 | 1.000 | ✅ |
| 原句揉进长句中间 | 1.000 | ✅ |
| 同构改写（换 4 处词） | 0.778 | ✅ |
| 非照抄语句 | ≤ 0.148 | 不误伤 |

阈值 0.75，两侧余量都在 5 倍以上。

## 5. 防换皮：新稿 vs 样本全文

`verify --samples <目录>` 会额外算新稿与**样本全文**的二元组 Jaccard：

- ≥ **0.50** → 拦（疑似把样本换个开场就交）
- ≥ **0.35** → 只提示

实测：产出新稿与最相似的样本是 **0.081**（样本 3），离两条线都很远。

## 6. 一致度分数（style_score）是什么、不是什么

```
style_score = 100 × (1 − 所有指标 rel 的平均值)
```

- **是**：一个便于横向比较的归一化量。它随偏离项增多而单调下降。
- **不是**：概率、准确率、"像的程度"的物理量。
  它对**量纲无关**（所有 rel 都是"偏差 ÷ 带宽"），所以 80 分不代表"80% 像"。

实测参照档位：

| 稿子 | style_score |
|---|---|
| 同账号样本 | 86 ~ 93 |
| 本包产出（指标全过） | 80.6 |
| 本包第 1 轮产出（4 项偏离） | 53.1 |
| 异风格稿子 | 10 ~ 38 |

**判定用"有没有偏离项"（`ok`），不用分数阈值。** 分数只用来给两个都不合格的版本排序，
以及解释"这轮比上轮好多少"。
