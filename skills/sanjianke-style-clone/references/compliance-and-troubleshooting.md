# 合规红线、违禁词与排错手册

> 这份文档里的违禁词表是**启发式自检工具**，来自公开经验整理，
> **不构成法律意见，也不代表任何平台的官方审核标准**（官方标准不公开、且会变）。
> 高风险类目（医疗、保健食品、食品、金融、母婴、特殊化妆品）必须人工复核。

## 2. 「最X」的语境豁免（**被实测误伤逼出来的**）

**事故复盘**：真实原稿里写「回头翻一条自己播放量最低的视频」，
被本地闸门判成高风险「广告法第九条禁止最高级用语」并整篇拦截。
**这个诊断是错的** —— 那是在描述自己的数据，不是商品/服务宣称。

一个正确写法的稿子被判违规，代价是**使用者开始无视闸门**，
那时候闸门就等于废了。「宁可多报也别漏报」在这里代价过高。

**豁免条件刻意做得很窄**：

```
`最X` 前一个字 ∈ {量 率 数 分 位 条 次 段 部 集 页 个 天 月 年}
且 `最X` 后面紧跟「的」或「之」
且 `最X` **不在句首**          ← 句首一律不豁免
```

命中豁免时**整处放过，但在报告里登记**（`gates.compliance.exempted`），
stderr 会打印一行「本地放过 N 处疑似绝对化用语……请人工确认」。**不静默放过。**

**豁免词表刻意不含** `时` / `款` / `种` / `家` / `价`：
「课时最低的课程」「单价最低」都是真实的价格宣称形态，必须照拦。

**句首不豁免的理由**：`最好的产品` 出现在句首时没有前一个字可判，
按"前一个字是计量名词"的规则会**因为空字符串而误豁免**——
`"" in "量率数…"` 在 Python 里是 `True`。所以判据里必须有 `before and`。

| 用例 | 判定 |
|---|---|
| 播放量**最低**的视频 | ✅ 豁免（前一个字「量」，后跟「的」） |
| **最好**的方案其实是把流程写下来 | ❌ 拦（句首不豁免） |
| 课时**最低**的课程 | ❌ 拦（「时」不在豁免词表里） |
| 冲突**最强**的那一段 | ❌ 拦（「突」不是计量名词） |

最后一条是**已知的过度报告残留**：描述性用法会被拦。
要么改措辞，要么人工确认后放行；**不要改成只警告**。

## 3. 「第一」的排除项（同样是实测误伤）

**事故复盘**：真机跑 `write` 时，闸门报「合规：命中「第一」(高)」，
被拦的是「我见过太多同行栽**在第一**步。」——**序数用法，不是排他性宣称**。

第一版的规则是 `第一(名|品牌|选择)?(?!次)`，只排除了 `第一次`。
修法是补上同类的序数用法：

```
第一(?:名|品牌|选择)?(?!次|步|天|周|月|年|时间)
```

## 4. 占位符残留（命中即拦）

| 模式 | 说明 |
|---|---|
| `{...}` | 模板占位符没被替换干净 |
| `[待填]` / `[请填写…]` / `[TODO]` | 方括号占位符 |
| `XXX+` / `xxx+` | 占位符标记 |
| `（此处省略…）` | 省略标记 |
| `待补充` / `待补齐` | 待办标记 |
| `TODO` / `TBD`（词边界） | 英文待办标记 |
| `【待…】` / `【请…】` | 全角占位符 |

这类产出的问题不是"不好"，是**根本不能发**：`{客户痛点}` 和 `[待填]` 都不是文案。

## 5. 排出位置闸门：产出不许进包

`--outdir` / `--out` 解析后的绝对路径如果落在技能包目录内 → **exit=2**。

**理由不是洁癖**：SkillHub 的扩展名白名单只放
`.md .py .txt .json .sh .js .yaml .yml .csv`，**图片与其他二进制一律不许进包**。
一旦产出写进包里、格式越界，就是**整包被拒**。
所以这条做成硬闸门而不是提示，并且 `--outdir` / `--out` 都查。

## 6. 排错手册

| 现象 / 报错 | 原因 | 怎么办 |
|---|---|---|
| `Missing or invalid relay API key`（HTTP 401） | Key 无效/过期/写错 | 到 https://api.a7w.cn/ 重新领取；确认没把 `Bearer` 重复写进环境变量 |
| 点数不足（HTTP 402） | 账号点数用完 | 充值后重试 |
| 模型不存在（HTTP 404） | 模型名写错或已下架 | `run.py models` 现查在架模型名 |
| 上游 `502` / `upstream timeout` | 网关到上游的瞬时抖动，**实测很常见** | 已内置退避重试（最多 4 次）。连续失败就换模型 |
| 样本不足 3 篇（exit=2） | 有效样本 < 3 篇 | 补样本，或 `--samples` 多指一个目录。**这是硬闸门** |
| `--outdir 指到了技能包内部`（exit=2） | 产出目录在包里 | 换包外目录 |
| `给了 --budget 就必须给单价`（exit=2） | 预算没有单价就没意义 | 补 `--price-in` / `--price-out` |
| `样本自相似阈值…疑似混了别的作者`（exit=2） | 样本里混了不属于这个账号的稿子 | `baseline` 看最低那一对，剔掉那篇；确认无误加 `--force` |
| **风格偏离**（exit=3） | 新稿的某些指标超出容差 | 看 stderr 逐项偏差；`all --iterations 2` 让脚本把偏离项喂回模型定点修。**别改成只警告** |
| 反复卡在同一两项指标 | 定点修到天花板后来回摆 | 本包已保留"偏离最少的一轮"。想省 token 用 `--iterations 2`；或调 `--temperature` 换一轮 |
| **照抄示例**（exit=3） | 新稿有句子与样本首尾句太近 | 重跑。三层判据 + 片段级判据都会报，看 stderr 里的 `rule` |
| 合规命中「最X」但你看不出问题 | 程度副词作描述 | §2 的豁免覆盖了"数据极值"形态；其余靠人工确认（**这是已知的过度报告**） |
| 合规命中「第一」，但那是"第一次/第一步" | 序数用法 | 已排除 `次/步/天/周/月/年/时间`；仍有残留就人工确认 |
| `模型返回的不是合法 JSON` | 模型在 JSON 前后多吐了字符 | 已用 `json.JSONDecoder().raw_decode()` 扫第一个完整对象。仍失败就 `--no-json-mode` 并换模型 |
| 模型没返回 `choices` / 产出为空 | 被 `max_tokens` 截断 | 加大 `--max-tokens`（长篇建议 4096 以上） |
| 换在架模型后正文被截断 / 只吐出一段思考 | `models` 列表里有推理模型，先花 completion token 出思维链 | 用默认 `deepseek-chat`；非要用推理模型就把 `--max-tokens` 提高 1.5~2 倍 |
| HTTP 200 但 `model:null`、内容为空、usage 为空 | 把 `deepseek-flash`（路由**目标名**）当**请求名**用 → **静默失败**，状态码骗人 | 请求名用 `deepseek-chat`；换模型用 `models` 列表里的名字 |
| 档案文件不是合法 JSON（exit=2） | 用 `profile --out` 但**没加 `--json`** | 加 `--json`；或用 `--outdir`（同时落 `.json` 与 `.md`） |
| Windows 中文乱码 | 控制台代码页不是 UTF-8 | `chcp 65001`，或 `PYTHONIOENCODING=utf-8` |
| 样本里出现奇怪的口头禅（`30秒`、`视频超清vr`） | n-gram 切到了数字/拉丁边界 | 已要求 n-gram **纯汉字**；若仍有，检查样本里是否有大量中英混排 |
| 开场句式全部判成同一类 | 标题行被并进了第一句 | 已排除标题行（`## 第 N 篇｜…`）并改判**开场段** |

**收集排错信息时请附上**：完整命令、`--dry-run` 的输出、原始报错文本、退出码。
**不要在报错信息或截图里带上你的 API Key。**

## 7. 关于样本的合法性

把某个账号或作者的稿子作为样本，**前提是你已经取得合法授权**。

本包输出的是**统计描述**（句长、人称占比、标点密度…），不是原文片段；
`prompt_echo` 闸门会拦住"把样本原句搬进新稿"，
`sample_overlap` 闸门会拦住"把样本换个开场就交"。
但这两个闸门是**工程手段，不是法律保障**——
用本工具批量仿冒他人身份、规避平台原创规则，责任由使用者承担。
