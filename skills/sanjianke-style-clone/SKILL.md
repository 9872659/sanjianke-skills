# 三剪客 · 风格克隆体

> ## ⚠️ 先申请你自己的 API Key
>
> **本 Skill 不内嵌任何密钥，也不代付费用。** 请到
> **[算力集市 api.a7w.cn](https://api.a7w.cn/)** 注册并创建**你自己的** API Key
> （新用户有赠送点数，可以先免费试跑几条）。
>
> 拿到后填进环境变量 `A7W_API_KEY`，或直接传给 `--key` 参数。
> **请勿使用他人提供的 Key** —— 用量与费用都记在 Key 所属账号上。

## 能做什么

**学一个账号的调性，然后按它写。**

喂 3~20 篇同一个账号的稿子 → 抽出**风格档案**（全是数字）→ 按档案写新稿 →
**风格一致性自检**（新稿逐指标 vs 档案）→ 迭代到贴合。

它替代的是这么一件事：矩阵号、代运营、品牌统稿，都需要"把这个号的调性复制给另一个写手"。
常见的做法是甩几篇范文过去说"照着写"，或者写一句"让模型模仿这个风格"。
这两种做法都没有验收标准——**"像不像"没人能反驳，也就没人能用它做门禁。**

本包换了个做法：

| 常见做法 | 本包 |
|---|---|
| "照着这几篇的调性写" | 抽出一份**数字档案**：平均句长 23.8、带宽 ±15、第一人称 77%… |
| "读起来挺像的" | 新稿的每一项**重新数一遍**，逐项给偏差值，超出容差就标红 |
| 容差拍脑袋定 | 容差由**样本自身的偏差分布**自标定，并打印自证通过率 |
| 抄范文也算"学会了" | 三层判据 + 片段级有序覆盖，把"搬样本原句"抓出来 |

**这个包存在的理由，是"像不像"可以被证伪。** 见下面「可测量，还是读起来像」一节——
那里有反例测试的实测数字。如果指标区分不了同风格与异风格，这个包就不该存在。

| 你最关心 | 答案 |
|---|---|
| 多少钱 | 只调大模型。实测一次 `all`（2 轮迭代）**4715 token**；单次 `write` 约 2500 token。很便宜 |
| 要多久 | 抽档是**纯本地、零成本、秒级**；单次 `write` 实测 5~8 秒 |
| 要装什么 | **什么都不用装**。只用 Python 标准库，不需要 pip install 任何东西 |
| 抽档要钱吗 | **不要。** `profile` / `verify` / `diff` / `baseline` 全是纯本地统计，不调模型 |
| 抽档靠模型吗 | **不靠。** 档案里的每一项都是本地数出来的，模型插不进话——所以同一批样本抽两次，档案逐字节相同 |

### 风格档案长什么样（每一项都能在新稿上重新数）

| 类别 | 指标 |
|---|---|
| **句长分布** | 平均句长 + 带宽、句长标准差、篇间离散、中位数、p10/p90、短句(≤12字)占比、长句(≥30字)占比 |
| **段落节奏** | 平均段长 + 带宽、最长段、序数开头段占比（`一、`/`1.`/`第一，`） |
| **人称分布** | 我/我们、你/你们、他/她/他们的占比，以及**主导人称**与逐篇投票 |
| **标点密度** | 每百字：叹号 / 问号 / 省略号 / 破折号 / 冒号 / 引号 / 逗号 / 顿号 / 全部 |
| **词组密度** | 每百字：缓和词（其实/大概）、转折词、序数词、顺承词、比喻词 |
| **口头禅** | top-5，**按"出现在几篇里"排序**（跨篇复现的才是调性，单篇复读的是内容词） |
| **开场套路** | 逐篇句式类别 + 票数：疑问式 / 场景对白 / 时间切入 / 第一人称叙事 / 共鸣现象式 / 数据切入 / 结论前置 / 陈述式 |
| **结尾套路** | 逐篇句式类别 + 票数：行动召唤 / 鼓励收束 / 价值升华 / 留白反问 / 总结归纳 / 回扣开头 / 平铺收束 |
| **自相似基线** | 样本两两风格指纹相似度（均值/最低/最高）+ **自相似阈值**（判"算不算同一个账号"） |
| **容差自标定** | 每个指标的容许偏差倍数（`dev_limit`）+ 样本观测到的最大相对偏差 |

反例（模型形容词）在本包里**一个都没有**。档案里出现"幽默风趣"这种词，
就意味着下一句只能靠感觉——那就没法验收。

### 可测量，还是读起来像

这是本包唯一值得你花时间看的一节。**如果 verify 的指标区分不了"同风格"与"不同风格"，
那它就是假绿，这个包的卖点不成立。** 所以本包把"能不能区分"做成了可重复的实测。

实测设置：6 篇同一作者/同一账号的样本（推广长文体，均 ~1850 汉字），
档案从这 6 篇抽出；对照组是 4 篇**别的风格**的稿子（学术论文体，均 ~600 汉字）
——主题同样在"视频画质/内容运营"这个圈里，只换调性。

| 被测稿子 | 一致度 | 偏离项 | verify 结论 |
|---|---|---|---|
| 样本 1~6（同账号，逐篇） | 86.0 ~ 93.0 | **0 / 26** | ✅ 全部通过（6/6） |
| 产出的新稿（`all` 第 2 轮，跑通的那次） | 80.6 | **0 / 26** | ✅ 通过 |
| 同一产线重跑一次（`all` 第 2 轮） | 57.6 | 4 / 26 | ❌ 拦下 |
| 异风格 01 | **10.3** | 10 / 26 | ❌ 拦下 |
| 异风格 02 | **19.4** | 8 / 26 | ❌ 拦下 |
| 异风格 03 | **37.7** | 6 / 26 | ❌ 拦下 |
| 异风格 04 | **38.0** | 6 / 26 | ❌ 拦下 |

**1. 同风格样本 6/6 全过。** 这是容差自标定的自证：容差就是按"样本自己必须先过得去"定的。
如果同账号的样本自己对不上自己的档案，那这份档案就是假的，后面所有结论都不用看。
`profile` 与 `baseline` 都会打印这个通过率。

**2. 异风格 4/4 被拦下。** 这才是关键的一半。判"像"很容易，判"不像"才需要指标真的有判别力。

**3. 判别力来自哪几项**（异风格样本被拦的项）：

| 指标 | 档案（同账号） | 异风格实测 | 相对偏差 |
|---|---|---|---|
| 平均句长 | 23.75 汉字 | 38.79 汉字 | 1.00（超容差） |
| 第一人称占比 | 0.77 | **0.00** | 3.83 |
| 第三人称占比 | 0.16 | 1.00 | 4.18 |
| 长句(≥30字)占比 | 0.32 | 0.64 | 2.15 |
| 平均段长 | 65.43 汉字 | 100.17 汉字 | 1.52 |
| 口头禅命中 | 需 ≥2 个 | **0 个** | 1.00 |

**4. 花 token 的独立检验（不依赖本包的指标）。** 本地指标只能证明"数字对上了"，
不能证明"读起来像"。所以做了一次盲判：把 3 篇样本的首尾片段当"作者原文"给裁判模型，
再给三份候选——本包产出、别人的稿子、同一作者的另一篇样本——打乱顺序，问"哪几份同一人写的"。
两轮（不同顺序）结果一致：

| 候选 | 第 1 轮（顺序 CAB） | 第 2 轮（顺序 BCA） |
|---|---|---|
| 本包产出 | same_author=**True**，8/10 | same_author=**True**，7/10 |
| 别人的稿子 | same_author=**False**，1/10 | same_author=**False**，1/10 |
| 作者另一篇原文 | same_author=True，9/10 | same_author=True，8/10 |

裁判给出的可指认证据（原文引用）：
"开场同样是具体场景+身体细节的第一人称（「手心是潮的」），与原文「我盯着后台看了很久」同款；
核心修辞是「不是A，是B」的重新定义句……"
—— 与本包的指标（第一人称 77%、开场句式、句长带宽）指向同一批证据。

**5. 所以答案是：真的可测量。** 但要说清可测量的**边界**：
换风格后指标会塌，说明它测的是"调性"这一层（句长/人称/段落/标点/口头禅），
不是"主题"这一层。同风格但换选题，指标照样成立；**换了作者的调性，指标塌得很明显。**

**6. 已知的假绿风险（写出来，不藏）**：容差是相对量，样本本身越齐，容差越紧；
样本本身很杂（比如一个号的稿子本来就有两种写法），容差会被撑宽，判别力下降。
所以 `baseline` 会打印自相似阈值与逐篇通过情况——**如果你的样本自相似阈值很低，
先用它筛样本，别急着写稿。**

## 怎么用（命令行）

### 第 0 步：获取 API Key

到 **[api.a7w.cn](https://api.a7w.cn/)** 注册，创建一个 API Key（形如 `sk-...`）。

### 第 1 步：装依赖

**零依赖。** 不需要 `pip install` 任何东西，只要机器上有 Python 3.7+：

```bash
python3 --version
```

包里自带的 `scripts/a7w.py` 是零依赖客户端（只用 `urllib` / `json` / `mimetypes`），
`scripts/run.py` 也只用标准库。

### 第 2 步：填 Key

```bash
# Linux / macOS
export A7W_API_KEY=sk-你的key

# Windows PowerShell
$env:A7W_API_KEY="sk-你的key"
```

也可以存进配置文件反复用（推荐）：

```bash
python3 scripts/a7w.py login --key sk-你的key
```

### 第 3 步：抽风格档案（免费，不花钱）

把同一个账号的 3~20 篇稿子放进一个目录，然后：

```bash
python3 scripts/run.py profile --samples ./样本目录 --json --out profile.json
```

**这一步不调模型、不花钱、不用 Key。** 档案是数出来的：

```
平均句长 23.8 汉字（允许 8.8~38.7）
平均段长 65.4 汉字（允许 42.5~88.3）
人称占比：我/我们 77%｜你/你们 7%｜他/她 16%｜主导人称：我/我们
标点密度（每百字）：破折号 1.03｜逗号 5.74｜顿号 1.36
口头禅：「不超过」(14 次/6 篇)、「用多少」(9 次/6 篇)…
开场句式：疑问式×4、第一人称叙事×1、陈述式×1
```

同时会打印**自证**：`6 篇样本套这份档案，通过 6/6 = 100%`。

### 第 4 步：先确认网关通（免费，不花点数）

```bash
python3 scripts/run.py models
```

这个命令打的是 `GET https://api.a7w.cn/api/v1/models`，会列出当前在架的模型。

> **模型名会变，一定用 `models` 子命令现查，别写死在脚本里。**
> 但要注意：`deepseek-chat` 这个别名**实测可用**（会路由到 `deepseek-flash`），
> 而它**不在** `/api/v1/models` 的返回列表里 —— 所以"列表里没有"不等于"不能用"。

### 第 5 步：按档案写稿

```bash
python3 scripts/run.py write --profile profile.json --topic "短视频代运营的第一次报价"
```

想先看不花钱的提示词：

```bash
python3 scripts/run.py write --profile profile.json --topic "…" --dry-run
```

### 第 6 步：风格一致性自检

```bash
# 自检刚写出来的稿子
python3 scripts/run.py verify --profile profile.json --result 结果.json

# 拿**别人的**稿子来验（这就是反例测试）
python3 scripts/run.py verify --profile profile.json --file 别人的稿子.md
```

`verify` 会给一张**逐指标对照表**：档案值、允许区间、新稿值、偏差、相对偏差、结论。
超容差的项标红并进入 stderr 汇总，退出码变 3。

### 完整工作流

```bash
# 0) 先看样本之间像不像同一个账号（免费）——样本杂就别急着写
python3 scripts/run.py baseline --samples ./样本目录

# 1) 抽档（免费）
python3 scripts/run.py profile --samples ./样本目录 --json --out profile.json

# 2) 一条命令跑完：抽档 → 写 → 自检 → 迭代（要花 token）
python3 scripts/run.py all --samples ./样本目录 --topic "选题" \
    --iterations 3 --outdir D:/styleclone/out

# 3) 只对照指标，不出结论（免费）
python3 scripts/run.py diff --profile profile.json --result 结果.json
```

### 直接用 curl 调（不依赖本包脚本）

本包底层就是一个标准的 OpenAI 兼容调用：

```bash
curl -sS -X POST "https://api.a7w.cn/api/v1/chat/completions" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{"role": "user", "content": "按这些指标写一篇稿子，只输出 JSON：平均句长 23.8、第一人称 77%…"}],
    "temperature": 0.7,
    "max_tokens": 4096,
    "response_format": {"type": "json_object"}
  }'
```

> **成功响应不带 `code` 字段。** 实测成功时返回的就是标准 OpenAI 形态
> （`id` / `object` / `created` / `model` / `choices` / `usage` / `system_fingerprint`），
> `"code" in payload` 为 `False`。`code==1` 那套信封**只用于生成应用的响应**，
> 不适用于本端点——所以别拿 `code` 判成败。

## 参数说明

### 全局

| 参数 | 说明 |
|---|---|
| `--key` | 临时指定 Key；优先级最高。**别把它写进脚本或文档** |
| `--json` | 以 JSON 输出，**写在子命令前面或后面都可以**；JSON 模式下 stdout 只有一个完整 JSON，人读进度走 stderr |
| `--out <文件>` | 把结果写到文件。`--json` 下写 JSON，否则写 Markdown |
| `--outdir <目录>` | 产出目录。**指到包内直接 exit=2** |
| `--model` | 模型名，默认 `deepseek-chat`（实测可用）。用 `models` 现查在架模型 |
| `--temperature` | 采样温度，默认 `0.7` |
| `--max-tokens` | 最大输出 token，默认 `4096` |
| `--dry-run` | 只打印将发送的提示词，**不调模型、不花钱** |
| `--no-json-mode` | 不要求上游返回 JSON 对象（个别模型不支持 `response_format` 时用） |

### 样本输入（`profile` / `baseline` / `all` / `cost` / `verify` 共用）

| 参数 | 说明 |
|---|---|
| `--samples <路径>` | 样本目录或文件，**可重复多次**。目录会递归找 `.md` / `.txt` / `.markdown` |
| `--sample-files <文件>` | 单个样本文件，可重复多次 |
| `--force` | 样本自相似阈值过低时强行继续（默认拒绝，exit=2） |

样本量硬门槛：**少于 3 篇拒绝抽档**（exit=2）；超过 20 篇只取前 20 篇并提示
（样本越多，档案越像"跨主题的平均值"，平均值没有调性）。

### `profile` —— 抽风格档案

**纯本地统计，零成本，不调模型。** 同一批样本抽两次，档案逐字节相同。

### `write` —— 按档案写新稿

| 参数 | 说明 |
|---|---|
| `--profile <文件>` | **必填**。`profile --json --out` 生成的档案 |
| `--topic "选题"` | **必填** |
| `--brief "要求"` | 额外要求 |
| `--evidence "素材"` | 可以使用的真实素材。**没写就不许编数字** |
| `--price-in` / `--price-out` | 单价（点/百万 token），配合 `--budget` 用 |
| `--budget <点>` | 预算上限。超了就地中止，exit=5 |

### `verify` —— 风格一致性自检（**纯本地，零成本**）

| 参数 | 说明 |
|---|---|
| `--profile <文件>` | **必填** |
| `--result <结果.json>` | `write` / `all` 的结果文件 |
| `--file <稿子.md>` | 直接给一篇稿子 —— **拿别的风格的稿子跑就是反例测试** |
| `--text "正文"` | 直接给正文 |
| `--samples <路径>` | 可选；给了就额外做"与样本全文的相似度"防换皮检查 |

### `diff` —— 指标对照表（纯本地）

输出档案 vs 新稿的并排指标表，比 `verify` 更简短，只列关键项。

### `baseline` —— 自证与反例判据（纯本地）

打印：样本自证通过率、逐篇偏离项、风格指纹两两相似度、**自相似阈值**、
自标定出的每个指标的 `dev_limit`。

### `all` —— 抽档 → 写 → 自检 → 迭代

| 参数 | 说明 |
|---|---|
| `--iterations <N>` | 最多迭代几轮，默认 `2`；指标全过就提前停 |
| 其余 | 同 `write`（含 `--budget`） |

**迭代不是单调变好的，所以本包保留"最好的一轮"**，不是最后一轮。
实测（同一批样本、同一选题、3 轮）：

| 轮次 | 一致度 | 偏离项 |
|---|---|---|
| 1 | 47.7 | 5 |
| 2 | 71.0 | **1** |
| 3 | 75.8 | **1** |

第 3 轮和第 2 轮卡在同一批指标上，来回摆。如果最后吐的是"最后一轮"，
产出质量就取决于轮数奇偶——所以记分规则是：偏离项少者优先，同分看一致度，
再同分保留更早的那一轮（少花钱）。采用哪一轮会写进结果（`best_round`）与 stderr。

### `cost` —— 只算钱

| 参数 | 说明 |
|---|---|
| `--samples <路径>` + `--topic` | 按样本集与选题估算 |
| `--from-result <结果.json>` | 读真实调用记录里的 token 数（**不是估算**） |
| `--price-in` / `--price-out` | 单价，单位「点/百万 token」 |
| `--budget` | 预算上限。超了 exit=5 |
| `--iterations` | 按几轮估算，默认 2 |

**为什么不给默认单价**：实测 `GET /api/v1/pricing` 的规则里**不含文本大模型**；
`GET /api/v1/models` 的记录里**也没有任何价格字段**；`chat/completions` 的成功响应里
`usage` 只有 `prompt_tokens` / `completion_tokens` / `total_tokens`，**没有点数**。
所以拿不到可信的文本模型单价，**本包拒绝凭空编一个**——
token 数我们估（实测标定），金额必须由你给单价。

### `models` —— 列出在架模型

| 参数 | 说明 |
|---|---|
| `--type` | 模型类型，默认 `text`；传 `all` 看全部 |
| `--json` | 原始 JSON |

## 六道硬闸门

**硬闸门 = 命中即拦截 + 标红 + stderr 汇总 + 退出码非 0。不许只警告。**

| # | 闸门 | 判什么 | 退出码 |
|---|---|---|---|
| 1 | **合规** | 广告法违禁词；「最X」按**可枚举语境豁免**，**句首不豁免** | 3 |
| 2 | **占位符残留** | `{}`、`[待填]`、`XXX`、`（此处省略）`、`待补充`、`TODO`/`TBD`、`【待填】` | 3 |
| 3 | **`prompt_echo`** | 与提示词示例（样本首尾句）去标点后相等 / 字符二元组 Jaccard ≥ 0.75 / 覆盖度 ≥ 0.60；外加**片段级有序覆盖 ≥ 0.75** | 3 |
| 4 | **风格偏离** | 新稿的每一项指标 vs 档案，超出自标定容差即拦，逐项列偏差值 | 3 |
| 5 | **样本量** | 有效样本 < 3 篇 → 拒绝抽档 | 2 |
| 6 | **成本上限 / 产出位置** | `--budget` 超限就地中止；`--outdir`/`--out` 指到包内 | 5 / 2 |

外加一项防换皮：新稿与**样本全文**的二元组 Jaccard ≥ 0.50 → 拦（≥ 0.35 只提示）。

### 为什么第 3 道闸门在本包里格外重要

**本包的提示词里确实会放样本** —— 不放假样本，模型无从知道这个账号的句式长什么样。
但只放**每个样本的开场句与结尾句**（最多 2N 句），不放正文：

- 放正文 → 模型的最优策略就是"把样本改几个词"，闸门会一直响，而它也确实没别的办法可用；
- 只放首尾句 → 模型必须自己造正文，这才是"学调性"与"抄样本"的分界。

代价是"把首尾句原样搬进新稿"变成最省力的写法，所以这道闸门在本包里不是防意外，
是**防必然**。三层判据（去标点相等 / Jaccard / 覆盖度）之外还加了**片段级判据**：

把示例原句后面接几个字（`…就是没关系，第一步本来就是这样走出来的这个道理。`），
`exact` 不成立（不是完全相同）、`jaccard` 只有 0.53（够不到 0.75）、
`contain` 被长度窗口挡住（目标 37 字 > 示例 16×1.5=24）—— **三条全漏，而人眼一看就是抄的。**
所以补了一条"等长窗口 + 最长公共子序列"的有序覆盖判据：

| 形态 | 有序覆盖度 | 是否抓住 |
|---|---|---|
| 原句照抄 | 1.000 | ✅ |
| 原句 + 补 3 字 | 1.000 | ✅ |
| 原句揉进长句开头 | 1.000 | ✅ |
| 原句揉进长句中间 | 1.000 | ✅ |
| 同构改写（换 4 处词） | 0.778 | ✅ |
| **非照抄语句（133 条实测）** | **最高 0.148** | 不误伤 |

阈值 0.75，两侧余量都在 5 倍以上。

### 退出码（可直接用于 CI）

| 退出码 | 含义 |
|---|---|
| `0` | 全部干净 |
| `2` | 参数/配置错误（样本不足 3 篇、`--outdir` 指包内、给了 `--budget` 没给单价） |
| `3` | **有硬闸门命中**（合规 / 占位符 / 照抄示例 / 风格偏离 / 防换皮） |
| `4` | 调用失败（网络 / 鉴权 / 点数 / 模型名） |
| `5` | **预算超限，已就地中止** |
| `1` | 未预料的内部异常（`--json` 下给 `kind:"internal"` 信封 + stderr 完整 traceback） |
| `130` | 用户中断 |

**`--json` 输出契约**（给流水线与 agent 消费，**只在 `--json` 下生效**）：

- 成功：结果对象里多一个 `"ok": true`；顶层是数组时包成 `{"ok": true, "data": [...]}`
- 失败：stdout 输出一个 JSON 信封，形如
  `{"ok": false, "exit": 3, "error": {"kind": "gate", "message": "…"}}`（`exit` 就是本次真实退出码），
  `kind` 取 `gate` / `usage` / `budget` / `call` / `interrupt` / `internal`。
  `internal` 是**没预料到的异常**（代码 bug）的兜底：stdout 给信封、
  **完整 traceback 原样打到 stderr**、退出码固定 1 —— 报 bug，不藏 bug
  —— 只有在**本次还没吐过任何 JSON 结果**时才补这个信封；**已经吐过结果时
  （风格偏离、照抄示例、预算超限都是这一类），`ok` 就写在那个结果里，退出码不变**
- 人读文案照旧走 stderr；**退出码语义一个都不变**；非 `--json` 模式输出与以前完全一致
- `--json` 写在子命令**前面或后面都可以**

### 容差是怎么定的（**不是拍脑袋**）

每个指标的容许偏差 = `band × dev_limit`，而 `dev_limit` 由**样本自身的偏差分布**标定：

1. 先按标准口径（`dev_limit = 1.0`）算出指标带宽 `band`；
2. 拿每篇样本**逐篇**与（含它自己在内的）档案比对，记录每项的相对偏差；
3. `dev_limit = clamp(样本观测到的最大相对偏差 × 1.5, 1.0, 2.0)` —— 留 1.5 倍余量给没见过的稿子；
4. 类别型指标（开场/结尾句式）：样本内部类别不统一 → 这一项**放开**。

**这四步的意义是：同一个人写的稿子必须先过得去，闸门才有资格拦别人。**
容差写死会出现两种坏结果之一——严到样本自己都过不去（闸门一直响，最后没人看），
或者松到什么都能过（那就是假绿，比闸门失效更糟）。

`baseline` 会把自标定结果整张表打出来，可以自己核。

## 排错

| 现象 / 报错 | 原因 | 怎么办 |
|---|---|---|
| `Missing or invalid relay API key`（HTTP 401） | Key 无效、已过期或写错 | 重新到 https://api.a7w.cn/ 领取；确认没把 `Bearer` 重复写进环境变量 |
| 点数不足（HTTP 402） | 账号点数用完 | 到 https://api.a7w.cn/ 充值后重试 |
| 模型不存在（HTTP 404） | 模型名写错或已下架 | `python3 scripts/run.py models` 现查在架模型名 |
| 上游 `502` / `upstream timeout` | 网关到上游的瞬时抖动，**实测很常见** | 脚本已内置退避重试（最多 4 次）。连续失败就换模型 |
| 样本不足 3 篇（exit=2） | 有效样本 < 3 | 再补样本，或 `--samples` 多指一个目录。**这是硬闸门，不是警告**：宁可拒绝抽档，也不给一份不可信的档案 |
| `--outdir 指到了技能包内部`（exit=2） | 产出目录在包里 | 换包外目录。包内只放文档与脚本，扩展名白名单只允许 `.md .py .txt .json .sh .js .yaml .yml .csv`，图片一律不许进包 |
| `给了 --budget 就必须给单价`（exit=2） | 预算没有单价就没意义 | 补 `--price-in` / `--price-out`（点/百万 token） |
| `样本自相似阈值…疑似混了别的作者`（exit=2） | 样本里混了不属于这个账号的稿子 | 用 `baseline` 看是哪一对相似度最低，把那篇剔掉；确认无误可加 `--force` |
| **风格偏离**（exit=3） | 新稿的某些指标超出容差 | 看 stderr 的逐项偏差；用 `all --iterations 2` 让脚本把偏离项喂回模型定点修。**别把闸门改成只警告** |
| **照抄示例**（exit=3） | 新稿里有句子与样本首尾句太近 | 重跑；或在提示词侧调整（本包已禁止照抄，仍在抄说明模型在偷懒）。三层判据 + 片段级判据都会报 |
| 合规命中「最X」但你看不出问题 | 可能是程度副词作描述 | `最X` 前一个字是计量类名词（量/率/数/分/位/条/次/段/部/集/页/个/天/月/年）且后面紧跟「的/之」时会**豁免但登记**（`gates.compliance.exempted`），报告里会说明；**句首不豁免** |
| 合规命中「第一」，但那是在说"第一次/第一步" | 序数用法不是排他性宣称 | 已排除 `第一次` / `第一步` / `第一天` / `第一周`（实测误伤逼出来的排除项）。仍有残留就人工确认后放行，别改成只警告 |
| `模型返回的不是合法 JSON` | 模型在 JSON 前后多吐了字符 | 脚本已用 `json.JSONDecoder().raw_decode()` 扫第一个完整对象。仍失败就加 `--no-json-mode` 并换模型 |
| 模型没返回 `choices` / 产出为空 | 输出被 `max_tokens` 截断 | 加大 `--max-tokens`（长篇建议 4096 以上） |
| 换了在架模型后正文被截断、或只吐出一段思考 | `models` 列表里有**推理模型**，会先花 completion token 出思维链再给答案 | 用默认的 `deepseek-chat`（实测非推理、最快）；非要用推理模型就把 `--max-tokens` 提高 1.5~2 倍 |
| HTTP 200 但 `model:null`、内容为空、usage 为空 | 把 `deepseek-flash`（`deepseek-chat` 的路由**目标名**）当**请求名**用就是静默失败，状态码骗人 | 请求名用 `deepseek-chat`；要换模型就用 `models` 列表里的名字 |
| 档案文件不是合法 JSON（exit=2） | 用 `profile --out` 但**没加 `--json`**，写出来的是 Markdown | 加 `--json`，或用 `--outdir`（它会同时落 `style-profile.json` 与 `style-profile.md`） |
| 迭代到某一轮分数不再涨、甚至回退 | 定点修到天花板后来回摆 | 本包已保留"偏离最少的一轮"并在 stderr 说明采用了第几轮。想省 token 就 `--iterations 2` |
| Windows 下中文乱码 | 控制台代码页不是 UTF-8 | 先执行 `chcp 65001`，或加 `PYTHONIOENCODING=utf-8` |

**收集排错信息时请附上**：完整命令、`--dry-run` 的输出、原始报错文本、退出码。
**不要在报错信息或截图里带上你的 API Key。**
