# 去背景与换底指南

本文只说**怎么把图抠干净、换对底**。接口参数看 `api-nano_banana.md`，计费口径看 `通用说明.md`。

---

## 一、先定一件事：你要的是「白底图」还是「透明底图」

| 你要的 | 为什么要这个 | 提示词怎么写 |
|---|---|---|
| **纯白底** | 电商主图、平台合规底色、统一店铺视觉 | `去掉背景，换成纯白背景 #FFFFFF` |
| **纯色底** | 品牌色底、证件照换底 | `去掉背景，换成纯色背景 #1E90FF` |
| **透明底** | 免抠素材、后期叠到任意背景上、做贴图 | `去掉背景，只保留主体，输出透明背景` |
| **换场景** | 商品放进使用场景、人像换环境 | `把背景换成 [场景描述]，主体保持原样，光影自然衔接` |

**白底和透明底不是一回事。** 白底是「背景变成了白色」，透明底是「背景没了」。
要叠到别的画面上用，就直接要透明底，别先出白底再自己抠一遍。

## 二、四条提示词模板（直接抄，改场景词就行）

**1）电商主图 · 纯白底**

```
去掉背景，主体保留完整不变形，换成纯白背景 #FFFFFF，边缘干净无残留，
商品居中、留出均匀边距，保留原有材质、纹理与高光细节
```

**2）人像 · 透明底**

```
去掉背景，只保留人物主体，输出透明背景，头发边缘自然无白边，
人物比例与姿态保持原样，不改变肤色与服装颜色
```

**3）证件照 / 形象照 · 指定色底**

```
去掉背景，换成纯色背景 #438EDB，人物居中、双肩完整，
边缘干净，保留原有五官与发丝细节，不改变人物特征
```

**4）商品 · 换使用场景**

```
把商品的背景换成 [原木桌面 + 柔和晨光]，商品保持原样不变形不变色，
投影与光源方向一致，画面自然、有真实感
```

### 让一次就成的三句话

不管哪种要法，把这三句写进去，可用率会明显提高：

- **主体保留完整、不变形** —— 防主体被改形状
- **边缘干净、无白边** —— 防出现残留边
- **保留原有细节 / 材质 / 颜色** —— 防商品被「重新画一遍」

## 三、素材怎么拍 / 怎么选，成图就好一半

| 要点 | 说明 |
|---|---|
| 主体与背景对比度 | 浅色商品别放浅色背景上拍；用深色或高饱和背景垫一下 |
| 主体完整入画 | 主体被裁掉的部分，模型补不出来 |
| 光线均匀 | 强投影、反光会把边缘判断带偏 |
| 分辨率够 | 长边建议 ≥ 1000px；要 2K 成图，原图别太小 |
| 背景别太碎 | 杂乱背景会增加边缘判断难度 |

> 已经拍好的图也能用，只是「对比清晰、光线干净」的原图成品率更高。

## 四、档位怎么选

| 用途 | 建议 | 理由 |
|---|---|---|
| 电商主图、朋友圈、社媒配图 | `nano-banana` · 1K | 24 点一次，够用且最省 |
| 要更稳的主体一致性 | `nano-banana-2` · 1K | 38 点一次 |
| 详情页、需要放大看细节 | `nano-banana-2:official` · 2K | 官方高清，按分辨率分档 |
| 印刷、大幅面物料 | `nano-banana-pro:official` · 4K | 出母版才值得 |

**先算钱再选档。** 1K 的 24 点和 4K 的 61 点起，差两倍多。

## 五、批量换底

批量场景的瓶颈不在接口，在**素材准备**和**并发控制**。推荐流程：

1. **先把原图全部上传**到对象存储 / 图床，导出成一份 URL 清单（每行一个 URL）。
2. **用 `--no-wait` 批量提交**，每次提交记下 `task_id` 和对应的文件名。
3. **统一收结果**：按 `task_id` 查任务，把 `image_url` 下载下来，用原文件名映射保存。
4. **控制并发**：一次别发太多，几十条一批最稳；发完一批再发下一批。

```bash
# 1) 批量提交（示例：urls.txt 每行一个公网图片地址）
while read -r url; do
  python3 scripts/a7w.py call nano_banana submit \
    --body "{\"action\":\"edit\",\"prompt\":\"去掉背景，换成纯白背景 #FFFFFF，主体保留完整，边缘干净\",\"image_urls\":[\"$url\"]}" \
    --no-wait
done < urls.txt

# 2) 收结果（示例：查到 image_url 后下载）
python3 scripts/a7w.py task <task_id>
```

用 Python 写批量更省事：`import` 包里的 `scripts/a7w.py`，直接用
`a7w.call("nano_banana", "submit", {...})`，它自带网络抖动重试与异步轮询。

## 六、出图之后

| 想做的事 | 怎么做 |
|---|---|
| 严格 alpha 通道交付 | 先用提示词出**纯色底**成图，再用本地工具一键转 alpha，边界最可控 |
| 统一尺寸 | 本地批量缩放裁切，别让模型负责尺寸 |
| 统一色调 | 本地批量套一层调色，比逐张重生成便宜得多 |
| 检查边缘 | 放大到 200% 看主体边缘有没有残留色块 |

## 七、常见问题快查

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 出来的图跟原图无关 | `action` 没传 `edit` | 加上 `"action": "edit"` |
| 报参数错误 | `image_urls` 传成了字符串 | 改成数组 `["https://..."]` |
| 主体被改形状 | 提示词没写「保留完整、不变形」 | 补上这三句 |
| 边缘有白边 | 原图主体与背景对比低 | 换更高对比的原图，或补「边缘干净无白边」 |
| 报「未命中可用计费规格」 | 普通模型传了 2K / 4K | 普通模型用 `1K`；高清用 `:official` 模型 |
| 图片 URL 拉不到 | 链接不公开或带鉴权 | 换成匿名可访问的公网直链 |
