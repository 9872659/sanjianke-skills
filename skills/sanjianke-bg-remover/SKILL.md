# 图片一键去背景 · 换底出图

商品图底色不统一、人像要出透明底、海报素材想换个场景 —— 这些都是同一件事：
**把主体从背景里分离出来，再换一个你想要的底。**

**上传一张公网图片，写清你要什么底，约 30 秒拿回成图。** 不用装环境、不用买显卡、
不用懂图像分割。

| 你最关心 | 答案 |
|---|---|
| 多少钱 | **24 点起一次**（0.24 元，1 元 = 100 点），高清档位另计 |
| 要多久 | 异步任务，通常 30 秒内；**查询免费**，可以放心轮询 |
| 要装什么 | **什么都不用装**。包里自带零依赖客户端，或者直接用 `curl` |
| 能拿什么 | 纯白底 / 纯色底 / 指定场景的合成图，1K / 2K / 4K 可选 |
| 能商用吗 | 可以。生成内容的使用与合规责任由使用者承担 |

## 一、四种常见要法，照着抄

| 你要的效果 | `prompt` 里这么写 | 结果 |
|---|---|---|
| **电商主图纯白底** | `去掉背景，主体保留完整，换成纯白背景 #FFFFFF，边缘干净，商品居中，保留原材质与细节` | 一张白底商品图 |
| **透明底 / 免抠素材** | `去掉背景，只保留主体，输出透明背景 PNG，边缘干净无白边，保持原分辨率` | 一张去背主体图 |
| **换到指定纯色底** | `去掉背景，换成纯色背景 #1E90FF，主体不变形、不改色，边缘自然过渡` | 一张指定色底图 |
| **换到另一张背景图** | `把主体的背景换成 [场景描述]，主体保持原样、光影自然衔接、比例正确` | 一张合成图 |

提示词只说**你要什么**，不用教模型怎么做。**把「保留主体、边缘干净、不变形」写进去**，
这三句最影响可用率。

## 二、三分钟跑通

### 第一步：拿到你自己的 Key

到 **[api.a7w.cn](https://api.a7w.cn/)** 注册，在控制台创建一个 API Key（形如 `sk-...`），
填进环境变量：

```bash
export A7W_API_KEY=sk-你的key      # Windows: $env:A7W_API_KEY="sk-你的key"
```

### 第二步：提交去背景任务

`action` 传 `edit`（基于参考图编辑），`image_urls` 里放**原图的公网地址**：

```bash
curl -sS -X POST "https://api.a7w.cn/api/v1/apps/nano_banana/submit" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "edit",
    "prompt": "去掉背景，主体保留完整，换成纯白背景 #FFFFFF，边缘干净，商品居中",
    "model": "nano-banana",
    "image_urls": ["https://你的存储/商品图.jpg"],
    "aspect_ratio": "1:1"
  }'
```

返回里带一个 `task_id`，记下来：

```json
{ "code": 1, "msg": "success", "data": { "task_id": "task_xxxx", "status": "pending", "frozen_points": 24 } }
```

### 第三步：拿成图（免费）

```bash
curl -sS -X POST "https://api.a7w.cn/api/v1/apps/nano_banana/query" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"task_id":"<上一步的 task_id>"}'
```

`data.result.status` 走到 `completed` 时，`data.result.image_url` 就是成图地址，直接下载即可。

### 零安装用法

```bash
export A7W_API_KEY=sk-你的key

# 看这个插件有哪些接口与参数
python3 scripts/a7w.py schema nano_banana

# 去背景换白底（客户端会自动轮询到结束，并可直接落盘）
python3 scripts/a7w.py call nano_banana submit \
  --body '{"action":"edit","prompt":"去掉背景，换成纯白背景 #FFFFFF，主体保留完整，边缘干净","image_urls":["https://你的存储/商品图.jpg"]}' \
  --out 白底图.png
```

`--out` 会自动把返回的结果地址下载到本地；加 `--no-wait` 则只提交、不等结果。

## 四、素材要求

| 要求 | 说明 |
|---|---|
| 格式 | JPG / PNG / WebP 等常见图片格式 |
| 访问 | **必须是公网可访问的 URL**，不支持本地路径、不支持 Base64 |
| 分辨率 | 建议长边 ≥ 1000px；原图越清晰，成图边缘越干净 |
| 主体 | 主体与背景**对比度越高越好**（浅色商品别放在浅色背景上拍） |
| 数量 | `image_urls` 是数组，可传多张做参考；换底场景传 1 张原图即可 |

> 本地文件先传到对象存储 / 图床拿到公网链接，再来调。

## 五、常见坑

| 坑 | 表现 | 怎么避 |
|---|---|---|
| **忘了传 `action: "edit"`** | 变成凭空文生图，跟原图没关系 | 基于原图改图，`action` **必须**是 `edit` |
| **`image_urls` 写成字符串** | 报参数错误 | 它是**数组**：`["https://.../a.jpg"]` |
| **拿本地路径当入参** | 报参数错误 | 一律用**公网可访问的 URL** |
| **没写「保留主体、边缘干净」** | 主体被改形状、出现白边 | 把这三句写进 `prompt`，比事后修图省事 |
| **普通模型传了 2K / 4K** | 报「未命中可用计费规格」 | 普通模型只吃 `1K`；要高清档位用 `:official` 结尾的模型 |
| **重复提交** | 扣两次钱 | 先记 `task_id`，用 `query`（免费）确认状态 |
| **拿 `code == 0` 判断成功** | 明明成功却判成失败 | 平台成功码是 **`1`**（`{"code":1,"msg":"success"}`） |

## 六、批量换底

做店铺装修、矩阵号素材、批量铺货时经常一次要处理几十上百张。思路是：
**先把所有原图传到对象存储拿到公网 URL，再逐个提交，并控制并发**，
用 `--no-wait` 批量提交、之后再按 `task_id` 统一收结果，比串行等结果快得多。

`references/去背景指南.md` 里给了批量脚本的写法和并发建议。
