# 合规红线与判定口径

## 0. 免责声明（必读）

本文件与 `scripts/run.py` 里的词表是**启发式自检工具**：

- 词表来自公开经验整理，**不是小红书官方审核规则**，也**不构成法律意见**；
- 平台规则与类目资质要求会变，高风险类目（医疗、保健食品、金融、母婴、
  特殊化妆品）**必须由人工复核**并以其官方规则为准；
- 本包不提供"谐音绕过审核"类规避方案。命中一律建议改为合规表述。

## 2. 小红书平台特有红线

同一个表达在不同平台的风险不一样，所以单列一张表。

| 类型 | 典型词 | 等级 | 为什么 |
|---|---|---|---|
| 站外导流 | 微信、vx、VX、手机号、电话、扣扣、QQ、私信、加我、联系我 | 高 | 小红书对站外导流零容忍，出现联系方式即高危 |
| 站外电商 | 淘宝、天猫、京东、拼多多、链接在、评论区有链接 | 高 | 引导到站外电商平台，属违规导流 |
| **功效/身体结果** | 美白、祛斑、祛痘、淡斑、抗痘、生发、防脱、消炎、杀菌、抑菌、排毒、养胃、助眠、提高免疫 | 高 | 功效宣称，普通内容不得使用（特殊化妆品、保健食品需资质） |
| **医疗器械/药品** | 医用、药用、药妆、械字号、消字号、蓝帽子、疗程 | 高 | 须与注册证范围一致 |
| 虚假种草 | 亲测、实测、绝对、闭眼入、人手一个、全网 | 中 | 绝对化体验表述，笔记社区严查 |
| 诱导互动 | 点赞、收藏、关注我才能看、三连 | 中 | 诱导互动会被限流 |

**这份清单比广告法严的部分就是"功效/身体结果"那一行**：
「美白」「淡斑」「助眠」在日常生活里是普通说法，在小红书笔记里是高危表述。
本包按小红书口径抓，不按广告法口径抓。

## 3. 两处语境豁免（**都是被实测误伤逼出来的**）

"宁可多报也别漏报"在这里代价过高：**一个正确写法的稿子被判违规，
使用者就会开始无视闸门，闸门等于废了。** 所以有两处刻意写得很窄的豁免。

### 3.1「最X」：描述数据极值 vs 商品宣称

```
放过（并登记，不静默）：  播放量最低的视频 / 播放量最高的那条
照拦：                    最低价 / 最便宜 / 课时最低的课程 / 最好的选择
```

条件：`最X` **前一个字是计量类名词**（量/率/数/分/位/条/次/段/部/集/页/个/天/月/年）
**且**后面紧跟「的」或「之」。

豁免词表刻意**不含** `时/款/种/家/价`：「课时最低的课程」「单价最低」
都是真实的价格宣称形态，必须照拦。

**句首不豁免**：`最好用的产品` 在句首，永远照拦（实现上靠 `bool(before)` 那一步 ——
空字符串在 Python 里 `"" in "量率数…"` 是 `True`，漏了它句首的绝对化用语会被全部误豁免）。

### 3.2「第一」：叙事序数 vs 排他性宣称

**这一条是本包真机实测第一轮逼出来的。** 首次真机跑，3 篇笔记**全部**因为同一个理由
被判高风险拦截 ——"命中『第一』类排他性表述"。但真实原文是：

```
第一个坑就来了 / 第一个月做了 4 部 / 第一部 80 集的剧 / 我的第一版流程
```

这是"第一章"式的顺序词，不是排他性宣称。**三篇全红、理由全错**。

```
放过（并登记）：  第一个坑 / 第一个月 / 第一部剧 / 第一版流程 / 第 3 个月
照拦：            排名第一 / 销量第一 / 行业第一 / 第一名 / 第一品牌 / 第一选择 / 全国第一
不匹配（本来就不拦）：  第一次（正则里的 `(?!次)` 排掉了）
```

条件：「第」+ 1~2 位阿拉伯或中文数字 + 计量类量词（个/种/部/集/条/次/段/页/章/节/期/
款/年/月/天/周/秒/分钟/遍/轮/套/门/项/步/版/批/届/档/层/把/回/关）。

另外给「第一」那条正则加了 `(?<![国网史])`：不重复接「全国第一 / 全网第一 / 史上第一」，
那三种整串已经被"绝对化价格承诺"那条抓走了；少了这个 lookbehind，
「全国第一」会额外多报一条理由不对的「第一」，而序数豁免会把它误放过一半。

### 3.3「唯一」：否定式用法 vs 排他性宣称

```
放过：  看片这件事不该当成唯一入口（…'唯一入口' 仍照拦，见下）
```

实测原文是「看片这件事不是不该做，是不该当成唯一入口」—— 这是**反对排他**，
不是排他性宣称。所以只在「唯一 + 名词」时才判命中：
`唯一入口 / 唯一标准 / 唯一选择 / 唯一的办法 / 独家` 照拦。

## 4. 等级与退出码

| 等级 | 含义 | 处理 |
|---|---|---|
| 高 | 几乎一定触发审核 | **必须改**，硬闸门拦截，退出码 3 |
| 中 | 视上下文可能违规 | 硬闸门同样拦截（本库统一口径）；改掉或人工确认后重跑 |
| 低 | 需人工判断 | 同上 |

**本库的统一口径是"低风险也拦截"** —— 与 `sanjianke-multiplat-rewrite` /
`title-workshop` / `image-factory` 一致。想放行就改文本，不要改成只警告。

被豁免的疑似命中会在报告里**明确打印**（`gates.compliance.exempted`），**不静默放过**。

## 5. 判定口径的已知边界

| 边界 | 说明 |
|---|---|
| 按子串匹配 | 不理解语义，会有误报。两处豁免就是为了压误报，但仍然不是语义判断 |
| 不看图片 | **封面大字必须按同样口径人工自查**（出图提示词过了闸门 ≠ 图上文字没问题） |
| 不做谐音识别 | 故意改字规避的写法抓不到，且这类写法本身不建议使用 |
| 不替代人工 | 高风险类目必须人工复核 |
| 词表会过时 | 平台规则会变，词表在 `scripts/run.py` 的 `BANNED_PATTERNS` / `PLATFORM_REDLINES` 里，可自行维护 |

- [n03] 合规：命中「唯一入口」(中/广告法)
