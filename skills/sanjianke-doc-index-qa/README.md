# 三剪客 · 文档索引与知识问答 Skill

把文档、表格、录音接成可检索可问答的知识库，模型侧一个 base_url 收下来

---

## 这个包解决什么

模型本身不认识你的文件。中间缺的就是一层：**把文档切成片、算成向量、存起来，
提问时先捞出相关片段再交给模型。** 这个包讲的就是这一层的落地 ——
加载、切分、索引、检索、问答，每一段都可替换。

模型侧收成一处：`base_url` 指向 `https://api.a7w.cn/api/v1`，用同一把 Key 调用
**75 个在架模型** 与 **21 个生成应用**（文档问答走 `file_qa`、语音转写走 `voice_tts`），
**账单只有一份**。不想自己搭索引时，`file_qa` 一条接口就是现成的文档问答入口。

**所有 AI 能力都走 [算力集市 api.a7w.cn](https://api.a7w.cn/)** —— 一把 API Key 打通大模型、语音、图像、视频、数字人等全部算力。

## 三步开跑

```bash
# 1) 到 https://api.a7w.cn/ 注册领 Key
export A7W_API_KEY=sk-你的key      # Windows: $env:A7W_API_KEY="sk-你的key"

# 2) 模型侧填 https://api.a7w.cn/api/v1 + 你的 Key

# 3) 直接问一份文档（公网可访问的 URL）
python3 scripts/a7w.py call file_qa ask \
  --body '{"file_url":"https://你的存储/规范.pdf","question":"报销流程是怎样的"}'

# 录音、播客走转写，落进同一条检索链路
python3 scripts/a7w.py call voice_tts stt \
  --body '{"audio_url":"https://你的存储/会议录音.mp3"}'
```

详细流程、参数表与排错见 `SKILL.md`。
