# 三剪客 · 关系图可视化引擎 Skill

G6：关系图可视化引擎 的安装、常用命令与避坑要点

---

## 前置条件

- 数据必须是"节点 + 边"的关系结构，不是统计数据或地理数据
- 已确认要接入的大版本（v4 / v5 API 完全不同）；npm `latest` 标签当前指向 5.x 系列
- 节点有唯一 `id`，边的 `source` / `target` 能对应到已有节点
- 页面里有存在且宽高非 0 的 DOM 容器
- 已评估节点规模与布局耗时，知道是否需要裁剪 / 聚合

---

## 使用

让 Agent 加载本 Skill 后，按下面的顺序推进：

1. **先判适用性**：要画的是关系网络图才用它。统计图表、流程图、地图、纯表格都命中"不要用它"，直接换方案。
2. **锁定大版本**：执行 `npm ls @antv/g6` 或看 `package.json`。v5 是配置式写法（`new Graph({ container, data, layout, behaviors })`），v4 是 `new G6.Graph()` + `graph.data()` + `graph.render()`，两者不能混。
3. **准备数据与容器**：`{ nodes: [...], edges: [...] }`，节点带 `id`；容器给足宽高。
4. **配三件事**：`layout`（布局）、`behaviors`（交互）、`node` / `edge`（样式与配色），然后 `graph.render()`。
5. **收尾**：数据更新走 `setData` + 渲染；组件卸载时 `graph.destroy()`。

包内的 `SKILL.md` 有完整的六块内容：什么时候用 / 不用、安装、常用操作、常见坑、权限与用途说明、能力边界。布局、行为、插件、主题的准确名称清单以所装版本对应的官方文档为准。

## 依赖

- 运行环境：现代浏览器；服务端渲染需按官方文档配置 Node 侧环境
- 安装方式：`npm install @antv/g6` 或 `yarn add @antv/g6`
- 浏览器直引：需要包内 UMD 产物（`dist/g6.min.js`），全局命名空间与产物路径以实际版本为准
- 可选：GPU / WASM 加速布局需要相应运行环境支持
- React 项目可配合官方生态里的 React 封装使用
- 本包不包含第三方项目源码

---

## 安全

- 不内嵌任何密钥
- 本包自身不发起网络请求；关系数据由调用方提供，数据来源与脱敏由调用方负责
- 渲染在浏览器端完成，不写本地文件、不常驻后台进程
- 大数据量布局会大量占用浏览器 CPU / GPU，接入前评估设备承受能力
- 引入依赖前确认版本来源可信，并锁定大版本，避免被自动升级打断
