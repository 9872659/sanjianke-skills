# 三剪客 · Logseq 大纲双链笔记 Skill

Logseq：以大纲和双向链接为核心的知识管理工具，笔记就是本地 Markdown 文件，还带一个能直接读写图库的命令行。

---

## 前置条件

- 桌面端：从官方 Releases 下载安装包；Linux 也可以用官方提供的一键安装脚本。
- 只是试用：直接用网页版，不需要本地安装。
- 想用命令行：需要 Node.js 运行时，以及从源码构建出的命令行运行产物。
- 用数据库版之前先接受一点：它目前是 beta，官方提示存在数据丢失可能，重要资料请先做好备份。
- 命令行默认工作根目录是 `~/logseq`，图库在 `<root-dir>/graphs`。

---

## 使用

1. 先分清是文件版还是数据库版——命令行只操作数据库版图库。
2. 用 `logseq graph list` 拿到真实图库名，后续命令都按这个名字引用。
3. 常用动作：`upsert block` 写内容、`search` 找内容、`show` 看内容树、`query` 跑 Datalog。
4. 脚本里统一加 `--output json`；人类阅读时用默认的 human 输出。
5. 批量改动前先 `graph backup create` 打快照；导出归档用 `graph export`。
6. 出问题先跑 `logseq doctor`，再 `logseq server list` 看后台服务状态。

## 依赖

- Node.js 运行时（命令行）。
- 桌面端安装包或网页版浏览器（界面）。
- 从源码构建的运行产物（如果要自己跑命令行）。
- 可选：Logseq 云端账号（同步与协作）、系统钥匙串（存加密图库密码）。

---

## 安全

- 不内嵌任何密钥，登录态与加密密码都要在执行时提供。
- `~/logseq/auth.json` 里含 id / access / refresh 三类 token，不要提交进仓库或贴进日志。
- 加密图库的密码优先存系统钥匙串；回落到本地文件时注意文件权限。
- 不要把图库目录放进第三方自动同步盘，容易把数据写坏；要么用官方同步，要么用 Git 这类显式提交的方式。
- 数据库版处于 beta，关键数据务必保留独立备份。
- 备份只覆盖主数据库文件，不要把它当成完整快照。
- 用命令行直连图库做批量删除前，先确认目标范围，并保留一份可恢复的快照。
