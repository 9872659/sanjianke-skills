# 三条路线与引擎差异

## 一、先做判断：这条片子是哪种"糊"

**这一步比选工具重要。** 同样是糊，成因不同，超分能做的事天差地别。

### 四类成因

| 现象 | 成因 | 超分有效性 | 该走哪条路线 |
|---|---|---|---|
| 放大看有**方块、蚊噪、边缘毛刺** | 编码压缩伤（码率太低、被平台二次转码） | ✅ **提升明显** | 本地 ffmpeg 往往就够 |
| 整体蒙一层、细节糊成一团 | 解析力不足（源分辨率就低） | ⚠️ **能做，但有上限** | AI 超清模型 |
| 有运动模糊 / 失焦 | 拍摄问题（快门慢、跑焦） | ❌ **救不了** | 不要做，浪费钱 |
| 有噪点但结构还在 | 高 ISO 拍摄 | ✅ 降噪后提升明显 | 本地降噪 + 锐化 |

### 一条可操作的判据

把原片**截图放大到 200%**：

- 还能看到**结构和边缘**（哪怕带着方块）→ 细节还在，**值得超分**
- 放大后是**一片平滑色块** → 细节已经没了，超分只会得到"更平滑的糊"

### 为什么运动模糊救不了

超分模型做的是"根据已有像素推断缺失的高频细节"。运动模糊是**曝光期间像素被物理抹平**了——信息在拍摄那一刻就没进传感器。任何模型都只能靠"猜"，猜出来的不是你原来的画面。

**遇到运动模糊，正确做法是补拍或换素材，不是超分。**

## 二、三条路线的定位

| | 在线站 | api.a7w.cn | 本地 ffmpeg |
|---|---|---|---|
| **入口** | vr.a7w.cn | `flashvsr` 插件 | 自己的机器 |
| **引擎** | AI 超清模型 | FlashVSR 专用模型 | lanczos 插值 + cas 锐化 |
| **成本** | 0.3 元/秒 | 按平台计费 | 零 |
| **速度** | 看排队 | 看排队 | 看 CPU |
| **离线** | ❌ | ❌ | ✅ |
| **批量** | 界面里排队（并发 1~4） | 脚本化，最灵活 | 完全自己控制 |
| **上限** | 4K | 看模型 | 只受机器限制 |
| **能造细节吗** | ✅ 能 | ✅ 能 | ❌ **不能** |

### 决策树

```
源片有运动模糊 / 失焦？
├─ 是 → 别做超分，补拍或换素材
└─ 否 → 源片分辨率是多少？
        ├─ ≥ 2160（4K） → 不需要超分；只是被压缩花了就用本地去块+锐化
        ├─ 1080 左右，被压缩花了 → 【本地 ffmpeg】性价比最高
        ├─ < 1080，但细节结构还在 → 【在线站】几条 / 【api.a7w.cn】几十条以上
        └─ < 480，老设备素材 → 【在线站 / API】上 AI 模型，效果最明显
```

## 三、引擎差异详解

### AI 超清模型（生成式）

代表：阿里云百炼 · 爱诗 **PixVerse**（`pixverse/pixverse-upscale`）

**原理**：扩散类模型，根据低清输入**生成**高频细节。

- **强项**：低清素材提升最明显；对压缩伤也有修复作用
- **弱项**：按秒计费；对运动模糊无效；生成出来的"细节"是模型推断的，不是原始画面
- **注意**：拿已经是 4K 的源片去跑，**不会有提升**（4K 档要求输入源低于 4K）

### FlashVSR（视频超分专用模型）

代表：`api.a7w.cn` 的 `flashvsr` 插件

**原理**：面向视频序列的超分模型，会利用**帧间信息**。

- **强项**：视频连续性好，适合整段处理，不容易出现逐帧不一致的闪烁
- **弱项**：需要把素材放到**公网可访问的地址**（不支持本地路径）
- **参数**：只有 `input_url`（必填）、`duration`（可空，平台会自己探测）、`mode`

### 传统插值 + 锐化（非 AI）

代表：ffmpeg 的 `lanczos` + `cas` + `hqdn3d`

**原理**：纯数学。lanczos 做高质量重采样，cas 做对比度自适应锐化，hqdn3d 做时域降噪。**不生成任何新信息。**

- **强项**：**免费、离线、可批量、结果可复现**；对"被平台压花的片子"改善观感很明显
- **弱项**：**造不出真实细节**。它让画面看起来更"实"，不是更"真"
- **什么时候够用**：源片本来是 1080p，只是发出去被压糊了 —— 这种情况的本质是"压缩损失"，不是"分辨率不足"，去块 + 锐化正好对症

> **一句话区分**：
> 源片**信息还在**（有方块但结构清楚）→ 传统插值就够，别花冤枉钱
> 源片**信息真缺**（本身就低清）→ 才需要上 AI 模型

## 四、常见误判

| 误判 | 实际情况 |
|---|---|
| "超分能让糊片变大片" | 只能改善观感，不能凭空造细节 |
| "AI 超分什么都能修" | 运动模糊、失焦、严重过曝都修不了 |
| "分辨率越高越好" | 源片 1080p 拉到 4K，文件大 4 倍，观感提升很小 |
| "本地免费所以更好" | 该上 AI 的时候用本地，等于白做 |
| "一次拉到 4K 一步到位" | 分档处理（720→1080→4K）有时比一步到位稳 |
| "多线程更快" | 实测相反，见 `local-ffmpeg.md` |
