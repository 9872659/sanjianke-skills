# 三剪客 · 用自然语言驱动网页抓取 Skill

不写 CSS 选择器，用一句自然语言描述你要什么，让 LLM 带着图流程把网页抓成结构化数据；支持多页批处理、生成抓取脚本、读取本地文档。

---

## 前置条件

- Python 环境：当前主版本声明 `Python >=3.12, <4.0`（以 PyPI 项目页元数据为准）。先 `python --version` 对一下版本。
- 建议使用独立虚拟环境：本库依赖链较重（含 LangChain 与浏览器自动化），装进全局环境容易和已有库顶版本。
- 装完 Python 包后必须执行 `playwright install`，否则抓不了网页内容。
- 模型准备：云端模型需要对应服务方的 API Key；本地模型需要先装 Ollama 并 `ollama pull` 拉取模型。
- 抓取前确认目标站点的 robots.txt 与服务条款允许自动抓取。

---

## 使用

1. 先装库、再装浏览器内核、最后配模型——三步缺一不可。
2. 选一个图流程：单页抽取用单页图；一批 URL 用多页图；想固化流程就用生成脚本的图。
3. 写提示词时把想要的字段说清楚，字段名最好直接写进提示词，减少结果漂移。
4. 跑之前先用一两个页面验证，确认提示词稳定、字段齐了，再批量跑。
5. 批量跑时先估算模型调用次数与费用——多页与并行版本会成倍放大开销。
6. 涉敏数据用本地模型，并置 `SCRAPEGRAPHAI_TELEMETRY_ENABLED=false` 关闭遥测。

## 安全

- 不内嵌任何密钥；API Key 由使用者自行提供，请用环境变量或密钥管理工具注入，不要硬编码进脚本。
- 默认会收集匿名使用指标，可通过环境变量退出：把 `SCRAPEGRAPHAI_TELEMETRY_ENABLED` 置为 `false` 即可关闭。
- 使用云端模型时，抓到的页面内容会发送给模型服务方；处理敏感数据请改用本地模型。
- 抓取行为受目标站点条款与当地法规约束，请自行确认授权与合规；本 Skill 不代替合规审查。
- 开源版本不提供托管的代理与反爬能力，这部分策略由使用者自行负责配置。
