# 三剪客 · AI 短视频自动化生产框架 Skill

给一个主题，让它自己写脚本、配音、找素材、上字幕并渲染出片：环境与密钥准备、Docker/Colab 起步、网页界面用法、本地依赖版本要求和常见坑。

---

## 前置条件

- 优先准备 Docker；不想在本机装依赖就用 Colab，两者是上游给出的推荐路线。
- 本地裸装路线需要上游指定版本的 Python、ffmpeg 与较新的语音转写依赖，具体版本见仓库安装说明。
- 需要脚本生成、语音合成、素材检索三类外部服务的密钥；翻译配音还需要对应的语音服务配置。
- 运行环境要能访问上述外部服务，并预留足够磁盘与内存存放素材和成片。
- 本地与容器形态都会监听 31415 端口，请确认端口未被占用。

---

## 使用

1. 按 `SKILL.md` 的「安装」一节选一条路线：Docker、Colab 或本地。
2. 准备好密钥文件（`.env`），确认变量名与仓库配置模块实际读取的名称一致。
3. 起服务并打开网页界面，先在界面里核对密钥与素材库。
4. 选任务类型：短视频、长视频还是整片翻译配音，对应不同引擎。
5. 先用一个测试主题跑通全链路，确认脚本、配音、素材、字幕、渲染都正常，再批量生产。
6. 详细命令、引擎职责划分与排错对照，见 `SKILL.md`。

## 依赖

- 上游仓库：https://github.com/RayVentura/ShortGPT
- 容器路线：Docker。
- 本地路线：上游指定版本的 Python、ffmpeg 与语音转写依赖；Python 依赖见仓库 `requirements.txt`。
- 外部服务：脚本生成、语音合成、素材检索各需一个服务的密钥。
- 运行时会调用 ffmpeg 等外部程序完成音视频处理。
- 不包含任何模型权重，全部能力来自外部服务。

---

## 安全

- 不内嵌任何密钥；所有密钥通过环境变量或本地配置文件注入，不要写进镜像、代码仓库或日志。
- `.env` 文件不要提交到版本库，也不要在截图与工单里粘贴真实密钥。
- 网页界面与容器服务默认监听本地端口，不要直接暴露到公网；确需远程访问时加反向代理与鉴权。
- 素材来自公开素材站与图片搜索，商用前请逐项确认素材授权与平台条款。
- 对他人视频做翻译配音涉及原始内容的版权与声音权益，只在自有或已获授权的内容上执行。
- 外部服务会把你的主题与文案发送到第三方，涉密或未公开的内容不要走这条流水线。
- 自动化产出的脚本可能包含事实性错误，对外发布前必须人工核稿。
