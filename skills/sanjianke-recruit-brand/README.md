# 招聘雇主品牌 一条 JD 视频 14 元

**一条 JD 视频 14.54 元，一天 6 条 80.34 元。** 前 30 秒 HR 出镜，把岗位、城市、薪资、职责一次讲清；后 15 秒切办公空镜，团队氛围落成画面；末尾定格招聘海报，把投递入口和截止日期推上去。

校招换一套话术，`--track campus` 就是 30 秒版：公司介绍 → 培养体系 → 成长故事 → 投递入口。

`plan` 一条命令把 6 项里的**脚本部分**全部写好（四段分镜、口播、3 条标题、平台描述、6 个标签、6 张图 prompt、九宫格排版、一周排期、成本单），落在 `~/.a7w/recruit/<social|campus>-<日期>/`，纯本地、不联网、0 点。

命名规则：`日期_校招或社招_岗位_城市_平台_秒数`，一个岗位一个目录，交付单一页能对得上。

## 社招 45 秒的四段结构

| 时间 | 段落 | 谁在说 | 画面 | 口播干什么 |
|---|---|---|---|---|
| 0-15.3 秒 | 岗位亮点 | 数字人出镜 | HR 正面半身像，工牌可见，左侧留字幕位 | 报公司 + 岗位 + 城市 + 薪资 + 职责，一句一个信息 |
| 15.3-24.3 秒 | 团队氛围 | 办公空镜 | 开放办公区横移，两人对屏讨论，白板有排期 | 报团队人数 + 汇报线 + 协作方式 |
| 24.3-39.1 秒 | 成长路径 | 数字人出镜 | HR 换第二个机位，身后是职级墙与导师位 | 报职级起点、几步到哪儿、去年几位走过、平均几年 |
| 39.1-45 秒 | 投递方式 | 海报定格 | 二维码与投递入口居中，底部留截止日期 | 报投递入口 + 截止日期 + 初筛时效 |

秒数按权重分（34 / 20 / 33 / 13），`--seconds 60` 时四段等比缩放，口播稿不用手改。

## 员工见证九宫格

1080x1080，三位见证各占三格：

- 第 1 格：头像，正方形裁切、正面、肩线在格内 2/3
- 第 2 格：「姓名｜岗位｜入职年限」一行放得下，例：小林｜后端开发｜入职 2 年
- 第 3 格：一句话见证，14 字内，写具体的事，不写形容词

三个人选固定成三个视角：**入职 1 年的新人讲上手速度 / 入职 3 年的骨干讲成长与晋升 / 应届转正的校招生讲培养体系**。三个视角，一套模板，`plan` 直接写进交付单。

## 三条用钱换来的规矩

**一、数字人那条 schema 接口是收费的。** `GET /api/v1/apps/pic_lipsync` 会命中 `/apps/<app>/*` 的通配计价，按该应用 flat 单价即时扣费、不退（实测 dressing_diffusion 200 点、nano_banana 72 点各一笔）。本包只用 `GET /api/v1/apps` 列表 + `GET /api/v1/pricing` 两条 cost:0 确认 pic_lipsync 在架，`doctor` 一条 submit 都不发。

**二、「缺参数会停在扣费之前」在 pic_lipsync 上不成立。** `/submit` 是 reserve_sync 口径：先按秒冻结点数，再参数校验，再全额退 —— 净额 0，但钱包被短暂动过。所以本包不给它做探针，估时直接按 15 点/秒算。

**三、text 模式自带口播，一条片子只要一次 avatar。** `content` 给文案，`audio_url` 只当参考音色，数字人段不用再单独出 tts；只有空镜那段才走 `voice`。顺手记一条：pic_lipsync 输出实测 480x832 / 24fps，成片合成时再放大到 1080x1920。

## 合规检查（`qc` 已经做成默认动作）

- **六类限定零出现**：年龄、性别、婚育、户籍、身高体重、形象。岗位要求换成能力描述：「能独立负责一条业务线」比「35 岁以下」招得准。
- **薪资写区间与结构**：`15-25K·14薪` 一处一个数字，「薪资面议」这类写法换掉。
- **招聘主体照写**：公司全称写进文案，内推码与官网入口一致，投递入口带截止日期。
- **成长路径给具体名词**：职级表起点与终点、训练营名字、导师带教、轮岗月数、去年走通的人数与平均年限。
- **夸大与承诺换成可核对数字**：团队人数、晋升年限、截止日期、初筛时效；员工见证写事不写形容词。

## 退出码

| 码 | 含义 |
|---|---|
| `0` | 成功 |
| `2` | 用法错（缺 `--text` / `--image` / `--file`、秒数越界、选项缩写） |
| `3` | 自检或合规检查没过 |
| `4` | 需要确认 —— 没给 `--yes` |
| `5` | 预算不足 —— **一个请求都不发** |
| `6` | 调用失败 |
| `1` | 内部错误 |
| `130` | 被 Ctrl-C 中断 |

`--json` 成功是 `{"ok": true, ...}`，失败是 `{"ok": false, "exit": 5, "error": {"kind": "budget", "message": "…"}}`，stdout 只有一个 JSON 文档；`--json` 写在子命令前后都可以。
