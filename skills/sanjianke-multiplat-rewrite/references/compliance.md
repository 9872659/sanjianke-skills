# 合规红线与本地闸门

> **免责声明**：本包内置的违禁词表与判定口径是**启发式自检工具**，来自公开经验整理，
> **不构成法律意见，也不代表任何平台的官方审核标准**（官方标准不公开、且会变）。
> 内容的使用与合规责任由使用者承担；医疗、保健食品、金融、母婴、特殊化妆品等
> 高风险类目必须人工复核。

本包内置两层合规模板 + 六道硬闸门，全部**确定性、零成本、不依赖模型自评**。
为什么不让模型自己判合规：模型的自评会被自己的措辞带跑——它刚写完那句话，
天然倾向于认为那句话没问题。合规判定必须是外挂的、逐字匹配的。

## 一、广告法违禁词（全平台通用）

按风险等级分三档，命中即扣分（高 40 / 中 20 / 低 8，取最重一档，不叠加）。

### 高风险（命中即退出码 3，必须人工复核）

| 类别 | 典型表述 | 依据 |
|---|---|---|
| 最高级用语 | 最好 / 最佳 / 最优 / 最快 / 最先进 / 最流行 | 广告法第九条禁止「最高级」用语 |
| 绝对化价格 | 全网最低 / 史上最便宜 / 全国第一 | 绝对化价格承诺，无法举证 |
| 排他性排名 | 第一名 / 排名第一 / 销量第一 / 行业第一 / TOP 1 / No.1 | 「第一」类排他性表述 |
| 权威性词汇 | 国家级 / 世界级 / 全球级 / 国际级 | 明令禁止 |
| 绝对化效果 | 100% / 百分之百 / 百分百 | 绝对化效果承诺 |
| 保证类 | 绝对有效 / 保证成功 / 无效退款 | 绝对化保证与效果担保 |
| 医疗功效 | 根治 / 治愈 / 药到病除 / 无副作用 / 抗癌 / 降血压 | 非药品医疗器械不得宣称 |
| 投资承诺 | 零风险 / 稳赚 / 躺赚 / 保本 / 保收益 / 日入过万 / 月入十万 | 投资类收益承诺 |
| 教育承诺 | 包过 / 保过 / 保录取 / 保证提分 / 不过退费 / 100% 就业 | 教育培训效果承诺 |
| 虚构背书 | 央视推荐 / 国家认证 / 权威认证 / 官方指定 | 不得虚构权威背书 |
| 特殊品类 | 催情 / 壮阳 / 丰胸 / 减肥药 / 美白针 / 生发神器 | 特殊功效与特殊品类 |

### 中风险（扣 20 分，同样拦截）

虚假优惠（免费领 / 0 元购）、促销时限（秒杀 / 限时抢 / 最后一天）、
排他性表述（独家 / 唯一 / 首个 / 首创 / 领先技术）、
成分宣称（纯天然 / 无添加 / 零添加）、
站外导流（点击链接 / 加微信 / 私信我 / 扫码加 / vx / 加V）、
标题党（震惊 / 惊呆 / 不看后悔 / 删前必看）。

### 低风险（扣 8 分）

标点堆砌（连续两个以上感叹号、连续三个以上问号）——容易被判标题党或低质内容。

## 二、平台特有红线

**同一个表达在不同平台的风险不一样**，所以单列一张表。

典型例子：**「加微信」在公众号里是常规运营话术，在小红书里直接判违规导流。**

| 平台 | 高危（级别 = 高） | 中危 |
|---|---|---|
| 公众号 | —— | 诱导分享/关注（关注领 / 转发朋友圈领 / 集赞） |
| 小红书 | 站外导流（微信 / vx / 手机号 / 私信 / 加我 / 联系我）、引导到站外电商（淘宝 / 京东 / 链接在评论区） | 虚假种草与绝对化体验（亲测 / 实测 / 闭眼入 / 人手一个 / 全网）、诱导互动（点赞 / 收藏 / 关注才能看 / 三连） |
| 抖音 | 站外导流（微信 / vx / 手机号 / 私信 / 主页有链接） | 带货引导（点击链接 / 小黄车 / 橱窗 / 购买链接） |
| 知乎 | 私域引流（私信我 / 加微信 / 公众号 / 知识星球） | 无依据权威自称（我是专家 / 我是医生 / 官方认证）、商业转化（付费咨询 / 课程 / 训练营） |
| 头条 | —— | 站外导流（微信 / 私信我 / 加我）、引导下载（点击下方 / 下载APP） |

**小红书为什么最严**：小红书对站外导流的处置是直接限流甚至封号，
而且它对「虚假种草」的判定范围比广告法更宽——「亲测」这类词在别处是口语，
在小红书笔记里会被拿来核对是否有真实消费记录。所以在小红书这一列，
「联系我」和「淘宝链接」都是高危。

## 三、虚构数据（本地闸门查不到，必须人工复核）

违禁词表是**逐字匹配**的，它管不了「凭空编了一个数字」。

**模型在这一点上非常不可靠**：它会为了「让文章更有说服力」顺手造一个数据，
而且造得很像真的（「实测 3 天涨了 2000 粉」）。

所以改写完成后请检查：

- [ ] 稿子里出现的**每一个数字**，都能在原稿或 `--evidence` 里找到出处
- [ ] 稿子里出现的**每一个案例 / 机构 / 头衔**，都能找到出处
- [ ] 没有把原稿的「据说 / 大概」升级成确定表述
- [ ] 没有把原稿的「某个平台」升级成具体平台名（如果原稿没写）

`plan` 子命令的 `needs` 字段会诚实告诉你**原稿缺什么**——
如果它说「原稿没有任何数据支撑」，那这一版就不该出现数据。

## 四、合规扣分与退出码

| 命中 | 扣分 | 是否拦截 |
|---|---|---|
| 广告法违禁词（高） | 40 | 是 |
| 广告法违禁词（中） | 20 | 是 |
| 广告法违禁词（低） | 8 | 是 |
| 平台特有红线 | 按等级同上 | 是 |
| 占位符残留 | 40 | 是 |
| 照抄提示词示例 | 30 | 是 |
| 字数超出区间 | 按偏离程度，上限 60 | 是 |
| 结构缺项（标题/正文/结尾） | 每项 25 | 是 |
| 结尾无行动指令 | 25 | 是 |
| 话题标签数不符 | 8 | 否（软扣分） |
| emoji 策略不符 | 5 | 否（软扣分） |
| 段落风格不符 | 0 | 否（只报告） |

**任一硬闸门命中 → 标红 + 汇总到 stderr + 退出码 3。**

得分 = `100 − 各项扣分之和`（下限 0）。

**为什么标签数和 emoji 只扣分不拦截**：硬闸门的标准是「发出去会出事」。
标签数量少 2 个是质量问题，不是合规问题。把风格问题也做成硬闸门，
会让工具在正常使用中频繁返回非 0，最后没人看退出码——闸门就废了。

## 四之二、「最X」的语境豁免（误伤也是缺陷）

合规闸门自己也会误伤，而**一个正确写法的稿子被判违规，代价比漏报更大**——
使用者会开始无视闸门，闸门等于废了。

实测事故：原稿改写后有一句「回头翻一条自己播放量最低的视频」，
被「最X」规则判成**高风险**「广告法第九条禁止最高级用语」并整篇拦截。
这个诊断是错的——那是在描述自己的数据，不是对商品/服务的绝对化宣称。

所以加了一条**很窄**的语境豁免：

- 条件：`最X` 前一个字是**计量类名词**（量/率/数/分/位/条/次/段/部/集/页/个/天/月/年）
  **且** `最X` 后面紧跟「的」或「之」
- 动作：**整处放过**，但在产出里登记 `gates.compliance.exempted`，
  报告与 stderr 都会明说「本地放过 1 处疑似绝对化用语」——**不静默放过**

校准（实测）：

| 文本 | 判定 | 对不对 |
|---|---|---|
| 回头翻一条自己播放量最低的视频 | 放过 | ✅ 真误伤，该放过 |
| 全网最低价 | 高 | ✅ 真违规，该拦 |
| 价格最低 / 成本最低 / 单价最低 | 高 | ✅ 真违规，该拦 |
| 课时最低的课程 | 高 | ✅ 真违规，该拦（豁免词表**刻意不含** `时`/`款`/`种`/`家`/`价`） |
| 最好的产品 | 高 | ✅ 真违规，该拦 |

**已知残留**：「最X」作程度副词描述时仍会报（实测「片头三秒直接上冲突最强的那一段」
被判高风险）。这类判定需要理解语义，正则做不到。本包**选择保留这条误报**，
不继续堆特例——每加一条特例就多一个放过真违规的口子，
而合规闸门的误判方向必须是「宁可多报」。

> 写这段代码时踩到的坑：`before in MEASURE_PREFIX` 里的 `before` 在句首是空字符串，
> 而 Python 里 `"" in "量率数…"` 是 `True`——**句首的「最好/最低」会被全部误豁免**。
> 必须写成 `bool(before) and before in MEASURE_PREFIX`。
> 这个 bug 是被罐头数据测出来的，不是看出来的。

## 五、高风险类目的额外提醒

以下类目的内容，**任何自动自检都不足以作为发布依据**，必须人工复核：

- **医疗 / 药品 / 医疗器械**：疗效宣称是刑事红线级别
- **保健食品**：不得宣称疾病预防或治疗功能
- **金融 / 理财 / 保险**：收益承诺、风险表述都有强监管
- **教育培训**：效果承诺、升学承诺被明令禁止
- **母婴 / 特殊化妆品**：成分宣称需与检验报告一致
- **房产 / 汽车**：价格与配置表述需与实物一致

**建议**：这类内容不要用本包直接出终稿。本包可以做结构改写（开场 / 段落 / 结尾），
但**事实性表述必须逐句人工核对后再发**。
