# 平台规格表（唯一事实来源）

这张表就是 `scripts/run.py` 里的 `PLATFORMS` 常量。**提示词从它读，本地闸门也从它读。**
改某个平台的字数区间、段落长度、标签数量，**只改这张表 / 那个常量，不要去改逻辑**。

> 口径来源：各平台公开创作规范 + 三剪客团队自己的投放经验整理。
> 这是**经验口径**，不是平台官方审核标准（官方标准不公开、且会变）。
> 区间取值偏保守，宁窄不宽——窄了最多让模型多改一版，宽了会放出「看起来达标其实不像那个平台」的稿子。

## 总览

| key | 平台 | 正文区间 | 段数 | 单段字数 | 标签 | emoji | 标题字数 |
|---|---|---|---|---|---|---|---|
| `wechat` | 公众号 | 1200~2200 | 6~12 | 80~220 | 0 | 否 | 14~24 |
| `xiaohongshu` | 小红书 | 350~800 | 4~10 | 10~60 | 5~8 | 可（2~6 个） | 10~20 |
| `douyin` | 抖音 | 300~600 | 6~14 | 8~40 | 3~5 | 否 | 12~20 |
| `zhihu` | 知乎 | 800~1500 | 5~12 | 60~260 | 0~3 | 否 | 14~26 |
| `toutiao` | 头条 | 600~1200 | 5~12 | 30~120 | 0~3 | 否 | 16~26 |

**字数怎么算**：正文字数 = 去掉所有空白字符后的字符数。中文一个字算一个，中文标点算一个，
emoji 算一个。**不含**标题、结尾引导、话题标签。

为什么去掉空白：抖音口播稿是一句一行，如果换行算进字数，同一个内容「排成一段」和
「排成二十行」会差出二十个字，五个平台共用的这把尺子就废了。

**段数怎么算**：正文按换行拆，一个非空行 = 一段。抖音的一行是一个气口，
公众号的一行是一个自然段——含义不同，但计数口径统一。

## 公众号（`wechat`）

| 维度 | 规格 |
|---|---|
| 正文区间 | 1200~2200 字 |
| 段数 / 单段 | 6~12 段，每段 80~220 字 |
| 开场 | 现象 / 数据 / 一个具体场景切入，**前两段不出现结论** |
| 结尾 | 把全文结论收成一句能被直接转述的话，再补一句关注或留言引导（问一个具体问题） |
| 标签 | 不用话题标签（`hashtags` 返回空数组） |
| emoji | 不用 |
| 标题 | 双段式或完整陈述句，14~24 字，偏理性，有信息势能；可用 `｜` 分隔主副题 |
| 语感 | 书面但不端着，讲道理不讲情绪，允许长句与转折，段落之间有递进 |

**硬性要求**

1. 全文要有清晰的递进结构：现象 → 拆解 → 结论，不能是并列的要点清单
2. 至少有 2 处具体的、来自原稿的事实或例子，不许自己编数字

**为什么这么定**：公众号是唯一撑得起长文的平台。它的阅读场景是「主动打开 + 愿意读几分钟」，
所以信息量本身就是价值。反过来，公众号最怕的是「一段一句的短句流」——
那是在用小红书的节奏写公众号，读者会觉得内容很空。

## 小红书（`xiaohongshu`）

| 维度 | 规格 |
|---|---|
| 正文区间 | 350~800 字 |
| 段数 / 单段 | 4~10 段，每段 10~60 字（**不超过 3 行**） |
| 开场 | 第一人称身份 + 一个具体痛点，第一句就要说人话 |
| 结尾 | 口语化互动引导：收藏 / 评论 / 「你们还有别的办法吗」，不要总结陈词 |
| 标签 | 5~8 个，放正文最后 |
| emoji | 可以用 2~6 个点缀，别每句都挂 |
| 标题 | 口语短标题，10~20 字，像朋友说话；可用 1 个 emoji 开头 |
| 语感 | 像朋友发消息，短句、多分段、允许语气词（真的 / 反正 / 亲测） |

**硬性要求**

1. 每段不超过 3 行，段与段之间空行
2. 必须有 5~8 个话题标签，放在正文最后
3. 不许出现站外联系方式（微信号 / 手机号 / 私信我 / 加V）

**为什么这么定**：小红书的阅读场景是「滑到 → 三秒决定要不要看」，
所以第一句必须自我暴露（我是谁、我遇到什么问题），而不是铺陈背景。
段短是因为手机屏幕上超过三行的段落会被划走。标签数是分发机制：
小红书的话题标签直接参与流量分配，少于 5 个等于放弃了免费的曝光入口。

## 抖音（`douyin`）

| 维度 | 规格 |
|---|---|
| 正文区间 | 300~600 字（≈ 60~120 秒口播） |
| 段数 / 单段 | 6~14 行，每行 8~40 字 |
| 开场 | 前 3 秒必须出钩子：反常识结论 / 直接的问题 / 「先别急着…」 |
| 结尾 | 口播式引导：一句关注理由 + 一句评论区互动 |
| 标签 | 3~5 个 |
| emoji | 不用（这是要念出来的稿子） |
| 标题 | 口语钩子，12~20 字，能直接念出来 |
| 语感 | 纯口语，一句一行（一行一个气口），短句为主，允许「你」「我」对说 |

**硬性要求**

1. 一句一行，每行都是一口气能念完的短句
2. 全篇不许出现书面连接词（因此 / 综上 / 首先其次最后）
3. 必须能直接念：不出现括号注释、不出现 emoji、不出现 Markdown 记号

**为什么这么定**：这是本包里唯一一份**要被念出来**的稿子。
书面语在嘴上念会立刻暴露——「因此」念出来像播音员，「所以」才像人说话。
一句一行不是为了好看，是因为写稿时用换行切气口，录制时就不用二次断句。
字数 300~600 对应 60~120 秒，是按正常语速 5 字/秒估的。

## 知乎（`zhihu`）

| 维度 | 规格 |
|---|---|
| 正文区间 | 800~1500 字 |
| 段数 / 单段 | 5~12 段，每段 60~260 字 |
| 开场 | 结论前置或反直觉判断切入 |
| 结尾 | 收在一条可操作的判断，或一句克制的求赞同 |
| 标签 | 0~3 个 |
| emoji | 不用 |
| 标题 | 提问式或结论前置，14~26 字，专业、有信息密度 |
| 语感 | 克制、给依据，像业内人士在答一个真问题；允许分点，但每点要有一句展开 |

**硬性要求**

1. 至少有一处明确给出「什么情况下这个结论不成立」的边界条件
2. 不许出现「我是专家」「官方认证」这类无依据的权威自称

**为什么这么定**：知乎的读者是在**找答案**，不是在找乐子。
所以结论前置比悬念开场有效得多——他要先判断这篇值不值得读。
「边界条件」这条硬性要求来自知乎的社区文化：只讲结论不讲适用范围的回答会被踩，
主动交代「这个结论什么时候不成立」反而是可信度最高的写法。

## 头条（`toutiao`）

| 维度 | 规格 |
|---|---|
| 正文区间 | 600~1200 字 |
| 段数 / 单段 | 5~12 段，每段 30~120 字 |
| 开场 | 悬念或数字切入，第一段就给信息增量 |
| 结尾 | 一句总结 + 一句泛化的讨论引导，不要硬求关注 |
| 标签 | 0~3 个 |
| emoji | 不用 |
| 标题 | 悬念式或数字式，16~26 字，通俗但不标题党 |
| 语感 | 通俗、信息前置、句子偏短，面向泛人群，少用行话 |

**硬性要求**

1. 每段只讲一件事，段落短、信息密度高
2. 不许标题党：标题里许诺的内容，正文必须真的给到

**为什么这么定**：头条的流量来自信息流推荐，读者是**泛人群**，没有前置语境。
所以行话要换成人话。同时头条对标题党的判定很严——
标题许诺了正文没给到，会直接压推荐量，所以「标题党」被写成了一条硬性要求而不是风格建议。

## 本地闸门按这张表查什么

| 闸门 | 用表里的哪个字段 | 不达标会怎样 |
|---|---|---|
| 字数区间 | `chars` | **硬闸门**：标红 + 按偏离程度扣分（上限 60 分）+ 退出码 3 |
| 结构完整性 | 产出必须有标题 + 正文 + 结尾引导 | **硬闸门**：缺项标红 + 每项扣 25 分 + 退出码 3 |
| 结尾引导有效性 | `cta`（每平台一张正则） | **硬闸门**：结尾没有该平台的行动词等于没引导 |
| 话题标签数 | `hashtags` | 软扣分 8 分（不拦截） |
| emoji 策略 | `emoji` | 软扣分 5 分（不拦截） |
| 段落风格 | `para_chars` / `para_count` | 软扣分（不拦截，风格问题不是发布风险） |
| 平台特有红线 | `PLATFORM_REDLINES` | **硬闸门**：标红 + 扣分 + 退出码 3 |

### 结尾引导（`cta`）为什么必须按平台判定

实测踩出来的坑：头条的结尾规格是「一句总结 + 一句**泛化的讨论引导**（你身边有这种情况吗），
不要硬求关注」。模型照着规格写了「你身边有做二创的朋友吗，他们卡在哪一步？」——
而闸门原来的通用动作词表只有「关注/收藏/评论」，于是判它「结尾没有行动指令」并整篇拦下。

**闸门与规格自相矛盾，等于用闸门否定自己写的规格。**
所以 CTA 判定必须跟着平台走：

| 平台 | 结尾要出现的动作词 |
|---|---|
| 公众号 | 关注 / 留言 / 在看 / 转发 |
| 小红书 | 收藏 / 评论 / 告诉我 / 评论区教教我 |
| 抖音 | 关注 / 点赞 / 评论区扣 1 |
| 知乎 | 赞同 / 评论 / 欢迎补充反例 |
| 头条 | 讨论引导（你身边…吗 / 他们卡在哪一步 / 评论区说说） |

**通用词表只作兜底**，正常路径走 `PLATFORMS[platform]["cta"]`。

**为什么只有前四项算硬闸门**：硬闸门的标准是「发出去会出事」。
字数不够是**质量不达标**（读者体验差），合规违禁是**会被罚**（平台处罚 / 广告法），
两者不是一回事。把风格问题也做成硬闸门，会让工具在正常使用中频繁退出码非 0，
最后没人看退出码——闸门就废了。
