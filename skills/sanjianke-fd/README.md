# 三剪客 · 极速文件查找 Skill

fd：find 的现代替代品——默认并发遍历、默认忽略 .gitignore、语法就是 `fd 关键词`，还能把命中结果直接批量交给一条命令处理

---

## 前置条件

- 一个能跑命令的终端；`fd` 在 Windows / macOS / Linux 上都有官方预编译包
- 从包管理器或官方 Releases 安装（源码编译需要 Rust 工具链）
- **Debian / Ubuntu 用户请注意**：这两个发行版上包名是 `fd-find`，装完可执行文件叫 **`fdfind`**，直接敲 `fd` 会报 command not found
- 不需要账号、Key 或网络服务；查找过程全程本地
- 如果要用 `-x` / `-X` 批量处理结果，需要先准备好你要调用的那条命令本身

---

## 使用

最短跑通路径：

```bash
fd --version                       # 1. 确认装好，并确认命令名（可能是 fdfind）
fd needle                          # 2. 在当前目录找文件名含 needle 的条目
fd -e py                           # 3. 找所有 .py 文件
fd -t f -S +100M                   # 4. 找大于 100MB 的普通文件
fd -u 'config'                     # 5. 连隐藏文件与被忽略的都一起找
```

日常最省事的三条：

```bash
fd -e jpg -x convert {} {.}.png    # 逐个转换（占位符 {} 是完整路径、{.} 是去扩展名的路径）
fd -e rs -X wc -l                  # 一次性把所有结果交给 wc -l
fd -q pattern && echo 命中          # 只关心"有没有"，不关心结果内容
```

排错顺序：命令找不到 → 确认是不是要用 `fdfind`；结果为空 → 依次检查隐藏文件（`-H`）、忽略规则（`-I` / `-u`）、以及模式是不是被当成正则解释了（要通配就加 `-g`）。

## 依赖

- **运行环境**：Windows / macOS / Linux（含 musl 静态构建的各架构），官方提供单文件可执行程序，不需要额外运行时
- **安装方式**：apt / dnf / pacman / brew / winget / scoop / choco 等包管理器，或 `cargo install fd-find` 从源码编译
- **版本差异**：包管理器仓库里的版本可能明显落后于上游最新版，先用 `fd --version` 确认；功能开关在不同版本间可能有增删
- **可选依赖**：`-x` / `-X` 调用的外部命令（如 `convert`、`clang-format`、`wc`）需要自行安装
- **配置文件**：全局忽略文件默认位于 `$XDG_CONFIG_HOME/fd/ignore`，未设置时是 `$HOME/.config/fd/ignore`
- **环境变量**：`LS_COLORS` 影响着色，`NO_COLOR` 关闭着色

## 安全

- 不内嵌任何密钥：本 Skill 不包含账号、token 或任何凭据
- **`fd` 自身是只读的**：它只遍历目录元数据并打印结果，不修改、不删除任何文件
- **风险来自 `-x` / `-X`**：这两个开关会把你指定的命令对每个命中结果执行一遍。如果那条命令是 `rm`、`mv`、`sed -i` 之类的破坏性操作，错误的结果集会直接变成数据损失
  - 执行破坏性命令前，先不带执行开关跑一次，确认命中集合完全正确
  - 用 `-1` 或 `--max-results 3` 在最小样本上试跑
  - 注意 `-x` 默认并行执行，顺序不可预测
- **忽略文件会被读取**：`.gitignore`、`.ignore`、`.fdignore` 与全局忽略文件都会被解析——它们只影响筛选结果，不执行其中内容
- **权限报错默认静默**：遍历中遇到的 permission denied 默认不显示，容易让人误判成"没有匹配"；需要显式加 `--show-errors` 才可见
- **不要对根目录做无条件全盘遍历**：`fd pattern /` 这类命令会深入系统目录，既慢又可能掩盖真正的目标；能用 `-d` 限深度或指定子目录就别图省事
