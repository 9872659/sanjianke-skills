# Java 工程接入大模型与 Agent 能力 Skill

把大模型与 Agent 能力接进你自己的 Java 工程：一个 Key、一个 base_url 统一调用 75 个在架模型，
并覆盖工具声明、Agent 运行时、RAG、MCP 与可观测。

---

## 前置条件

- **JDK 8+** 即可起步；涉及 MCP、Skills 这类较新的模块通常要求 **JDK 17+**，按你实际引入的模块定。
- 构建工具用工程原有的 **Maven / Gradle**，不需要额外装什么；接入前先用
  `mvn -q dependency:tree` 核对坐标与版本，**做到「先核对再写代码」**。
- **Python 3.8+**（可选）：只用于包内零依赖客户端 `scripts/a7w.py`，只用标准库，不需要安装任何第三方包。
- 一个 **api.a7w.cn 账号与 API Key**，形如 `sk-...`；Key 通过环境变量 `A7W_API_KEY` 注入。
- 能访问 `https://api.a7w.cn` 的网络出口（内网 / CI 需放行该域名）。
- Windows 用户：文档里的 `python3` 换成 `python.exe`。

## 使用

拿到这个 Skill 后，Agent 会按这套顺序干活：

1. **先核对坐标**。用 `mvn dependency:tree` 与本地库确认要引的模块到底解析到哪个版本，别一边写代码一边试坐标。
2. **接模型**。把 `base_url` 指向 `https://api.a7w.cn/api/v1`、Key 从 `A7W_API_KEY` 注入，跑通第一条 `chat/completions`。
3. **收口接口层**。工程里只暴露一个 `ChatModel` 门面，业务代码不直接 new 客户端。
4. **声明工具**。工具少就用注解式（`@ToolDef` / `@ToolParam`），要动态生成就用编程式（自己实现 `Tool`）。
5. **按轮次挂工具组**，并做一次**启动期全量工具名重名校验**，防工具泄漏。
6. **加拦截器**。记住 Body 在责任链末端才构建；要给之后创建的所有模型挂条件拦截器，走全局注册入口。
7. **需要 RAG 就串 RAG**：加载 → 解析 → 切分 → Embedding → 检索 →（可选）Rerank。
8. **需要多轮工具调用 / 审批 / 挂起恢复 / 重启不丢状态**，再上 Agent 运行时；否则不必。
9. **排错用逐层加回法**：加流式 → 加一个工具 → 加一个工具组 → 加一个拦截器，哪一步坏了问题就在那一步。

完整命令、参数与避坑表见 `SKILL.md`；接入十一步见 `references/integration.md`。

## 依赖

- **Java 侧**：按你工程实际选择的那套模块坐标引入（`<your-groupId>` / `<your-artifactId>` / `<VERSION>`），
  由 Maven / Gradle 解析。核心模块不强制挂在 Spring 容器里，普通 Java 程序也能用。
- **模型侧**：任何说 OpenAI 协议的 Java 客户端，只改 `base_url` 与 `model` 两处。
  一个 Key 可调 75 个在架模型，Embedding / Rerank 也走同一套地址与同一把 Key。
- **Python 侧**：`scripts/a7w.py`，**只用标准库**（`urllib`），无第三方依赖。
- **网络**：需要能访问 `https://api.a7w.cn`；MCP 远程传输还需能访问你自选的 MCP Server 地址。

## 安全

- **不内嵌任何密钥**，也不代付费用。请求只发往 `api.a7w.cn`，不发送到其他任何地址。
- **Key 等同于余额**：只从环境变量 `A7W_API_KEY` 或 `~/.a7w/config.json` 读，
  不要写进代码、不要提交进 Git。
- **Key 可单独设消费上限（quota）**，打满后这个 Key 就调不动了 —— 这跟账号余额是两回事，报错也不同码。
- **Skills 会给模型「读说明 + 执行」的能力**：生产环境务必配沙箱，并限制可访问的目录与网络出口。
- **工具与回执要幂等**：回调接口按 `task_id` 幂等并返回 2xx，否则平台会按 1–10 次重试，容易重复消费。
- **异步任务提交时就预冻结点数**：网络超时先查 `task_id` 再决定是否重提，不要直接重发。
- **生成内容的合规责任由使用者承担**，本 Skill 不提供任何合规结论。
