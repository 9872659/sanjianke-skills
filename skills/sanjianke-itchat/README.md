# 三剪客 · 个人微信号自动化接口 Skill

用 Python 驱动个人微信号收发消息的接口库：扫码登录后注册消息处理器，做自动回复、附件收发、群消息处理。

> **重要前提**：它依赖的网页版登录通道自 2017 年起先对新注册账号关闭、2019 年起进一步整体收紧，仓库本身也长期未更新，文档标注的 Python 支持是 2.7 与 3.5。**本 Skill 以接口参考、历史脚本维护与风险说明为主，不建议用于新项目。**

---

## 前置条件

- 已确认需求是否真的必须走个人号：能改用平台官方开放接口或企业侧方案时，优先改道。
- 使用**不用于重要用途的测试账号**，并清楚自动化行为可能触发平台风控。
- 独立虚拟环境：该库面向早期 Python 生态，避免老依赖影响主环境。
- 接受一个事实：登录通道是否对某个账号开放由平台决定，**不是本地配置能解决的**，本 Skill 不提供绕过方式。

---

## 使用

1. 先读 `SKILL.md` 的「什么时候用 / 不用」——多数新需求在这一步就会被判定为不该用。
2. 如果确实要跑：`pip install itchat`，然后在独立虚拟环境里尝试登录。
3. 接口用法按官方文档站对照：`auto_login`（含 `enableCmdQR` / `hotReload` / `loginCallback` / `exitCallback` / `statusStorageDir`）、`msg_register`、`run`、`send`、`search_friends`、`new_instance`、`logout`。
4. 消息处理用装饰器按类型注册；处理器返回值即回复内容；`msg.user.send()` 主动发消息；`msg.download()` 下载附件。
5. 群消息用 `isGroupChat=True` 注册，用 `msg.isAt` 判断是否被 @。
6. **登录失败就果断换路线**，不要对同一条通道反复重试。

完整的六块说明（什么时候用 / 不用、安装、常用操作、常见坑、权限与用途说明、能力边界）见 `SKILL.md`。

## 安全

- 不内嵌任何密钥。
- 登录态本身就是凭证，等价于你的个人账号身份：状态文件不要提交到版本库，也不要复制给他人。
- 登录后会生成二维码图片，`loginCallback` 未设置时默认自动删除；请自行确认工作目录里没有遗留。
- **账号风险**：自动化行为可能触发平台风控，批量加好友、群发等操作风险极高，且大概率违反平台规则。
- **合规前置**：使用前请自行确认平台规则与适用法规；本 Skill 不提供绕过平台限制的方案，也不代替合规审查。
- 不要把本库用于向他人发送未获同意的营销内容。
