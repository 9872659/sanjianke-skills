一堆 PDF、Word、网页躺在硬盘里，你希望有人问「退款流程是什么」时，它能翻出正确的那一段并答上来 —— 这就是知识库问答（RAG）。

**你不用自己部署 embedding，也不用自己部署对话模型。** 检索链路在本地跑，模型这一层全部换成
[算力集市 api.a7w.cn](https://api.a7w.cn/) 的 OpenAI 兼容网关：**一个 `base_url`、一把 Key、
换 `model` 就是换模型**，75 个在架大模型随便挑。

## 一、两条路线，按需选

| 你想要的 | 走哪条 | 代价 |
|---|---|---|
| **马上对一个公网文档提问**，不折腾切分与检索 | a7w 自带的文档问答接口 `file_qa` | 接口**免费**，把文档放到公网可访问的地址即可 |
| **自己掌控切分、召回、拼 prompt** | 本地流水线 + a7w 模型网关 | 免费额度内本地跑，只有模型调用扣点 |
| **要语义检索（按意思找）而不只是关键词** | 本地向量检索 + a7w 网关做 embedding | 向量这一层自己存，embedding 与生成都走 a7w |

**建议顺序**：先用 `file_qa` 跑通「能答上来」这件事，再决定要不要自建流水线。
两条路线可以并存，共用同一把 Key。

## 二、三分钟跑通

### 第一步：拿到你自己的 Key

到 **[api.a7w.cn](https://api.a7w.cn/)** 注册，在控制台创建一个 API Key（形如 `sk-...`），
填进环境变量：

```bash
export A7W_API_KEY=sk-你的key      # Windows: $env:A7W_API_KEY="sk-你的key"
```

验一下这把 Key 通不通（列一下你这个账号可用的应用）：

```bash
curl -sS "https://api.a7w.cn/api/v1/apps" \
  -H "Authorization: Bearer $A7W_API_KEY"
```

### 第二步：先拿到可用模型名（不要猜）

模型上下架很频繁，**动手前先查一次**：

```bash
curl -sS "https://api.a7w.cn/api/v1/models" \
  -H "Authorization: Bearer $A7W_API_KEY"
```

记下你要用的对话模型名（例如 `DeepSeek-V4-Flash`），后面填进 `model` 字段。

### 第三步：把检索到的片段交给模型（这就是 RAG 的核心一步）

```bash
curl -sS -X POST "https://api.a7w.cn/api/v1/chat/completions" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "DeepSeek-V4-Flash",
    "messages": [
      {"role": "system", "content": "只根据资料回答；资料里没有就说不知道，不要编。"},
      {"role": "user", "content": "资料：\n1) 退款需在收货后 7 天内发起，需保持商品完好。\n2) 生鲜类不支持无理由退款。\n\n问题：退款期限是多久？"}
    ],
    "temperature": 0.2,
    "max_tokens": 512
  }'
```

返回里 `choices[0].message.content` 就是答案。
**RAG 做的事情，就是把「资料」这一段换成你检索出来的真实片段** —— 检索在你本地跑，生成走 a7w。

### 第四步：免自建的文档问答（可选，免费）

把文档放到公网可访问的地址，直接问：

```bash
# 应用类接口的统一路径就是 /api/v1/apps/<应用代号>/<接口代号>
# 参数名先查一次，别猜：
python3 scripts/a7w.py schema file_qa

python3 scripts/a7w.py call file_qa chat --json '{"文档地址参数":"https://你的存储/产品手册.pdf","问题参数":"退款流程是什么？"}'
```

`file_qa` 的接口代号是 `chat`（文件问答，同步）与 `parse`（剧本解析，异步），
**两个接口实测都是免费的**。参数名以 `schema file_qa` 的实际返回为准。

## 四、素材要求

| 要求 | 说明 |
|---|---|
| 文档格式 | PDF / Word / Markdown / 纯文本都可以；**本地先转成纯文本再切分**最稳 |
| 传给接口的地址 | **必须是公网可访问的 URL**，不支持本地路径、不支持 Base64 |
| 切分粒度 | 中文建议 300~500 字一块，重叠 10%~15%，**按标题层级切比按字数切更好** |
| 召回数量 | 从 `top_k = 3` 起步，看答不上来再往上加；块给多了既贵又容易跑题 |
| 上下文长度 | 拼进去的资料总量要留足余量，超长会被截断；长文档先摘要再拼 |
| 表格与图片 | 表格建议转成 Markdown 保留结构；图片走 OCR 或直接不入库 |

> 本地文件先传到对象存储 / 图床拿到公网链接，再走接口。

## 五、常见坑

| 坑 | 表现 | 怎么避 |
|---|---|---|
| **模型名靠猜** | 404 或直接报错 | 动手前先跑 `GET /api/v1/models`，**以接口返回为准** |
| **拿本地路径当入参** | 报参数错误 | 一律用**公网可访问的 URL** |
| **参数名靠猜** | 报参数缺失 | 先跑 `python3 scripts/a7w.py schema <应用>` 看真实字段名 |
| **拿 `code == 0` 判断成功** | 明明成功却判成失败 | 平台成功码是 **`1`**（`{"code":1,"msg":"success"}`） |
| **`max_tokens` 给得太小** | `content` 返回 `null`、`finish_reason` 是 `length` | 推理型模型会先花 token 说思维链，正文被挤没了；**先把这个值调大**，不是接口坏了 |
| **把思维链当答案** | 输出里混着推理过程 | 思维链字段在不同线路上是 `reasoning` 或 `reasoning_content`，两个都取一下 |
| **重复提交异步任务** | 扣两次钱 | 先记 `task_id`，用查询接口确认状态（查询免费） |
| **一次塞几十个片段** | 又贵又跑题、还容易超长 | 先召回 3~5 块，用「只根据资料回答」兜住幻觉 |
| **把 Key 写进代码** | 泄露即等于泄露余额 | 只从环境变量 `A7W_API_KEY` 或 `~/.a7w/config.json` 读 |
| **PowerShell 吃掉 JSON 引号** | 请求体被截断 | 改用 `python3 scripts/a7w.py call <应用> <接口> --json '{...}'`，把请求体交给客户端脚本处理 |

## 六、计费

1 元 = 100 点，1 点 = ¥0.01，**按量计费、没有月费**。

| 动作 | 点数 | 折合 |
|---|---|---|
| 本地切分、本地建索引、本地检索 | **0** | 免费，不经过平台 |
| `file_qa` 文件问答 / 剧本解析 | **0** | 免费（实测口径） |
| 查询异步任务、列应用、看接口 schema | **0** | 免费 |
| 模型网关 `chat/completions` | 按 tokens 计点 | 各模型单价不同，输入与输出分别计价；**以实际扣费为准** |

- **控成本的第一旋钮是 `max_tokens`**，第二旋钮是召回块数（拼进去多少 token）。
- 平台同时给出**标准价**与**租户实际结算价**两套字段，两者可能差很多；
  **做预算一律按实际扣费算**，每次返回里的 `usage` 就是本次真实用量。
- 调用失败会退款；异步任务提交时预冻结点数，完成后多退少补。
