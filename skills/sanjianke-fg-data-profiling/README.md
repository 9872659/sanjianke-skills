# 三剪客 · 数据画像与质量体检 Skill

接手一张陌生数据表时先做一次体检：一行代码生成包含单变量、多变量、时间序列、文本分析的报告，输出 HTML / JSON / Notebook 控件，并标注需要处理的数据质量问题

---

## 前置条件

- **Python 3 环境**，并建议独立虚拟环境。
- **pandas**。数据以 DataFrame 为输入，pandas 会随包一起装好；注意与已有环境的版本兼容。
- **较新的浏览器**。报告是 HTML + CSS 渲染的，查看时需要能正常渲染的浏览器。
- **老用户迁移**：环境里不能残留旧包（原名 `ydata-profiling`），否则会与新包冲突。
- **可选扩展**：要在 Jupyter 里用控件查看装 `[notebook]`；要更细的 Unicode 文本分析装 `[unicode]`；走 Spark 处理大数据装 `[pyspark]`。

---

## 使用

面向「先摸清数据底细」的任务，推荐顺序：

1. 读 `SKILL.md` 的「什么时候用 / 不用」，确认需求是探索性分析与质量体检，而不是清洗或门禁校验。
2. 按「安装」一节把包装好；从旧包迁移过来的，先卸旧再装新，并把代码里的导入名改成 `data_profiling`。
3. 用 pandas 读入数据，先确认表头、编码、分隔符都正确；确认列类型基本符合预期。
4. 数据量较大时先抽样，再生成报告；不要拿几十万行以上直接全量跑。
5. 一行生成报告对象：`ProfileReport(df, title="...")`，再按需要 `to_file()` / `to_json()` / `to_widgets()` / `to_notebook_iframe()`。
6. 报告出来后，重点看「警报」与「总览」两部分，逐条回到业务语义判断哪些需要处理。
7. 含敏感数据的表，先用官方敏感数据相关配置处理，再决定报告的分发范围。

CLI 用法适合标准 CSV 快速出报告；参数与配置项以官方文档为准。

## 安全

- 不内嵌任何密钥：本 Skill 正文不含账号、密钥或端点。
- 不需要任何凭证即可使用；不要为了生成报告去引入不必要的凭据配置。
- **报告本身是数据泄露面**：生成的 HTML 会呈现列级样例、分布与相关性等细节。含个人信息、业务敏感字段的数据，务必先用官方敏感数据处理配置处理，并在分发前确认范围。
- 输出目录应选择有访问控制的路径，避免把报告写到 Web 可直接访问的静态目录下。
- 大数据集分析会占用较多内存与磁盘，在共享机器上运行前先确认资源余量，避免影响同机其他任务。
- 本 Skill 只做诊断，不修改原始数据；任何清洗动作都要在被明确授权后另行执行。
