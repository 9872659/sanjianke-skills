# 通用说明（本 Skill 用到的 api.a7w.cn 能力共用）

## 一、响应信封

所有应用接口返回统一信封：

```json
{ "code": 1, "msg": "success", "data": { } }
```

- **`code` 为 `1` 才是成功**（HTTP 200 不等于业务成功，失败时也可能返回 HTTP 200）
- 失败时 `data` 可能是空数组，错误原因在 `msg`
- 少数裸对象端点（如账单、价格）没有 `code/data` 外壳，直接返回对象

## 二、权限与用途说明

| 能力 | 是否申请 | 用途 |
|---|---|---|
| 网络访问 | **申请** | 调用 `api.a7w.cn` 的应用接口（本 Skill 唯一的联网行为） |
| 读取文件 | 仅读取用户指定的输入文件（图片/音频/视频/文本） | 作为接口的素材入参 |
| 写入文件 | 仅在传入 `--out` 时 | 保存接口返回的 JSON 或下载产物 |
| 凭证 | 读取**使用者自己**提供的 API Key | 从 `~/.a7w/config.json` 或环境变量读取 |
| 子进程 / 后台常驻 | 不申请 | 脚本执行完即退出 |

**不内嵌任何密钥。** 脚本只把 Key 发往 `api.a7w.cn`，不发送到其他任何地址。

## 三、关于异步任务

标记为「异步」的接口是**任务制**：提交后返回 `task_id`，需要轮询到完成。
`a7w.py call` 默认**自动轮询到结束**再返回，也可以手动控制：

```bash
# 只提交，不等结果
python3 scripts/a7w.py call <app> <api> --body '{...}' --no-wait

# 之后用 task_id 查状态（免费）
python3 scripts/a7w.py task <task_id>
```

- 异步任务在**提交时会预冻结点数**，完成后按实际用量多退少补
- **不要重复提交同一个任务** —— 每次提交都可能产生费用；网络超时先查 `task_id`
- 不想轮询就传 `callback_url`，任务终态时平台会 POST 通知你的地址

## 四、常见错误

| 返回 | 含义 | 处理 |
|---|---|---|
| HTTP 401 | Key 无效或过期 | 重新创建 Key 后 `login` |
| HTTP 402 / `code:402` | 点数不足 | 去算力中心充值；错误信息里有本次所需点数 |
| `Invalid.Params` | 参数不合法 | 用 `schema <app>` 核对参数名与必填项 |
| HTTP 404 | 应用 / 接口代码拼错 | 应用代码用**下划线**（`nano_banana`，不是 `nano-banana`） |
| 任务 `status: failed` | 上游处理失败 | 看 `error` 字段；换素材或稍后重试 |
| HTTP 429 | 排队任务达上限 | 降并发，等队列消化后重试 |

## 五、计费口径说明

平台的计价单位是**点数**，**1 元 = 100 点、1 点 = 0.01 元**。

平台同时给出两套价格字段：

- `fixed_price` / `input_price`：**标准价**，对外公示用
- `tenant_fixed_points` / `tenant_points_per_1k_input`：**你所在租户的实际结算价**

两者可能不一致。**做预算用租户价，最终以实际扣费为准** —— 每次调用返回的
`data.usage.points_cost` 就是本次真实扣费，也可以去用户中心核对账单。

计费口径随能力不同：图片按**点数/张**或分辨率档位、视频按**点数/秒**（分辨率分档）、
语音合成按**点数/千字**、语音识别按**点数/次**、文档问答按**点数/百万 Token**、
工具类按**点数/次**。

## 六、能力边界

- **不提供 API Key**：Key 必须由使用者自己申请
- **不代付费用**：调用消耗的是使用者自己账号的点数
- **不保证可用性**：接口由平台提供，可用性、限流与计费以站内为准
- **不替代内容合规审查**：生成内容的使用与合规责任由使用者承担
- **接口可能随时调整**：动手前先跑 `python3 scripts/a7w.py schema <app>`，以实际返回为准
