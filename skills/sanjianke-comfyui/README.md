# 三剪客 · 节点式出图流水线 Skill

把出图流程画成一张能存、能改、能批量跑的节点图：装好本地服务、按显卡选对推理后端、摆好模型目录、用 HTTP 把工作流接进自己的程序。

---

## 前置条件

- 一台有可用显卡的机器（NVIDIA / AMD / Intel / Apple Silicon / Ascend 各有安装路径）；显存越大，能跑的模型与分辨率越从容。
- 手动安装方式需要 Python 与 Git，并建议使用独立虚拟环境，避免污染系统 Python。
- 与本机显卡匹配的 PyTorch 构建；装错版本会直接报「未启用 CUDA」一类错误。
- 磁盘空间要够放权重；不同模型类别放在 `models/` 下不同子目录，不是堆一个目录就行。
- 想把出图接进程序时，要先把流程在界面里跑通，再导出成接口格式的工作流文件。
- 网络用于拉依赖、下模型、装自定义节点；推理本身可以完全本地。

---

## 使用

1. 按平台装好：桌面版最省事；Windows 也可用免安装便携包；喜欢命令行就 `pip install comfy-cli` 后 `comfy install`；要完全掌控环境就手动建虚拟环境、装 PyTorch、装 `requirements.txt`。
2. 摆好模型：检查点放 `models/checkpoints`、VAE 放 `models/vae`，其余按类别放；已有别的出图工具下好模型时，用 `extra_model_paths.yaml` 指过去复用。
3. 起服务：`python main.py`，默认本机 `8188` 端口；显存不足时按档调整（`--lowvram` / `--novram` / `--reserve-vram`），一次只留一档。
4. 在界面里搭好流程，确认能出图，再把工作流以接口格式导出。
5. 接程序调用：向 `/prompt` 提交工作流，连 `/ws` 订阅执行消息或轮询 `/history`，用 `/view` 取回图片。

完整的启动开关、接口调用写法与避坑条目见 `SKILL.md`；命令与开关以 `python main.py --help`、`comfy --help` 的当前输出和官方文档为准。

## 依赖

- ComfyUI 本体（克隆仓库运行、官方桌面版、或 Windows 免安装便携包）。
- Python 与 Git（手动安装方式）；命令行方式另需 `comfy-cli`。
- 与本机显卡匹配的 PyTorch 构建（CUDA / ROCm / Metal 等）；项目依赖由 `pip install -r requirements.txt` 安装。
- 模型权重：检查点、VAE、文本编码器等按需自备，不随项目分发。
- 可选：自定义节点（第三方扩展，按需安装，依赖需单独装齐）。
- 可选：要批量调用在线算力时，需要对应平台的账号与 Key。

---

## 安全

- 不内嵌任何密钥；本地出图不需要任何 Key，只有接入外部算力或在线节点能力时才需要。
- 默认只监听本机回环地址。改成监听全网等于把服务暴露出去，而它没有账号与权限体系——只在可信网络里这么做，并用防火墙限制来源。
- 自定义节点是第三方代码，会以服务进程的权限运行，能读写你的文件与网络。装之前确认来源可信，别见一个装一个。
- 保存环境快照之后再折腾节点，出问题能快速回到可用状态，而不是逐个手工回退。
- 工作流 JSON 里会带上模型名、提示词、种子等参数。把它和产出的图片一起对外分享前，先确认里面没有不该外传的信息。
- 出图结果能否商用取决于模型与素材的授权，与这个工具无关，自己确认清楚再用。
