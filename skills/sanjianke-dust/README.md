# 三剪客 · 磁盘占用可视化的命令行工具 Skill

dust：磁盘占用可视化的命令行工具 的安装、常用命令与避坑要点

---

## 前置条件

- 任意 Linux / macOS / Windows 终端即可；Windows 建议用 GNU 版或 `scoop` 包（MSVC 版需要系统带 VC++ 运行库）。
- 需要一个可读的目标目录。不需要 root；只有想看到无权目录的内容时才需要提权。
- 自行编译需要 Rust 工具链（`cargo`）；用包管理器或预编译可执行文件则不需要任何编译环境。
- 无需网络、账号或 Key；只有在用安装脚本或包管理器拉取时才联网。

---

## 使用

最短跑通路径：

```bash
dust                          # 统计当前目录，按占用从大到小
dust -d 2 -n 30 /var/log      # 指定目录、深度 2、最多 30 条
dust -F -n 20 ~               # 列出家里最大的 20 个文件
dust -j /data > usage.json    # 输出 JSON，便于脚本消费
```

什么时候该用、什么时候不该用、常见坑与能力边界，见同目录的 `SKILL.md`。

---

## 依赖

- 运行期：无第三方运行时依赖，单个可执行文件即可。
- 安装期：视方式而定——`cargo install du-dust` 需要 Rust 工具链；`brew`、`dnf`、`deb-get`、`pacstall`、`conda`、`mise`、`x-cmd`、`scoop` 走各自包管理器；也可以直接下载发行版页面的压缩包。
- 可选：`jq` 之类的 JSON 工具，用来加工 `dust -j` 的输出（非必需）。

---

## 安全

- 不内嵌任何密钥。
- 纯只读工具：统计过程不修改、不移动、不删除被扫描的文件，也不写缓存目录。
- 运行期间不产生任何网络请求，全部统计在本机完成。
- 提权有影响面：`sudo dust` 之类的用法会让进程读到全部文件元数据，只在确实需要看全时使用。
- 结果可能泄露信息：占用清单会暴露目录名与文件大小，把 JSON 或文本输出外发前先确认内容范围。
- 配置文件只影响展示默认值，不含任何凭证。
