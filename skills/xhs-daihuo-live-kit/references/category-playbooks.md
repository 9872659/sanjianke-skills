# 分品类打法

不同品类的观众动机、演示方式和合规红线完全不同。写内容前先定位品类，套对应打法。

每个品类给五件事：**内容角度 / 演示动作 / 直播重点 / 合规红线 / 常见坑**。

---

## 1. 家居清洁

- **内容角度**：脏 → 干净的对比最有效；「住了三年才发现」这类反常识开场
- **演示动作**：现场处理真实污渍，前后同框对比（同一机位、同一光线）
- **直播重点**：演示占时长 40% 以上，让观众看到过程而不是听描述
- **合规红线**：杀菌、抑菌需消字号资质；不得宣称「除螨」除非有检测依据
- **常见坑**：只拍干净结果不拍过程；用夸张污渍摆拍被识破

## 2. 食品 / 生鲜

- **内容角度**：口感描述 + 食用场景；「一个人住怎么吃」这类人群切入
- **演示动作**：开袋、称重、试吃（真实反应，不表演）
- **直播重点**：讲清规格、保质期、储存方式、发货时效——退单主要来自预期差
- **合规红线**：不得宣称保健功效；「纯天然」「零添加」「有机」需认证或删除
- **常见坑**：用「好吃到哭」代替具体口感；不写净含量导致售后纠纷

## 3. 美妆 / 护肤

- **内容角度**：肤质 + 使用周期记录；成分只讲与体感相关的部分
- **演示动作**：质地展示、上脸/上手延展、妆前妆后同光线对比
- **直播重点**：肤质分类推荐（油皮/干皮/敏感），不做「所有人都适用」的推荐
- **合规红线**：美白、防晒、祛斑、防脱属特殊化妆品，需注册证；不得宣称「药妆」
- **常见坑**：滤镜前后差过大被质疑；用「修复」「抗老」当功效承诺

## 4. 服饰 / 鞋包

- **内容角度**：身材数据 + 版型适配；「身高体重+尺码」是最强信任要素
- **演示动作**：试穿、拉伸、透光测试、细节走线近景
- **直播重点**：尺码对照必须常驻屏幕；退货率是这类目的核心指标
- **合规红线**：材质、成分、产地必须与标识一致（纯羊毛、真皮、进口面料）
- **常见坑**：不说尺码只夸版型；「显瘦十斤」这类效果承诺

## 5. 3C / 数码

- **内容角度**：真实使用场景 + 参数解读；对比同价位短板
- **演示动作**：实测跑分、续航实测、拆解做工、同场景对比
- **直播重点**：把参数翻译成体验（「5000mAh = 重度用一天」）
- **合规红线**：官方授权、正品保证需有依据；保修期限要与政策一致
- **常见坑**：只念参数不讲体验；把「原装」与「原装配件」混用

## 6. 母婴 / 儿童

- **内容角度**：月龄/年龄分段 + 安全细节；家长最关心「会不会伤到孩子」
- **演示动作**：材质触感、边角处理、清洗方式、质检报告展示
- **直播重点**：主动讲安全边界与不适用情形，比讲优点更能成交
- **合规红线**：不得宣称益智、增高、促进发育；「食品级」「可吞咽」需检测依据
- **常见坑**：用可爱包装替代安全说明；宣称「宝宝专用」但执行标准不符

## 7. 家电

- **内容角度**：解决什么家务负担 + 占地面积 / 噪音 / 耗电
- **演示动作**：实机运行，噪音用分贝仪、耗电用计量插座
- **直播重点**：售后与安装政策要讲在成交前，避免签收后纠纷
- **合规红线**：杀菌率、静音、省电等参数必须有检测报告或明确数值
- **常见坑**：说「静音」却不给分贝；「医用级」这类等级暗示

---

## 通用打法（任何品类都适用）

1. **先定人群再定内容**：同一件商品对「租房党」和「有娃家庭」卖点完全不同
2. **把参数翻译成体验**：观众不买参数，买的是参数带来的生活变化
3. **主动说不适合谁**：反向说明能显著提升可信度，也减少退货
4. **证据优先级**：实拍 > 检测报告 > 参数 > 形容词，形容词基本没有说服力
5. **合规先过一遍**：不同品类的红线不同，用 `--category` 叠加规则再扫

```bash
# 例：美妆类笔记
python3 scripts/compliance_check.py --file note.md --category cosmetics

# 例：食品直播脚本
python3 scripts/compliance_check.py --file script.txt --category food --strict
```
