# 选品评分卡

## 1. 先算账，再谈感觉

选品的第一步永远是毛利测算。**不要心算，用脚本**：

```bash
python3 scripts/selection_calc.py --price 89 --cost 32 --shipping 6 --commission 0.2 --return-rate 0.08
python3 scripts/selection_calc.py --price 89 --cost 32 --shipping 6 --commission 0.2 --target-roas 3
python3 scripts/selection_calc.py --batch products.csv
```

```
单件毛利      = 售价 - 成本 - 物流 - 包材
佣金后毛利    = 单件毛利 - 售价 × 佣金率
退货后毛利    = 佣金后毛利 × (1 - 退货率)
保本 CPA      = 退货后毛利（投放超过就是纯亏）
建议 CPA 上限 = 退货后毛利 × 0.5（留一半利润给经营与退款）
```

**判定线**（按佣金后毛利占售价的比例）：

| 毛利率 | 结论 |
|---|---|
| < 20% | 没有投放空间，只能纯自然流，谨慎 |
| 20% – 35% | 可测试，投放预算要克制 |
| ≥ 35% | 有投放余量，可主推 |
| 退货后毛利 ≤ 0 | 直接放弃，卖一单亏一单 |

**关于目标 ROAS**：脚本会反推所需 CPA。如果所需 CPA 高于建议上限，说明按当前毛利跑不动这个投产比——要么提价、要么换品、要么放弃投放。

## 2. 类目经验参考值

退货率与毛利结构没有通用值，下面是经验区间，**拿到真实数据后必须替换**：

| 类目 | 退货率经验区间 | 毛利特点 | 备注 |
|---|---|---|---|
| 家居清洁 | 3% – 8% | 毛利高、复购中等 | 重货物流成本高 |
| 食品 / 生鲜 | 5% – 12% | 毛利中等、复购高 | 损耗与临期风险 |
| 美妆 / 护肤 | 8% – 20% | 毛利高 | 退货即报废，成本高 |
| 服饰 / 鞋包 | 25% – 45% | 毛利高但退货吞噬利润 | 尺码是核心变量 |
| 3C / 数码 | 5% – 15% | 毛利低、客单高 | 售后成本高 |
| 母婴 | 5% – 12% | 毛利中等、复购高 | 合规门槛高 |
| 家电 | 8% – 18% | 毛利中等、物流贵 | 安装售后复杂 |

服饰类的退货率常被低估：**先用 40% 算一遍，如果还能赚再考虑做。**

## 3. 六维评分卡（每维 0–5 分，满分 30）

| 维度 | 0 分 | 3 分 | 5 分 |
|---|---|---|---|
| **需求强度** | 需要被说服才买 | 有明确搜索需求 | 刚需 + 高频复购 |
| **毛利空间** | 佣金后毛利 < 15% | 20% – 35% | > 40% |
| **内容可拍性** | 讲不清、看不出效果 | 能演示 1 个卖点 | 3 秒内出效果、适合视频 |
| **竞争烈度**（越高越好） | 头部品牌垄断搜索页 | 有中小玩家跑出来 | 竞争分散、长尾词多 |
| **复购潜力** | 一次性耐用品 | 半年内可能复购 | 月度消耗品 |
| **合规风险**（越高越好） | 医疗/金融等受限类目 | 需谨慎表述 | 普通类目，无资质门槛 |

**结论阈值**：

- **≥ 24 分** → 可主推
- **18 – 23 分** → 可测试，并给出最小验证动作
- **< 18 分** → 放弃
- **任一维度为 0 且属合规或毛利** → 直接放弃，不看总分

## 4. 高风险类目清单（先问资质，再谈内容）

| 类目 | 关键限制 |
|---|---|
| 保健食品 | 不得宣称功效，不得替代药物，需蓝帽子 |
| 普通食品 | 不得宣称治疗、减肥、增强免疫；「纯天然」「零添加」需依据 |
| 化妆品 | 美白/防晒/祛斑/防脱/染发/烫发属特殊化妆品，需注册证 |
| 医疗器械 | 需械字号，表述以注册证范围为准 |
| 母婴 / 儿童 | 不得宣称益智、增高、促进发育 |
| 金融 / 理财 / 保险 | 不得承诺收益、保本、零风险 |
| 学科培训 / 考证 | 不得承诺通过率、包过 |
| 珠宝 / 玉石 / 收藏 | 不得虚构材质、产地、升值空间 |

扫描时叠加对应类目规则：

```bash
python3 scripts/compliance_check.py --file note.md --category cosmetics
python3 scripts/compliance_check.py --file note.md --category food --category health
```

## 5. 竞品调研表

选品阶段至少看 10 篇同类目在跑的笔记，填这张表再决定角度：

| 序号 | 笔记标题 | 形式 | 角度 | 数据表现 | 我能不能做得更好 |
|---|---|---|---|---|---|
| 1 |  | 图文/视频 | 痛点/对比/攻略 | 赞藏评 | 差异点是什么 |

**看什么**：

- 哪些角度已经被写烂（避开）
- 哪些角度数据好但没人延展（跟进）
- 评论区在问什么（这就是你的下一篇选题）
- 头部账号的短板（价格、专业度、更新频率）

**不看什么**：不要照抄标题。抄结构可以，抄句子会被判同质化。

## 6. 最小验证动作

判定为「可测试」时，必须给出一个能在 7 天内完成、有明确判据的动作：

- 出 3 篇不同角度的图文笔记，看 7 天点击率与主页访问量
- 直播 1 场 30 分钟，看人均停留时长与商品点击率
- 先跑小额投放（不超过建议 CPA 上限的一半），看实际获客成本

不要给「多发几篇看看」这种没有判据的动作。

## 7. 输出模板

```
【选品结论】可主推 / 可测试 / 放弃
【毛利测算】售价 xx ｜ 成本 xx ｜ 物流 xx ｜ 佣金 xx% → 佣金后毛利 xx（占售价 xx%）
           保本 CPA xx ｜ 建议 CPA 上限 xx
【评分】需求 x ｜ 毛利 x ｜ 可拍性 x ｜ 竞争 x ｜ 复购 x ｜ 合规 x ｜ 合计 xx/30
【竞品情况】跑得最好的角度是 xx；没被延展的角度是 xx
【最大风险】一句话说清最可能翻车的点
【最小验证】7 天内可完成、有判据的动作
【待补充】缺少的输入项
```
