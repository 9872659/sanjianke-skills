# 数据复盘

没有复盘的内容生产是随机试错。本文件给出笔记与直播的两套漏斗、诊断表和复盘模板。

**前提**：本技能不抓取平台数据。所有指标必须由用户从创作者后台导出或提供；拿不到就标「待补充」。

---

## 1. 笔记漏斗

```
曝光 → 点击（封面+标题） → 停留（正文前 2 行） → 互动（赞藏评） → 主页访问 → 商品点击 → 成交
```

| 指标 | 健康信号 | 异常含义 |
|---|---|---|
| 点击率 | 高于同类目均值 | 低 → 封面与标题没给理由 |
| 互动率 | 赞藏评 / 点击 ≥ 3% | 低 → 正文全是形容词，没有可用信息 |
| 主页访问率 | 稳定且非 0 | 低 → 内容没建立「这个人还懂别的」 |
| 商品点击率 | 与内容强相关 | 低 → 挂车时机突兀 |
| 收藏率 | 明显高于点赞 | 高收藏=工具型内容，可复制成系列 |

**判读顺序**：先看点击率，再看互动率，最后看转化。前一层不达标时，优化后一层没有意义。

---

## 2. 直播漏斗

```
场观 → 平均停留 → 互动（评论/点赞） → 商品点击 → 下单 → 支付
```

| 指标 | 诊断 | 对应动作 |
|---|---|---|
| 场观低 | 开播时段 / 封面标题 / 预热不足 | 换时段、改直播间标题、提前发预告笔记 |
| 停留短 | 开场 3 分钟没给理由 | 重写开场，先给「今天讲什么、值多少」 |
| 互动少 | 提问门槛太高 | 换成两字能答的问题 |
| 点击低 | 上架与口播脱节 | 对齐上架时间，讲完卖点再上链接 |
| 下单低 | 信任没建立 | 补资质、实测、售后说明 |
| 支付低 | 价格预期未对齐 | 成交前把规格、运费、售后讲透 |

---

## 3. 时段诊断表

把直播按分钟切段，逐段填「讲什么 / 在线人数 / 互动数」，找出掉人点。

| 时段 | 讲什么 | 在线人数 | 掉人 | 判断 |
|---|---|---|---|---|
| 00:00–03:00 |  |  |  | 开场是否给到停留理由 |
| 03:00–08:00 |  |  |  | 痛点是否对得上 |
| 08:00–15:00 |  |  |  | 演示是否有判据 |
| 15:00–22:00 |  |  |  | 信任材料是否充分 |
| 22:00–30:00 |  |  |  | 行动指令是否明确 |

**掉人最猛的 3 分钟，就是下一场优先改的地方。**

## 4. 单篇笔记复盘模板

```
【笔记】标题 / 发布时间 / 形式（图文/视频）
【数据】曝光 xx ｜ 点击率 xx% ｜ 互动率 xx% ｜ 收藏 xx ｜ 商品点击 xx ｜ 成交 xx
【漏斗判定】卡在哪一层：
【本期变量】与上一篇相比，只改了哪一项（封面 / 标题 / 正文结构 / 标签 / 发布时间）
【结论】保留什么，改掉什么
【下一次只改一项】：
```

**纪律**：一次只改一个变量，否则数据好了也不知道为什么好。

---

## 5. 周报模板

```
【本周产量】笔记 x 篇 ｜ 直播 x 场
【最好的一篇】标题 + 数据 + 归因（为什么它好）
【最差的一篇】标题 + 数据 + 归因
【直播场次】场观 / 平均停留 / 点击率 / 支付率，与上周对比
【下周调整】只写 1–2 条具体改动，不写方向性口号
【待补充数据】
```

---

## 6. 归因纪律（避免自欺）

| 陷阱 | 表现 | 纠正 |
|---|---|---|
| 一次改多个变量 | 数据涨了但不知道原因 | 一次只改一项 |
| 用绝对数比较 | 「这篇 5000 曝光比上篇 3000 好」 | 比较点击率与互动率 |
| 忽略发布时间 | 把时段差异当成内容差异 | 固定发布时段后再比内容 |
| 样本太小 | 3 篇就下结论 | 至少 7 篇同变量样本 |
| 只报喜 | 只复盘爆款 | 差的那篇信息量更大 |

---

## 7. 与投放的关系

- 自然流数据决定内容能不能跑，投放只是放大
- 自然流留存差的内容，投不出正 ROI；先修内容再花钱
- 用 `selection_calc.py` 先算清保本 CPA 与建议 CPA 上限，再决定投不投

```bash
python3 scripts/selection_calc.py --price 89 --cost 32 --shipping 6 --commission 0.2 --target-roas 3
```
