# 合规规则与判定口径

## 0. 免责声明（必读）

本文件与 `scripts/compliance_check.py` 是**启发式自检工具**：词表来自公开经验整理，
既不是平台官方审核规则，也不构成法律意见。平台规则与类目资质要求会变动，高风险类目
（医疗、保健、食品、金融、母婴、特殊化妆品）必须由人工复核并以其官方规则为准。

本技能不提供「谐音绕过审核」类规避方案；命中一律建议改为合规表述。

---

## 1. 五类基础规则

用 `--list-rules` 查看当前词表全集：

```bash
python3 scripts/compliance_check.py --list-rules
```

### 1.1 极限词 / 绝对化用语（高风险）

| 类型 | 典型词 |
|---|---|
| 最高级 | 最好、最佳、最强、最低价、最便宜、最有效、全网最低、史上最低 |
| 排名类 | 第一、排名第一、销量第一、领先品牌、世界级 |
| 绝对类 | 绝对、100%、百分百、永久、终身、一劳永逸、绝无仅有、空前绝后 |
| 无根据背书 | 国家级、顶级、顶尖、极致、独家、唯一、万能 |
| 促销强度 | 超值、秒杀、全网（中风险，需真实依据） |

**改法**：把绝对说法换成可验证的具体事实。

| 命中 | 建议替换 |
|---|---|
| 全网最低价 | 我对比过的三家里这个价格更低 |
| 效果最好 | 在我用过的四款里，这款用起来最舒服（主观感受） |
| 100% 有效 | 我这批用户里多数反馈 xx（需真实数据） |
| 永久 | 正常使用下可用 x 年（或直接删掉） |

### 1.2 医疗 / 功效类（高风险）

| 类型 | 典型词 |
|---|---|
| 治疗类 | 治疗、治愈、根治、药到病除、疗效、药用、医用 |
| 症状类 | 消炎、杀菌、抑菌、抗癌、降血压、降血糖、降血脂、镇痛 |
| 美容类 | 美白、祛斑、祛痘、生发、防脱（特殊化妆品需注册证） |
| 身体类 | 减肥、瘦身、丰胸、增高、排毒、提高免疫力、无副作用 |
| 边界模糊 | 修复、抗老、淡纹、除螨、敏感肌可用（中风险） |

**改法**：只描述使用感受与使用场景，不描述身体结果。

| 命中 | 建议替换 |
|---|---|
| 根治口臭 | 我早上刷完，到中午口气还是清爽的（主观感受） |
| 祛痘 | 我用下来觉得泛红没那么明显了（主观感受） |
| 提高免疫力 | 喝起来比白水有味道，我每天会多喝两杯 |

### 1.3 金融 / 收益承诺（高风险）

稳赚、稳赚不赔、包赚、躺赚、暴利、保本、零风险、无风险、
日入过万、月入十万、投资回报、包过、通过率。

**改法**：直接删除，改为说明适用场景与不确定性。

### 1.4 站外导流（中高风险）

| 类型 | 典型词 |
|---|---|
| 即时通讯 | 微信、威信、V信、vx、加V、扣扣、QQ号 |
| 联系方式 | 手机号、公众号、扫码加 |
| 站外平台 | 淘宝、天猫、京东、拼多多、抖音、快手、闲鱼、咸鱼 |
| 交易话术 | 私聊、加我、私信我、一手货源、代购、低价出 |

正则还会识别疑似手机号、邮箱、站外账号。**改法**：全部删除，交易只走平台内商品卡/小店。

### 1.5 平台敏感操作（中风险）

刷单、刷量、好评返现、点赞返现、返现；三天见效、立即见效、一分钟搞定；
仅此一天、限时抢购、过了今天就没有；以及「最后 N 件」「已抢 N 单」这类正则匹配。

## 2. 类目规则

```bash
python3 scripts/compliance_check.py --explain                      # 看类目说明
python3 scripts/compliance_check.py --file note.md -c cosmetics   # 叠加化妆品规则
python3 scripts/compliance_check.py --file note.md -c food -c health
```

| `--category` | 覆盖范围 | 追加的重点词 |
|---|---|---|
| `cosmetics` | 美妆护肤 | 药妆、医学护肤、械字号面膜、毛孔隐形 |
| `food` | 食品生鲜 | 纯天然、零添加、有机、绿色食品、养胃、解酒 |
| `health` | 保健食品 | 增强抵抗力、调理、药食同源、代替药物、疗程 |
| `mother-baby` | 母婴 | 益智、促进发育、无激素、可吞咽、食品级 |
| `apparel` | 服饰鞋包 | 纯羊毛、真皮、进口面料、显瘦十斤、不缩水 |
| `digital` | 3C 数码 | 官方授权、正品保证、原装、终身保修 |
| `appliance` | 家电 | 杀菌率 99%、医用级、静音、省电 |

### 资质对照表

| 类目 | 需要的资质 | 常见误解 |
|---|---|---|
| 普通食品 | 食品经营许可证 | 「零添加」不是法定概念，不能随便写 |
| 保健食品 | 蓝帽子 + 广告审查 | 有蓝帽子也不能宣称治病 |
| 普通化妆品 | 备案 | 备案 ≠ 可以宣称美白祛斑 |
| 特殊化妆品 | 注册证 | 美白/防晒/祛斑/防脱/染发/烫发 |
| 消毒产品 | 消字号 | 「杀菌」「抑菌」属此类，普通清洁品不能写 |
| 医疗器械 | 械字号 | 表述不得超出注册证范围 |

## 3. 自定义规则

不同团队有各自的敏感词。用 JSON 合并自有词表：

```json
{
  "terms": [
    { "category": "品牌规范", "level": "high", "term": "内部代号", "advice": "不得外露" }
  ],
  "regex": [
    { "category": "品牌规范", "level": "medium", "pattern": "XHS-\\d+", "label": "内部编号" }
  ]
}
```

```bash
python3 scripts/compliance_check.py --file note.md --rules my-terms.json --strict
```

`level` 只能是 `low` / `medium` / `high`，非法值会被直接拒绝（不会静默忽略）。

---

## 4. 等级与退出码

| 等级 | 含义 | 处理 |
|---|---|---|
| `high` | 高风险，几乎一定触发审核 | 必须改，不允许发布 |
| `medium` | 中风险，视上下文可能违规 | 建议改，或补充真实依据 |
| `low` | 需人工判断 | 逐条确认语境 |

`verdict` 取值：`blocked`（有 high）/ `review`（有 medium）/ `check`（有 low）/ `pass`。

```bash
python3 scripts/compliance_check.py --file note.md --strict   # 有 high 时退出码 1
```

CI 集成示例：

```yaml
- name: 合规自检
  run: python3 scripts/compliance_check.py --file content/note.md --format json --strict
```

`--format json` 输出含 `summary`、`verdict`、`findings`、`disclaimer`，便于流水线解析。
`--format csv` 适合直接导入表格。

---

## 5. 判定口径

- **按子串匹配**：脚本是术语匹配，不理解语义，会有误报（如「最近」里的「最」）
- **不看图片**：封面大字需人工按同样口径自查
- **不做谐音识别**：故意改字规避的写法脚本抓不到，且这类写法本身不建议使用
- **不替代人工**：高风险类目必须人工复核

---

## 6. 自检流程

1. 生成文案
2. 跑脚本（带上类目）：`python3 scripts/compliance_check.py --file note.md -c cosmetics`
3. 逐条处理 `high`，评估 `medium`
4. 高风险类目追加人工复核
5. 交付物末尾附「合规自检结果」小节

## 7. 交付时的合规小节模板

```
【合规自检】已运行 compliance_check.py --category cosmetics
- 结论：review
- high：0 项
- medium：2 项
  - 「杀菌」→ 建议改为「清洁后不易留味」
  - 「最后 50 件」→ 需补充真实库存依据，否则删除
【人工复核提示】本品属普通化妆品，未宣称美白/祛斑等特殊功效
```
