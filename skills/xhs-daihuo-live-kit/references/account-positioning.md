# 账号定位与冷启动

内容能跑起来的前提是账号被认得出。本文件给定位方法、简介模板和 30 天冷启动计划。

---

## 1. 人设三要素

| 要素 | 回答的问题 | 例子 |
|---|---|---|
| 身份 | 你凭什么讲这个 | 「租了五年房的上班族」 |
| 场景 | 你在什么处境里用这些东西 | 小户型、预算有限、通勤 |
| 立场 | 你会不会说真话 | 「只推自己用超过一个月的」 |

三要素必须能一句话说完。说不完，说明定位还没定。

---

## 2. 垂直定位矩阵

选一个**主赛道** + 一个**人群限定**，不要什么都发。

| 主赛道 | 人群限定示例 | 内容角度 |
|---|---|---|
| 家居收纳 | 租房党 / 小户型 | 小空间改造、平价替代 |
| 厨房小电 | 一人食 / 上班族 | 快速出餐、清洗便利 |
| 个护美妆 | 敏感肌 / 学生党 | 成分避雷、平价平替 |
| 服饰穿搭 | 微胖 / 通勤 | 版型适配、尺码对照 |
| 母婴用品 | 新手妈妈 | 安全细节、月龄适配 |

**判断标准**：陌生人刷到你 3 篇笔记，能不能说出「这个号是讲 xx 给 xx 看的」。

---

## 3. 简介模板

```
一句话身份 + 一句话内容边界 + 一句话立场

例：
租房五年｜只测小户型能放下的东西
不接没用满一个月的东西
缺点都写在正文里
```

不要写：联系方式、外站平台名、「私信领福利」、「全网最低」。

---

## 4. 主页装修检查

- [ ] 头像清晰、有辨识度，不用网图
- [ ] 昵称含赛道关键词，便于被搜到
- [ ] 简介说清「讲什么、给谁看」
- [ ] 置顶 3 篇分别是：爆款代表作、最干货的一篇、最真实的一篇
- [ ] 无站外联系方式、无夸大表述

---

## 5. 冷启动 30 天计划

| 阶段 | 天数 | 目标 | 产出 |
|---|---|---|---|
| 定位期 | 1–3 | 定人设与赛道 | 人设一句话、简介、主页装修 |
| 试水期 | 4–10 | 找内容手感 | 7 篇不同角度的图文 |
| 收敛期 | 11–18 | 找出能跑的角度 | 保留前 2 个角度，各出 3 篇 |
| 稳定期 | 19–25 | 建立更新节奏 | 固定发布时段，5 篇 |
| 放量期 | 26–30 | 复制成功模型 | 按最优模型出 5 篇 + 开一场直播 |

**每个阶段的判据**：

- 试水期：至少 2 篇点击率高于账号均值
- 收敛期：同一角度连续 3 篇都不掉
- 稳定期：固定时段发布后，单篇曝光中位数上升
- 放量期：出现第一篇带动主页访问的笔记

**纪律**：试水期不要投流。内容没跑通之前，投放只是把钱换成难看的数字。

---

## 6. 矩阵号注意事项

如果做多账号：

| 可以 | 不可以 |
|---|---|
| 不同人群、不同语气的差异化内容 | 同一篇文案换标题重复发 |
| 不同品类分开运营 | 互相导流、互相评论刷量 |
| 统一供应链、统一素材库 | 批量私信、批量评论引流 |

平台对同质化内容和互刷行为识别能力很强，矩阵做不好等于集体降权。

```

  → 数据复盘（references/data-review.md）
```
