## 前置条件

- 目标是"画常规统计图表"，不是关系图、流程图或地图
- 已确认要接入的大版本（v3 / v4 / v5 语法互不兼容）；npm `latest` 标签当前指向 5.x 系列
- 页面里有真实存在且宽高非 0 的 DOM 容器供图表挂载
- 前端工程已具备 Node.js 与 npm / yarn 等包管理器
- 团队接受引入一套可视化依赖的体积与学习成本

---

## 使用

让 Agent 加载本 Skill 后，按下面的顺序推进：

1. **先判适用性**：命中"不要用它"里的任何一条（关系图、地图、纯表格展示、后端出图），直接换方案，别硬接。
2. **锁定大版本**：看 `package.json` 或执行 `npm ls @antv/g2`，确定当前是 v3 / v4 / v5 中的哪一版，再去看对应版本的官方文档——示例写法差异很大。
3. **准备容器**：在页面里放一个宽高确定的容器元素，等 DOM 就绪、容器可见后再创建图表。
4. **写声明**：`new Chart({ container })` → 选 mark（`interval` / `line` / `area` / `point` …）→ `.data()` 绑数据 → `.encode()` 映射通道 → 按需配置坐标轴、图例、Tooltip 与 transform → `chart.render()`。
5. **收尾**：组件卸载或路由离开时调用 `chart.destroy()`。

包内的 `SKILL.md` 有完整的六块内容：什么时候用 / 不用、安装、常用操作、常见坑、权限与用途说明、能力边界。链式 API 的确切签名与可配置项，以所装版本对应的官方 API 文档为准。

## 依赖

- 运行环境：现代浏览器
- 安装方式：`npm install @antv/g2` 或 `yarn add @antv/g2`
- 浏览器直引：需要包内 UMD 产物（如 `dist/g2.min.js`），全局命名空间与产物路径以实际版本为准
- 服务端出图：需要额外配置无头渲染环境，具体方案见官方文档
- 可选扩展：3D、自动化可视分析等需另装官方扩展包
- 本包不包含第三方项目源码

---

## 安全

- 不内嵌任何密钥
- 本包自身不发起网络请求；图表数据由调用方提供，数据来源与脱敏由调用方负责
- 渲染在浏览器端进行，不写入本地文件，不启动后台进程
- 不要把生产环境的接口地址、Token 写进图表声明代码里
- 引入依赖前确认版本来源可信，锁定大版本以免被自动升级打断
