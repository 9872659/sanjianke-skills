# 三剪客 · 多语种自然语言处理 Skill

中文与多语种的分词、词性、命名实体、依存句法、成分句法、语义角色、语义依存、词形还原等十大任务一次调完，既能在本地跑原生模型，也能用几 KB 的客户端远程解析

---

## 前置条件

- **Python 3.6 或更高**（上游 README 明确要求）
- **先想清楚走哪条路**，两条路的依赖差别极大：

  | 路线 | 安装命令 | 依赖量 | 适合场景 |
  |---|---|---|---|
  | RESTful 客户端 | `pip install hanlp_restful` | 极轻，几 KB | 手机端、轻量服务、不想装深度学习栈 |
  | 原生 API | `pip install hanlp` | 重，引入 PyTorch / TensorFlow 2.x | 离线、数据不能出网、要自己训练 |

- **原生路线还要准备**：能放下预训练模型的磁盘空间、首次加载时的外网连通性；GPU / TPU 是推荐而非必需
- **RESTful 路线还要准备**：一个 auth key（匿名可用但官方建议申请，走上游论坛的申请帖）
- **许可要分清**：代码 Apache-2.0 可商用；**模型与 RESTful API 是 CC BY-NC-SA 4.0 非商业协议**，商用前务必核实
- **长文本要先切句**：多任务模型不预测句子边界，输入必须是已经切好的句子列表
- **不需要安装 Docker**：上游没有官方镜像；想省事就用 RESTful 路线

## 使用

加载这个 Skill 之后，Agent 会按 `SKILL.md` 里的六个板块来干活：判断该不该用、怎么装、常用操作怎么跑、有哪些坑、权限边界在哪、能覆盖到什么程度。

典型用法：

1. **选路线**——「数据不能出网」就走原生 API，「手机端要接」就走 RESTful；接口长得很像，切换成本低。
2. **选模型**——多任务联合模型一次拿全部标注；中文高精度场景换中文单语单任务模型。
3. **抽实体**——NER 返回形如 `[词, 实体类型, 起, 止]` 的结构，中文有 MSRA 数据集的多个预训练常量可选。
4. **理关系**——语义角色标注拿到「谓词 + 论元」，语义依存拿到词与词之间的语义关系。
5. **看结果**——`Document.pretty_print()` 在终端里画出依存树与各任务对照表。
6. **排障**——「传整段进去结果乱」「首次调用卡很久」「RESTful 和本地结果不一致」这类现象，对照「常见坑」表逐条排查。

## 安全

- 不内嵌任何密钥：本 Skill 正文里没有任何 token、口令或私有地址；RESTful 的 auth key 需要你自己申请并自行保管
- **数据出网风险**：RESTful 路线会把待解析的文本发到远端服务。敏感文本必须先确认合规，能离线就改走原生 API
- **许可分两套**：代码 Apache-2.0 可商用，但**模型与 RESTful API 采用 CC BY-NC-SA 4.0 非商业协议**。别只看代码协议就上线商用
- **首次加载会下载并加载远端分发的模型权重**：确认下载来源可信
- **原生 API 会持续占用 GPU / 大量内存**：与服务同机部署时要评估资源占用，避免把生产环境拖垮
- **训练场景的语料要合规**：自己训练模型时，所用标注数据的来源与授权需要自己负责
