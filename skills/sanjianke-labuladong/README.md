# 三剪客 · 算法题解语料库 Skill

一套可放到本地的算法题解语料：按专题检索套路、按题目定位讲解、从一篇题解扩到同类练习，以及怎么把它挂进自己的 Agent。

---

## 前置条件

- 能访问仓库：本机装了 `git`，或者能下载仓库压缩包。
- 至少一个 Markdown 阅读器；想在资料里定位内容，需要能列目录、能按关键词全文检索。
- 明确它是什么：这是**讲解语料**，不是软件、没有命令行参数、没有接口，也不带判题能力。
- 想把资料挂进 Agent，需要事先约定好本地路径与检索方式（先检索、再精读命中文件）。
- 需要核对题目细节时，准备一个能打开原题页面的网络环境。

---

## 使用

1. 取资料：`git clone https://github.com/labuladong/fucking-algorithm.git`，或下载压缩包；只要个别专题时用稀疏检出。
2. 看结构：顶层是若干中文专题目录加图片与说明文件，每个专题目录里的索引文件是该专题的文章清单。
3. 定位内容：先看专题索引确定有哪些文章；不知道归哪个专题时，用题名、英文 slug 或算法名做全文检索。
4. 精读命中文章：只读相关的那一两篇，抽取「适用范围 / 模板骨架 / 复杂度与变体」三段，而不是整目录读入。
5. 核对题目：涉及具体题目时回到原题页面，确认编号、函数签名与边界条件。
6. 扩到同类：根据所在专题挑同类型文章当延伸练习；验证答案要靠在线判题或本地用例。

具体检索写法、内容层面的坑与边界说明见 `SKILL.md`。

## 依赖

- 仓库内容本身：纯 Markdown 长文与配图，无需任何运行时。
- `git`（克隆与更新），或任意能下载 ZIP 的工具。
- 检索工具：能列目录、能按关键字在 `*.md` 内搜索即可（`ls` / `grep` 一类，或等价的文件检索能力）。
- 可选：能打开原题页面的网络环境；可选：你自己的判题或对拍方式。
- 不需要任何账号、Key 或算力。

## 安全

- 不内嵌任何密钥；获取公开仓库不需要凭证。
- 资料目录按只读知识源使用，不要在上游内容里就地改动；自己做笔记请另存到别的目录。
- 仓库内容为第三方个人整理，有独立的授权与转载约定。引用做摘要与指路没问题，成篇转载或商用前先确认授权。
- 讲解与代码片段可能滞后于题库现状。把它们当参考而不是结论，更不要直接提交未经核对的代码。
- 图片与外部链接指向第三方站点，打开前注意来源；不要因为资料里出现链接就默认可信。
