# 三剪客 · 大模型双语电子书翻译 Skill

整本书翻译的实操说明：从试译几段到整本出的完整流程、多端点接法、人物名与术语一致性、被中断后怎么续、以及 epub/PDF 输出上的那些预期差。

---

## 前置条件

- **Python 3.10+**（上游 README 标注），或者改用容器路线免装环境。
- 一个可用的模型端点：官方 API、Anthropic 格式端点、厂商自有接口、自建或本地的 OpenAI 兼容服务都可以；也有一条不需要任何凭证的公开机翻路线可用于先跑通流程。
- 对应的凭证：通过命令行参数、环境变量或 provider 配置文件传入。**不要把密钥硬编码进脚本或提交进仓库。**
- 可访问外网（或配置代理）：翻译过程要实时请求模型服务。
- 磁盘空间：原书、双语成品、中断时的临时文件都要落盘；epub 成品的体积通常是原书的数倍。
- **版权前提**：上游把这条写在最前面——只翻译你有权翻译的材料（自己持有权利的、获得许可的、公有领域的，或法律允许的情形）。这是硬门槛。

## 使用

1. 先按 `SKILL.md` 的「安装」一节选路线：源码脚本、PyPI 包命令行、或 Docker 镜像。
2. 不要一上来就整本跑：先用试译开关翻开头几段，确认译文风格、术语处理和这一轮的用量。
3. 整本执行时挑端点写法——官方 API、任意 OpenAI 兼容地址（记得 `/v1` 结尾并加引号）、或某个机翻引擎格式；接自定义服务可在 provider 配置里声明。
4. 在意前后一致就开会话模式并配术语表：人名与专有名词一行一条钉死，跨窗口的译法靠交接报告延续。
5. epub 输入先确认要翻哪些标签：默认只翻 `<p>`，诗歌、引文、表格单元格需要额外指定或先用计划模式分类。
6. 长任务留意中断产物：跑挂后留在目录里的临时双语文件就是进度，重命名即可或显式续跑（续跑与并行互斥）。
7. 出片后抽查章节结构与原文译文对应关系；不需要那句模型署名说明就用开关去掉。完整参数与排错对照见 `SKILL.md`。

## 安全

- 不内嵌任何密钥；本 Skill 不要求也不能提供 API Key。
- 密钥优先走环境变量或 provider 配置文件，避免出现在 shell 历史与进程列表中。
- 使用本地代理型路线时，工具会与本机服务通信并可能拉起本地边车进程；了解它的行为后再在生产机器上开。
- 待翻译的原书与术语表会以明文经过你配置的端点，敏感或未公开材料请确认该端点的数据使用条款。
- 译文与临时文件都落在工作目录：批量处理受版权保护或含个人信息的材料时，注意目录权限与后续清理。
- 只处理你有权翻译的内容；不要用它绕过 DRM 或内容保护机制。
- 机器翻译与模型翻译都可能出错，用于对外发布或正式用途前必须人工复核。
