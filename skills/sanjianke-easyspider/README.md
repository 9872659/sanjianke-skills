# 三剪客 · 可视化无代码爬虫 Skill

不写代码，用点选的方式在页面上圈出要采集的字段，任务可本地跑、命令行跑、无头跑或挂到服务器统一管理

---

## 前置条件

- 操作系统满足官方要求：Windows 10 x64 / Server 2016 以上；macOS 11.1 以上；Linux 为 Ubuntu 20.04+、Deepin、Debian 及其衍生版
- 从上游 Releases 页面或官方站点下载页获取程序包（官方声明交流群不是下载渠道）
- 明确要采集的目标网址，以及是否有登录、翻页、滚动加载、iframe 等特殊形态
- 确认目标站点允许自动化访问，采集内容已获得授权，不涉及未授权的个人信息
- 需要命令行或 API 触发时，先确认执行程序路径与本机版本实际支持的参数

---

## 使用

1. 下载并解压对应系统的程序包，运行主程序进入图形界面
2. 输入目标网址，在页面上点选要采集的元素，配置提取字段、循环与翻页方式
3. 保存任务并在界面里试运行，确认字段和行数正确
4. 需要后台跑时用命令行执行：

   ```bash
   cd /path/to/EasySpider
   ./EasySpider/resources/app/chrome_win64/easyspider_executestage.exe \
     --ids [37] --headless 1 --read_type local --saved_file_name result_37
   ```

5. 要嵌进自己的流程、动态改输入参数时用 API 取执行 ID：

   ```bash
   curl -X POST http://localhost:8074/invokeTask \
     -d "id=157" \
     -d 'params={"urlList_0":"https://www.baidu.com/s?wd=1","loopTimes_循环_1":"15"}'
   ```

6. 结果可导出 Excel / CSV / TXT，或直接写入 MySQL
7. 完整的命令行参数表、API 字段说明、各系统版本要求与坑位对照表，见 `SKILL.md`

关键约定：`--read_type remote` 需要主程序或服务端常驻；`local` 模式直接读本地 `execution_instances` 下的任务文件，不需要启动主程序。

## 依赖

- 图形界面本体与执行程序（随程序包提供），依赖系统自带的浏览器内核组件
- 运行环境：满足上表版本要求的 Windows / macOS / Linux
- 用命令行执行需要知道执行程序的实际路径；用 API 触发需要 8074 端口上的服务在监听
- 可选：MySQL（结果入库）、代理 IP 服务、验证码识别服务、Selenium Docker 容器地址
- 不需要注册账号，任务与数据默认都保存在本地，不经过第三方服务器

---

## 安全

- 不内嵌任何密钥
- 目标站点的登录态、Cookies、代理账号、MySQL 连接信息、验证码服务密钥放在配置文件或用户配置目录里，不要写进任务文件，也不要提交进仓库
- 只采集已获授权的数据源；涉及个人信息、版权内容、平台条款限制的场景先取得许可再动手
- 不要用采集能力去绕过目标站点的访问控制或风控；工具具备验证码识别等能力，不代表这些用法合规
- 打开无头模式或并行多开前，确认对目标站点的访问频率在其可承受范围内，避免给对方造成压力
- 程序包只从上游 Releases 页面或官方站点下载页获取，不要使用来路不明的转发包
- 采下来的数据按最小必要原则保存，结果导出与入库时不要保留不需要的个人标识字段
- 外挂自定义插件、执行自定义 JavaScript 与系统命令时，只运行自己信任的代码
