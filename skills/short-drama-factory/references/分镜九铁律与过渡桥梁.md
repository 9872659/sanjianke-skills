# 分镜九铁律与过渡桥梁

> 这九条不是建议，是**写死在提示词里的硬约束**。少了任何一条，成片就会出现对应的问题。

---

## 一、九条铁律

| # | 铁律 | 不做会怎样 |
|---|---|---|
| 1 | **台词零删改**——逐字搬运，禁合并 / 精简 / 省略修饰词 | 台词被「优化」掉，剧情对不上 |
| 2 | 台词时长按 **4 字/秒**估算，按情绪分配，**不平均切** | 节奏平板，该慢的地方赶 |
| 3 | 每个镜头 **≤15 秒** | 超长镜头必漂移 |
| 4 | 长台词**超 20 字强制拆镜**，按语义停顿点切；不可切时用表情 / 运镜填满，**禁单镜死固定** | 一句话塞一个镜头，脸必换 |
| 5 | **在场人物不能凭空消失**（没写「离开」就还在场，必须有视觉痕迹） | 人突然没了，观众出戏 |
| 6 | **人物外观交给图片资产**——长相 / 服装 / 发型**不进**分镜提示词 | 文字描述与参考图打架，一致性崩 |
| 7 | 声音只写**环境音 + 音效**，**禁 BGM** | 每镜自带 BGM，合成时打架 |
| 8 | 画面只写**动作、姿态、表情、正在发生的状态变化** | 写成小说，模型抓不到可执行信息 |
| 9 | **光影时辰要写**（会被带进出图提示词） | 同一场戏光线乱跳 |

### 逐条解释

#### 铁律 1 · 台词零删改

**逐字搬运，禁合并 / 精简 / 省略修饰词。**

模型天生喜欢「优化」文本——把「你……你怎么会在这里？」改成「你怎么在这里？」。**在短剧里这是致命的**：台词的停顿、结巴、重复本身就是表演信息。

#### 铁律 2 · 4 字/秒，按情绪分配

按 **4 字/秒**估算时长，**但不平均切**。

```
紧张的对峙  → 语速快，字/秒可以到 5
情绪崩溃    → 语速慢，字/秒降到 2~3，留白
```

**不平均切**的含义：不是「这句 12 字就给它 3 秒」，而是**按情绪张力重新分配**总时长。

#### 铁律 3 · 单镜 ≤15 秒

15 秒是**上限**，不是目标。**实际上限应该更低**——见铁律 4 与「长镜头漂移」。

#### 铁律 4 · 超 20 字强制拆镜

**按语义停顿点切**。不可切时（比如一个长名字、一句无法断开的话）**用表情 / 运镜填满**，**禁止单镜死固定**。

「死固定」= 镜头不动、人物不动，只是等台词念完。这是最廉价也最容易被观众察觉的偷懒。

#### 铁律 5 · 在场人物不能凭空消失

**没写「离开」就还在场，必须有视觉痕迹。**

哪怕是个背影、一只手、画面边缘的衣角。**观众对「人凭空消失」极其敏感**，这一点比换脸更容易被察觉。

#### 铁律 6 · 人物外观交给图片资产

**长相 / 服装 / 发型不进分镜提示词。**

原因：分镜提示词里的文字描述会和**参考图的硬约束**打架。参考图说「黑灰夹克」，你文字里写「深色外套」，模型就在两者之间摇摆——一致性就崩了。

**外观统一交给锚点资产去锁**（见 `一致性双锁与禁文字原文.md`）。

#### 铁律 7 · 只写环境音 + 音效，禁 BGM

每镜自带 BGM 的话，**后期合成时 BGM 会互相打架**。BGM 应该由后期按情绪曲线统一生成一条。

#### 铁律 8 · 只写动作、姿态、表情、状态变化

分镜提示词**不是剧本**。写「他心里很痛苦」模型没法执行；写「他垂下眼，握拳，指节发白」可以。

**只写正在发生的、可看见的。**

#### 铁律 9 · 光影时辰要写

这一条是**项目既定规范**，会被**带进出图提示词**。

同一场戏如果每镜光影不一样，剪起来就像不同时间拍的。

## 二、四类过渡桥梁

**每个镜头都必须写明用了哪一类。**

这是防止「镜头之间像硬拼」的关键。

### ① 动作桥梁

前一组结尾是**动作的起始态**，后一组首镜是该动作的**进行 / 完成态**。

```
上镜末态：陈默右手抬起，手伸向门把
下镜首镜：陈默的手已经握住门把，正在下压
```

### ② 情绪接力

前一组结尾用**反应镜 / 眼神 / 微表情**为后一组铺垫。

```
上镜末态：周桂芳眼神一凝，嘴唇微张
下镜首镜：陈默察觉到了这个反应，眉头一动
```

### ③ 空间与视线

用**空镜、视线引导、声音延续**建立空间联系。

```
上镜末态：陈默转头看向窗外
下镜首镜：窗外雨幕（空镜），远处车灯划过
```

### ④ 台词与动作黏合

前一组末尾的**声音延续到后一组首镜**。

```
上镜末态：陈默开口说"我见过你"（声音未落）
下镜首镜：周桂芳的反应（画面切了，但上镜声音还在延续）
```

### 桥梁类型速查

| 类型 | 用在什么场景 |
|---|---|
| 动作桥梁 | 连续动作被拆成两个镜头 |
| 情绪接力 | 需要观众反应时间，铺垫下一场 |
| 空间与视线 | 场景转换，需要建立空间关系 |
| 台词与动作黏合 | 对白密集，避免声音被硬切 |

## 三、分镜表要有的字段

| 字段 | 说明 |
|---|---|
| **镜号** | `sg_001` 这种稳定 ID，下游靠它引用 |
| **景别** | 全景 / 中景 / 中近景 / 近景 / 特写 —— **也决定用哪个模型档位** |
| **机位** | 平视 / 俯视 / 仰视 / 过肩 |
| 时长 | 按 4 字/秒估算，按情绪分配 |
| 台词 | **逐字**，含说话人 |
| 光影时辰 | 会被带进出图提示词 |
| 音效 | 环境音 + 音效，**不含 BGM** |
| **来自哪段剧本** | 用于「改一句台词只重出受影响的镜头」 |
| **过渡桥梁** | 用了四类里的哪一类 |
| 起始快照 / 变化 / 末态 | 见站位记忆 |

## 四、站位记忆：完整格式

**每个镜头一行**，三件事：

```
【镜号】sg_001
起始：<谁在哪、朝哪、什么姿态、道具在谁手上、什么状态>
变化：<这一镜里发生了什么状态改变>
末态：<这一镜结束时的状态>          ← 必须与下一镜的"起始"逐字一致
```

### 实例

```
sg_001  起始：陈默在楼梯口端站立，面朝周桂芳；信闭合在陈默右手
        变化：陈默停步、收拢右手、换左手抬信
        末态：陈默举信至胸前；周桂芳视线在信上；信在陈默手中（开启）

sg_002  起始：陈默举信至胸前；周桂芳视线在信上；信在陈默手中（开启）   ← 逐字一致
        变化：周桂芳伸手接信，陈默松手
        末态：信在周桂芳手中（开启），双手捧持；陈默双手垂下
```

### 为什么「逐字一致」很重要

因为出图时会把 **本镜起始快照 + 上一镜末态 + 光影** 一起拼进提示词。

如果两段文字不一致（比如上镜末态写「信在陈默手中」、下镜起始写「陈默拿着信」），模型会**认为是两个不同的状态**，画面就接不上。

### 服务端自检

第 N 镜末态与第 N+1 镜起始不一致时，**记警告并列出镜头对**。

**只警告不阻断**——因为有些连续快切确实是有意为之的。

## 五、四类桥梁 × 九铁律的配合

举一个完整的镜头串例子：

```
sg_001  [中景/平视/5s]
        台词：陈默"我见过你。"
        光影：傍晚，侧逆光，门口有几缕光斜切进来
        音效：雨声、远处汽车鸣笛（无 BGM）
        起始：陈默站在门口，面朝屋内；伞收在右手滴水
        变化：陈默开口说话，伞尖水滴落地
        末态：陈默说完，伞尖刚滴落一滴水；周桂芳在屋内转身
        桥梁：情绪接力（为 sg_002 的周桂芳反应镜铺垫）
        → 遵循：铁律1（台词逐字）· 铁律2（5 字→约 1.5s，但留白到 5s）· 铁律7（无 BGM）· 铁律9（光影）

sg_002  [近景/平视/4s]
        台词：（无）
        光影：同 sg_001
        音效：雨声延续（声音延续）
        起始：周桂芳在屋内转身，脸朝向门口方向；手里拿着抹布
        变化：周桂芳视线落在陈默身上，抹布从手中滑落
        末态：周桂芳僵在原地，抹布落地；陈默仍在门口
        桥梁：台词与动作黏合（sg_001 的声音延续进入本镜）
        → 遵循：铁律5（陈默没写离开就还在场）· 铁律8（只写可见动作）
```

**注意 sg_002 的「起始」与 sg_001 的「末态」的关系**——不是逐字一致（因为这是**新增信息**：周桂芳转身、手里有抹布），而是**状态可接**：sg_001 末态说「周桂芳在屋内转身」，sg_002 起始写「周桂芳在屋内转身」继续细化。

**逐字一致的要求适用于同一组连续动作被拆成两镜的情况**（见上面 sg_001/sg_002 的站位记忆例子）。

## 六、自检

- [ ] 台词**逐字**搬运，没有被模型「优化」
- [ ] 时长按 **4 字/秒**估，且**按情绪分配**，不是平均切
- [ ] 每个镜头 **≤15 秒**
- [ ] 超 20 字的台词**拆镜了**，且不可切时用了表情/运镜填满（没有死固定）
- [ ] **在场人物都还在场**（有视觉痕迹），没写「离开」的没消失
- [ ] 分镜提示词里**没有出现人物长相 / 服装 / 发型**
- [ ] 声音只有**环境音 + 音效**，**没有 BGM**
- [ ] 画面只写了**动作 / 姿态 / 表情 / 状态变化**
- [ ] 写了**光影时辰**
- [ ] 每个镜头标了**用了哪类过渡桥梁**
- [ ] 每个镜头有**起始快照 / 变化 / 末态**，且末态与下一镜起始可接
- [ ] 分镜表记了**「来自哪段剧本」**（用于增量重出）
