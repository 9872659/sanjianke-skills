# 电商主图方法论

> 本文件讲**为什么这么做**。命令与参数见 `SKILL.md`，平台尺寸见 `platform-specs.md`，
> 闸门口径见 `compliance-and-gates.md`。

## 一、白底主图为什么不能「生成」，只能「实拍 + 合成」

这是本包最重要的一条设计取舍，先说清楚，免得你花了钱才发现方向不对。

**AI 出图擅长的是「氛围」，不擅长「你的那个具体商品」。** 让模型「画一个纯白背景的榨汁杯」，
它会画出一个**看起来像榨汁杯、但不是你卖的那款**的东西：杯身比例、logo 位置、
按键形状、颜色深浅都会跑偏。买家收到货发现和主图不一样，就是「图实不符」，
这是平台处罚最重的一类问题之一。

所以本包的立场是：

| 图位 | 该怎么做 | 本包提供什么 |
|---|---|---|
| 第 1 张白底主图 | **拍实物**，抠图 / 棚拍去背，背景推到纯白 | 平台规格口径、白底提示词约束（若你要生成氛围版） |
| 第 2~4 张（规格/卖点/场景） | 实拍为主；场景图可用 AI 生成氛围 | `generate` 出图（商品图作风格与主体参考） |
| 第 5 张资质 | **你真实持有的资质材料**，只改版式 | `action=edit` 基于你的资质图改版式 |

`--product-image` 传实物图 URL 之后，本包在第 5 位会走 `action=edit`——
**edit 是「基于参考图编辑」，这就保证了产出里有你的真实商品/资质，而不是模型凭空画的。**

⚠️ 第 5 位不传资质图 URL 时，本包会**明确警告**：那次产出的是**示意版式、不是资质本身，
不许当作资质材料上架**。真机实测踩到过：模型会给第 5 位写一条「自有实拍图与拆解视频」
当依据，然后照样画一张看起来很像资质的图出来。**闸门能拦文案，拦不住你自己拿去上架。**

## 二、白底主图的具体要求

平台要的不是「白一点」，是**纯白**（RGB 255,255,255 或极接近），并且通常要求：

| 项 | 常见做法 | 说明 |
|---|---|---|
| 背景 | 纯白，无渐变、无阴影、无道具 | 有阴影的商品在部分场景会被判「非白底」 |
| 主体占比 | 约 **70%~85%** | 太小显得空、被缩略图吞掉；太满贴边会被裁 |
| 留白 | 四周留白，主体**不贴边** | 平台可能在主图上叠角标、水印、价格标 |
| 文字 | **不要**在主图上压字 | 白底主图是被检索与抓取的那一张，压字容易被判违规 |
| 数量 | 一张商品一个主图位 | 不要在一张白底图里拼两个商品 |

**本包做的事情与不做的**：会把「纯白背景」写进第 1 位的出图提示词，并在白底位缺这句时
**自动补上**；但**不会去检测产出图的背景像素是否真的纯白**——背景干净度需要人工看一眼。
这是**已知边界**，写在 `SKILL.md` 的「已知边界」一节里。

## 三、五张主图位怎么分工

这是本包与「新媒体配图工厂」最本质的区别：那些包分的是**文章里的插图角色**，
本包分的是**平台固定的语义槽**。买家看主图的顺序是有心理动线的，所以顺序不能随意调换。

| 第几张 | slot | 买家此刻在想什么 | 这张图要回答什么 |
|---|---|---|---|
| 1 | `main` | 「这是什么东西？值不值得点进去？」 | 一个核心利益点 + 干净的主体 |
| 2 | `spec` | 「有多大？什么材质？我能不能用？」 | 规格、材质、型号、适用与**不适用**人群 |
| 3 | `selling` | 「凭什么信你？」 | 放大一个**可验证**的做工细节 + 证据型文案 |
| 4 | `scene` | 「我用起来是什么样？」 | 真实使用场景、人群代入 |
| 5 | `qualification` | 「出问题找谁？有资质吗？」 | 可查验的资质/参数/售后（**用真实材料**） |

### 为什么不是「把卖点平均分给 5 张图」

因为**图位的语义是固定的**。把「续航 12 杯」放在第 2 张（规格）是对的，
放在第 4 张（场景）就浪费了那一位。乱塞的结果是五张图变成五张重复的主图，
买家划完还是不知道尺寸——这恰恰是运营最常见的失败模式。

### 关于「不适合谁」

`spec` 位提示词里明确要求写「适用人群或**不适用**人群」。
这一条看起来会劝退，实际是转化利器：买家自己在做匹配，
主动说出「不适合需要保温 12 小时以上的场景」比空喊「人人适合」更让人信。
**前提是这是真的**——不许为了显得诚实而编一个不存在的缺点。

## 四、详情页长图怎么办

详情页是**长图**：宽度固定（常见 750），高度按内容分屏累加，常见 6~15 屏。

上游 `nano_banana` 单张出不了长图，所以本包的口径是：

```
按屏出图（单屏 3:4）→ 本地拼接 → 得到详情页长图
```

`--platform detail` 的 `design_ratio` 记 1:3，只是「单屏约占长图三分之一」的**记录口径**，
生成仍用 `3:4`。拼接命令见 `platform-specs.md`。

**详情页分屏的常见结构**（按顺序）：

1. 首屏：商品全貌 + 核心卖点（与第 1 张主图呼应，不要重复同一张）
2. 痛点屏：不讲产品，先讲买家现在的麻烦
3. 规格屏：把 `spec` 位的参数放大讲
4. 细节屏 ×2~3：每个可验证细节一屏
5. 场景屏：真实使用
6. 资质与售后屏
7. 规格参数表（**文字屏，用本地排版工具做，不要 AI 出图**）

⚠️ 第 7 屏这类**以文字为主**的屏，**不要用 AI 出图**。AI 出图的文字基本都是错的，
参数表必须用本地排版（HTML/PPT/PS）做。

## 五、构图与视角的几条实操口径

| 品类 | 主图视角 | 说明 |
|---|---|---|
| 小件（杯子、饰品、3C） | 正面平视 或 轻微俯视 15~30° | 避免大俯视，会看不出体积 |
| 服饰 | 平铺俯视 或 真人模特 | 平铺要摆正，不要歪斜 |
| 大件（家电、家具） | 3/4 侧视 | 平视会显得扁平，3/4 有纵深 |
| 食品 | 45° 俯视 + 特写 | 强调质感与分量 |
| 拆解/细节 | 微距 | 焦点单一，背景干净 |

**光线**：白底图用**均匀柔光**，避免硬阴影；场景图用**单一方向光**（如左上方晨光），
有方向的光才有立体感。

**同一套图的统一性**：五张图应共享色板（建议 2 主色 + 1 点缀色）、同一光线方向、
同一画风。本包的 `sellpoints` 提示词里已经写了这个约束。

## 六、常见失败模式

| 失败模式 | 表现 | 怎么避 |
|---|---|---|
| 五张图一个样 | 划完不知道区别 | 按**主图位**分配内容，不要平均分卖点 |
| 白底不白 | 背景是浅灰/带渐变 | 实拍去背，别指望 AI 生成准 |
| 主图贴边 | 主体被平台角标盖住 | 主体占比 70%~85%，四周留白 |
| 图上压字糊了 | AI 生成的文字是乱码 | 一律「不要在图上生成文字」，文字后期压 |
| 编造资质 | 图上写「国家级检测认证」但拿不出报告 | 本包合规闸门会拦；**没有就如实缺位** |
| 编造销量 | 「月销 10 万+」来自想象 | 销量只写后台真实数；闸门会拦 |
| 场景图摆拍不存在的效果 | 「一杯顶三杯」式演示 | 演示要能复现，不能演的别画 |
| 详情页所有屏都用 AI 出图 | 参数表全是错字 | 文字屏用本地排版 |

## 七、与新媒体配图的边界（别把两个包混用）

| 你要做的事 | 用哪个包 |
|---|---|
| 给公众号文章配插图 | `sanjianke-image-factory`（新媒体配图工厂） |
| 出小红书笔记封面 | `sanjianke-image-factory` 或 `xhs-daihuo-live-kit` |
| 出**电商平台商品主图与详情图** | **本包** |
| 写商品笔记与直播脚本（文案，不出图） | `xhs-daihuo-live-kit` |
| 把图做成短视频 | `sanjianke-short-video-maker` |

**最直接的判据**：如果产出要**上传到电商后台的商品图位**、要满足
「淘宝 800x800 白底」「抖音商城 3:4」这类**平台规格**、要按主图位分配卖点，
那就是本包；否则是配图工厂。
