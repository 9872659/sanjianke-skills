# 三剪客 · AI 科研全流程 Skill

把选题、查文献、做实验、写论文串成一条可执行流水线

---

## 前置条件

- 一句写下来的研究方向（一句话就够，但要写下来）
- 一个可读写的项目目录，用来放选题池、文献卡、综述矩阵、实验台账与草稿
- 需要检索时有网络；不检索、只做发散整理和写作时，可完全离线
- 要核对文献，需要你自己具备打开原文的权限（预印本站点、机构订阅等）
- 文献管理工具可选，任意引用管理器或纯文本清单都行，没有也能跑完整条流程

---

## 使用

四段流程，每段一份参考资料，开工前把该段的检查清单贴到对话里，收尾逐条打勾再进下一段。

| 阶段 | 做什么 | 看哪份 |
|---|---|---|
| 选题与头脑风暴 | 九入口发散 → 硬门槛与打分卡收敛 → 写成一句可证伪主张 | `references/01-选题与头脑风暴.md` |
| 文献检索与综述 | 关键词矩阵与三入口检索 → 三关筛选 → 文献卡与综述矩阵定位空白 | `references/02-文献检索与综述.md` |
| 实验设计与复现 | 主张拆成实验 → 变量与基线 → 重复与方差 → 实验台账 | `references/03-实验设计与复现.md` |
| 论文写作与投稿 | 一句话主张 → 图表先行 → 投稿前自检与审稿人预演 | `references/04-论文写作与投稿.md` |

建议的最小用法：先用阶段一收敛出 1~3 个候选选题，再用阶段二确认「这是真空白还是我没搜到」，
确认后再进阶段三开实验，最后按阶段四组织写作。**不要跳段**——跳过的部分通常会在投稿前回来找你。

## 依赖

- 无第三方 Python / Node 依赖，本 Skill 不含脚本
- 可选的文献管理工具（Zotero、BibTeX 或纯文本清单）
- 可选的版本管理工具，用于管理草稿与实验配置的变更历史

---

## 安全

- 不内嵌任何密钥
- 不索取、不读取、不存储任何账号、密钥或 API Key
- 不向任何外部站点上传你的稿件、数据或实验配置
- 写入范围限定在你的项目目录内；不覆盖已有文件，除非你明确要求
- 不启动常驻进程或后台服务
- 涉及人类受试者、隐私数据或其他受监管材料时，合规与伦理判断请走你所在机构的正式流程
