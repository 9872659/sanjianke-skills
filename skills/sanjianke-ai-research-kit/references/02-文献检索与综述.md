# 文献检索与综述

目标：用可复算的方式确认「这个题有没有人做过、做到哪一步、我自己判断的空白是真的还是我没搜到」，
并产出一份能直接长成论文引言与相关工作的综述矩阵。

这一段的核心纪律只有一条：**凡是要写进稿子的引用，必须能打开原文核对。**
任何无法核对的条目，一律留空并标注，绝不补全。

---

## 一、检索式的构造

### 1. 先建关键词矩阵

不要凭一个词硬搜。把概念拆成 2~4 个维度，每个维度列出同义词、缩写、上下位词。

```text
概念 A（研究对象）   ：术语1 | 同义词 | 缩写 | 上位词 | 下位词
概念 B（方法/机制）  ：术语2 | 同义词 | 缩写 | 上位词 | 下位词
概念 C（场景/数据）  ：术语3 | 同义词 | ...
概念 D（指标/结果）  ：术语4 | ...
```

然后用组合检索 `(A) AND (B) AND (C)`，并准备两套降级策略：
- 结果太少 → 去掉 C 或 D，放宽到 `(A) AND (B)`
- 结果太多 → 加年份限制或限定在标题/摘要字段

### 2. 三个入口交叉，缺一不可

| 入口 | 作用 | 注意 |
|---|---|---|
| 预印本站点 | 拿到最新、还没正式发表的工作 | 未经同行评审，结论要打折看 |
| 文献数据库 | 拿到已发表工作与引用关系 | 收录有滞后，别把「搜不到」当成「没有人做」 |
| 代码仓与项目页 | 看真实实现、数据、超参、issue 里的坑 | 论文没写的细节常常在这里 |

三个入口的结果必须交叉比对。只在数据库搜到 0 条，不等于这个方向是空白。

### 3. 滚雪球

找到 3~5 篇最核心的文献后，从它们向外扩：
- **后向**：它们的参考文献里反复出现的，通常是奠基工作
- **前向**：谁引用了它们，尤其看最近 12 个月的新工作
- **横向**：同一批作者的其他工作，常能看出这条线的走向

滚雪球两轮之后如果还在不断撞见同一批文献，说明覆盖够了；如果每篇都是新的，
说明你的检索式还太宽，先回去收窄。

### 4. 检索记录（必须留痕）
每轮检索记下：检索式、入口、时间、命中数、纳入数。
三个月后你会想知道「当时为什么没看到那篇」，这份记录就是答案。

## 二、三关筛选

| 关卡 | 看什么 | 处理 |
|---|---|---|
| 第一关：标题 | 是否与本方向相关 | 明显无关的直接排除，**排除理由只写一句** |
| 第二关：摘要 | 问题、方法、数据、结论是否成立 | 不确定的一律**保留**进下一关，宁可多读 |
| 第三关：全文 | 实验设置是否可比、结论是否有支撑 | 精读并写文献卡 |

纳入与排除标准要在开始筛选**之前**写好，不要边看边改。
一旦边看边改，你的筛选就会被「我期望看到什么」带偏。

```text
纳入标准：
  1. 发表于 <年份区间>
  2. 研究对象是 <...>
  3. 报告了 <指标 M> 的量化结果
排除标准：
  1. 只有摘要无全文
  2. 纯立场性文章、无实验
  3. 与本研究对象实质不同（说明在哪一点不同）
```

## 三、文献卡模板

一篇精读文献一张卡，存进 `01-文献卡/`，文件名统一：
`<年份>-<第一作者姓>-<短标题>.md`。命名统一比内容漂亮更重要，三个月后你会感谢自己。

```markdown
# <标题>

- 出处 / 年份 / 类型（会议、期刊、预印本）
- 可核对标识（DOI 或稳定链接）
- 核对状态：已打开原文核对 / 仅见摘要（未核对的内容不得进入稿子）
- 语种：

## 它解决什么问题

## 它的方法（一句话 + 关键部件）

## 数据与实验设置
- 数据：
- 基线：
- 指标：
- 是否报告方差 / 重复次数：

## 结论
- 作者自己的结论：
- 我能确认的结论（只写证据支撑得住的部分）：

## 局限与可疑处
- 作者声明的局限：
- 我发现的薄弱点：

## 与我候选选题的关系
- 支持 / 冲突 / 无关：
- 可复用的部件（方法、数据、评测协议）：
- 它没有回答的问题：
```

写卡时的两条硬规则：
1. **把「作者的结论」和「我的判断」分栏写**。混着写，三个月后就分不清哪句是谁的。
2. 任何指标数字都要连出处一起写（哪张表、哪个图）。凭记忆写的数字，等于没有。

## 四、综述矩阵

把文献卡横向摊成一张表，一行一篇，列是统一的结构化字段。
矩阵的价值不在记录，而在**空白变得可见**。

| 文献 | 问题 | 方法类 | 数据 | 指标 | 场景 | 报告方差 | 结论方向 |
|---|---|---|---|---|---|---|---|
| A (年份) |  |  |  |  |  | 是/否 | 正/负/混合 |
| B (年份) |  |  |  |  |  |  |  |

### 从矩阵读空白

- **空的格子**：某个「方法类 × 场景」组合没有任何一行 → 可能是空白
- **互相矛盾的列**：同一组合下两行结论方向相反 → 往往是可做的复现或调和工作
- **系统性缺失**：几乎所有行都「报告方差 = 否」→ 这一片的方法可靠性本身就是个题
- **扎堆的格子**：某格特别拥挤 → 除非你有明确的差异化理由，否则别进去

读出的每个空白，**必须标注它的类型**：

| 标注 | 含义 | 后续动作 |
|---|---|---|
| 确认空白 | 多个入口、多种检索式都没找到 | 可以进候选选题 |
| 疑似空白 | 只搜了 1~2 个入口，或语种受限 | 补一轮检索再判断 |
| 未确证 | 可能有但我没搜到 | 写进稿子时必须如实说明 |

把「未确证」写成「没有人做过」，是综述里最常见也最伤人的错误。

## 五、引文核对纪律（不可协商）

1. 每一条要进稿子的引用，都要能打开原文，且标题、年份、出处三者一致。
2. **禁止**根据标题猜测作者、页码、卷期；禁止「补全」看起来不完整的条目。
3. 引用管理器导出的条目**也要核对**，库里的元数据经常有错（年份错、会议与期刊混、作者顺序错）。
4. 无法核对的条目：从稿子里删掉，或保留但标注「待核对」并**明确告知合作者**。
5. 引用内容与原文观点一致——不要引用一篇论文来支持它其实反对的观点。
6. 二手引用（引 A 文里说的 B 文）如果能拿到 B 文原文，就引 B 文；拿不到就写清转引来源。

核对完成后做一次抽查：随机抽 10% 的引用重新打开核对。抽查发现的错误率超过一成，
就全部重核一遍。

## 六、综述写作的骨架

相关工作不是文献罗列，要有组织逻辑。常用三种：

| 组织方式 | 适用 | 结构 |
|---|---|---|
| 按方法类 | 方法路线差异明显 | 每类一小段，段末点出该类共同局限 |
| 按时间线 | 技术演进快 | 讲清每次变化的驱动力，落到当前状态 |
| 按问题维度 | 同一问题有多种解法 | 每段一个子问题，比较各自取舍 |

段落收尾句永远是同一个任务：**指出这一类工作留下的空缺，并接到你自己的选题上。**
如果某段收尾接不上你的选题，这段可能不该出现。

---

## 七、阶段检查清单

- [ ] 关键词矩阵覆盖了 2~4 个维度，每个维度含同义词与缩写
- [ ] 预印本、数据库、代码仓三个入口都搜过
- [ ] 滚雪球走了至少两轮（后向 + 前向）
- [ ] 每轮检索都记录了检索式、入口、时间、命中数与纳入数
- [ ] 纳入/排除标准在筛选前就已写好，中途没有改动
- [ ] 精读文献都有文献卡，且严格区分了「作者结论」与「我的判断」
- [ ] 每张卡上的指标数字都连表号或图号
- [ ] 综述矩阵里每个空白都标了类型（确认空白 / 疑似空白 / 未确证）
- [ ] 所有进入稿子的引用都能打开原文核对
- [ ] 已完成 10% 引用抽查，错误率可接受
