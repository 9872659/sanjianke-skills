# 三剪客 · 出海本地化小组

**产品线 L3（多智能体协作型）。**

给一份源语言材料 + 一个目标市场，四个立场不同的角色各自独立审一遍，
**一条命令出成品**：译文 + 术语表 + 四席裁决 + 互否全过程记录。

> ## ⚠️ 先申请你自己的 API Key
>
> **本包不内嵌任何密钥，也不代付费用。** 请到
> **[算力集市 api.a7w.cn](https://api.a7w.cn/)** 注册并创建**你自己的** API Key
> （新用户有赠送点数，可以先免费试跑一两条）。
>
> 拿到后填进环境变量 `A7W_API_KEY`，或直接传给 `--key` 参数。

## 这个包解决什么问题

出海本地化真正的成本不在"翻不出来"，在**没人能否掉这一稿**：

- 译审翻完就交了，因为没人会打回他；
- 文化上说"总体还可以"，因为挑不出具体那句也不会有人追究；
- 同一个词前面译 `mini-series`、后面译 `short drama`，没人全篇数过；
- 合规最后一眼扫过就放行，因为前面都说没问题了。

一份稿子被四个人看过，等于被零个人看过 —— 每个人的判断都建立在
"别人已经看过了"这个假设上。本包把这个假设**拆掉**：

| 常见做法 | 本包 |
|---|---|
| 一个模型分四次扮演不同角色，共享同一份上下文 | 四个角色各有**字段白名单**，看不到什么被写死成结构 |
| 译审知道文化适配觉得哪里有问题 | 译审的提示词里**没有**文化适配的任何文字，也没有合规裁决 |
| 合规顺着前面几席的结论走 | 合规的提示词里明写「本小组内部没有给出任何风险结论，**你不得假设前道已经放行**」 |
| "术语应该是一致的吧" | 本地按源句↔译句对齐**逐处核对**，不一致就列出全部出现位置 |
| 数字翻译过去大概没错 | 本地抽数字与单位、按目标市场算期望换算值，丢了或算错都拦 |
| "改了几轮，应该差不多了" | 轮次用尽仍有打回/否决会**明说**，附未决项，退出码 6 |

## L1 / L2 / L3 三层分界

| 层 | 形态 | 同族已有的包 |
|---|---|---|
| **L1 单点生成型** | 一个输入 → 一个产出，开箱即用 | 爆款标题工坊、一稿多平台改写 |
| **L2 智能体型** | **单循环**：抽档 → 写 → 自检 → 迭代（**一个声音在自我迭代**） | 内容质量闭环、风格克隆体 |
| **L3 多智能体协作型** | **多角色分工互审**，一条命令出成品 | 内容团队、评审委员会、短剧小组、← **本包** |

## 与 `sanjianke-multiplat-rewrite` 的分界表（这张表是本包存在的理由）

两者都是"给一份材料、出一条命令、出多个产出"，**很容易被误认为是同一件事加了个翻译步骤**。
下面逐项对照说明为什么不是：

| 维度 | L1 · 一稿多平台改写 | **L3 · 出海本地化小组（本包）** |
|---|---|---|
| 语言 | **同一种语言**，只换平台形态 | **跨语言**：源语言 → 目标语言 |
| 变的是什么 | 字数 / 段落 / 开场 / 结尾 / 标签（**形态**） | 语言本身 + 术语 + 单位 + 文化意象（**语义与本地惯例**） |
| 角色数 | **1** 个（一个改写者按五张规格表各写一遍） | **4** 个，各自独立调用 |
| 立场冲突 | **没有冲突**：五个平台互不影响，谁也不会否掉谁 | **结构性冲突**：文化适配可以为了"这个意象在美国读起来不对"否掉一句完全准确的译文 |
| 目标市场 | 无此概念 | **是一等公民**：它同时决定文化规则包与合规法域，并进断点 key |
| **术语一致** | **结构上不存在**：同语言改写没有"源词→目标词"的映射 | **核心机制**：术语表 + 版本 + 逐处对齐核对 + 全部出现位置 |
| **文化风险** | **结构上不存在**：不跨文化就没有文化误读 | **核心机制**：禁忌 / 宗教 / 颜色 / 数字 / 幽默失效 / 政治敏感，且**能否决** |
| 数字与单位 | 同语言，数字照抄即可 | **必须换算且要算对**：3 斤 → 3.31 lb、25 ℃ → 77 ℉；算错即拦 |
| 合规口径 | 一套（国内平台红线） | **两套**：源语言侧广告法 + **目标市场侧**自己的法域规则（FTC / 景表法 / UCPD / 清真…） |
| 信息隔离 | 不需要 | **必需**：四席互看不到结论，调用前用文本级扫描验证 |
| 迭代对象 | 同一篇稿的措辞与结构 | **译文会被退回重译**，而重译只带"要求"、不带提要求的席位 |
| 终止 | 五篇都合格就完事 | 四席全部放行，或**轮次用尽带未决项**（退出码 6），不许假装谈拢 |
| 谁能否谁 | **没有人能否任何人** | 译审能打回、术语官能打回、文化适配能否决、合规**一票否决** |

**一句话记住**：`multiplat-rewrite` 回答「同一篇稿子在不同平台该怎么写」，
本包回答「这份材料到了另一个语言与市场，**能不能发、谁说了算**」。

**反过来说清楚**：如果你要的是"同一语言、多平台分发"，用 `multiplat-rewrite` 更省
（单角色、五张规格表、成本更低）。本包的价值在**跨语言之后那四件互相牵制的事**，
不在"多跑几次模型"。

## 四个角色与职权

| 角色 | 目标函数 | 产出物 | 否决权 |
|---|---|---|---|
| **译审** | 意思准不准、有没有漏译错译 | 译文 + 逐句回译对照 | **能打回**（意思错就得重译） |
| **文化适配** | 目标市场的文化能不能接受 | 文化风险清单（禁忌 / 宗教 / 颜色 / 数字 / 幽默失效 / 政治敏感） | **能否决**（踩红线必须改） |
| **术语官** | 术语全篇一致、与行业惯例一致 | 术语表 + 不一致清单（**全部出现位置**） | **能打回**（同词多译必须统一） |
| **合规** | 目标市场的广告法 / 平台规则 | 风险裁决（放行 / 可替换 / 打回 / **一票否决**） | **一票否决** |

零成本看这张表：

```bash
python3 scripts/run.py roles
```

### 一条协作命令的走向

```
                ┌─▶ 术语官 glossary_check（纯本地，零成本）──┬─ 一致 ─┐
译审 translate ─┼─▶ 文化适配 culture（**能否决**）─────────┼─ pass ─┼─▶ 定稿
                └─▶ 合规 compliance（**一票否决**）────────┴─ pass ─┘
     ▲                                                             │
     │        打回要求（**去立场化**：只带"改成什么"，                     │
     └──────── 不带"谁在什么立场上说了什么"）◀── 任一席打回/否决 ──────┘
```

**四席是并行独立关系，不是投票，也不是串行放行**：任何一席打回都足够让这一稿退回重译；
四席里没有任何一席能替另一席放行。

### 信息隔离怎么落地（不是口头约定）

| 角色 | 看得到（白名单） | 看不到（被显式排除） |
|---|---|---|
| 译审 | 源文、目标语言、目标市场、术语表、上一轮要求 | 文化风险清单、文化适配裁决、合规裁决 |
| 术语官 | 源文、译文、术语表、目标语言、目标市场 | 文化风险清单、文化适配裁决、合规裁决 |
| 文化适配 | 源文、译文、目标市场、目标语言 | 术语不一致清单、术语官裁决、合规裁决 |
| 合规 | 源文、译文、目标市场、目标语言 | 术语不一致清单、术语官裁决、文化风险清单、译审问题清单 |

`assert_isolation()` 在**每次调用前**用文本级扫描验证（prompt 里出现别的席位的结论标记词
就抛异常、退出码 3、**一分钱不花**），判定结果逐条写进产出与流程日志。
真机实测：四席分别扫了 **14 / 0 / 13 / 16** 个标记词，泄漏 **0** 条。

## 快速上手

### 0. 拿 API Key

到 **[api.a7w.cn](https://api.a7w.cn/)** 注册，创建一个 API Key（形如 `sk-...`）。

### 1. 填 Key

```bash
# Linux / macOS
export A7W_API_KEY=sk-你的key

# Windows PowerShell
$env:A7W_API_KEY="sk-你的key"
```

也可以存进配置文件反复用：

```bash
python3 scripts/a7w.py login --key sk-你的key
```

### 2. 零成本先看一眼（不联网 / 不花钱）

```bash
python3 scripts/run.py roles
python3 scripts/run.py cost --file 源文.md --rounds 1 --price-in 1000 --price-out 2000
python3 scripts/run.py translate --file 源文.md --target-lang en --market us --dry-run
```

### 3. 一条命令出成品

```bash
python3 scripts/run.py run --file 源文.md \
    --target-lang en --market us --rounds 1 \
    --outdir /tmp/localize-out --json --out /tmp/localize-out/run.json
```

`--outdir` 里会落：`final.md`（定稿译文）、`final.json`、`glossary.json` / `glossary.md`、
`translation.md`（逐句回译对照）、`REPORT.md`（总报告）、`log.json`、
`localize-state.json`（断点）。**同一个 `--outdir` 重跑，命中断点的步骤只打印"跳过（零成本）"。**

### 4. 读回全过程

```bash
python3 scripts/run.py log --outdir /tmp/localize-out
```

## 十个子命令

| 子命令 | 干什么 | 花钱 |
|---|---|---|
| `roles` | 列出四席职权、隔离白名单、支持的市场与语言 | 否 |
| `glossary` | 源文 → 术语表（源词 → 目标语规范译法） | 是 |
| `translate` | 译审出译文 + 逐句回译对照 | 是 |
| `culture` | 文化适配出风险清单（**能否决**） | 是 |
| `glossary_check` | 术语一致性核对（**能打回**，纯本地、可零成本重跑） | **否** |
| `check` | 对一份已有译文跑**全部本地闸门**（术语 + 数字单位 + 占位符 + 照抄示例 + 锚点） | **否** |
| `compliance` | 目标市场合规裁决（**可否决 / 一票否决**） | 是 |
| `run` | 一条命令跑完整协作：四席互审 + 轮次上限 + 明确出口 | 是 |
| `log` | 读回全过程：谁在第几轮打回了什么、引用了哪句 | 否 |
| `cost` | 报价 / 用真实 usage 核算 | 否 |
| `models` | 列出 api.a7w.cn 当前在架的模型 | 否 |

支持的目标市场：`us` / `eu` / `jp` / `sea` / `me` / `br`。
支持的目标语言：`zh` / `zh-tw` / `en` / `ja` / `ko` / `es` / `pt` / `fr` / `de` /
`ar` / `th` / `vi` / `id` / `ru`。

**市场不是装饰**：它同时决定文化适配的规则包与合规的法域，所以**进断点 key** ——
换了市场却复用上一次的合规结论，是这类工具最危险的一种静默复用。

## 七道硬闸门

**硬闸门 = 命中即拦截 + 标红 + stderr 汇总 + 非 0 退出码。不许只警告。**

| # | 闸门 | 判什么 |
|---|---|---|
| 1 | **合规** | **源语言侧 + 目标市场侧分开扫**；产出侧排除"引用材料"与"警告语境"，被排除的**全部留原因**，但闸门仍有牙 |
| 2 | **占位符残留** | `{}` / `[待填]` / `XXX` / `（此处省略）` / `TODO` |
| 3 | **照抄提示词示例** | 三条判据 + 相对长度守卫；**覆盖度判据必须加适用窗口**，否则长文对短示例会饱和误报 |
| 4 | **锚点到句子** | 每条意见必须引用真实原文；本地校验，**编造的引文剔出**；未锚定率 > 40% 判定位失败 |
| 5 | **术语一致性** | 同一源词全篇必须同一译法；不一致 → 标红 + **列出全部出现位置** |
| 6 | **数字与单位保全** | 数字/日期/货币/规格必须还在且**单位正确换算**；丢了或没本地化 → 拦 |
| 7 | **裁决完整性** | 打回/否决必须留可读理由；**不许假装谈拢** |

### 退出码（可直接进 CI）

| 码 | 含义 |
|---|---|
| 0 | 四席全部放行，且没有硬闸门命中 |
| 1 | 未预料异常（`--json` 下给 `kind:"internal"` 信封 + 完整 traceback 到 stderr） |
| 2 | 用法/配置错误（文件不存在、市场名错、`--outdir` 在包内、`--budget` 没配单价、术语表与源文对不上） |
| 3 | 硬闸门命中（含信息隔离被破坏） |
| 4 | 调用失败（网络 / 401 / 402 / 404） |
| 5 | 预算超限，已就地中止（**未发起下一次调用**） |
| 6 | **轮次用尽仍有打回/否决**（未决项如实报出，产出带未决项落盘） |
| 130 | 用户中断 |

## 真机实测（一次完整 `run`）

材料：**187 字**中文投放素材（短剧出海、道具规格、订阅价格、含绝对化用语）。
方向：中文 → 英文；目标市场：美国；`--rounds 1`。

| 角色 | 裁决 | 关键理由 |
|---|---|---|
| 译审 | **打回重译** | 数字还在但没按目标市场换算 2 处（`3 斤`、`2 公斤` 没换单位） |
| 术语官 | **打回重译** | `投放` 应为 `ad placement`（2 处出现，1 处命中） |
| 文化适配 | **打回重译** | `jin` 美国人不认识；龙在美式基督教语境常被读成邪恶象征；素材里点名 TikTok 在美属政治敏感；`best`/`guarantee` 属绝对化宣称 |
| 合规 | **一票否决** | `best` / `guarantee` / `100%` 违反 FTC 可举证要求；源文侧「最好」「保证」「100%」命中 |

- **成本**：4 次调用、共 **7140 token**（入 5013 / 出 2127），单席耗时 2.8~4.2 秒
- **退出码**：6（轮次用尽仍有 4 席打回/否决）→ 产出带未决项落盘，**没有假装谈拢**
- **信息隔离**：四席扫过 14 / 0 / 13 / 16 个标记词，泄漏 **0** 条
- **两道特色闸门**：术语一致性查出 1 条不一致并给出全部出现位置；
  数字与单位查出 2 处「原数字还在但没换单位」

### 这四个角色是真的在互相否，还是各写各的？

**是真的在互相否。** 证据有四条，都能在 `REPORT.md` 里逐条复核：

1. **四席里有三席反对、但不是同一批理由**：译审说的是**数字没换单位**（它只管忠实），
   术语官说的是**`投放` 一处用了别的说法**（它只管一致），文化适配说的是
   **`jin`、龙意象、点名 TikTok**（它只管目标市场能不能接受）——
   三席盯的是同一份译文的**三个不同侧面**，各自给了具体改法。
2. **合规的一票否决真的终止了流程**：最终裁决就是"一票否决"，
   产出是**带未决项**的稿子，而不是"改完就发"。
3. **如果四席是同一个声音，术语官不会单独报出 `投放` 那一条** ——
   它是纯本地判定（不调模型、不看别人的意见），却抓到了模型自报清单里没有的一处不一致。
   **这就是"多角色"与"一个角色多跑几次"最实在的区别。**
4. **两席剑指同一句话，但不是抄结论**：文化适配与合规都盯上了 `best`。
   这**不是**隔离泄漏 —— 两席的提示词里都没有对方的任何文字（隔离表里的
   `markers_checked` / `leaked` 就是证据）。真因是那句话在两个立场下都站不住：
   一个说"这样写没人信"，一个说"这样写违法"。**立场不同、结论相似，是独立判断的结果。**

反过来说：如果四席每次都齐刷刷地反对、且理由是同一批话，那就是"一个声音演四遍"。

## 排错

| 现象 | 怎么办 |
|---|---|
| 401 / 402 / 404 | 到 https://api.a7w.cn/ 重新创建 Key 或充值；模型名用 `run.py models` 现查 |
| 上游 502 / upstream timeout | 脚本已内置退避重试（最多 4 次）；连续失败就换模型 |
| `上游返回的 JSON 坏了`（报错里带 `finish_reason`） | 三种坏法都实测到过：**截断**（`finish_reason=length`）、**模型偶发语法错**（`finish_reason=stop`，内容有正常收尾）、**传输被切断**。脚本当场自动重试；**只有 `length` 才该加大 `--max-tokens`**，其余情况加大它没用 → 换模型或拆段跑。**别用长度判断**：同一端点实测能拿到 3984 字符的完整内容 |
| `译审返回里没有可用的译文` | 看 `<outdir>/raw/` 里的**原始返回**（报错信息里也会打出顶层键与 `finish_reason`） |
| `!! 信息隔离被破坏` | 这是**代码 bug**（模板串了上下文），不是模型问题。报出来 |
| `术语表针对的不是这一版源文` | 这就是它该做的：**拒绝静默复用**。重新跑 `glossary` |
| 术语一致性标红 | 看 `glossary_check` 输出的**全部出现位置**；改完重跑（这个子命令零成本） |
| 数字与单位标红 | 看报告里的上下文；"丢数字"和"没本地化"是两回事，报告里分得清 |
| 退出码 6 | **这是设计行为**：分歧如实报出。看 `REPORT.md` 的未决项，人工决定是改还是不发 |
| `unrecognized arguments: --out` | 本包**不允许长选项前缀缩写**（故意的：`--out` 曾被静默吃成 `--outdir`），写全 |

更多排错见 `references/成本与排错.md`。
