# 出片流水线 · 七道工序

**一个选题 → 一条能发的短视频。** 本文只讲工序怎么衔接、每步传什么、怎么验收。
字幕与合成的细节看 `字幕与合成.md`，批量看 `批量出片.md`。

---

## 全景

```
选题
 ├─① 脚本   模型网关 chat/completions   → 口播稿（按镜头分段）+ 画面关键词
 ├─② 配音   voice_tts tts / tts_async  → 逐段音频
 ├─③ 出图   nano_banana submit          → 每镜头一张配图
 ├─④ 出片   full_video submit           → 需要动感的镜头出 4～15 秒片段
 ├─⑤ 字幕   分段累计时长 或 stt         → SRT
 ├─⑥ 音乐   music_generation / search   → BGM
 └─⑦ 合成   本地 ffmpeg（+ flashvsr）   → 成片
```

**关键顺序约束**

- ① 必须**按镜头分段**输出 —— 后面 ②③④⑤ 全部按同一套 `shot_id` 对齐
- ② 必须在 ⑤ 之前 —— 字幕的时间轴来自配音
- ③ 尽量在 ④ 之前全部出完并人工过一遍 —— 图定了视频才稳
- ⑥ 与 ② 分开做 —— **不要在出片接口里要求配乐**，会与配音打架

---

## ① 脚本 · 按镜头分段

| 项 | 内容 |
|---|---|
| 路径 | `POST /api/v1/chat/completions` |
| 传什么 | 选题 + 时长 + 镜头数要求 |
| 拿回什么 | JSON 数组：`shot_id` / `line` / `visual` |
| 验收 | 前 3 秒有钩子；每镜头一句话 ≤25 字；镜头数 8～12（60 秒片） |

**指令模板：**

```
你是短视频编导。围绕选题「{选题}」写一条 {秒数} 秒 {画幅} 口播稿。要求：
1) 开头 3 秒必须有钩子（提问 / 反转 / 数据）；
2) 分成 8～12 个镜头，每个镜头一句话，不超过 25 字；
3) 每个镜头给一个英文画面关键词（用于文生图），风格统一；
4) 结尾给一句行动号召。
输出 JSON 数组，每项含 shot_id、line、visual。只输出 JSON，不要解释。
```

**模型选择**：日常出稿用 `DeepSeek-V4-Flash`（快、省）；
要打磨文案用 `DeepSeek-V4-Pro` 或 `Qwen3.7-Max`。
推理模型 `max_tokens` 设太小会只返回 `null`，结构化产出建议 ≥ 200。

## ② 配音 · 逐段合成

| 项 | 内容 |
|---|---|
| 路径 | `POST /api/v1/apps/voice_tts/tts`（≤500 字）<br>`POST /api/v1/apps/voice_tts/tts_async`（≤10000 字） |
| 传什么 | `text`（该镜头那句话）+ `reference_id`（可选音色）+ `format` |
| 拿回什么 | 音频 URL |
| 验收 | 语速舒服（`prosody.speed` 1.0～1.1）；单段时长与画面预期匹配 |

**逐段合成而不是整段合成** —— 这样字幕时间轴可以直接累加（见 `字幕与合成.md`），
改一句只重做那一段。

想用自己的声音：先 `clone_voice` 一次拿音色 ID，之后所有片子复用。

## ③ 出图 · 每镜头一张

| 项 | 内容 |
|---|---|
| 路径 | `POST /api/v1/apps/nano_banana/submit` |
| 传什么 | 英文 `prompt` + `aspect_ratio`（与成片一致） |
| 拿回什么 | 图片 URL |
| 验收 | 风格统一（同一批用同一个风格前缀）；主体清晰；画幅正确 |

**统一风格的小技巧**：在每条 `prompt` 后加同一个风格后缀，例如
`, soft natural light, clean minimal, high detail, {画幅} vertical`。

**省钱关键**：**静态画面就到此为止**，别继续出视频。
用本地 ffmpeg 的 zoompan 给图片加缓慢推拉，免费做出「活」的感觉：

```bash
# 一张图做出 6 秒缓慢推近的效果（Ken Burns）
ffmpeg -loop 1 -i shot01.png -t 6 -vf \
  "zoompan=z='min(zoom+0.0015,1.15)':d=150:s=1080x1920,fps=25" \
  -c:v libx264 -pix_fmt yuv420p shot01.mp4
```

## ④ 出片 · 只给需要动感的镜头

| 项 | 内容 |
|---|---|
| 路径 | `POST /api/v1/apps/full_video/submit` |
| 传什么 | `content`（须含一项文本）+ `ratio` + `duration`（4～15 秒整数）+ `resolution` |
| 拿回什么 | 视频 URL |
| 验收 | 动作自然、无穿模；时长与画面节奏匹配；画幅一致 |

**只给这些镜头出视频**：开头钩子、需要动作展示的、需要转场的。
其余镜头一律用 ③ 的图片 + zoompan。

**硬约束**：`duration` 只能 4～15 秒整数；首帧尾帧各最多 1 张；
首尾帧模式**不能与参考媒体模式混用**。

## ⑥ 音乐 · BGM 与音效

| 要什么 | 用什么 | 关键参数 |
|---|---|---|
| 现成配乐 | `music_search/search` | `keyword`（如「轻快 科技」）+ `page_size` ≤ 20 |
| 生成专属 BGM | `music_generation/create` | `type: "generate"` + `prompt`（写**情绪**）+ `instrumental: true` |
| 环境音 / 音效 | `mmaudio/submit` | 视频 URL + 「空间 + 声源 + 强弱」描述 |

**BGM 描述写情绪，别写乐器清单**：`轻快的科技感电子音乐，节奏明快，情绪向上，无人声`
比 `钢琴 + 合成器 + 鼓` 好用得多。

## ⑦ 合成 · 本地 ffmpeg

```
1. 按 shot_id 顺序拼画面          → video.mp4
2. 按 shot_id 顺序拼配音          → voice.mp3
3. BGM 压到 0.15～0.2 倍后混音    → mix.mp3
4. 挂 SRT 烧字幕                  → out.mp4
5. （可选）flashvsr 超分
```

完整命令见 `字幕与合成.md`。**合成放本地做** —— 改一版字幕、调一次音量，
不应该产生任何费用。

## 产物命名约定（建议）

```
proj/<选题>/
├── 00-脚本文案/   script.json
├── 01-配音/       dub/shot01.mp3 …
├── 02-图片/       imgs/shot01.png …
├── 03-片段/       clips/shot01.mp4 …
├── 04-字幕/       sub.srt
├── 05-音乐/       bgm.mp3
├── 06-成片/       out.mp4
└── tasks.csv      task_id / 状态 / 点数
```

**`tasks.csv` 是断点续跑的命根子**：每次提交任务就写一行，
重跑只补 `failed` 的行，不重做已经成功的镜头。
