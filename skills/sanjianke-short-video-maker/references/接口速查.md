# 接口速查 · 短视频流水线用到的全部接口

**路径规则：一律 `/api/v1/apps/<应用代号>/<接口代号>`**，
应用代号与接口代号都用**下划线**，都可以现场查：

```bash
python3 scripts/a7w.py apps                # 列全部应用
python3 scripts/a7w.py schema <应用代号>    # 看该应用的接口与参数
```

> **不要用平台的 `endpoint_path` 字段拼 URL。** 部分应用给出的路径属于别的路由族
> （例如 `voice_tts` 给的是 `/v1/tts`、`wan` 给的是 `/v1/videos/generations`），
> 直接拿去请求打不通。**只用上面那条规则。**

---

## 一、模型网关（写脚本）

| 项 | 内容 |
|---|---|
| 路径 | `POST /api/v1/chat/completions` |
| Base URL | `https://api.a7w.cn/api/v1` |
| 模型清单 | `GET /api/v1/models` |
| 计费 | 按点数/百万 Token，输入输出分别计价 |

**常用模型**：`DeepSeek-V4-Flash`（快、省，日常出稿）、`DeepSeek-V4-Pro`（打磨文案）、
`Qwen3.7-Max`、`GLM-5.2`、`Kimi-K2.6`。

```bash
curl -sS -X POST "https://api.a7w.cn/api/v1/chat/completions" \
  -H "Authorization: Bearer $A7W_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"DeepSeek-V4-Flash","messages":[{"role":"user","content":"……"}]}'
```

> 推理模型会把 token 先花在思维链上，`max_tokens` 设太小会只返回 `null`，
> 结构化产出建议 ≥ 200。正文一律取 `choices[0].message.content`。

## 二、配音与字幕 · voice_tts（6 个接口）

| 接口 | 路径 | 模式 | 计费 |
|---|---|---|---|
| `tts` | `POST /api/v1/apps/voice_tts/tts` | 同步 | 50 点/千 Token；文本 ≤500 字 |
| `tts_async` | `POST /api/v1/apps/voice_tts/tts_async` | 异步 | 同上；文本 ≤10000 字 |
| `tts_live` | `POST /api/v1/apps/voice_tts/tts_live` | 异步 | 同上；流式上游 |
| `clone_voice` | `POST /api/v1/apps/voice_tts/clone_voice` | 同步 | 200 点/次（租户价） |
| `stt` | `POST /api/v1/apps/voice_tts/stt` | 同步 | 30 点/次 |
| `list_voices` | `GET /api/v1/apps/voice_tts/list_voices` | 同步 | 免费 |

**`tts` / `tts_async` 关键参数**

| 参数 | 说明 |
|---|---|
| `text` | **必填**，待合成文本 |
| `reference_id` | 音色模型 ID；不传用系统默认音色 |
| `model` | `s1` / `s2-pro`（默认 `s2-pro`） |
| `format` | `wav` / `pcm` / `mp3`（默认）/ `opus` |
| `prosody` | 语调对象：`speed` / `volume` / `normalize_loudness` |
| `mp3_bitrate` | `64` / `128` / `192` |
| `sample_rate` | 按格式限制 |
| `callback_url` | 仅 `tts_async`：任务终态回调地址 |

**`clone_voice`**：`title` 必填；`audio_url` 与文件上传二选一，
支持 mp3 / wav / ogg / flac；`visibility` 可设 `public` / `unlist` / `private`。

**`stt`**：`audio_url` 或文件上传二选一；`language`（不传自动检测）；
**`ignore_timestamps` 默认 `true`，要精确时间戳就传 `false`**。

## 三、出图 · nano_banana

| 接口 | 路径 | 模式 | 计费 |
|---|---|---|---|
| `submit` | `POST /api/v1/apps/nano_banana/submit` | 异步 | 24 点/次起（`nano-banana` · 1K） |
| `query` | `POST /api/v1/apps/nano_banana/query` | 同步 | 免费 |

| 参数 | 类型 | 说明 |
|---|---|---|
| `prompt` | string | 必填，画面描述（建议英文） |
| `action` | string | `generate`（文生图）/ `edit`（基于参考图改） |
| `image_urls` | array | `edit` 时必填，公网 URL 数组 |
| `model` | string | `nano-banana`（24 点）/ `nano-banana-2`（38）/ `nano-banana-2-lite`（24）/ `nano-banana-pro`（45）/ 各 `:official` 高清档 |
| `resolution` | string | `1K` / `2K` / `4K`（普通模型只吃 `1K`） |
| `aspect_ratio` | string | `9:16` / `16:9` / `1:1` / `auto` 等 |

## 四、出片 · 视频应用

| 应用 | 接口 | 适合 |
|---|---|---|
| `full_video` | `POST /api/v1/apps/full_video/submit` | **通用首选**：文 / 首尾帧 / 多模态参考 |
| `happy_horse` | `POST /api/v1/apps/happy_horse/submit` | 一阶段声画一起出、多语言对白 |
| `seedance` | `POST /api/v1/apps/seedance/create` | 480p / 720p / 1080p 分档 |
| `wan` | `POST /api/v1/apps/wan/create` | 多参考混用、角色参考 |

### full_video

| 参数 | 类型 | 说明 |
|---|---|---|
| `content` | array | **必填**，须含一项文本；可传首帧 / 尾帧 / 参考媒体 |
| `ratio` | string | 画幅，默认 `16:9`；竖屏用 `9:16` |
| `duration` | integer | **4～15 秒整数** |
| `resolution` | string | `480P` / `768P` / `1080P` / `2K` / `4K` |
| `aigc_watermark` | boolean | 是否添加生成标识 |

> 首帧尾帧各最多 1 张；参考图最多 9 张；参考视频 / 音频各最多 3 个；
> **首尾帧模式不能与参考媒体模式混用**。

### happy_horse

必填：`model`、`prompt`（≤2500 字）、`duration`（3～15 秒整数）、`resolution`（`720P` / `1080P`）。
价格档：720P **0.9 点/秒**、1080P **1.6 点/秒**（按 `duration` 计费）。

## 五、口播数字人（口播号路线）

| 接口 | 路径 | 必填 | 计费 |
|---|---|---|---|
| `image_human/submit` | `POST /api/v1/apps/image_human/submit` | `file_url`（人物图）+ `ref_file_url`（驱动音频） | `fast` 1.5 / `standard` 2 / `2k` 4 / `4k` 8 点每秒 |
| `lipsync/submit` | `POST /api/v1/apps/lipsync/submit` | `video_url` + `audio_url` | 见 `schema lipsync` |

`image_human` 的 `mode` 四档价差 **5.3 倍**，发布平台会压缩的渠道用 `fast` 或 `standard` 就够。

## 六、音乐与音效

| 接口 | 路径 | 模式 | 计费 |
|---|---|---|---|
| `music_generation/create` | `POST /api/v1/apps/music_generation/create` | 异步 | 65 点/次 |
| `music_generation/lyrics` | `POST /api/v1/apps/music_generation/lyrics` | 同步 | 12 点/次 |
| `music_generation/timing` | `POST /api/v1/apps/music_generation/timing` | 同步 | 免费 |
| `music_generation/mp4` / `wav` / `midi` | 同名路径 | 混合 | 20 / 14 / 14 点/次 |
| `music_search/search` | `POST /api/v1/apps/music_search/search` | 同步 | 10 点/次 |
| `mmaudio/submit` | `POST /api/v1/apps/mmaudio/submit` | 异步 | 按配置 |

`music_generation/create` 关键参数：`type`（`generate` / `extend` / `concat` / `cover` / `inspo` …）、
`prompt`（灵感模式 ≤500 字）、`lyric` + `style`（自定义模式）、
**`instrumental: true`（纯伴奏，开启后忽略歌词）**、`vocal_gender`（`m` / `f`）。

`music_search/search` 参数：`keyword`、`page`（从 1 开始）、`page_size`（最大 20）。

## 八、通用

| 用途 | 路径 |
|---|---|
| 查异步任务 | `GET /api/v1/tasks/{task_id}` |
| 列全部应用 | `GET /api/v1/apps` |
| 看某应用接口与参数 | `GET /api/v1/apps/{app}` |
| 模型清单 | `GET /api/v1/models` |
| 计费规则表 | `GET /api/v1/pricing` |

**响应信封**：`{code, msg, data}`，**`code` 为 `1` 才是成功**
（HTTP 200 不等于业务成功）。异步任务在提交时预冻结点数，完成后按实际用量结算。

## 九、客户端命令

```bash
python3 scripts/a7w.py apps                    # 列应用
python3 scripts/a7w.py schema voice_tts        # 看接口与参数
python3 scripts/a7w.py call voice_tts tts --body '{...}' --out out.mp3
python3 scripts/a7w.py call nano_banana submit --body '{...}' --out out.png
python3 scripts/a7w.py call full_video submit --body '{...}' --no-wait
python3 scripts/a7w.py task <task_id>          # 查任务（免费）
```

> 模型网关（`/chat/completions`）不走 `a7w.py`，用 `curl` 或任意 OpenAI SDK。
