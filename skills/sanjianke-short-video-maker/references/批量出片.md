# 批量出片

一条片子跑通之后，剩下的事就是**把选题铺开**。
批量出片的问题从来不是「接口能不能并发」，而是**断了怎么续、钱花在哪、质量怎么保**。

---

## 一、选题清单

一份 JSONL，一行一个选题：

```jsonl
{"topic": "人工智能如何改变日常生活", "aspect": "9:16", "seconds": 60, "voice": "男声-沉稳"}
{"topic": "三个让厨房变整齐的小习惯", "aspect": "9:16", "seconds": 45, "voice": "女声-轻快"}
{"topic": "为什么夏天更容易犯困", "aspect": "9:16", "seconds": 60, "voice": "男声-沉稳"}
```

字段设计原则：**只放「随选题变化的东西」**（选题、时长、音色、画幅），
公共参数（模型、分辨率、风格后缀）写在脚本里当默认值。

---

## 二、批量纪律

| 纪律 | 做法 | 为什么 |
|---|---|---|
| **先跑通一条** | 一条完整成片验证后再铺开 | 一上来 50 条，参数错了就是 50 倍损失 |
| **并发 2～4 路起步** | 视频生成最贵最慢，从低并发开始 | `429` 是排队上限到了；并发高不一定快 |
| **一条一张任务表** | `proj/<选题>/tasks.csv` | 混在一起就无法按片对账 |
| **每条片子独立目录** | 图片 / 配音 / 片段 / 字幕分开放 | 复用同一目录会互相覆盖 |
| **给 Key 设上限** | quota 设成预算的 1.2 倍 | 参数写错时能止损 |
| **边出边抽检** | 每条成片抽查字幕、音量、画幅 | 等 50 条跑完再检查，改起来成本高 |

---

## 三、任务表与断点续跑

`tasks.csv` 字段：

| 字段 | 说明 |
|---|---|
| `topic` | 选题（用于区分片子） |
| `shot_id` | 镜头编号 |
| `stage` | 工序：`script` / `dub` / `image` / `clip` / `sub` / `bgm` / `render` |
| `app` | 应用代号，用来按应用汇总成本 |
| `task_id` | 平台任务 ID，**去重与续跑都靠它** |
| `status` | `pending` / `completed` / `failed` |
| `points` | 实际扣点，用来对账 |
| `output_url` | 该步产出，下一步直接用 |
| `updated_at` | 时间戳 |

**续跑规则**

```
1. 提交前先读 tasks.csv，跳过 (topic, shot_id, stage) 已 completed 的
2. 提交后立刻追加一行 status=pending 并写入 task_id
3. 收到终态后更新为 completed / failed，回填 points 与 output_url
4. 重跑只处理 failed 与 pending
```

**`pending` 的行先查一次再重提** —— 网络超时里的任务可能已经成功了，
直接重提就是白花钱。

## 四、批量脚本骨架

```python
import csv, json, os, time, urllib.request

HOST = "https://api.a7w.cn"
KEY = os.environ["A7W_API_KEY"]
POLL = 5
FIELDS = ["topic", "shot_id", "stage", "app", "task_id", "status",
          "points", "output_url", "updated_at"]


def post(app, api, body):
    req = urllib.request.Request(
        "%s/api/v1/apps/%s/%s" % (HOST, app, api),
        data=json.dumps(body, ensure_ascii=False).encode(), method="POST",
        headers={"Authorization": "Bearer " + KEY, "Content-Type": "application/json"})
    with urllib.request.urlopen(req, timeout=300) as r:
        d = json.load(r)
    if d.get("code") not in (1, 200):
        raise RuntimeError(d.get("msg"))
    return d.get("data") or {}


def chat(model, prompt):
    """模型网关：写脚本。"""
    req = urllib.request.Request(
        HOST + "/api/v1/chat/completions",
        data=json.dumps({"model": model,
                         "messages": [{"role": "user", "content": prompt}]},
                        ensure_ascii=False).encode(), method="POST",
        headers={"Authorization": "Bearer " + KEY, "Content-Type": "application/json"})
    with urllib.request.urlopen(req, timeout=300) as r:
        d = json.load(r)
    return d["choices"][0]["message"]["content"]


def wait(task_id, timeout=1800):
    end = time.time() + timeout
    while time.time() < end:
        time.sleep(POLL)
        req = urllib.request.Request("%s/api/v1/tasks/%s" % (HOST, task_id),
                                     headers={"Authorization": "Bearer " + KEY})
        with urllib.request.urlopen(req, timeout=120) as r:
            t = json.load(r)
        st = t.get("status")
        if st in ("completed", "failed", "cancelled", "error"):
            return st, t
    return "timeout", {}


def rows(path):
    if not os.path.isfile(path):
        return []
    with open(path, encoding="utf-8") as f:
        return list(csv.DictReader(f))


def write_all(path, rs):
    with open(path, "w", newline="", encoding="utf-8") as f:
        w = csv.DictWriter(f, fieldnames=FIELDS)
        w.writeheader()
        w.writerows(rs)


def done(rs, topic, shot_id, stage):
    return any(r["topic"] == topic and r["shot_id"] == str(shot_id)
               and r["stage"] == stage and r["status"] == "completed" for r in rs)


def run_topic(topic, aspect="9:16", seconds=60, voice=None):
    """跑一个选题的完整流水线（各工序的轮询已省略，按 wait() 接上即可）。"""
    base = os.path.join("proj", topic)
    os.makedirs(os.path.join(base, "dub"), exist_ok=True)
    os.makedirs(os.path.join(base, "imgs"), exist_ok=True)
    csv_path = os.path.join(base, "tasks.csv")

    # ① 脚本
    script = chat("DeepSeek-V4-Flash",
                  "围绕选题「%s」写 %d 秒 %s 口播稿，分 8～12 个镜头，"
                  "每镜头一句话 ≤25 字，给英文画面关键词，"
                  "输出 JSON 数组（shot_id / line / visual），只输出 JSON。"
                  % (topic, seconds, aspect))
    shots = json.loads(script)

    rs = rows(csv_path)
    for shot in shots:
        sid = shot["shot_id"]

        # ② 配音
        if not done(rs, topic, sid, "dub"):
            body = {"text": shot["line"], "format": "mp3"}
            if voice:
                body["reference_id"] = voice
            data = post("voice_tts", "tts", body)
            rs.append({"topic": topic, "shot_id": sid, "stage": "dub",
                       "app": "voice_tts", "task_id": data.get("task_id", ""),
                       "status": "completed", "points": "", "output_url": "",
                       "updated_at": time.strftime("%Y-%m-%dT%H:%M:%S")})
            write_all(csv_path, rs)

        # ③ 出图
        if not done(rs, topic, sid, "image"):
            data = post("nano_banana", "submit",
                        {"action": "generate", "prompt": shot["visual"],
                         "aspect_ratio": aspect})
            tid = data.get("task_id")
            rs.append({"topic": topic, "shot_id": sid, "stage": "image",
                       "app": "nano_banana", "task_id": tid, "status": "pending",
                       "points": "", "output_url": "",
                       "updated_at": time.strftime("%Y-%m-%dT%H:%M:%S")})
            write_all(csv_path, rs)
            # st, detail = wait(tid)   # 拿到结果后回填 URL 与 points

    print("完成选题：%s（镜头 %d 个）" % (topic, len(shots)))


if __name__ == "__main__":
    for line in open("topics.jsonl", encoding="utf-8"):
        line = line.strip()
        if line:
            cfg = json.loads(line)
            run_topic(cfg["topic"], cfg.get("aspect", "9:16"),
                      cfg.get("seconds", 60), cfg.get("voice"))
```

**并发做法**：把 `run_topic` 放进 `concurrent.futures.ThreadPoolExecutor`，
`max_workers` 从 **2～4** 起步。每提交一个任务就落盘一次，进程挂了也能续上。

## 五、对账

```powershell
# 按应用汇总点数（本项目全部片子）
Get-ChildItem proj -Recurse -Filter tasks.csv | ForEach-Object {
  Import-Csv $_.FullName
} | Group-Object app | ForEach-Object {
  $p = ($_.Group | Measure-Object points -Sum).Sum
  "{0,-16} {1,10:N0} 点  {2,9:N2} 元" -f $_.Name, $p, ($p / 100)
}
```

```bash
# 失败的任务
python3 -c "
import csv, glob
for f in glob.glob('proj/**/tasks.csv', recursive=True):
    for r in csv.DictReader(open(f, encoding='utf-8')):
        if r['status'] != 'completed':
            print(f, r['shot_id'], r['stage'], r['app'], r['status'])
"
```

**对账口径**：每次调用返回的 `data.usage.points_cost` 是本次真实扣费；
任务级用量在 `GET /api/v1/tasks/{task_id}` 的 `usage`；
账号级流水在用户中心。

> 平台同时给出**标准价**（`fixed_price` / `input_price`）与
> **租户实际结算价**（`tenant_*`）。**做预算一律用租户价，最终以实际扣费为准。**

## 六、成本预估（先算再跑）

一条 60 秒竖屏（8 个镜头）的参考量级：

| 工序 | 数量 | 参考点数 |
|---|---|---|
| 脚本 | 1 次模型调用 | 约 5～20 点 |
| 配音 | 约 200 字 | 约 10 点 |
| 出图 | 8 张 | 192 点 |
| 出片（只给 3 个镜头） | 15 秒 | 参考 300 点（20 点/秒 · 1080P） |
| 字幕 `stt` | 1 次 | 30 点 |
| BGM | 1 首 | 65 点 |
| **合计** | | **约 600～900 点 ≈ 6～9 元** |

含 30% 废片率后约 **8～15 元/条**。

**省钱三招（按优先级）**
1. **静态画面别出视频** —— 用图片 + 本地 zoompan 缓动，免费
2. **少出图** —— 同场景复用配图
3. **分辨率锁够用档** —— 竖屏平台会二次压缩，720P 通常够
