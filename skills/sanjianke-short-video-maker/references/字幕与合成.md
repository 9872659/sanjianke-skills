# 字幕与合成

字幕是短视频量产里最容易卡住的一环。难的从来不是「识别文字」，
而是**时间轴从哪来**。本文给两条都能落地的做法，以及完整的合成命令。

---

## 一、先选做法

| 你的画面怎么来的 | 用哪条 | 为什么 |
|---|---|---|
| **按镜头逐段出的**（图片 / 视频片段） | **做法一：分段累计时长** | 时间轴与画面天然一一对应，改一句只重做一段 |
| 一整段素材池混剪 | 做法二：`stt` 精确时间戳 | 画面与句子不必严格对应，整段转写更省事 |

---

## 二、做法一：分段合成，累计时长（推荐）

### 原理

每句话单独合成一段音频，用每段音频的**真实时长**累加，
得到每句的起止时间，直接写成 SRT。

```
shot01.mp3  3.2 秒  →  00:00:00,000 → 00:00:03,200
shot02.mp3  4.1 秒  →  00:00:03,200 → 00:00:07,300
shot03.mp3  2.8 秒  →  00:00:07,300 → 00:00:10,100
```

### 第一步：取每段音频时长

```bash
# 单文件
ffprobe -v error -show_entries format=duration -of csv=p=0 dub/shot01.mp3

# 整个目录（输出：文件名,时长）
for f in dub/*.mp3; do
  echo "$f,$(ffprobe -v error -show_entries format=duration -of csv=p=0 "$f")"
done
```

### 第二步：生成 SRT

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""把「文案 + 音频时长」写成标准 SRT。零依赖。"""
import json
import subprocess
import sys


def duration(path):
    out = subprocess.run(
        ["ffprobe", "-v", "error", "-show_entries", "format=duration",
         "-of", "csv=p=0", path],
        capture_output=True, text=True, check=True).stdout.strip()
    return float(out)


def ts(sec):
    h = int(sec // 3600)
    m = int(sec % 3600 // 60)
    s = sec % 60
    return "%02d:%02d:%06.3f" % (h, m, s)


def main(script_json, dub_dir, out_srt):
    shots = json.load(open(script_json, encoding="utf-8"))
    lines, cur = [], 0.0
    for i, shot in enumerate(shots, 1):
        audio = "%s/shot%02d.mp3" % (dub_dir, shot["shot_id"])
        dur = duration(audio)
        lines.append("%d\n%s --> %s\n%s\n" % (i, ts(cur), ts(cur + dur), shot["line"].strip()))
        cur += dur
    with open(out_srt, "w", encoding="utf-8", newline="\n") as f:
        f.write("\n".join(lines))
    print("已生成 %s，共 %d 条，总时长 %.1f 秒" % (out_srt, len(shots), cur))


if __name__ == "__main__":
    main(sys.argv[1], sys.argv[2], sys.argv[3])
```

```bash
python3 make_srt.py script.json dub sub.srt
```

### 断句与小节奏

| 要点 | 说明 |
|---|---|
| **一行别超 15～18 字** | 竖屏一行太长会被裁；超了就拆成两条字幕 |
| **长句拆条** | 一条音频里有两句时，按字数比例拆分时长 |
| **前后各留 0.1～0.2 秒** | 字幕别贴着语音边缘切，观感更舒服 |
| **别在词语中间断** | 中文按语义断，不按固定字数硬切 |

## 三、做法二：用 `stt` 拿精确时间戳

把整条配音传回 `voice_tts/stt`，`ignore_timestamps` 设为 `false`：

```bash
python3 scripts/a7w.py call voice_tts stt \
  --body '{"audio_url":"https://你的存储/voice.mp3","language":"zh","ignore_timestamps":false}'
```

返回里含识别文本与时长信息（`data.text` / `data.duration` / `data.language`）。
**要时间轴就取精确时间戳字段，再转成 SRT。**

> **先跑一次 `python3 scripts/a7w.py schema voice_tts` 核对当期参数与返回结构，
> 以实际返回为准** —— 接口字段可能调整。
> 如果返回的是整段文本没有细分片段，就退回**做法一**，或者按标点自行切分。

**适合**：素材混剪号、画面与句子不要求严格对应的场景。
**计费**：30 点/次。

## 四、合成命令（ffmpeg）

### 1) 画面拼接

```bash
# concat.txt 每行：file 'clips/shot01.mp4'
ffmpeg -f concat -safe 0 -i concat.txt -c copy video.mp4
```

不同分辨率或编码的片段不能直接 `-c copy`，先统一转一遍：

```bash
ffmpeg -i in.mp4 -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2" \
  -c:v libx264 -pix_fmt yuv420p -r 25 norm/shot01.mp4
```

### 2) 配音拼接

```bash
ffmpeg -f concat -safe 0 -i dub.txt -c copy voice.mp3
```

### 3) 混音（BGM 压低）

```bash
ffmpeg -i voice.mp3 -i bgm.mp3 -filter_complex \
  "[1:a]volume=0.18[b];[0:a][b]amix=inputs=2:duration=first[a]" \
  -map "[a]" mix.mp3
```

音量经验值：**BGM 0.15～0.2 倍**。听不清台词就继续往下压，
别用「感觉刚好」当标准。

### 4) 合成 + 烧字幕

```bash
ffmpeg -i video.mp4 -i mix.mp3 -vf "subtitles=sub.srt:force_style='FontSize=18,Outline=2,Alignment=2,MarginV=90'" \
  -c:v libx264 -pix_fmt yuv420p -c:a aac -b:a 192k -shortest out.mp4
```

| 参数 | 说明 |
|---|---|
| `FontSize` | 竖屏建议 16～20（SRT 相对字号） |
| `Outline` | 描边，保证浅色画面也能看清 |
| `Alignment=2` | 底部居中 |
| `MarginV` | 距底部边距，避开平台 UI 遮挡区 |
| `-pix_fmt yuv420p` | **必加**，否则部分播放器 / 平台不认 |
| `-shortest` | 以最短流为准，避免尾部黑屏 |

### 5) 给静态图加缓动（省钱关键）

```bash
# 6 秒缓慢推近
ffmpeg -loop 1 -i shot01.png -t 6 -vf \
  "zoompan=z='min(zoom+0.0015,1.15)':d=150:s=1080x1920,fps=25" \
  -c:v libx264 -pix_fmt yuv420p shot01.mp4
```

## 五、导出检查清单

- [ ] 分辨率与画幅正确（`9:16` → 1080×1920）
- [ ] `-pix_fmt yuv420p` 已加，播放器兼容
- [ ] 字幕与语音同步，没有提前或滞后
- [ ] 字幕不出安全区（不被平台 UI 遮挡）
- [ ] 台词清晰，BGM 不盖过人声
- [ ] 无爆音、无静音段、无尾部黑屏
- [ ] 总时长符合投放要求

## 六、常见问题快查

| 现象 | 原因 | 处理 |
|---|---|---|
| 字幕比语音慢一拍 | 用了整段转写的粗时间轴 | 改用做法一：分段合成累计时长 |
| 字幕被平台 UI 挡住 | 边距太小 | 调大 `MarginV` |
| 某些播放器放不出画面 | 像素格式不兼容 | 加 `-pix_fmt yuv420p` |
| 拼接后时长错乱 | 片段帧率 / 分辨率不一致 | 先统一转码再 concat |
| 尾部几十秒黑屏 | 音视频长度不一致 | 加 `-shortest` |
| 中文显示成方块 | 字幕字体缺中文 | 指定中文字体或改用烧字幕后导出 |
| `stt` 返回没有细分时间戳 | 当期返回结构如此 | 退回做法一，或按标点自行切分 |
