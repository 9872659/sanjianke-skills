# 三剪客 · 图片与视频一键去背景 Skill

把图片或视频的主体从背景里抠出来，输出透明底、纯色底或换背景的成片：安装、图像与视频两类命令、蒙版与边缘参数、Docker 与批量处理、常见报错排查。

---

## 前置条件

- Python 3.6 及以上，并且要安装与所用 Python 版本对应的开发包。
- 装好 torch 与 torchvision（稳定版）；想要 GPU 加速就装对应 CUDA 版本的 torch。
- 装好 ffmpeg 4.4 及以上，命令行里能直接调用 `ffmpeg -version`。
- 首次运行需要联网下载模型权重，并保证用户模型缓存目录可写。
- HEIC / HEIF 图片输入需要额外装 `pillow-heif`。
- 走 Docker 路线需要本机 Docker；处理视频时要给容器足够的共享内存。
- 处理视频会占用较多 CPU 与内存，建议先在一小段素材上验证参数再跑全片。

---

## 使用

1. 按 `SKILL.md` 的「安装」一节装齐系统依赖、torch 与包本体。
2. 先确认设备：GPU 可用就走 GPU，否则退回 CPU（速度差距明显）。
3. 判断素材类型选模型：人像用专用人像模型，通用物体用默认模型，追求速度用轻量模型。
4. 按需要的输出选命令：透明底图、纯色底、换图片底、纯蒙版、透明视频、透明 GIF、遮罩素材。
5. 边缘不满意时用边缘细化开关及其参数调整，必要时换模型重试。
6. 批量任务用文件夹模式，一次处理整个目录。
7. 详细参数、可复制示例与排错对照，见 `SKILL.md`。

## 安全

- 不内嵌任何密钥；常规用法不需要账号或 API Key。
- 模型权重从网络下载，请确认下载源可信并注意校验；下载中断会产生损坏的模型文件，需要删除后重下。
- 用 HTTP 服务形态对外暴露时，URL 查询参数会让服务端代你发起网络请求，等于开放了一个服务端请求入口，必须做白名单与访问控制，不要暴露在公网。
- 处理人像素材涉及肖像权与个人信息，请在取得授权的范围内使用，并按适用的个人信息保护要求存储与销毁原图。
- 处理他人上传的内容时，输出文件落盘路径要由服务端决定并限制目录，避免被构造路径写到预期之外的位置。
- 这个工具的输出是推断结果，抠像错误可能造成画面信息缺失，正式出片前请人工抽检。
