# 三剪客 · 极速无损压缩命令行工具 Skill

lz4：极速无损压缩命令行工具 的安装、常用命令与避坑要点

---

## 前置条件

- Linux / macOS / BSD 上通常不需要额外环境；Windows 需要 C 编译环境（源码构建）或 vcpkg 这类依赖管理器。
- 源码构建需要 `make` 和一个 C 编译器；包管理器安装则不需要任何编译工具。
- 需要可写的目标磁盘：压缩产物在某些数据上可能并不比源文件小多少，归档前先确认空间够。
- 不需要网络、账号或 Key；只有在安装或下载源码时才联网。

---

## 使用

最短跑通路径：

```bash
lz4 big.log                    # 生成 big.log.lz4，保留源文件
lz4 -d big.log.lz4             # 解压（输入以 .lz4 结尾时默认即解压）
lz4 -9 big.log big.log.lz4     # 换高压缩档，显式写输入和输出
lz4 -t big.log.lz4             # 校验产物完整性
tar -cf - ./logs | lz4 -9 > logs.tar.lz4   # 流式归档压缩
```

什么时候该用、什么时候不该用、常见坑与能力边界，见同目录的 `SKILL.md`。

## 依赖

- 运行期：无第三方运行时依赖，单个可执行文件即可。
- 安装期：包管理器方式零编译依赖；源码构建需要 `make` 与 C 编译器；Windows 走 vcpkg 或自行构建。
- 可选：`tar`（归档必须靠它，`lz4` 本身不打包目录树）、发行版 man page（查参数与默认值）。
- 多线程压缩需要构建时带多线程支持，线程数上限受 `LZ4_NBWORKERS_MAX`（默认 200）约束。

---

## 安全

- 不内嵌任何密钥。
- 不提供加密：需要保密时请先加密再压缩，别指望压缩本身带来隐私保护。
- 默认保留源文件，只有显式加 `--rm` 才会删除；涉及删除的批量脚本建议先在测试目录跑一遍。
- `-f` 会强制覆盖已存在的目标文件，归档脚本里慎用，避免覆盖历史备份。
- 参数与压缩档位只影响体积、速度与校验，不会改变文件内容的语义（无损压缩）。
