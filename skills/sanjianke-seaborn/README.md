# 三剪客 · 统计数据可视化 Skill

把「这批数据分布长什么样、两组之间有没有关系」快速画成图：安装与依赖、五种图的典型写法、主题与调色板、数据集接口与离线注意点、类别图默认外观变更等常见坑

---

## 前置条件

- **Python 3.10 或更高**（官方要求）。
- **numpy / pandas / matplotlib**。安装本库时会一并装好；如果环境里已有旧版本，注意兼容性。
- **可选统计依赖**。回归拟合、聚类热图、部分统计计算需要 scipy 和 / 或 statsmodels，官方提供 `seaborn[stats]` 一次装齐。
- **需要中文标签时**：系统要装有支持中文的字体，并在 matplotlib 中显式指定字体族。
- **需要使用内置示例数据集时**：环境需能联网（数据从在线仓库下载后缓存到本地）。

---

## 使用

本 Skill 面向「把已有结构化数据画出来」的任务，推荐顺序：

1. 读 `SKILL.md` 的「什么时候用 / 不用」，确认需求是静态统计图；要交互图表、仪表盘就不要用这个库。
2. 确认数据已经是 DataFrame / 向量形态，列名清晰；数据清洗交给 pandas，不要指望绘图库代劳。
3. 先 `sns.set_theme()` 定好主题，再画具体图，避免逐图调样式。
4. 按图型选函数：关系图用 `scatterplot` / `lineplot`，分布用 `histplot` / `kdeplot`，分组对比用 `boxplot` / `violinplot`，相关性用 `heatmap`，两两关系用 `pairplot`。
5. 需要单张坐标轴继续加工时，用轴级函数；需要按变量分面成一组子图时，用 `relplot` / `displot` / `catplot` 这类图级函数。
6. 落盘用 matplotlib 的 `savefig`；在服务器或容器里不要依赖 `show()`。
7. 遇到颜色不对、缺包、中文方块、返回对象不对等问题，先查「常见坑」表。

函数名、参数与对象接口的完整清单以官方 API 参考页为准。

## 依赖

| 依赖 | 说明 |
|---|---|
| Python ≥ 3.10 | 官方要求的运行环境 |
| numpy | 数值计算基础 |
| pandas | 数据承载；本库接口围绕 DataFrame 设计 |
| matplotlib | 实际绘图层；本库是它的高层封装 |
| scipy（可选） | 层次聚类热图、部分统计功能 |
| statsmodels（可选） | 回归类绘图功能 |
| 支持中文的字体（可选） | 图上有中文标签时需要 |
| 网络（可选） | 仅内置示例数据集接口需要 |

## 安全

- 不内嵌任何密钥：本 Skill 正文不含账号、密钥或端点。
- 不需要任何凭证即可使用；不要为了画图去引入不必要的凭据配置。
- 内置示例数据集接口会发起网络请求并写入本地缓存目录，在受限网络或对出网有审计要求的环境里请先确认。
- 绘图本身不执行数据内容；但把外部来源的数据直接读入 pandas 再画图时，数据解析风险来自 pandas，应在读入阶段做校验。
- 图与报告中可能包含敏感数据（个人信息、业务指标），落盘与对外分享前先确认脱敏要求。
