# 知识付费招生 一门课 15 条链路素材

**一门课一天的招生素材 23 张，138 点 = 1.38 元。** 5 个招生环节乘 3 个核心版位排成 15 条链路素材；加一条 15 秒痛点视频、60 字讲师背书、一首配乐，整套 1,099 点 = 10.99 元。

知识付费运营一天真正要交的不是「一张海报」，是「一条招生链路」：痛点视频把人拦住，讲师背书让人信，大纲让人看清拿什么，价格锚点把总价摊成单节价，行动号召把人接进私域。少一环，转化就在那一环断掉。

## 招生链路 5 个环节（顺序就是转化顺序）

| 环节 | 一句话作用 | 前 3 秒说什么 | 主标 | 行动号召 |
|---|---|---|---|---|
| `L1` 痛点 | 把学员当下的处境说出来 | 会剪也会改，就是接不到单 | 会剪也会改，就是接不到单 | 先领 3 节试听 |
| `L2` 讲师背书 | 资历、作品量、带过的人 | 8 年影视后期讲师，带过 1200 名学员 | 8 年影视后期讲师 | 私信领讲师作品集 |
| `L3` 课程大纲 | 几章几节、每节交付什么 | 6 章 32 节，每节都留交付物 | 6 章 32 节 | 领完整大纲 |
| `L4` 价格锚点 | 原价、早鸟、摊到每节 | 早鸟 1280 元，原价 2980 元 | 早鸟 1280 元 | 锁早鸟名额 |
| `L5` 行动号召 | 加微 / 进群 / 领试听 | 今天进群，先领 3 节试听课 | 今天进群领试听 | 加微信进群 |

**命名 `课程码-环节_版位_v版本`：**

```
KP01-L1_3x4_v1.png     课程 01 / 痛点 / 小红书 3:4 / 第 1 版
KP01-L4_1x1_v1.png     课程 01 / 价格锚点 / 社群方图 / 第 1 版
KP02-L5_9x16_v2.png    课程 02 / 行动号召 / 视频号竖版 / 第 2 版
```

文件名就是排期表的主键：一眼看出这条素材站在链路哪一环、属于哪门课、第几版。`qc` 会按这条正则逐个验。

## 五个版位

| `--size` | 比例 | 请求尺寸 | 上架尺寸 | 平台 | 安全区 |
|---|---|---|---|---|---|
| `3x4` | 3:4 | 1152x1536 | 1242x1660 | 小红书笔记封面 / 公众号内页 | 上 1/3 主标，中段画面，底部 15% 留白 |
| `9x16` | 9:16 | 720x1280 | 1080x1920 | 视频号 / 抖音 / 快手 | 顶部 12% 角标，底部 18% 行动号召 |
| `1x1` | 1:1 | 1024x1024 | 1080x1080 | 社群 / 朋友圈 / 私域承接页 | 主体居中偏上，四角放价格与名额 |
| `16x9` | 16:9 | 1280x720 | 1920x1080 | 直播封面 / 公众号头图 / B 站 | 主体居中，左侧 1/4 给课程名 |
| `4x5` | 4:5 | 1024x1280 | 1080x1350 | 朋友圈广告 / 视频号动态 | 中心构图，上下各留 10% |

五个请求尺寸都在 gpt-image 的合法区间里：16 的倍数、长短边 3:1 内、单边 3840 内、总像素 655,360~8,294,400。`qc` 按这四条再验一遍，省得跑完 15 张才发现尺寸不合法。

## 封面 3 秒抓人 / 学员见证 / 私域承接

**封面 3 秒抓人**：主标压到 12 字内（「会剪也会改，就是接不到单」），副标 20 字内给结果（「30 天做出可以接单的片子」）。图先出**无字底版**，文字用排版叠上去 —— AI 出中文容易错字，底版 + 叠字比直接出带字图稳得多，也方便后期换价。

**学员见证排版**：3:4 竖版，左图右文，一句话引用 + 一个结果数字（「第 3 周接到 800 元的活」）。三张一组发，比单张可信；`plan` 的 `--witness 3` 就是这个数量，`--proof` 决定引用语。

**私域承接话术**：加微给东西、进群给规则、试听给筛子、催单给事实、复购给路径。`plan` 一次写全 5 条，`qc` 检查每条素材的行动号召都落在承接动作上（加微 / 进群 / 领 / 试听 / 扫码）——公域素材只负责把门推开，成交发生在私域。


## 退出码

| 码 | 含义 |
|---|---|
| `0` | 成功 |
| `2` | 用法错（缺 `--course`、秒数越界、选项缩写） |
| `3` | `qc` 检查没过 |
| `4` | 需要确认 —— 没给 `--yes` |
| `5` | 预算不足 —— **一个请求都不发** |
| `6` | 调用失败 |
| `1` | 内部错误 |
| `130` | 被 Ctrl-C 中断 |

`--json` 成功是 `{"ok": true, ...}`，失败是 `{"ok": false, "exit": 5, "error": {"kind": "budget", "message": "…"}}`，stdout 只有一个 JSON 文档；`--json` 写在子命令前后都可以。

## 三条用钱换来的规矩

**一、轮询一次就是一次的钱。** 应用层的 `/query` 每查一次按该应用单价结算，`nano_banana/query` 实测 72 点/次，一天轮询 30 次就是 2,160 点 —— 比一套招生包还贵。本包 `status` 只打 `GET /api/v1/tasks/<id>`，价目表里这条是 cost:0，等半小时也是 0 点。

**二、`GET /api/v1/apps/<app>` 是收费的。** 它命中 `/apps/<app>/*` 的通配计价，按该应用 flat 单价即时扣费、不退（实测 dressing_diffusion 200 点、nano_banana 72 点各一笔）。要目录只看 `/api/v1/apps` 列表和 `/api/v1/pricing`，两条都是 cost:0。

**三、首帧图与参考图有域名白名单。** 外站地址一律 400 `url_not_allowed`，只认 vr.a7w.cn、cdn2.jiujiushuyuan.cn/vr/、oss.gpu.likeadmin.cn/openapi/。`film --image 封面.png` 与 `img --ref 讲师照.jpg` 会先 `POST /api/v1/upload`（免费）换地址。

## 合规检查（`qc` 已经做成默认动作）

- **收益承诺是高压线**：月入过万 / 包就业 / 保过 / 零风险这类词换成可验证的事实（「第 3 周接到 800 元的活」）。
- **价格三处对齐**：主标早鸟价、副标原价与单节价、口播里的数字保持一致。
- **五个环节五套说法**：五个环节的前 3 秒各不相同，A/B 才测得出是哪一环在起作用。
- **承接动作一句**：每条素材结尾都落到加微 / 进群 / 领 / 试听 / 扫码，公域只负责把门推开。
- **大纲图带交付物**：每章写清交付什么，大纲图才不只是目录。
- **见证可追溯**：引用语与结果数字来自真实学员，发布前留档。
