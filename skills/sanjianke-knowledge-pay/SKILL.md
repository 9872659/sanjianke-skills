## 三条干货（别人不写进文档的）

**一、轮询一次就是一次的钱。** 应用层 `/query` 每查一次按该应用单价结算，`nano_banana/query` 实测 72 点/次；盯一天进度就能吃掉一整套招生包的预算。本包 `status` 只打 `GET /api/v1/tasks/<id>`，价目表里这条是 cost:0，等半小时也是 0 点。

**二、`GET /api/v1/apps/<app>` 是收费的。** 它命中 `/apps/<app>/*` 的通配计价，按该应用 flat 单价即时扣费、不退（实测 dressing_diffusion 200 点、nano_banana 72 点各一笔）。要目录只看 `/api/v1/apps` 列表和 `/api/v1/pricing`，两条都是 cost:0。

**三、首帧图与参考图有域名白名单。** 外站地址一律 400 `url_not_allowed`，只认 vr.a7w.cn、cdn2.jiujiushuyuan.cn/vr/、oss.gpu.likeadmin.cn/openapi/。`film --image 封面.png` 与 `img --ref 讲师照.jpg` 会先 `POST /api/v1/upload`（免费）换地址。

## 三条行业做法（`plan` 已经排进话术里）

- **封面 3 秒抓人**：主标压到 12 字内（「会剪也会改，就是接不到单」），副标 20 字内报结果；先出无字底版，文字用排版叠上去 —— AI 出中文容易错字，底版 + 叠字更稳。
- **学员见证排版**：3:4 竖版左图右文，一句话引用 + 一个结果数字（「第 3 周接到 800 元的活」），三张一组发。
- **私域承接话术**：加微给东西、进群给规则、试听给筛子、催单给事实、复购给路径，`plan` 一次写全 5 条。

## 合规检查（`qc` 已经做成默认动作）

- **收益承诺是高压线**：月入过万 / 包就业 / 保过 / 零风险这类词换成可验证的事实（「第 3 周接到 800 元的活」）。
- **价格三处对齐**：主标早鸟价、副标原价与单节价、口播里的数字保持一致。
- **五个环节五套说法**：前 3 秒各不相同，A/B 才测得出是哪一环在起作用。
- **承接动作一句**：每条结尾都落到加微 / 进群 / 领 / 试听 / 扫码，公域只负责把门推开。
- **大纲图带交付物、见证可追溯**：每章写清交付什么；见证引用语与结果数字来自真实学员，发布前留档。
